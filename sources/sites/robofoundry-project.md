## 一句话摘要

NTU / 北航 / NUS / 云蝶 / 上交等联合团队的 **RoboFoundry** 官方页：强调从 **Code-as-Policy 执行** 到 **System-as-Policy 演化** 的 **Act–Reflect–Repair–Promote** 闭环，并在 EmbodiedBench、RoboMemArena、LIBERO-PRO 与真机实验上展示跨 backbone 与跨具身迁移。

## 公开信息要点（截至复核日 2026-09-30）

- **核心叙事：** 整个 agent **支撑系统** 才是 executable policy；context 与 skill **协同演化**；语义决策与具身执行解耦。
- **结果面板：** EmbodiedBench 四套件；RoboMemArena 四类记忆任务；LIBERO-PRO 三类扰动；context evolution 对 π₀.₅ / PrediMem 的增益表；EB-Habitat spatial 子集 evolution trace（21.4%→78.0% held-in）。
- **真机 / 仿真视频索引：** 化学长程、毛巾泛化、套娃、人形语义导航等（页内列表）。
- **资源链接：** arXiv / 项目页视频 / BibTeX；**无 Code 按钮**。
