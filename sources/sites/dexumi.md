# DexUMI（项目页）

> 来源归档（ingest）

- **标题：** DexUMI: Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation
- **类型：** site / project-page
- **官方入口：** <https://dex-umi.github.io/>
- **论文：** <https://arxiv.org/abs/2505.21864>
- **代码：** <https://github.com/real-stanford/DexUMI>
- **数据：** <https://umi-data.github.io/>

- **一句话说明：** 用按目标机械手优化的可穿戴外骨骼采人手动作/触觉，再通过分割、视频修复和机器人手渲染缩小训练—部署视觉差的无机器人采集框架。
- **开源状态（2026-07-28 核查）：** **已开源**（MIT）— CAD/硬件教程、数据处理、Diffusion Policy 训练、XHand/Inspire 部署入口和样例数据均已发布。
