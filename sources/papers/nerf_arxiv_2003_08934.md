# NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis

> 来源归档（foundational paper + authors' project page + code release）

- **标题：** NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis
- **作者：** Ben Mildenhall, Pratul P. Srinivasan, Matthew Tancik, Jonathan T. Barron, Ravi Ramamoorthi, Ren Ng
- **机构：** UC Berkeley、Google Research、UC San Diego
- **发表：** ECCV 2020（Oral；Best Paper Honorable Mention）
- **arXiv：** <https://arxiv.org/abs/2003.08934>
- **作者项目页：** <https://www.matthewtancik.com/nerf>
- **官方代码：** <https://github.com/bmild/nerf>
- **方法讲解：** <https://docs.nerf.studio/nerfology/methods/nerf.html>
- **入库日期：** 2026-10-22
- **一句话说明：** 从已知相机位姿的多视图图像优化一个连续 5D 神经场，以空间位置和观察方向为输入、输出体密度与视角相关颜色，再沿相机射线做可微体渲染以合成新视角。
- **沉淀到 wiki：** [具身感知六种空间表征](../../wiki/concepts/embodied-perception-six-spatial-representations.md)

## 核心摘录

### 表示与渲染

- 场景表示为 MLP 参数化的连续函数：位置决定体密度，位置与观察方向共同决定 RGB 辐射；沿相机射线采样并用体渲染合成像素。
- 论文的关键设计包括位置编码以表达高频细节，以及粗到细的分层采样，将更多采样预算放到可见表面附近。
- 训练需要多视图 RGB 图像及相机位姿。它优化的是新视角合成，不直接给出适合碰撞检查或规划的显式占据地图。

### 开源状态与复现入口

作者项目页提供论文、示例和代码入口；官方 `bmild/nerf` 仓库公开参考实现。Nerfstudio 文档可作为后续实现的模块化方法讲解，描述场表示、射线采样和体渲染组件。
