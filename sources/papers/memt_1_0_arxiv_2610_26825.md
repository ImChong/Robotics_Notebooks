- **版本：** arXiv v4（2026-11-20），[HTML](https://arxiv.org/html/2610.26825v4) · [PDF](https://arxiv.org/pdf/2610.26825v4)
- **核对范围：** 本次核对 v4 架构、Pro 训练设置、评测与官方模型卡；尚未完成全文及附录逐节复核。
- **通读：** 未完成

- **一句话说明：** 将持续演化的记忆纳入模型计算，通过 Gated DeltaNet-2、Mixture-of-Storage 和两阶段训练构建 MemT-1.0-Nano / Flash / Pro。

## 核心摘录

1. **问题：** 常见参数化记忆方法难以同时积累历史信息、在推理时使用记忆并维持可扩展状态；完整上下文 KV cache 随历史增长而增大。
2. **架构：** MemT-1.0 将动态 local memory 与可训练 hyper memory 纳入模型计算；生成时读取当前记忆，轮次或片段结束时以稳定的 Gated DeltaNet-2 机制逐 token 更新状态。Mixture-of-Storage（MoS）用于扩展原生记忆容量。
3. **训练：** 先进行 backbone preparation，再以 continued pre-training 与 post-training 两阶段训练；报告称使用 34B tokens 数据及专门训练、推理基础设施。
4. **模型族：** Nano 基于 Qwen3.6-35B-A3B；Flash 基于 DeepSeek-V4-Flash。Pro 基于 NVIDIA Nemotron-3-Ultra-550B-A55B，报告和模型卡的规格为总参数 554B、激活参数 59B、可训练记忆参数 4.23B、动态记忆状态 13M。
5. **评测：** 报告覆盖 11 项记忆基准。作者称Pro、Flash、Nano 在官方报告的同类参数化记忆方法中依次排名前三；总体上，强文本记忆系统仍领先，尤其是需要从长历史检索细粒度证据的任务。
6. **效率与应用：** 在 128K 历史长度下，报告称 Nano 相对完整上下文 KV cache 达到约 1.86×端到端推理加速、持久存储减少约 66×；程序性经验还被用于长程 agentic coding 任务。

## v4 新增核对要点（2026-11-24）

- Pro 的 CPT 冻结 Nemotron 骨干，只优化记忆参数，使用交叉熵；后训练仍冻结骨干，以全上下文教师的 Top-64 目标计算 KL 损失。训练以最多 65,536 token 的 pack 和 2,048 token 存储步组织。
- 通用能力噪声设置（表 4）：Pro 相对同样有噪声的骨干，六项基准平均变化为 -0.11 个百分点；LongBench v2 降低 5.17 个百分点，不能认为所有任务均无损。
- 128K 历史效率数字及程序性经验 coding 试验属于 Nano，不是 Pro 的部署保证。

## 需要保留的边界

- 以上性能数字是论文所述实验配置下的结果，不应外推为所有模型、硬件或机器人任务上的保证。
- 论文展示的是记忆基础模型与 coding-agent 应用；机器人任务级记忆的适配仍需针对目标环境验证。
- 模型权重、数据和仓库软件采用不同发布条款，按各自发布页面核对。
