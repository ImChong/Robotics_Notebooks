# X-WBC：跨具身人形全身控制基础模型

## 核心原理（方法）

X-WBC 的出发点是一条工程观察：**一机一策略** 让运动经验被困在各自本体里，换台机器人就要从头训。它的解法是把全身控制拆成 **可共享的** 与 **不可共享的** 两半：

| 层 | 内容 | 为什么这样切 |
|----|------|--------------|
| **共享层** | 人类运动语义 | 人怎么走、怎么挥手，在不同人形身上语义相同——这部分值得用所有机器人的数据一起训 |
| **对齐层** | Human-centered command tokens | 把 **完整人类运动**、**机器人参考运动**、**稀疏 VR 观测** 三类命令源编码进同一表示，下游因此不必为每种输入各写一套接口 |
| **骨干** | causal Transformer | 从 **混合多机器人 rollout** 里学可复用的时间结构；混合正是跨本体联合训练的载体 |
| **本体层** | 轻量机器人专属模块 | 把共享表示映射到各机的本体感知与动作空间——形态差异（连杆长度、关节配置、驱动能力）不强行塞进共享骨干 |

**读法：** 这套切分的赌注是「运动语义可共享、物理执行不可共享」。共享层越厚，跨本体迁移越划算；本体层越厚，越退化回一机一策略。论文的真机结论（形态差异仍需专属模块）就是这条边界的实测位置。

## 实验与评测

| 维度 | 规模 / 结果 | 读法 |
|------|-------------|------|
| **仿真本体** | **9 个** 人形本体联合训练 | 主张成立的前提是「多机一起训」优于「各训各的」——这是本文的核心消融轴 |
| **联合训练收益** | 论文报告联合训练 **改善跟踪** | 跟踪误差是 WBC 的直接指标；注意这是跨本体平均，不等于每台机都变好 |
| **跨命令源一致性** | 对齐表示支持 **同一策略吃三类命令源** | 验收项不是成功率，而是换命令源（全身运动 / 参考运动 / 稀疏 VR）后行为是否一致 |
| **训练语料之外** | 在 **外部运动** 上仍具竞争力 | 即泛化到未参与训练的动作；这一条比榜内跟踪误差更能说明「基础模型」的成色 |
| **真机** | **4 台** 真机同一接口 | feasibility 级证据：说明共享接口能落地，未报跨机统一的量化成功率 |

**验收提醒：** 本页所有数字来自论文与 [摘录归档](../../sources/papers/x_wbc_arxiv_2609_15213.md)，未与其他跨本体工作在同一运动集上重测；跟踪误差高度依赖参考运动分布与重定向质量，换语料即不可比。

## 与其他工作对比

> 下表只做 **定位对照**：各工作的机器人集合、参考运动语料与跟踪指标定义都不同，**不可横比误差数字**。

| 对照 | 差异读法 |
|------|----------|
| **一机一策略 WBC**（要替代的默认做法） | 每台机独立训练，运动经验不流动；X-WBC 的全部主张就是「异构人形可以当 **联合数据源**」。代价是要维护一套跨本体的命令对齐与本体适配层 |
| [模型-based WBC](../concepts/whole-body-control.md)（Khatib–Sentis 一脉） | 跨本体靠的是 **显式模型**：换机器人换 URDF 与动力学参数即可，不需要数据；X-WBC 走学习路线，换来的是人类运动语义的可迁移性，失去的是可解析的优先级保证 |
| [SONIC](../methods/sonic-motion-tracking.md) / [GentleHumanoid](../methods/gentlehumanoid-motion-tracking.md) | 同为运动跟踪策略，但训练目标是 **单本体做深**（跟踪精度、接触柔顺）；X-WBC 优先做 **宽**。深与宽是取舍：本文未主张在单机跟踪精度上胜过专精策略 |
| [BFM-Zero](./paper-bfm-zero.md) / [多技能师生蒸馏 BFM](../methods/teacher-student-multi-skill-bfm.md) | 同属「人形基础模型」叙事，但共享的东西不同：BFM 系共享的是 **潜命令空间/技能**（多在同一本体内），X-WBC 共享的是 **跨本体的运动时间结构** |
| [TWIST2](./paper-twist2.md) | 同样吃 VR / 遥操作命令源，落点在 **数据采集与遥操作链路**；X-WBC 把 VR 稀疏观测当成 **命令源之一** 收进统一 token 空间，二者可串联而非竞争 |
| [运动重定向（GMR 等）](../methods/motion-retargeting-gmr.md) | **上游而非竞品**：重定向解决「人类动作怎么变成这台机器人的参考」，X-WBC 假设参考已给定，解决「一套策略怎么服务多台机」。重定向质量直接决定本页跟踪数字的上限 |
| [跨具身知识链](../overview/hub-cross-embodiment.md) | 定位入口：X-WBC 落在「控制层跨本体」一支，与操作层的跨本体 VLA 预训练不是同一问题，不要把两边的泛化结论互相外推 |
