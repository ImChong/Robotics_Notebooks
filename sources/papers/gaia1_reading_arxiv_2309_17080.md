# GAIA-1 论文通读（生成式世界模型视角）

> 来源归档（原文通读 · 支撑 `wiki/methods/generative-world-models.md`）

- **标题：** GAIA-1: A Generative World Model for Autonomous Driving
- **作者：** Anthony Hu、Lloyd Russell、Hudson Yeo 等（Wayve）
- **类型：** paper / world-model / driving
- **原文：** <https://arxiv.org/abs/2309.17080>（2026-11 通过 arXiv PDF 获取全文，v1）
- **一句话说明：** 把世界建模写成「离散图像 token 的下一 token 预测」，再用视频扩散解码器还原高清视频，可用视频、文本、动作三种提示。
- **核对范围：** 通读 §1–§6（模型、数据、训练、推理、缩放）、§7 能力展示的文字部分、§9 结论与局限；§8 相关工作与附录仅浏览，图表细节（Fig. 9–13 的视频样例）只读图注，未逐一核对。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **两段式结构（§1）：** 世界模型负责场景高层成分与动态，视频扩散解码器负责把潜表示还原为高质量视频。
- **输入编码（§2.1）：** 图像经预训练 tokenizer 离散化为 n=576 个 token（288×512，下采样 D=16，词表 K=8192）；文本用 T5-large，每步 m=32 个 token；动作为 2 个标量（速度、曲率）；每步按 文本-图像-动作 交错。
- **世界模型（§2.3、§4.2）：** 自回归 Transformer，6.5B 参数，目标为在因果掩码下预测下一个图像 token；训练时随机丢弃条件，以同时支持无条件 / 动作条件 / 文本条件生成（比例 20%/40%/40%）；视频从 25Hz 时间下采样到 6.25Hz。
- **视频解码器（§2.4、§4.3）：** 2.6B 的 3D U-Net 视频扩散，多任务（图像生成、视频生成、自回归解码、插帧）联合训练，负责时间上采样回 25Hz；推理用 DDIM 50 步。
- **数据（§3）：** 伦敦 2019–2023 年约 4,700 小时 25Hz 专有驾驶数据（约 4.2 亿张图），按经纬度、天气、转向 / 速度行为做加权平衡。
- **采样（§5.1）：** argmax 会陷入重复循环，纯采样会落入不可靠长尾，故用 top-k 采样；文本对齐用 classifier-free guidance，并对 token 与帧调度引导强度。
- **缩放（§6）：** 用不足 20 倍算力训练的小模型（0.65M–650M）拟合幂律，可较准确预测 6.5B 模型的最终交叉熵，说明存在类 LLM 的缩放规律。
- **能力（§7）：** 分钟级长场景想象、同一提示下多种合理未来、对偏离车道等训练集中未出现的自车动作做出反应；作者将其归纳为涌现的高层结构、泛化、情境感知（含坡道引起的俯仰 / 侧倾）。以上为定性展示。
- **局限（§9）：** 自回归生成尚不能实时，但可并行生成多个样本。
