# img2threejs.io（官方在线演示画廊）

> 来源归档（ingest）

- **标题：** img2threejs — Live Three.js Model Showcases
- **类型：** 官方网站 / 在线演示画廊
- **官方入口：** <https://img2threejs.io/>
- **源码项目：** <https://github.com/img2threejs/img2threejs>（Apache-2.0；详见[仓库归档](../repos/img2threejs.md)）
- **核对日期：** 2026-10-22
- **一句话说明：** 在线展示由 img2threejs 编写的程序化 Three.js 模型，可查看对象、拆分命名部件、播放可用动画并阅读模型源码。
- **开源状态：** 主技能与工具链已开源；网站页面提供“View the Open-Source Project”链接至官方 GitHub 仓库。是否所有画廊前端代码均在主仓内，公开首页未说明，故不作此推断。

## 页面公开信息

首页标题为 “Open-source image-to-3D studies”，说明画廊展示从单张参考图重建的程序化 Three.js 模型。可见示例包括 AWP Medusa procedural model、rigged mouse warrior character、dual-sword procedural character、procedural BMX bicycle、Sony WF-1000XM3 reconstruction 与 procedural isometric house。

## 与主仓的关系

主仓 README 的 “Open the Live Demo Gallery” 链接指向本网站；页面又链接至 GitHub 开源项目。该站用于查看运行中的重建结果，项目的技能规约、安装方式与分阶段工具链以主仓 README、`SKILL.md` 和 `docs/ARCHITECTURE.md` 为准。
