## 一句话说明

端到端室内可交互 3D 场景重建：`uv run litereality run` 跑 scene init + agentic authoring；依赖 Blender 5.x、Claude/Codex agent CLI、Modal 或本地 GPU 上的 TRELLIS/GroundingDINO；输出 `Room.glb` / `Room.blend`。
