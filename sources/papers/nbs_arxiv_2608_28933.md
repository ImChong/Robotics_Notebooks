## 摘录 1：核心主张

- **范式挑战：** 立体匹配仍是少数 **SOTA 仍强依赖架构归纳偏置**（相关体、迭代 refinement、冻结深度专家）的 CV 任务。
- **NBS 答案：** **无任何架构归纳偏置** 的端到端 ViT 即可同时达到 **SOTA 精度与更高效率**——靠 **大规模合成数据** 纯数据驱动超越显式几何工程。
- **结构：** 校正双目 patchify → 联合 token 集上 **局部 + 全局交替 self-attention** → **DPT 头** 解码视差；masked L1 + 多尺度 gradient-matching 监督。

## 摘录 2：关键设计

| 模块 | 要点 |
|------|------|
| **骨干** | **DINOv2 初始化 ViT-Large**；早期局部 attention，之后交替全局 attention；同一 attention 动态平衡 **跨图匹配** 与 **单目语义** |
| **位置编码** | 将 DINOv2 的 37×37 网格上采样至 **148×148**（2K 推理 **296×296**）；亚像素视差需细粒度位置；bad@0.5 最多降 **7.2 pt** |
| **训练数据** | 多阶段分辨率 **966×546 → 1932×1330**；**2.4M 内部合成场景 + 13 公共数据集** |
| **推理** | Flash-Attention + FP16；SimpleProc-S 966×546：**0.060 s**、**1.23 GB**、351.5M 参数、3.7 TFLOPs |
