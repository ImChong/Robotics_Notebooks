## 页面核查要点

- 项目页链接到作者维护的 GitHub 仓库；截至 2026-10-25，训练、评测、ONNX 导出、仿真与 G1 硬件部署入口均已公开。
- 官方 README 明确说明，该项目借鉴 SuperMimic，但代码是作者仅依据论文自行实现的基础算法；这不是 SuperMimic 作者的代码，也未得到其认可。
- 统一策略的跨机器人动作跟踪评测在仿真中进行；论文报告的物理机器人演示为 Unitree G1。X2 Ultra 与 T2 真机验证尚属未来工作。
- 项目页中的技术报告与源码入口分别归档于 [MorphMimic 技术报告](../papers/morphmimic_technical_report_2026.md) 和 [MorphMimic 官方仓库](../repos/morphmimic.md)。
