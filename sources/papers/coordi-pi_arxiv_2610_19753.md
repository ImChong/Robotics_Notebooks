# Coordi-pi: Coordination-Aware Dual-Hand Action Representation for Bimanual Dexterous Manipulation

> 来源归档（paper）

- **标题：** Coordi-pi: Coordination-Aware Dual-Hand Action Representation for Bimanual Dexterous Manipulation
- **中文标题：** Coordi-pi：面向双臂灵巧操作的协调感知双手动作表示
- **类型：** paper
- **arXiv：** <https://arxiv.org/abs/2610.19753>
- **入库日期：** 2026-10-21
- **线索来源：** [公众号综述（33 篇 Manipulation）](../raw/wechat_senlanke_manipulation_33_papers_2026-10-12_16.md)（具身运控lab，2026-10-20）
- **一句话说明：** 把左右手动作交错为独立 token，并用手部身份嵌入与同步编码表达双手协作。
- **沉淀到 wiki：** [`wiki/entities/paper-coordi-pi-bimanual-action-tokens.md`](../../wiki/entities/paper-coordi-pi-bimanual-action-tokens.md)

## 摘要要点（arXiv 摘要页）

- 现有双臂 VLA 把两侧动作拼接在同一控制步的单个向量中，跨手交互是隐含的。
- 方法：左右手动作作为独立 token 交错排列，并加入手部身份嵌入与同步编码。
