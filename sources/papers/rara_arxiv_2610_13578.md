## 论文要解决的问题

VLA / 扩散策略预训练后，用少量目标示范做标准微调（FT）在训练分布内有效，但会扭曲预训练表征，导致分布外（OOD）输入上泛化下降。RARA 的主张：微调前先减小“新示范表征”与“相近预训练示范表征”之间的错配，微调中再限制被检索示范的表征漂移。

## 方法与训练信息

1. **示范级检索：** 冻结 CLIP 文本编码器编码任务指令，对每个目标任务求平均并归一化，按余弦相似度取预训练示范 top-K（K=100）。
2. **帧级配对：** 示范切成长度 H=16 的重叠动作块，与首步观测配对；距离为动作块上的 DTW（夹爪维度单独缩放）。正样本取最近 m+=4 个块，负样本取距离高于中位数的块（每步 64 个）。
3. **阶段 1 对齐：** 多正样本对比损失 + λ1·L_anchor（λ1=1，τ=0.07）；投影头为 2 层 MLP（1024→512→256，GELU，ℓ2 归一化），阶段结束后丢弃。训练 3,000 步，每步 32 目标帧 + 32 预训练帧；AdamW，编码器 lr 1e-5、投影头 1e-4，200 步 warm-up，余弦调度。
4. **阶段 2 微调：** L_BC + λ2·L_anchor（λ2=1），锚点只作用于被检索帧（无动作标签），冻结的预训练策略副本提供参考表征；全策略可训练，batch 128，lr 1e-4，300 epochs。
5. **锚点层：** Diffusion Policy 取双相机 ResNet-18 池化输出（1024 维），距离为 MSE；GR00T 取视觉塔输出 token，距离为按参考表征批方差归一化的平方误差。
6. **基座与数据：** RoboTwin 2.0（Aloha-AgileX 右臂）用 Diffusion Policy，自采约 2,000 条预训练示范（5 类任务），目标任务各 50 条；RoboCasa 与真机用 GR00T N1.7，预训练数据为 DROID（76k 示范），RoboCasa 目标各 100 条、真机 50–80 条 VR 遥操作示范。

## 论文报告的结果

成功率（%，种子均值，ID / OOD）：

- **RoboTwin（Diffusion Policy，4 任务均值）：** FT 67.4 / 47.3；Co-FT 64.4 / 47.6；STRAP 72.6 / 52.4；RETAIN 47.0 / 34.2；BlindVLA 67.9 / 47.2；RARA 76.0 / 58.3。
- **RoboCasa（GR00T N1.7，5 任务均值）：** FT 69.2 / 44.3；Co-FT 67.1 / 43.7；STRAP 66.1 / 48.1；BlindVLA 68.5 / 46.8；RARA 74.0 / 55.5（表中无 RETAIN）。
- **真机 Franka（GR00T N1.7）：** 文字称相对 FT 平均 +16.4（ID）/ +19.2（OOD）；逐任务数字在图中，抽取文本未给出（第 4 个真机任务名也未抽到）。
- **汇总：** 13 项任务相对 FT 平均 +9.5（ID）/ +13.6（OOD）。
- **消融（RoboTwin 均值 ID/OOD）：** 随机预训练数据 50.3/34.9；随机阶段 1 配对 65.3/40.6；阶段 2 改用 Co-FT 65.8/48.1；仅阶段 1 66.6/43.2；仅阶段 2 73.0/46.2；完整 RARA 76.0/58.3。
- **表征诊断：** Move Pill Bottle / Place Container 的目标帧特征畸变（ID/OOD）FT 为 0.50/0.49 与 0.47/0.48，RARA 为 0.23/0.23 与 0.31/0.33；预训练帧 CKA，RARA 为 0.92 与 0.91（FT 为 0.68 与 0.87）。
- **锚点位置：** Move Pill Bottle 上八个锚点层位置均优于 FT（21.2%），范围 32.0–39.7%。

## 复现与解释边界

- 作者自述局限：依赖预训练数据中存在与目标同类的任务；实验以视觉变化为主，同机器人、同动作空间；附录 G 报告当预训练数据含不同技能时锚点可能有害。
- 官方仓库 README 的“Expected results”给出 move pill bottle ID：FT 44.0、Co-FT 44.7、RARA 59.3（150 rollouts），与论文表中该任务 ID 数字（FT 32.9、RARA 51.6）不一致；本归档只引用论文表内数字，仓库数字仅作复现参考，差异原因未核实。
- 仓库只覆盖 RoboTwin 药瓶任务的 Diffusion Policy 流程；GR00T / RoboCasa / 真机代码未在 README 中出现（截至 2026-10-12）。
