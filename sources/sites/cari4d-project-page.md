# CARI4D / FORM-HOI 官方页面与模型入口

- **CARI4D 研究项目页：** https://nvlabs.github.io/CARI4D/
- **CARI4D 论文：** https://arxiv.org/abs/2512.11988 （CVPR 2026）
- **研究代码：** https://github.com/NVlabs/CARI4D
- **商业可用模型卡：** https://huggingface.co/nvidia/cari4d_commercial
- **FORM-HOI 数据卡：** https://huggingface.co/datasets/nvidia/form-hoi
- **视频到数据管线：** https://github.com/nvidia-isaac/video_to_data
- **官网分工：** 研究项目页介绍单目 RGB 人–物 4D 重建；FORM-HOI 数据卡介绍四视角数据；Video to Data 仓库包含多视角 HOI 标定/重建管线。
- **许可区分：** FORM-HOI 数据卡为 CC BY 4.0；CARI4D CoCoNet Native MHR 模型卡适用 NVIDIA Open Model Agreement，模型文件访问需接受其条件；研究 GitHub 仓库许可应以仓库当前 LICENSE 为准。
- **模型卡边界：** 用于 3D/4D 姿态估计、动作分析、可视化、数据整理和机器人感知；模型卡明确不用于直接自主控制或生命攸关决策。contact logits 是接触估计，不是力测量。
