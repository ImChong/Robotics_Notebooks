## 摘录 1：生态三件套与规模（§1–§2，Table 1）

- **痛点：** 灵巧操作数据远小于语言语料；现有人类操作集常 (1) 实验室场景单一、(2) 视觉/语言/动作模态不对齐、(3) 缺贯穿感知–规划–动作的 benchmark。
- **WIYH 三组件：**
  1. **Oracle Suite** — 轻量可穿戴套件（H-FPVHive 胸挂多相机 + H-Gloves 六 IMU/五指尖压阻/三鱼眼 + H-Backpack Orin 算存）；在线 VIO+IR 粗定位 + 离线 SfM 精修，**无第三方外视跟踪** 下腕轨迹平均误差 **<5 mm**；相对遥操作 **5×** 采集效率（720 vs 150 episodes/天）。
  2. **WIYH Dataset** — **1045 h** · **125.4k clips** · **100+ skills** · **10** 野外场景；多视角 RGB、标定、手/腕 3D、触觉。
  3. **标注与 benchmark** — 400 h 原子动作指令、10 万级 VLM 数据；**HVL**（Spatial Referring / Subtask Prediction / Completion Verification）评测通用 VLM 在人类中心场景的空间与进度理解。
- **Table 1 对照：** 相对 Ego4D / Ego-Exo4D / EgoDex 等，WIYH 同时具备 Wild、相机标定、RGB、**触觉**、**3D Action**、深度、掩码、指令与 VLM 标注。

**对 wiki 的映射：** 升格 [`wiki/entities/paper-wiyh.md`](../../wiki/entities/paper-wiyh.md)；数据金字塔第 ③ 层「人类 Ego/Exo」对照 [Data Pyramid](../../wiki/entities/paper-data-pyramid-embodied-manipulation.md)、[ACE-Data-0](../../wiki/entities/paper-ace-data-0.md) 与 [HumanTouch](../../wiki/entities/humantouch.md)（规模向 ego 对照另见 EgoDex / Ego4D，论文 Table 1）。

## 摘录 2：采集与三阶段标注（§3）

- **采集协议：** 采集者穿戴 Oracle Suite 按场景 SOP 自然操作；单次约 10 分钟，含起止事件标记；模态含压阻触觉、腕/胸鱼眼 RGB、标定、左右手轨迹与骨架。
- **标注流水线（Figure 4）：**
  1. **原子动作：** Qwen2.5-VL-72B 视频分段 → 人工定义 skill/目标物 → 边界质检 → 指令增广。
  2. **感知：** SAM 实例掩码 + FoundationStereo 深度，人工修正。
  3. **视觉–语言：** CoT 长程分解、Spatial Referring、Subtask Prediction（四选一）、Completion Verification（进度二分类）；后三者为 **评测子集**。
- **场景多样性：** 宴会、洗衣、物流、酒店、办公、超市、工业、清洁、烛光等；技能词云覆盖 take/place/rotate/unfold 等，物体含衣物、纸箱、杯具等可变形/刚体/关节体。

**对 wiki 的映射：** 流程总览与数据集速查进实体页；LeRobot 转换见 devkit `wiyh2lerobot/`。

## 摘录 3：Benchmark 与 4D 重建应用（§4）

- **HVL（Table 2）：** GPT-4o / Qwen3-VL / Doubao 等在 **S.R.** 最高仅 ~46.5%、**C.V.** 略高于随机（~56%），**S.P.** 可达 ~77% —— 说明现有 VLM **高层分解尚可、空间指称与动态完成度弱**。
- **4DGS 世界建模（Table 3）：** 用 WIYH 深度/位姿监督 MegaSAM + TAPIR + Shape of Motion 动态高斯重建；几何指标随任务动态难度波动，验证深度标注对 Real2Sim / 空间智能的价值。

**对 wiki 的映射：** 汇入实体页「实验与评测」与「结论」；链 [world-action-models](../../wiki/concepts/world-action-models.md)。

## 摘录 4：跨本体操作实验（§5）

- **Cross-embodiment pretrain（StarVLA-PI）：** WIYH 原子指令预训练 + 真机 150 clip/任务后训练；**VLA 全量预训练** 将玫瑰插入/礼品包装平均成功率 **15%→70%**（优于仅 VLM 30%）。
- **Retargeting co-training：** 机器人单物体数据 \(D_r\) + Oracle 杂乱场景人类数据 \(D_h\)（重定向到低 DoF 灵巧手）；杂乱场景仅加机器人数据 500 clip 仅 **8%**，**co-train +800 人类 clip → 60%**（+52%）；单物体 co-train 亦有 +13.4% 增益。

**对 wiki 的映射：** 结论要点与 [VLA](../../wiki/methods/vla.md)、[imitation-learning](../../wiki/methods/imitation-learning.md) 交叉引用；训练数据管线见 [humanoid-training-data-pipeline](../../wiki/queries/humanoid-training-data-pipeline.md)。
