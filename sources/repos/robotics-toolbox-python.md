# Robotics Toolbox for Python

> 来源归档

- **标题：** Robotics Toolbox for Python
- **类型：** repo / Python 机器人学软件库
- **作者 / 维护者：** Peter Corke、Jesse Haviland 等贡献者
- **代码：** <https://github.com/petercorke/robotics-toolbox-python>
- **官方文档：** <https://petercorke.github.io/robotics-toolbox-python/>
- **官方 Wiki：** <https://github.com/petercorke/robotics-toolbox-python/wiki>
- **核心论文：** P. Corke & J. Haviland, “Not your grandmother’s toolbox – the Robotics Toolbox reinvented for Python,” ICRA 2021, pp. 11357–11363；[IEEE Xplore](https://ieeexplore.ieee.org/document/9561366)
- **许可：** MIT（仓库许可证）
- **入库日期：** 2026-10-26
- **一句话说明：** 面向机器人研究与教育的 Python 工具箱，提供串联机械臂的建模、运动学、动力学与轨迹工具，也包含移动机器人规划、定位、建图和 SLAM 算法。

## 一手资料核查

- 官方 README 说明，机器人模型可用 Denavit–Hartenberg 参数创建、从 URDF 导入，或调用工具箱附带的机器人模型；覆盖正/逆运动学、动力学与轨迹生成。
- 官方 README 还列出移动机器人运动模型、路径规划、定位、地图构建与 SLAM 功能，并展示 Panda URDF 模型、FK/IK 求解及轨迹动画示例。
- 官方文档与 Wiki 补充模型、运动学、动力学、轨迹和可视化后端说明。
- 官方 README 引用 ICRA 2021 论文作为工具箱的主要论文来源。源码公开在 GitHub，仓库标注 MIT 许可。
