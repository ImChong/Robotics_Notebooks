## 一句话摘要

项目页呈现 RoboHarn-Evo 的双层物理知识（Task Knowledge 与 Action Knowledge）、内外双循环、RMBench 结果和三项真机演示，并链接论文与官方代码。

## 公开信息核查（2026-10-16）

- **源码状态：已开源。** 项目页的 Code 链接指向官方 GitHub 仓；仓库含 Python 实现、benchmark 应用、配置和运行脚本，许可证为 Apache-2.0。
- **结果口径：** README 分别报告 RMBench 六任务平均、80 rollouts 的持续交互实验、跨 benchmark 零样本迁移和真机更新；不可把这些不同设置合并成同一指标。
- **真机演示：** Cover blocks、Press by number、Uncover, count & press。README 说明视频是剪辑并加速的片段，适合了解系统行为，不应单独作为成功率统计。
