# ANYmal Parkour 图表数据与绘图脚本

> 来源归档（部分开放代码资产）

- **标题：** ANYmal Parkour: Data-sets and plotting scripts for Fig. 3A / Fig. 3B / Fig. 4F
- **类型：** repo / Zenodo artifact
- **链接：** <https://doi.org/10.5281/zenodo.10638996>
- **作者：** David Hoeller、Nikita Rudin、Dhionis Sako、Marco Hutter
- **论文：** <https://arxiv.org/abs/2306.14874>
- **项目页：** <https://sites.google.com/leggedrobotics.com/agile-navigation>
- **入库日期：** 2026-07-28
- **一句话说明：** 公开论文部分图表的原始数据和绘图脚本，不含感知、低层技能、高层导航的训练或部署实现。
- **开源状态：** **部分开源**；可重画指定结果图，不能运行机器人策略。

## 可复现边界

| 可做 | 不可做 |
|------|--------|
| 重绘 Fig. 3A、3B、4F 的实验曲线 | 训练五个 locomotion 技能 |
| 核对部分真机/仿真结果数据 | 训练感知重建与高层导航 |
| 保存论文量化结果的原始锚点 | 部署到 ANYmal D |
