- README 的 2026-09 更新说明计划逐步发布代码与 checkpoints。
- 路线图包括 Stage 1/2 预训练 checkpoint、video pretraining、video-action/value training、MBRL、memory/变长训练基础设施、tactile code；本次核查时这些项目均未勾选，GitHub 文件区只列 README。
- 项目页的 Hugging Face 按钮指向团队模型主页 <https://huggingface.co/motus-robotics/>。该主页目录当前未确认 Motus2 专属权重；不可把 Motus 前作 checkpoint 混作 Motus2 权重。
- 发布状态会变化；复现前重新检查仓库文件、release 与 HF 模型卡。
