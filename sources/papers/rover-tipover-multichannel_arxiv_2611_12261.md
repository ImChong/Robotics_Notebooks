## 核心摘录（均出自论文，带章节）

1. **任务与动机（I）：** 倾覆有两类机制，渐进的车辆与地形相互作用，以及轮子打滑、冲击、失去支撑等突发扰动；作者认为两类目标放进共享表示会互相干扰，所以分开训练（引用多任务梯度冲突文献 [23]，论文未做共享表示的对照实验）。
2. **数据（III）：** 因 LuNiS 上采集真实倾覆有损坏风险，改用 Asguardv4 实验车，在 DFKI 场地的斜坡、岩石、松沙、陨石坑状地形上反复行驶；共 757,316 条同步 IMU 样本；按时间顺序切为 训练 / 验证 / 测试 / 训练 四块，两个训练块合并，窗口在各分区内单独生成、跨界窗口丢弃；论文自己强调这是按时间块而非按 session 或地形 run 的划分。
3. **输入（IV-A）：** 6 维 IMU（三轴线加速度 + 三轴角速度），100 Hz，窗口 50 样本。
4. **通道 A（IV-B）：** 因果空洞卷积 TCN，训练时联合预测 0.5 s / 1 s / 2 s 的倾覆概率，另有辅助时间到事件回归（仅训练用）；部署只用 0.5 s 头。
5. **通道 C（IV-C）：** GRU 编码器-解码器，仅用正常运动训练（训练序列在倾覆前留 pre-event gap），预测未来 IMU 序列，只取第一个预测样本与实测的 MAE 作为残差，超过由正常预测误差统计得到的阈值即触发。
6. **通道 B 融合（IV-D）：** R_t = α·p_t + (1−α)·ẽ_t，α = 0.85 在验证集上确定；无学习式融合层；融合分数经持续性（persistence）逻辑过滤，再优先级仲裁：通道 A 发早期预警，通道 B 或 C 触发紧急制动，并有锁定间隔抑制重复紧急指令。
7. **部署（IV-E）：** 作为 Rock 框架中的 Orocos RTT 任务组件，100 Hz 运行；整条流水线平均每周期 1.38 ms（论文未写测量所用硬件）；紧急制动后软件超时保持制动状态；车辆约需 0.5 s 完成停车。
8. **多视野（V-A，图 4）：** AUROC 随预测视野增大而下降，图中 0.5 s / 1 s / 2 s 约 0.944 / 0.929 / 0.911（正文只明写 2 s 为 0.911，另两个值来自图 4 柱顶标注）。
9. **主结果（V-A，Table I，124 个倾覆事件）：**
   - 通道 A（TCN）：P/R/F1 = 0.843/0.825/0.834，EP 102 / NE 8 / PE 7，Pred. 110/124，MLT 1.88 s
   - 通道 B（融合）：0.907/0.885/0.892，99/9/8，108/124，1.82 s
   - 通道 C（GRU）：0.639/0.795/0.703，57/24/8，81/124，0.74 s
   - 分层决策（最终输出）：0.934/0.913/0.921，114/7/0，121/124，1.82 s
   - 摘要与结论写 97.58% 事件覆盖（121/124）、1.82 s 中位提前量；0.5 s 制动后「估计剩余 1.32 s」。
   - 表脚注：EP = Early Prediction，NE = Near Event，PE = Post-Event，MLT = Median Lead Time。
10. **权衡（V-C，图 6）：** 多种运行配置（保守 / 早预警 / 高召回 / 敏感融合）在 F1 与中位提前量间有此消彼长；作者称所提方法接近 Pareto 前沿。图 6 中提前量更长的配置（约 2.0 s）F1 更低。
11. **论文自述局限（V-A、VI）：** 只在保留的时间块上评估，不能证明对未见地形或其他车体形态的泛化；高动态但可恢复的地形交互仍会误报；仅靠惯性测量难分辨「安全的瞬态机动」与真实危险；将来做显式时间到事件估计、视觉地形感知、不确定性感知预测，并移植到 LuNiS。

## 核对中发现的细节（我的判断，非作者自述）

- Table I 中 Pred. 等于 EP + NE（102+8=110，99+9=108，57+24=81，114+7=121），PE（事件后才报）看来不计入 Pred.；这是我从数字对上的推断，论文正文没有明说。
- 摘要说「在跨异质地形的 IMU 样本上」，但 III 节写的是 DFKI 场地数据；Zenodo 描述另含 Tenerife 火山地区的沙地与岩石采集，论文正文未提 Tenerife，也未说评估是否包含该部分。
- 论文标题与结论说「部署在行星车平台」，但 III 节说目标平台 LuNiS 因硬件风险未采集倾覆，评估用 Asguardv4；Table I 是在记录数据上按事件统计提前量，论文未报告实车闭环制动避免倾覆的试验。
