## 项目要点

- README 将 atopile 定义为电子设计语言、编译器和工具链，设计文件使用声明式 `.ato` 格式。
- 项目强调模块复用、带单位和容差的设计意图表达、参数化器件选择、约束检查，以及与 KiCad 原生协作。
- 上手路径包括编辑器扩展与 CLI（`ato build`）；仓库 README 提供示例工程和开发测试入口。
