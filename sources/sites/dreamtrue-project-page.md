# DreamTrue 项目页

- **项目：** [DreamTrue](https://brave-eai.github.io/DreamTrue/)
- **论文：** [arXiv:2610.12468](https://arxiv.org/abs/2610.12468)
- **代码：** [brave-eai/DreamTrue](https://github.com/brave-eai/DreamTrue)
- **数据/权重：** [ModelScope](https://modelscope.cn/datasets/huoxingdawang/DreamTrue)
- **核查日期：** 2026-10-11
- **状态：** 部分开源；官方仓库包含 calibration、wmvideo、reward 组件和部分数据，完整数据待发布。

DreamTrue 通过图像空间动作轨迹及离线几何校准对齐动作条件与视频，再用反事实动作后训练扩大交互覆盖，并以人工缺陷标注训练的视频奖励模型开展强化后训练。
