## 核心摘录

1. **方法两阶段（§3.1）：** 交互参考合成 + 策略学习；每个任务单独训练一个策略（§3.1）。
2. **参考合成（§3.2）：** 参考 τ_c = {q_robot, q_obj, 接触标签 l}（式 1）；GPT-6 Astra 生成任务模板（有序关键帧：全身姿态、机器人 - 物体 / 手 - 物体空间关系、接触标签）；按采样的空间配置实例化关键帧并定时序，再用现成运动生成模型 [34] 生成连续全身运动，过滤运动学 / 场景违约的候选，物体轨迹由交互手的运动与模板手 - 物体关系构造。
3. **策略学习（§3.3）：** 特权教师经冻结的预训练全身控制器 [26]（SONIC）输出潜变量命令 z 与手开合命令 h；奖励 r = 跟踪 + 交互 + 正则（式 2）；视觉策略（视觉编码器 [32] + MLP，输入第一视角 RGB 与本体感觉）用 L = L_PPO + λ·L_distill（式 4，式 3 为 MSE 蒸馏）。
4. **主结果（表 2）：** 五任务仿真均值 91.0%（92.8 / 91.7 / 87.6 / 84.3 / 98.5）；同一参考与教师下 VIRAL 39.6%、GR00T N1.7 23.4%；GRAIL 参考 + SUGARv2 学习管线 28.2%。摘要 / 引言称领先最强基线 51.4 个百分点（91.0 - 39.6）。
5. **参考合成成本（表 5）：** 0.4 min/条 对 GRAIL 36.1 min/条；教师成功率 98.0% 对 62.4%；物体 / 机器人跟踪误差 6.6 / 10.0 cm 对 9.8 / 13.8 cm。
6. **泛化（表 3，未见背景 / 同类未见物体，无额外训练）：** 均值 91.0 → 86.9（背景）/ 87.7（物体）/ 83.2（两者）。
7. **消融（表 4）：** 无教师蒸馏 0.0%；无参考型 RL 41.4%；初始化后只保留 RL、去掉持续蒸馏 70.6%。
8. **参考规模（§4.4、图 5）：** 20 / 50 / 100 / 200 / 500 条；20→100 条总体提升，之后增益有限、有时下降；正文用 100 条。
9. **真机（§4.6、表 6）：** Unitree G1，无真机数据微调；每任务 10 次：9 / 6 / 8 / 8 / 7，合计 38/50。失败分析：抓空后策略可能继续后续动作而不重试抓取，恢复能力有限。
10. **作者自述局限（§5）：** 参考合成只覆盖简化场景中的短时程交互；视觉策略是任务专用的；计划用合成参考支撑多任务 VLA。
