# SLIM-0.5B（arXiv:2608.09771）

> 来源归档（ingest）

- **标题：** SLIM-0.5B: Learning Action-Grounded Predictive Latents for Robot Manipulation
- **缩写：** **SLIM**（Self-supervised Latent Interaction Model）/ **SLIM-0.5B**
- **类型：** paper / vla / latent-policy / flow-matching / world-action / manipulation
- **arXiv：** <https://arxiv.org/abs/2608.09771>
- **HTML：** <https://arxiv.org/html/2608.09771>

- **项目页：** <https://kzz1031.github.io/slim-project-page/> — [`sources/sites/kzz1031-slim-project-page.md`](../sites/kzz1031-slim-project-page.md)
- **代码：** <https://github.com/kzz1031/SLIM> — [`sources/repos/slim.md`](../repos/slim.md)
- **权重：** <https://huggingface.co/kzzwang/SLIM-LIBERO>（LIBERO / LIBERO-Plus）；另 <https://huggingface.co/kzzwang/SLIM-CALVIN>

- **机构：** 复旦大学（Fudan）；北京智源人工智能研究院（BAAI）；清华大学（Tsinghua）；中国人民大学（RUC）
- **入库日期：** 2026-08-12
- **一句话说明：** **0.47B** 紧凑 latent interaction 策略：Stage-1 用掩码轨迹做 IDM（动作重构）+ FDM（未来 latent 预测）学动作接地表示；Stage-2 MoT + flow matching 做语言条件动作生成；**不**在推理时滚像素世界模型。LIBERO overall **97.5%**、LIBERO-Plus zero-shot **77.45%**、CALVIN ABC→D avg len **4.556**；真机端到端 **77.3 ms**、GPU mem **~2.01 GiB**。

## 核心论文摘录（MVP）

### 1) 问题与总贡献（Abstract / §1）

- **链接：** <https://arxiv.org/abs/2608.09771>
- **核心贡献：** 大 VLA 把开域语义与控制绑在同一大骨干；像素 WAM 又为无关外观付费并可能在推理时增加延迟。SLIM 把主计算放在 **观测 latent ↔ 动作 token** 交互，用自监督掩码轨迹学习动作接地的预测 latent，再用紧凑 MoT + flow matching 部署。

  - [SLIM-0.5B 实体](../../wiki/entities/paper-slim-05b.md)
  - [World Action Models](../../wiki/concepts/world-action-models.md)
  - [VLA](../../wiki/methods/vla.md)

### 2) 两阶段训练与 MoT（§3）

- **链接：** Method
- **核心贡献：**
  - 视觉 encoder：DINOv2 → \(\mathbf{Z}_t\)；语言：T5-small；未来 EMA 目标 \(\bar{\mathbf{Z}}_{t+H}\)。
  - MoT 双流：observation / action joint attention；语言经 per-stream cross-attention。
  - Stage-1：\(\mathcal{L}=\lambda_{\mathrm{IDM}}\mathcal{L}_{\mathrm{IDM}}+\lambda_{\mathrm{FDM}}\mathcal{L}_{\mathrm{FDM}}\)；默认 IDM:FDM=**0.125:1** + EMA。
  - Stage-2：仅 flow-matching；推理只需当前观测 + 语言 + 本体，**不喂未来 latent**。
- **对 wiki 的映射：**
  - [SLIM-0.5B 实体](../../wiki/entities/paper-slim-05b.md) — 流程与时序图
  - [DeFI](../../wiki/methods/defi-decoupled-dynamics-vla.md) — 正逆动力学对照（分模块 vs 同骨干）

### 3) 仿真与真机结果（§4 / 项目页）

- **链接：** Experiments / 项目页
- **核心贡献：**
  - LIBERO overall **97.5%**（0.47B）；LIBERO-Plus zero-shot **77.45%**（接近更大 VLA-JEPA 3B 的 79.5%）。
  - CALVIN ABC→D avg length **4.556**（领先所列 VLA/WAM 表）。
  - 真机：五任务 nominal+扰动 avg progress **67.8**；latency **77.3 ms**；policy-server GPU **2.01 GiB**。
  - 消融：无 Stage-1 / 关掉 EMA / 错 IDM:FDM 比会伤 OOD 与长程。
