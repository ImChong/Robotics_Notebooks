# VLA-Arena（PKU 等）

> 来源归档（ingest · 基准站点）

- **标题：** VLA-Arena: An Open-Source Framework for Benchmarking Vision-Language-Action Models
- **类型：** site（开源基准与排行榜）
- **发布方：** 北京大学人工智能研究院等（以站点为准）
- **原始链接：** <https://vla-arena.github.io/>
- **入库日期：** 2026-08-31
- **一句话说明：** 170 任务、L0–L2 难度与 Safety/Distractor/Extrapolation/Long Horizon 四维诊断的 VLA 开源评测框架与排行榜；StellaVLA 等模型在此公示成绩。

## 摘录要点

- **任务设计：** 11 个 task suite × L0/L1/L2；训练限 L0，L1/L2 测泛化；另支持语言（W0–W4）与视觉（V0–V4）扰动探针。
- **开源：** 站点提供 benchmark 框架、VLA-Arena-S/M/L 数据集与 leaderboard API。
- **StellaVLA 关联：** [arXiv:2608.11671](https://arxiv.org/abs/2608.11671) 论文链至本页排行榜；截至入库日 **StellaVLA 训练/推理代码不在此站发布**。
