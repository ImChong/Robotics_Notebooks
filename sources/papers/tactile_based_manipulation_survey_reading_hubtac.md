# Tactile-Based Robotic Manipulation 综述通读（力学驱动 ↔ 数据驱动）

> 来源归档（原文通读 · 支撑 `wiki/overview/hub-tactile.md`）

- **标题：** Tactile-Based Robotic Manipulation: From Mechanics-Driven to Data-Driven Perspectives
- **作者：** Jingyi Xiang, Yixuan Wang, Wenzhen Yuan（UIUC）
- **类型：** paper / survey / tactile
- **原文：** <https://arxiv.org/abs/2610.30438>（2026-11 通过 arXiv PDF v1 获取全文，30 页；Annual Review of Control, Robotics, and Autonomous Systems Vol.10 作者接受稿）
- **一句话说明：** 以"力学驱动（感知→动作）"与"数据驱动（IL / RL / VLA / 预测模型）"两条线梳理触觉操作，并给出传感器异构、轻量化、评测、力学经验回流四个开放问题。
- **核对范围：** 通读摘要、§1 引言、§2 触觉传感基础（信号、传感器分类、仿真与 sim-to-real）、§3 力学驱动（感知描述符、动作策略、讨论）、§4 数据驱动（IL、RL、VLA、预测模型及各节讨论）、§5 开放问题、§6 结论；参考文献列表（约 170 条）仅浏览，未逐条核对被引工作。本文无附录。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **两条范式（§1）：** 力学驱动 = 用接触力学和任务结构显式解释触觉信号（解析模型、手工特征、监督学习都算）；数据驱动 = 不显式建模中间物理量，直接从数据学隐式表征与策略。
- **信号与传感器（§2.1）：** 法向力、剪切力、力矩、接触几何、振动；按测量单元数分 F/T 传感器、阵列式（约 4–100 单元）、视觉式（高分辨率但体积大）。触觉传感本质是间接的：测的是接触引起的形变。传感器依赖强，算法跨传感器迁移差。
- **仿真（§2.2）：** 触觉仿真需同时建模接触力学与传感器转换；分物理 / 数据驱动 / 混合三类。缓解 sim-to-real：降低表征维度（二值接触、接触位置）、域随机化、域适应；涉及力估计、摩擦、滑移的任务仍需更高保真度。
- **力学驱动感知（§3.1）：** 接触力/力矩、接触形状、接触位置、物体位姿、滑移（含初期滑移；可由库仑摩擦或振动、微动、形变推断）、外在接触状态、物体属性。
- **力学驱动动作（§3.2）：** 触觉闭环伺服（接触状态与目标状态误差→关节指令）、基于感知的状态切换（滑移则加大夹持力、子任务阶段切换）、按感知到的物体属性更新底层控制参数。
- **力学驱动的优劣（§3.3）：** 优点是可解释、可靠、轻量低延迟；接触复杂或难建模时性能下降，由此催生数据驱动。触觉感知是主动的，感知与动作耦合。
- **触觉模仿学习（§4.1）：** 朴素地把触觉当额外输入或套用视觉预训练编码器常无提升；对策包括新触觉表征（点云、力图、预训练）、视觉 chunk 策略 + 高频触觉反应策略、输出力目标并接阻抗/导纳控制、随机遮蔽视觉、按接触概率加权融合等。收益体现在力调节、遮挡鲁棒、接触事件检测、新物体泛化；不同触觉信号的功能角色仍是开放问题。
- **触觉强化学习（§4.2）：** 真机 RL（数据成本、传感器磨损，动作空间小）、sim-to-real RL（灵巧手内旋转常用二值接触等简化触觉）、RL+IL（残差策略、VT-Refine 仿真微调）。触觉信号丰富度与数据效率、可仿真性的取舍随任务而变。
- **触觉 VLA（§4.3）：** 触觉作为主干的同等输入模态，或作为附加模块（常接入 action expert）；多数仍一任务一策略，泛化评测薄弱。
- **预测模型（§4.4）：** 触觉动力学模型 + MPC、视触觉世界模型（外部规划器或策略内使用）、预测作辅助训练目标（推理时零额外开销）。对短时程接触反应任务有效；长时程预测未被证实；像素级相似度指标可能不适合触觉；基础规模预测器速率低于接触动态。
- **开放问题（§5）：** 传感器异构与跨传感器表征；让触觉传感轻量化（延迟、耐久、可集成）；缺乏共同评测任务；力学驱动经验（如主动触摸）在数据驱动方法中被低估。
