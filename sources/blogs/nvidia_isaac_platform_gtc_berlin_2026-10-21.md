# NVIDIA Advances Isaac Platform（GTC Berlin 2026 官方新闻稿）

> 来源归档（blog / 厂商新闻稿）

- **标题：** NVIDIA Advances Isaac Platform for General-Purpose Robotics with New Reference Humanoid, Frameworks, Simulation Pipelines and Data
- **类型：** blog（NVIDIA 官方新闻稿）
- **链接：** https://nvidianews.nvidia.com/news/nvidia-advances-isaac-platform-for-general-purpose-robotics-with-new-reference-humanoid-frameworks-simulation-pipelines-and-data
- **日期：** 2026-10-21（GTC Berlin）
- **入库日期：** 2026-10-22

## 官方公布的内容（据新闻稿，WebFetch 摘要）

- **Isaac OS：** 基于 NVIDIA Holoscan 的开源运行时，连接 AI、传感器、控制与机器人硬件，面向实时性能。
- **Isaac Lab 3.0：** 正式可用（generally available）的开源框架，用于多 GPU 环境下训练机器人策略，从桌面到数据中心。
- **Human 1M：** 新闻稿称其为**数据集**（非数据流水线），包含多样人类活动、同步三视角视频与 3D 手部追踪，已在 Hugging Face 发布。
- **Agile ONE SN：** Agile Robots 的全栈开源参考人形，基于 Isaac GR00T 与 Jetson Thor，计划 2027 年初推出，并计划接入 NVIDIA Halos 安全能力。
- **合作方：** Newton 物理引擎（与 PhysX 并列，由 Isaac Lab 使用）；Schaeffler 提供执行器技术，作为 Newton 的独家基础组件；ABB Robotics、KUKA、Universal Robots、Sereact、Humanoid、NEURA Robotics、Franka Robotics；Hugging Face 与 Pollen Robotics（Microduck）。
