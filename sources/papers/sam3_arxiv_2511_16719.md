## 摘录 1：PCS 任务（§Abstract）

- **Concept prompt：** 短名词短语（如 “yellow school bus”）、图像 exemplar，或二者组合。
- **输出：** 匹配概念的全部实例掩码 + 身份；相对 SAM/SAM2「单目标提示」升级为 **穷尽概念实例**。
- **数据：** 可扩展 data engine → 约 4M 独特概念标签（含难负例）跨图像/视频。

**对 wiki 的映射：** [`wiki/entities/paper-sam3.md`](../../wiki/entities/paper-sam3.md)；机器人侧作开放词汇 2D 前端，接语义建图 / ObjectNav。

## 摘录 2：架构要点

- **共享骨干** 的图像级 detector + 基于记忆的 video tracker。
- **Presence head** 解耦识别与定位，提升检测精度。
- 相对既有 PCS 系统约 **2×** 精度增益（论文叙述）；保留并增强前代 SAM 视觉分割能力。

**对 wiki 的映射：** 与 [SAM](../../wiki/entities/paper-segment-anything.md)、[SAM 2](../../wiki/entities/paper-sam2.md) 形成谱系；零样本导航见 [zero-shot-object-navigation](../../wiki/tasks/zero-shot-object-navigation.md)。

## 摘录 3：与具身导航的接口

- 课程/工程常见组合：**SAM3（概念分割）+ BLIP-2（图文匹配/生成）** 支撑开放词汇目标发现与语义评分。
- 不替代 3D 建图与可通行规划；需与深度/LiDAR 融合（见 [2d-to-3d-semantic-lifting-gap](../../wiki/concepts/2d-to-3d-semantic-lifting-gap.md)）。

## 原文全文核验补充（v2 · 2026-03-28）

### 方法与监督边界（§2–4、附录 C–D）

- **PCS 不是复杂指代表达式分割：** 文本提示限定短名词短语（NP）；图像 exemplar 使用正/负标记框及其 ROI 特征，既可单独用也可和文本组合。对更复杂语言，论文将 MLLM 作为外部提示规划器，而非声称 SAM 3 内部直接理解长指令。
- **存在性与位置解耦：** detector 的全局 presence token 判断短语是否存在；局部 object query 判断在已存在条件下实例位置，最终对象分数是两者乘积。此设计与 UNVEIL 的独立“非对象概念”语义图属于不同任务。
- **视频检测与跟踪：** 同一视觉骨干供 DETR 式 detector 与 SAM 2 风格 memory tracker 使用；每帧新检测与已传播的 masklets 关联、更新并赋予实例身份。基础版每对象独立记忆计算，是 SAM 3.1 Multiplex 的优化入口。
- **四阶段训练：** 感知编码器预训练 → detector 预训练 → detector 微调 → 冻结 backbone 后训练 tracker。SA-Co 数据引擎按媒体与短语挖掘→候选 mask→ mask quality verification（MV）→ exhaustivity verification（EV）→人工修补闭环迭代；AI verifier 替代部分人审，提高标注吞吐量，但不会保证每个预测都完整。

### 评测数字及适用口径（§5–6、附录 E–F）

- **基准指标：** 图像 PCS 在正样本上量化定位 `pmF1`、以 `IL_MCC` 衡量概念存在性，`cgF1 = 100 × pmF1 × IL_MCC`；不可将 `cgF1` 和 COCO AP、像素 mIoU 或视频 `pHOTA` 混称为同一精度。
- **SA-Co 覆盖：** 论文报告 SA-Co/HQ 含约 **5.2M 图像、4M 独特短语**；视频数据 SA-Co/VIDEO 为 **52.5K 视频、24.8K 独特短语**；评测 SA-Co 包括 Gold/Silver/Bronze/Bio 与 VEval 多个子集。
- **视频 PCS 测试（SAM 3 原版）：** SA-Co/VEval 的 YT-Temporal-1B 为 **cgF1 50.8 / pHOTA 69.9**；SmartGlasses 为 **36.4 / 63.6**；这是按短语跟踪的任务，不是所有 VOS benchmark 的平均。
- **PVS 对照：** MOSEv2 val `J&F` 为 **60.3**；SA-37 交互图像分割 1/3/5 clicks 平均 mIoU 为 **66.1 / 81.3 / 85.1**。单次 click 并没有在所有设置上高于 SAM 2。
- **附录 H 与 SAM 3.1：** 默认 16 slots/bucket 的 mux/demux 共享记忆，原版 (O(N)) 对象级记忆前向转为 (O(ceil(N/16))) bucket-level 前向；附录的**同 detector Multiplex** 对照与正式 **SAM 3.1（新 detector）** 指标应区分。SAM 3.1 Release Notes 报 128 目标单 H100 约 **7×** 相对 2025-11 版整体加速（含其它推理优化），不是所有场景都 7×。

### 局限与模型卡（附录 B、I）

- 对医疗术语、飞机型号、热红外等细粒度域外概念的零样本泛化弱；通常要少量微调或域适配。
- SAM 3 原生只支持较短的 noun phrases；不宜直接承诺长指代、多属性推理。拥挤视频场景还存在重识别歧义、实例关联和显存/吞吐压力。
- 论文的基准对象是视觉分割与跟踪，不能直接当成机器人 3D 建图、碰撞安全、控制延迟或导航成功率的证据。
