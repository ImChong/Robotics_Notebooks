# The Coding Train — 官方教学站与课程入口

> 来源归档（sites / 课程项目页）

- **标题：** The Coding Train
- **URL：** <https://thecodingtrain.com/>
- **关于页：** <https://thecodingtrain.com/about>
- **类型：** 创意编程教学社区 / 视频课程
- **项目代码：** <https://github.com/CodingTrain/thecodingtrain.com>
- **官方课程入口：** [Code! Programming with p5.js](https://thecodingtrain.com/tracks/code-programming-with-p5-js)；[A Beginner's Guide to Machine Learning in JavaScript with ml5.js](https://thecodingtrain.com/tracks/ml5js-beginners-guide)
- **入库日期 / 复核日期：** 2026-10-10
- **一句话说明：** Daniel Shiffman 于 2015 年发起的创意编程学习社区，使用分主题视频、课程 Track、Coding Challenges 与直播带初学者学习 Processing、JavaScript、p5.js 及浏览器机器学习。

## 官方页面核查

- About 页将其定位为欢迎初学者的编程学习社区；站点 Tracks 是按顺序编排的视频教程，Challenges 覆盖算法艺术、机器学习、模拟等主题。
- 首页提供独立的 p5.js 编程 Track 与 ml5.js 浏览器机器学习 Track；ml5.js 官网也将 The Coding Train 的姿态 / 手部追踪教程列为示例。
- GitHub 官方组织将网站仓库列为置顶仓库；网站代码仓公开，采用 MIT 许可。课程和视频内容的使用条款应以各自站点说明为准，不从网站仓库的代码许可推断媒体许可。
