## 摘要级要点

- **痛点：** 生产级操作稳健性不单靠数据/算力 scaling；真正拖垮多阶段任务的是演示分布、策略归纳偏置与部署执行分布之间的系统错位 → 复合误差、卡死、重试成本高。
- **三分布：** $P_{\mathrm{train}}$（专家演示）→ $Q_{\mathrm{model}}$（学到的状态–动作映射）→ $P_{\mathrm{test}}$（含推理延迟与物理约束的真机轨迹）。
- **三支柱：**
  1. **Model Arithmetic (MA)** — 子集训练多 checkpoint，在权重空间插值；用 **DAgger OOD 验证损失** 选 α（greedy 最稳）。
  2. **Stage Advantage (SA)** — 直接建模 $A(s,s'|g)$（阶段条件），再阈值化最优性指示做 advantage-weighted BC；相对 $\pi^{*}_{0.6}$ 式 $V(s')-V(s)$ 更稳。
  3. **Train-Deploy Alignment (TDA)** — Heuristic DAgger（从失败态起步）+ 时空增强 + **temporal chunk-wise smoothing**（可与 RTC 正交叠加）。
- **任务：** Task A 展平折叠；Task B 条件取衣/分拣；Task C 挂衣（硬）。
- **主张数字：** 相对开源 $\pi_{0.5}$，成功率约 **+250%**；资源仅 20 h 数据 + 8 A100；附录含 24 h livestream。

## 核心摘录（面向 wiki 编译）

### 1) 管线（§III）

| 阶段 | 模块 | 关键机制 |
|------|------|----------|
| 覆盖不足 | Model Arithmetic | $\theta_{\mathrm{merged}}=\sum\alpha_i\theta_i$；子集训 → OOD（DAgger）验证选 α |
| 时序错配 | Stage Advantage | VLM 帧对 progress；$A_{\mathrm{stage}}=f_\theta(s,s'|g)$；$\epsilon=0.3$ 二值化 |
| 部署间隙 | TDA | Heuristic/标准 DAgger；翻转+左右臂交换；跳帧速度增强；chunk 平滑（Algorithm 1） |

### 2) 数据与训练

| 项 | 内容 |
|----|------|
| 规模 | Task A 2668 / B 3519 / C 2988 episodes（30 Hz SOP；均长 ~30–39 s） |
| 动作 chunk | $K=50$；执行 100 Hz |
| 优化 | AdamW，$2.5\times10^{-5}$，80k steps，batch 128 |
| MA | 4 checkpoints；合并策略含 average / inverse-loss / GD / greedy |
| 基线 | 仅 $\pi_0$ / $\pi_{0.5}$ 可跑通；GO-1 / X-VLA / DexVLA 全量 20 h 仍接近不可用 |

### 3) 关键消融结论

| 模块 | 结论 |
|------|------|
| 系统 | 单模块→两两→全系统单调提升；SA 主推吞吐量，TDA 主推成功率（重试成本↑） |
| MA | 子集合并 **优于** 单最佳子集与全量联合训练；OOD 验证优于 in-domain；greedy 最稳 |
| SA | SFR / MSTD 数值稳定性优于 $\pi^{*}_{0.6}$-style RECAP；长时程条件任务重试↓ |
| TDA | Heuristic DAgger 接近标准 DAgger 恢复质量且采集更省；chunk 平滑常优于 temporal ensembling / RTC，与 RTC 可叠加 |

### 4) 与近邻工作对照

| 工作 | 关系 |
|------|------|
| $\pi_0$ / $\pi_{0.5}$ / openpi | 骨干与训练/推理底座；本文是后训练+部署对齐配方 |
| $\pi^{*}_{0.6}$ / RECAP | SA 的数值稳定性对照（值差 → 直接/阶段 advantage） |
| LeHome / Learning to Fold | 同属叠衣；LeHome 偏竞赛 SO-ARM101 + 异步 AWR/RECAP；χ₀ 偏双臂协同长时程生产稳健 |
| STEAM | 另一条 advantage 路线（离线自监督 ensemble）；χ₀ 用手标阶段 + 在线/启发式 DAgger |
| RTC / ACT ensembling | 推理侧 chunk 对齐；本文提出 temporal chunk-wise smoothing |
