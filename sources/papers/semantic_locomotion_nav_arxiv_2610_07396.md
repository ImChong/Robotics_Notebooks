# 高程图看不到什么：语义感知运动与执行感知导航 论文来源归档

## 元数据

- **题目：** What the Elevation Map Cannot See: Semantic-Aware Locomotion and Execution-Aware Navigation for Humanoid Robot
- **作者：** Shunyu Yao, Songyang Liu, Dinghao Chen, Yuanyuan Lei, Shuai Li
- **单位：** arXiv 页面未列（周报标注佛罗里达大学，未核实）

- **入库日期：** 2026-10-12

## 论文要解决的问题

现有人形视觉语言导航（VLN）基准默认所有危险在高程图里可见、机器人也完美执行速度指令。现实里的手机、水/油渍、倒下的瓶子在高程图中几乎不可见，而且运动控制器的实际位移会偏离指令。论文提出一个带「难见危险 + 执行偏差」的仿真基准，以及把语义危险感知、地形运动和执行反馈闭环结合的 VLN-运动框架，并在 Unitree G1 上验证运动策略。

## 方法与训练信息

- **基准：** Isaac Sim；场景取 NaVILA 的 VLN-CE-Isaac 训练与未见验证划分，脚本生成障碍（40% 放在参考路径上，60% 在路径 1.0 m 内）。危险类型（Table 4）：箱子/crate（可见，0.06–0.24 m 高）、box（可见，0.05–0.18 m）、倒下的瓶子（模糊，0.071 m）、手机（不可见，0.014 m）、水/油渍（不可见，0 m）；正文说 “六类”，表中只列五行。扰动（强度 1.0）：摩擦 0.4–1.0、负载 ±2 kg、推力 ±0.8 m/s（每 3–7 s）、深度噪声 σ=2 cm、光照 450–1250、相机平移 ±5 mm / 旋转 ±4°、相机延迟 60–100 ms。
- **语义感知运动策略：** 在预训练 AME 策略上增加语义分支。输入为腰部 RGB-D 与 96 维本体向量，输出 29 个关节位置偏移；冻结 DINOv2-S 特征经可训练投影与语义 CNN 输入拼接，几何分支吃深度（部署时用 Fast-FoundationStereo 双目深度）。训练三步：①带真值地图与两个危险奖励项的 PPO 教师；②域随机化微调；③DAgger 蒸馏（前 200 次迭代教师控制，之后 800 次迭代逐步交给学生）。地形含不平地面、楼梯、桩、石桥各三档难度。
- **导航：** 高层 VLN 模块取自 NaVILA（VLN-CE-Isaac），由指令、当前 RGB 和前 L 帧输出相对目标位姿 (Δx, Δy, Δθ)，转换为平面速度指令。**反偏差（anti-deviation）：** 仿真中用 LingBot-Map 从同一单目 RGB 估计平面位姿，决策时锚定目标位姿，把残余位置/航向误差映射为补偿速度指令，替代输入运动策略的指令；控制增益原文未给。无反偏差的基线按固定间隔保持指令（间隔值未给）。

## 论文报告的结果

**运动（仿真，成功率 SR / 进度，无扰动）：**

| 方法 | L1 | L2 | L3 |
|------|------|------|------|
| Oracle | 99.0 / 99.7 | 95.6 / 98.2 | 95.0 / 98.1 |
| Elevation-only | 47.9 / 77.7 | 32.7 / 68.7 | 25.2 / 62.8 |
| Ours | 71.5 / 87.0 | 61.2 / 79.4 | 51.0 / 74.7 |

L3 且扰动 1.5× 时 Ours 为 22.7% SR / 56.7% 进度。

**不平地面（无扰动）：** Oracle SR 93.6、Elevation-only 9.4、Ours 50.6；危险接触率 HCR（可见 / 模糊 / 不可见）Oracle 2.2 / 1.7 / 1.9，Elevation-only 27.8 / 41.4 / 21.1，Ours 24.7 / 17.2 / 6.1；跌倒率 0.6 / 0.3 / 1.4。扰动 1.0× 时 SR 为 44.2（Ours）、9.7、86.9；1.5× 时 28.1、6.7、72.8，跌倒率 11.9 / 3.1 / 5.8。Ours 关闭了不可见危险 HCR 差距的约 74–100%，模糊约 51–61%，可见仅约 12–24%。

**真机 G1（每方法每表面 5 次）：** 塑料地面 clean SR：Elevation-only 0，Sonic 20，Ours 40；木板：0 / 0 / 60；塑料布：0 / 0 / 60。Sonic 为盲视的全身控制器（SONIC），由人类专家给速度指令，离开走廊比例 80–100%；Ours 无跌倒。物理扰动下 Ours clean SR：无扰动 60，2000 lm 手电 40，加 1 kg 负载 40，海绵棒敲击 60。

**导航（仿真）：** 语义分支使 Safe SR 提高 3.34–12.26 个百分点（5 障碍/尺度 0.5：35.38 vs 23.12；5/1.0：23.68 vs 17.27；10/0.5：17.55 vs 13.65；10/1.0：13.09 vs 9.75），危险侵入下降 8.63–11.15 点，跌倒率下降 8.64–9.75 点。反偏差消融（Ours vs 去除）：Safe SR 23.68 vs 11.98，SR 29.80 vs 19.50，SPL 0.256 vs 0.169，碰撞率 12.26 vs 35.93，危险侵入 12.81 vs 18.38，平均进度 43.20 vs 46.12。

## 复现与解释边界

- 无公开代码或项目页；用于识别语义危险的 “VLM” 组成、导航规划细节、导航回合数原文均未说明。
- Oracle 与 Ours 观测接口和训练角色都不同，50.6% vs 93.6% 的差距不能完全归因于感知。
- 真机仅 5 次/条件，且 Ours 的 clean SR 最高 60%；导航结果仅在仿真，反偏差定位依赖 LingBot-Map。
- 跌倒率在 1.5× 扰动下上升，可能与相机对光照的敏感性有关（论文推测）。
