- **项目主页：** <https://robots-last-exam.com/>
- **技术原文：** [From Robot Skills to Real Work](../blogs/robots-last-exam-from-robot-skills-to-real-work-2026-11.md)
- **核验日期：** 2026-11-28
- **核对范围：** 核对主页、首发技术文章、场景图库的官方入口与加载文案、Robot World 的公开说明、榜单口径和贡献 FAQ。仅做公开页面核验，未登录、未提交申请、未运行评测，也未验证浏览器 3D 性能。
- **通读：** 已完成

| 入口 | 核验与用途 |
|---|---|
| [主页](https://robots-last-exam.com/) | 技术概览、任务与功能设备演示，以及物理仿真片段。 |
| [场景图库](https://robots-last-exam.com/scenes/) | 依赖 JavaScript；展示场景可用的 3D 预览或录制片段，覆盖设备功能、物理与任务。不保证每个场景有公开交互预览。 |
| [Robot World](https://robots-last-exam.com/world/) | 仍在建设的桌面键鼠漫游入口，使用 WASD 移动、鼠标转向、E 进入与 Esc 暂停；不是提交机器人 rollout 的环境。 |
| [Agent 模式榜单](https://robots-last-exam.com/leaderboard/) | 完整流程与独立子任务分别排序，另列成本与时间。 |
| [共建说明](https://robots-last-exam.com/contribute/) · [官方申请页](https://robots-last-exam.com/next/apply) | 官方列出构建工作场所、设计新任务与完善物理三种方向；用户提供的 [入口](https://app.robots-last-exam.com/next/) 本次重定向至共建说明，说明页上的申请按钮链接至申请页。 |
