- 官方仓库已公开，但 README 明确将核心转换管线与机载观测生成标为进行中，命令生成、数据集、训练配置和模型细节仍计划发布。
- 仓库安装/运行指引尚未提供；项目页的 dataset 展示不等于可下载数据集。故记为**部分开放，当前缺少可复现的完整运行栈**。
