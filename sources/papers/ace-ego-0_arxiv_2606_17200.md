## 论文要点（作者自述，带章节）

1. **问题与定位（§1）：** 机器人轨迹采集昂贵；第一人称人类视频便宜但存在动作空间、形态、时间尺度、监督质量四方面不一致。作者提出 ACE-Ego-0：统一动作表示（空间 / 结构 / 时间三轴对齐）加上可靠性感知训练目标。
2. **统一动作表示（§3.1、附录 A.1）：** 机器人与人手动作都转到头部相机坐标系（式 1），旋转用连续 6D；双臂动作向量 22 维 = 2 × (位置 3 + 旋转 6D 6 + 夹爪 1 + 活动标志 1)（式 14、15）。人手以腕关节为末端原点，掌面 + 腕到指向量构造朝向（式 13），拇指到掌心距离线性映射到夹爪行程 [0.04, 0.10] m（§4.2 Stage 4）。
3. **形态条件（§3.1.2、附录 A.2–A.4）：** 机器人 URDF 建关节图（节点特征 29 维），经残差消息传递 + 均值池化得到 body 与 chain 两个摘要，投影成 morphology token；人类视频源用每数据集一个可学习 surrogate embedding。该 token 只注入动作专家，不进入 VLM。
4. **时间对齐分块（§3.1.3、式 3–5）：** H_d = round(f_d · T*)，附录表 8 给出 T* = 2 s；按（任务簇、相位桶、时长桶）组 batch 以减少 padding。
5. **可靠性感知目标（§3.2、附录 A.5）：** 机器人样本走标准 flow-matching 主损失（式 7）；人类样本走 Huber 辅助损失（式 8），权重 W = ρ_j · w_data · w_step（式 6、20）。表 6：λ_haux = 0.1，位置通道 ρ = 1.0，旋转 / 夹爪通道 ρ_low = 0.001，Huber β = 1.0，平滑窗口 3 帧。ρ_j 是经验指定而非学得（§3.2）。
6. **模型（附录 B.1、表 7、8）：** Qwen3-VL-4B-Instruct + 约 600M flow-matching DiT 动作专家（36 层，隐藏 1024），输入 256×256 头 + 腕相机，推理 4 步解码；预训练 128×A800、200K 步，微调 16×A800。
7. **数据（§4、表 1）：** 人类视频六源（Ego4D、EgoExo4D、EPIC-KITCHENS-100、HOI4D、EgoDex、Xperience-10M）过滤后共 1,478.9 小时伪动作；机器人 + 仿真约 4,534.8+ 小时（AgiBot Alpha/Beta 1,937.8、Galaxea R1Lite 488.1、AgiBot DigitalWorld 225.3、RoboCasa Tabletop 83.6、自采 Galbot 1,800+）；总计 6,013.7+ 小时。图 3 标注人类视频原始池 5,929 小时。
8. **五阶段伪动作流水线（§4.2、表 2、图 4）：** 数据整理（切 4–30 s 片段）→ 视频筛选（人脸检测阈值 0.5 的 ego-interaction 过滤 + 字幕需含操作动词与物体名词）→ 3D 手部重建（SAM3 跟踪、HaMeR 局部位姿、两阶段全局轨迹优化，N_root = 30、N_smooth = 200 的 L-BFGS，VIPE 相机位姿）→ 动作参数化 → 质量控制（完整性 / 静态 / 尖峰 / 双手四类过滤）。
9. **评测（§5）：** RoboCasa GR1 TableTop（24 任务，每任务 50 次）平均 72.8%，对比 DIAL 70.2、JoyAI-RA 63.2、ABot-M0 58.3、FLARE 55.0、GR00T-N1.6 47.6、Qwen3PI 43.9（表 3）。RoboTwin 2.0（50 任务，每任务 100 次）Easy / Hard 为 91.12 / 90.62，对比 Hy-VLA 90.9 / 90.1、JoyAI-RA 90.48 / 89.28、π0.5 82.74 / 76.76（表 4）。RoboTwin 训练用 2,500 条干净演示 + 25,000 条随机化演示（§5.2.2）。
10. **真机（§5.3、图 5a）：** ARX 双臂平台、头部 RGB-D、6 个任务、每任务 30 次；平均 78.3%，π0.5（同任务数据微调）71.7%，GR00T-N1.7 35.6%；五个任务领先，Pack Shoes 不领先。
11. **消融（§5.4、图 5b、表 5，均在 RoboCasa GR1）：** 去形态 token 70.9（−1.9）、去时间对齐分块 71.7（−1.1）、去人类辅助损失 69.2（−3.6）；预训练数据：Qwen 初始化 65.4、仅机器人 68.3、机器人 + 人类 72.8。
12. **人类数据增强微调（§5.5、图 6）：** Sweep Cubes 仅 34 条机器人演示时成功率 10%（1/10），加入 419 条任务相关人类视频后 40%（4/10）；末端轨迹凸包面积 0.062 m² 对 0.296 m²（4.8×）。
13. **局限（§7，作者自述）：** 只评桌面操作；预训练池无灵巧手与力 / 力矩数据；旋转与细粒度手指的伪动作保真度不足，目前仅位置通道被有效监督。

## 阅读者判断（非作者结论）

- 增益幅度：RoboTwin 对 Hy-VLA 的领先仅 0.22 / 0.52 个百分点；论文未报告多种子方差或置信区间。RoboCasa 对 DIAL 领先 2.6 个百分点。是否超出噪声，论文没有给统计依据。
- 消融与人类数据价值（表 5、图 5b）只在 RoboCasa GR1 仿真上做，且为单一数字；真机上只有 §5.5 一个任务（10 次试验）的人类数据对照，样本量很小。
- 真机对比中 π0.5 / GR00T-N1.7 的预训练数据与 ACE-Ego-0 并不相同，论文没有控制预训练数据量，因此 78.3% 对 71.7% 不能单独归因于「人类视频」或「统一表示」。
- 由于 ρ_low = 0.001，旋转与夹爪通道在人类辅助损失里几乎不贡献，实际效果近似「人类视频只教末端位置轨迹」；这是我据表 6 的推断，论文 §7 对此有类似表述。
- 论文标题与全文用 ACE-Ego-0；Berseth 清单与部分站内文章写作 ACE-Ego，站内另有一篇公众号文章把它记成 arXiv 2606.11241，与论文首页的 2606.17200 不符（未进一步查证 2606.11241 是什么）。
