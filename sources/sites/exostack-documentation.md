## 结构与开放结论
ESA（嵌入式板）、ExoCore（ROS 2 节点）、`exo_stack_resources`（config + algorithms）、PASE GUI（可视化/启动）；官方支持 Ubuntu 22.04、ROS 2 Humble、Python 3.10。
- **代码：** 上游代码在 GitHub 公开，但许可为 PolyForm Noncommercial 1.0.0，不能称可自由商用的开源；文档 CC BY-NC 4.0。
- **部署安全：** 人体实验和外骨骼安全认证超出单凭文档可验证的范围。
