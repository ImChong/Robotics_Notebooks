## 可用资源

官方 README 列出训练、推理和 RoboTwin 评测实现：`scripts/train.sh`、`scripts/infer.py`、`scripts/evaluate.sh`，以及 `src/e05/` 模型代码。仓库代码采用 MIT 许可证，第三方材料、权重与数据适用各自条款；VGGT-Omega 包含非商业研究条款。

README 提供 [RoboTwin 策略权重](https://huggingface.co/X-EraAI/e05-robotwin)、[具身预训练 VGGT 权重](https://huggingface.co/X-EraAI/e05-embodied-vggt)与[处理后的 RoboTwin 数据](https://huggingface.co/datasets/X-EraAI/e05-robotwin-data)下载链接；这些资源未在本次实际下载验证。处理后的数据约 378 GiB，完整训练默认 8 GPU；独立推理使用一张 GPU。真实机器人适配需自行准备任务配置及数据，发布的 VGGT 初始化权重并非完整真机策略。

模型卡说明发布的 109k 权重是 70 epoch 预算中第 50 epoch 的中间检查点，其历史结果为 clean 89.48%（5000 次）、random 49.431867%（4961/5000 次），不能当作完整 10000 次评测；与论文摘要结果分别记录。
