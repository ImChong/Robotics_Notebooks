# WetRobo（arXiv:2609.18435）

> 来源归档（paper）

- **标题：** WetRobo: A Reproducible Robot Kit for Coding Agents in Biological Laboratories
- **类型：** paper
- **arXiv：** <https://arxiv.org/abs/2609.18435>
- **PDF：** <https://arxiv.org/pdf/2609.18435>
- **代码：** <https://github.com/tsudalab/WetRobo>
- **入库日期：** 2026-09-17
- **一句话说明：** 湿实验可复现 kit：机械臂 + 设备 + 示范 + 控制栈 + AGENTS.md，让 coding agent 通过观测/写码/验证做现场 VLA 适配。

## 开源状态

- **已开源**（步骤 2.5 核查，2026-09-17）：GitHub 含 AGENTS.md、demo 与 evolved branch 示例。

## 核心摘录

四组件：Skill（AGENTS.md 规则）、Code exemplar（wetrobo+petri+cap+door branch）、Arm（AgileX Piper + Record3D + 腕部 RGB）、Incubator；每任务 15 条遥操作 demo。
