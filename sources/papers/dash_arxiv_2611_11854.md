# DASH — Asynchronous Humanoid VLA Control

- **通读：** 已完成

## 核心摘录
1. System 2 使用 Qwen3.5-0.8B 或 Qwen3-VL 2B/4B/8B 等视觉语言主干低频产生多层语义特征，经 LCM 提供缓存；System 1 用最新图像的 ResNet-152、DiT flow-matching 动作头及本体观测高频生成动作。两支可独立运行，不能把旧语义当作最新观测。
2. 训练随机采样 stale semantic 与 fresh visual 的时间差，模拟实际推理管线的异步偏移；动作侧含 adaptive temporal aggregation 处理动作片段的融合与连续性。
3. 论文将模型服务器、action server、environment server 分开。动作以约 20 Hz 控制；同步方式对大主干的观测/执行循环会降至约 9.7→4.1 Hz；异步控制在作者 RoboTwin 协议下提高任务成功率约 1–5.9 个百分点。
4. RoboTwin 50 项任务、每模型 250 episodes；作者报告真机 pick-and-place DASH 23/24（95.8%）对同步 16/24（66.7%），总样本量小且主要为准静态场景。
5. 局限：动态环境、强接触、高风险情形的稳定性不能由当前评测推出；模型长时延下的缓存失效和动作重规划需要工程监测。
