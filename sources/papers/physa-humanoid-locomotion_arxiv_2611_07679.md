## 核心摘录

1. **问题与发现（摘要、§1、附录 B.6）：** 作者让四个商用 VLM（GPT-4o-2024-05-13、GPT-4o-2024-11-20、Claude Sonnet 4.6、Gemini 2.5 Pro）给渲染 rollout 打 [0,10] 审美分，发现关节加速度越大的片段得分越高，平均 Pearson r=+0.66（表 7：+0.82、+0.49、+0.63、+0.71，每个模型 99–100 对片段）。附录 B.6「两条件设计说明」自述该 r 是混合了 PhySA 修正模块 checkpoint（平均 jerk 约 264）与 Prompt2Policy（约 377）两个训练条件的片段后合并计算的；单片段层面 Krippendorff α=−0.008（B.6）。
2. **方法（§3，式 1，图 2）：** r_total = r_task + α·r_VLM + r_phys + r_GMP。审美通道每 200k 步在后台线程调用 GPT-4o 对 12 帧片段打分（温度 0，只用 overall），EMA（0.8/0.2）平滑并映射为 r_VLM = vlm_ema/10 − 0.5，α=0.5 固定；物理通道把训练分成 4 个 2.5M 步的阶段，在阶段边界检查稳定性 / 能耗 / 回合回报三轴，满足条件（Δstability < −0.04 或全部指标提升 < 0.01，附录 A.1）时编辑 r_phys 中的惩罚项。r_GMP 是用 AMASS 动捕拟合的高斯运动先验，在所有条件下保持不变。
3. **MuJoCo Humanoid-v5 主结果（§4.2，表 1，附录 H.2 表 12）：** 单条 4 阶段训练链上，对 Prompt2Policy 关节加速度 423.8 → 171.4（−59.5%），回合长度 78.5 → 123.5，功率 999.6 → 568.6 W（−43.1%），单回合功 1195 → 1038 J（−13.1%）；但从零开始三个种子的复现仅 −7.2%（p=0.45，不显著）。功率降低来自关节速度范数 −35%，力矩范数反而 +6%（B.1、表 12）；两个髋关节占功率降低的 95.3%。
4. **与 PPO / Text2Reward / Eureka 对比（附录 B.4，表 6）：** 2.6M 步、3 种子 × 50 回合，关节加速度 PhySA 693 对 PPO 933、T2R 944、Eureka 1015（−25.7 / −26.6 / −31.7%，BH 校正后显著），但回合长度 73.7（对 126.9 / 116.4 / 186.2）与回合回报 322.4（对 667.2 / 625.9 / 879.2）显著更低。Eureka 的 10M checkpoint 原地抖动刷 alive bonus（B.5）。
5. **模块隔离（§4.3，图 4，表 4，表 5）：** 单独审美通道使粗糙度 +136%（N=8），单独修正模块 −29.8%（N=50）；组合栈中去掉 VLM 通道或把 α 在 0.2–0.8 间变化 4 倍，粗糙度无可测变化（N=30 配对，Δ=−2.0，p=0.863）。§3.2 解释：r_VLM 每 200k 步才更新且不依赖状态，只相当于改变 alive bonus。
6. **成本（§2、附录 B.7，表 2、表 8）：** 每 10M 步 50 次 VLM 调用，约 $0.85（1M 步实测 4 次调用 $0.0848）；同步每次更新调用一次约 1,220 次，约 24 倍（该 24× 是按更新次数估算，图 1 说明）。
7. **跨仿真器 / 本体（§4.4，附录 C、F、G，表 10、11）：** 同一人形、仅换 IsaacLab 物理引擎：直接迁移 −2.2%（p=0.71），平滑项 ×50 / ×60 重标度 −1.0% / −1.1%（p=0.91 / 0.87，N=5）。MuJoCo 内把 Δt 强制设为 1/60 s（N=3），关节加速度恶化近 5 倍，作者据此指向积分方案是跨仿真器差距的主要来源之一。Unitree G1（23 关节，同时换仿真器与本体，N=3，10M 步）：修正前 +3.4%（Humanoid-v5 的 alive 阈值 z≥1.1 m 在 G1 站高 0.793 m 时永不触发），修正后 −1.7%，38 组超参搜索最佳 −4.8%，均不显著。推球恢复（50–200 N，每条件 480 回合）无显著平滑提升（附录 C）。
8. **作者自述局限（§5、附录 C、E）：** 最大效果来自单次训练；回合很短（PhySA 123.5 步约 1.9 s，§4.2），测的是早期运动而非长时程步态；VLM 通道只通过「生存价值」起作用；未做 MuJoCo 内的 G1 实验，因此 G1 失败无法归因；bait 诊断只训练了 5M 步（附录 E）。
