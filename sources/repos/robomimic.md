# robomimic 官方代码仓库

- **标题：** robomimic
- **类型：** repo
- **链接：** https://github.com/ARISE-Initiative/robomimic
- **项目主页：** https://robomimic.github.io/
- **官方文档：** https://robomimic.github.io/docs/
- **主论文：** [What Matters in Learning from Offline Human Demonstrations for Robot Manipulation](https://arxiv.org/abs/2108.03298)（CoRL 2022）
- **入库日期：** 2026-10-17
- **核查日期：** 2026-10-17
- **一句话说明：** 用统一数据与训练接口研究机器人示范学习和离线强化学习的模块化框架，包含示范数据集、BC/序列策略与离线 RL 算法。
- **许可：** MIT（以仓库 LICENSE 为准）
- **开源状态：** 已开源 — 官方仓库提供实现、配置、示例与 Dockerfile；官方文档含安装、数据下载、训练及复现实验说明。
- **版本观察：** 仓库列出的 v0.5.0 更新加入 Diffusion Policy、多数据集训练和语言条件策略；官方文档同时提供 Transformer 与 Diffusion Policy 训练教程。具体算法列表以对应版本文档和配置为准。
