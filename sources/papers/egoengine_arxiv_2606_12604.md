## 方法要点（作者自述）

1. **数字孪生（§3.1）：** Aria Gen2 提供 RGB 与逐帧 21 点手部 3D 位姿；FoundationStereo 估深度，SAM2 取手臂掩码与物体掩码，FoundationPose 结合物体网格估 6D 物体轨迹。
2. **动作分支（§3.2）：** 先用 MINK 做逆运动学重定向（式 1），再以「物体轨迹跟踪误差」为目标在仿真中精修（式 2，超阈值提前终止）。每个时间块（附录 C.1：H = 20 步）按 Replay → MPC → RL 逐级升级的「MCTS 式」启发式贪心切换；RL 是加在重定向参考指令上的手部残差策略，用 PPO 训练；两块联合窗口（当前块加下一块）可行才执行当前块。
3. **视觉分支（§3.3）：** SAM2 掩码加 Inpaint-Anything v2 去人，渲染机器人，两遍差分渲染得遮挡感知掩码（式 3），再混合（式 4）。
4. **策略蒸馏（§3.4，附录 D）：** HPT（ResNet-18 视觉干 + 本体干 + 流匹配动作头，推理 10 步 Euler）在合成数据上训练，仅用合成数据，无真机示教、无联合训练。

## 实验设置与结果（作者报告）

- **数据（§4.1）：** TACO 2,500 段视频（仿真评测用其中 16 对）；自采 Aria 数据 200 段人类视频、4 个任务；另采 200 条真机遥操作示教仅作对照，不用于 EgoEngine。仿真为双臂 RB-Y1 + 双 XHand（12 自由度），真机为单臂 RB-Y1 + 一只 XHand。
- **视觉保真度（§4.2，Tab. 1，Fréchet 距离，越低越好）：** EgoEngine 614.7 / 644.2 / 473.1（ResNet18 / VGG16 / DINOv2），Phantom 620.0 / 650.8 / 470.6，人类视频 764.5 / 670.2 / 602.9。文内承认 DINOv2 上与 Phantom 基本持平。
- **动作保真度（§4.3，Tab. 2）：** TACO 上 EgoEngine 成功率 0.83、代价 34,842，对 H2S2R（纯 RL）0.83、73,675；Aria 上 0.90 对 0.90，代价 16,560 对 20,237；Replay（Mink）成功率 0.17 与 0.10，Spider（MPC）0.25 与 0.20。Fig. 5 与正文：Aria 上 2.36 → 2.88 demos/小时，效率提升 22.0%（单张 RTX 4090，不并行）。
- **真机策略（§4.4，Tab. 3）：** EgoEngine 在 Mustard / Drawer / Flower / Hammer 上成功率 0.40 / 0.35 / 0.70 / 0.60；真机示教 0.80 / 0.80 / 0.70 / 0.25；人类视频 0.00 / 0.10 / 0.00 / 0.00；Phantom 0.00 / 0.05 / 0.00 / 0.00。正文称 4 个任务中有 2 个持平或超过真机示教（Flower 持平、Hammer 超过）。每任务试验次数正文与附录未写明，仅从 0.05、0.25 这类取值推测为 20 次（推测）。
- **消融（Tab. 4，四任务平均成功率）：** 人类视频 0.03；仅视觉分支 0.05；仅动作分支 0.43；完整 0.51。作者据此认为动作生成是主要因素，视觉生成是附加增益。
- **附录 E：** E.1 样本效率（Mustard、Flower，演示数 1 / 5 / 20 / 50）作者承认 EgoEngine 并非处处优于真机示教，大数据量时遥操作更强；E.2 SPARC 平滑度 EgoEngine 总体 −4.81 优于真机示教 −6.60；Fig. E.2 为 TACO 切割长程示例，仅在仿真精修后回放到真机，为安全加了偏置。A.4 / Fig. A.3 只展示 EgoDex、EgoVerse 视频上数字孪生重建的 12 个定性例子，未做下游策略训练。

## 作者自述的局限（§6）

质量（视觉分支是混合合成而非学习式逼真生成；接触建模误差与 sim-to-real 差距）；可扩展性（数字孪生仍是瓶颈：高质量物体资产、严重遮挡下的物体状态估计、可变形物体）；效率（仿真轨迹优化在极大规模下仍慢）。
