## 一句话摘要

单条参考运动 → 关键帧稀疏化与轻量编辑 → 两阶段自适应 motion tracking（phase + tracking adapters）；仿真与 **Unitree G1** 真机在跳远/跳高/三级跳/台阶/网球/羽毛球等多任务、宽适应条件下验证；视频展示相对 DeepMimic-Adapt、AMP-Style、Stage1 的适应与模仿优势。
