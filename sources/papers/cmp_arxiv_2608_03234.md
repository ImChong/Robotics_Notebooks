## 摘要级要点

- **问题：** 现有运动先验（AMP/SMP）从整库学一个任务无关先验，全程均匀用；异构或失衡参考下会给当前上下文灌入无关/冲突监督。
- **主张：** 可在**原参考空间**在线适配，无需技能标签、数据集切分或独立 skill discovery（对照 ASE / CALM / C·ASE）。
- **机制：** 对比相关度 \(R_\phi(c,x)\)（高优势 online 正样本 + \(\mathcal{L}_{\mathrm{demo}}\) 锚定参考支撑）→ 软权重 \(\bar{w}_\phi\) → 轻量上下文残差适配器（基座先验原目标不变）。
- **实例化：** CMP-AMP（残差加在判别器 logit）；CMP-SMP（残差加在冻结 denoiser 的噪声预测）。
- **任务：** Target Location / Steering / Trajectory Following / Dodgeball / Dribbling；同一 MimicKit locomotion 参考集，无任务专用 demo。
- **结果：** 五任务上相对 AMP/SMP 提高 test return；多数任务更快到达 80% 基线最终回报；行走 clip ×100 失衡时 AMP −11.5%、CMP-AMP 仅 −2.8%；附录 E 模拟 G1 上 CMP-AMP 同样全面占优。

## 核心摘录（面向 wiki 编译）

### 1) 上下文条件参考重权

\[
w_{\phi}(c,x)=\frac{\exp(\alpha R_{\phi}(c,x))}{\mathbb{E}_{x'\sim p_E}[\exp(\alpha R_{\phi}(c,x'))]},\quad
q_{\phi}(x\mid c)=w_{\phi}(c,x)\,p_E(x)
\]

minibatch 归一化后 clip 到 \([w_{\min},w_{\max}]=[0.5,2.0]\)；适配器损失用 `stop-gradient` 权重，只更新 \(\psi\)。\(\alpha=0.5\)（AMP）/ \(1.0\)（SMP）。

### 2) 对比相关度

\[
R_{\phi}(c,x)=\frac{f_{\phi_c}(c)^\top g_{\phi_x}(x)}{\|f_{\phi_c}(c)\|_2\,\|g_{\phi_x}(x)\|_2}
\]

- **Online：** \(\hat A_i>0\) 的 rollout 为 \((c_i,x_i)\) 正对，按 \(\rho_i=\sigma(\hat A_i/\beta_{\mathrm{adv}})\) 加权（\(\beta_{\mathrm{adv}}=1\)）；正样本过少时取 batch 最高优势子集（最少 64 / fallback 0.35）。
- **Demo：** 同一批上下文下，参考 clip 为正、rollout clip 为负，防止 query 漂出参考支撑。
- \(\mathcal{L}_{\mathrm{rel}}=\mathcal{L}_{\mathrm{on}}+\lambda_{\mathrm{demo}}\mathcal{L}_{\mathrm{demo}}\)；\(\lambda_{\mathrm{demo}}=0.5\)（AMP）/ \(1.0\)（SMP）；温度 \(\tau=0.1\)。

### 3) 适配器实例化

- **AMP：** \(l_{\theta,\psi}(c,x)=\mathrm{sg}[l_\theta(x)]+\lambda_{\mathrm{res}}\Delta l_\psi(c,x)\)（\(\lambda_{\mathrm{res}}=0.03\)）；参考侧加权 BCE、策略侧未加权负项；奖励 \(r=-\log(1-\sigma(l_{\theta,\psi}))\)。
- **SMP：** \(\hat\epsilon_{\theta,\psi}=\mathrm{sg}[\epsilon_\theta]+\lambda_{\mathrm{res}}\Delta\epsilon_\psi\)（\(\lambda_{\mathrm{res}}=0.1\)）；冻结预训练 denoiser；另加残差正则 \(\eta=0.001\)；奖励沿用 SMP 的 \(\mathcal{K}=\{22,15,8\}\) 集成 score matching。

### 4) 任务上下文 \(c\)（附录 K；局部 heading 系）

| 任务 | \(c\) | 维数 |
|------|--------|------|
| Target Location | 目标位置 \(\tilde{\mathbf{x}}^*\) | \(\mathbb{R}^2\) |
| Steering | 运动方向、目标速度、朝向 | \(\mathbb{R}^5\) |
| Trajectory Following | 当前 + 未来路点 \(K=6,\Delta=0.30\,\mathrm{s}\)（最远 1.50 s） | \(\mathbb{R}^{12}\) |
| Dodgeball | 球相对位置与速度 | \(\mathbb{R}^6\) |
| Dribbling | 球位/速 + 期望方向/速度 | \(\mathbb{R}^9\) |

### 5) 主结果（Table 1，test return / 三 seed）

| Task | AMP → CMP-AMP | SMP → CMP-SMP |
|------|---------------|---------------|
| Location | \(408\pm1\) → **\(467\pm8\)** | \(376\pm31\) → **\(437\pm5\)** |
| Steering | \(299\pm12\) → **\(480\pm6\)** | \(496\pm10\) → **\(512\pm8\)** |
| Trajectory | \(184\pm1\) → **\(302\pm6\)** | \(252\pm1\) → **\(268\pm1\)** |
| Dodgeball | \(424\pm2\) → **\(458\pm12\)** | \(447\pm6\) → **\(471\pm3\)** |
| Dribbling | \(319\pm10\) → **\(456\pm5\)** | \(458\pm5\) → **\(466\pm2\)** |

样本效率（达基线 80% 最终回报的 env steps，×10⁸）：CMP-AMP Location 6.5→2.4、Trajectory 6.8→2.7、Dribbling 5.2→2.8、Dodgeball 7.6→5.6；Steering 与 AMP 同为 1.2。CMP-SMP 五任务达阈样本均下降。评测：每 seed 32 episode。

### 8) 消融要点（Appendix F/G，Dodgeball / Dribbling）

- Uniform Adapter：有上下文容量但权重全 1 → Dribbling 有收益、Dodgeball 几乎不抬。
- Shuffled Relevance：打乱相关度对应 → Dodgeball 方差大、达阈变慢。
- Online-only：去掉 \(\mathcal{L}_{\mathrm{demo}}\) → 最终回报可接近，样本效率更差；检索上远目标 query 漂出参考支撑。
- CMP-AMP 两边达阈样本最少（Dribbling 2.8、Dodgeball 5.6）。

### 9) 工程配置（附录 I / L / M）

- 运动 clip：MimicKit 10 帧 \(X_t=(x_{t-8},\ldots,x_{t+1})\)；\(\Phi(s_t)\) 不含任务上下文。
- 相关度编码器：各 256→128 MLP + SiLU，\(\ell_2\) 归一。
- AMP 适配器：motion/context 双支 256-d，融合标量 \(\Delta l\)；输出层零初始化。
- SMP 适配器：序列+timestep 嵌入后 3 层 MLP（宽 512）。
- 仿真：Isaac Gym Preview 4 / PhysX / 4096 envs / RTX 3090 或 4090。
