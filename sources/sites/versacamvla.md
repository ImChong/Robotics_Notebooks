## 项目内容与开放状态

项目入口由官方 GitHub README 链接。README 简介称该方法将标定 RGB 视图整合为紧凑场景 token，帮助机器人策略适配不同相机数量和未见视角，并提供抓取方块、堆叠方块、插入管件等演示 GIF。

官方仓库 README 标注 **“Code coming soon”**，并称实现将发布在该仓库。截至 2026-10-27，仓库没有训练或推理代码入口；当前状态为**演示素材已公开、方法实现待发布**，不能视为可运行开源项目。
