# OCLO 论文通读（无人体数据的柔顺人形移动操作）

> 来源归档（原文通读 · 支撑 `wiki/overview/frontier-humanoid-quadruped-2026-10-05-10-09.md`）

- **标题：** Dataset-Free Compliant Humanoid Loco-Manipulation with Dynamic Online Posture（OCLO）
- **作者：** Seungho Yeom, Zhenyu Wu, Jaeyoung Huh, Diego Williams, Yuheng Zhi, Soofiyan Atar, Michael Yip（加州大学圣迭戈分校、延世大学）
- **类型：** paper / humanoid / loco-manipulation
- **原文：** <https://arxiv.org/abs/2610.05678>（arXiv PDF v1，2026-10-05 版，2026-11 获取全文）
- **一句话说明：** 只训练下肢策略，仅凭两个末端目标，在线用解析可达性先验（可选策略在环 CEM 精修）生成骨盆高度与躯干姿态，并用弹簧阻尼位移参考训练全身柔顺。
- **核对范围：** 通读摘要、§I 引言、§II 相关工作与表 I、§III 方法（柔顺参考、程序化命令与奖励表 II、三阶段课程、在线姿态生成、双点接口）、§IV 全部仿真与实机实验（表 III、IV，图 3、4）、§V 讨论与局限及参考文献；论文无附录，项目页与代码未核对。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **架构（§III）：** 唯一学习部分是下肢策略（12 腿 + 3 腰关节，50 Hz PD 目标）；14 个手臂关节由 200 Hz 微分逆运动学跟踪柔顺参考；训练命令全部程序化生成，不用人体动作数据。
- **柔顺（式 1）：** 末端参考由虚拟质量–弹簧–阻尼生成，外力经饱和函数 s_ata（a=40 N）位移参考；刚度 kp~U[12,24] 随机化并进入观测。EE 误差对柔顺参考计算，使下肢与腰通过身体移动去“让”。
- **三阶段课程（§III-C）：** 站走 → 加末端目标与交互载荷 → 以骨盆高度/躯干姿态跟踪替换固定姿态惩罚；PPO，MuJoCo Warp / mjlab。
- **解析先验（式 2）：** h=max(h0−k_hδ,h_min)，θ=k_θδ+k_ηη，φ=0；δ 为较低目标低于站立可达的量，η 为前伸量；常数一次拟合，CPU 上约 0.07 ms。
- **策略在环精修（式 3）：** 冻结策略的 GPU 批量 rollout，代价含跌倒、捕获点、EE 误差、姿态可实现性、速度/力矩/限位及对上一姿态与先验的正则，无任务特定项；CEM 以先验初始化，N=64、H=1.0 s、约 2 Hz；GPU 每次重规划 1.4 s，CPU 并行 68±4 ms。
- **仿真结果（§IV，表 III）：** 每格 90 个配对回合。Track 上 CEM 单独 37.8%，先验 82.2%，先验+CEM 77.8%；精修使五项任务的 EE 姿态误差均下降（如 Track 17.6°→11.5°）；加到预训练 SONIC 上，五项任务中四项成功率提升 1.1–3.4 个百分点。消融：B1（无目标/力采样）与 B2（无力采样）在推力任务上明显弱于完整方案（如 Crouched Push 跌倒口径成功率 4.4% / 16.7% / 48.9%）。
- **实机（表 IV）：** G1 上各条件 10 次试验，OCLO(先验) 在躯干/末端推拉、侧拉大多 8–10/10，B1 在末端拉与侧拉为 0–1/10；另演示七项任务（蹲行、低处取箱、推拉车、擦拭等）。无腕力传感器，外力由电机力矩估计。
- **局限（§V，原文自述）：** 姿态接口仅控制骨盆高度与躯干俯仰/横滚，不含站距、落脚与步态时序；手臂冗余由微分 IK 单独处理，奇异附近可能退化；策略在环精修依赖仿真机器人模型并运行在离板 CPU；上游学习式策略留作未来工作。
