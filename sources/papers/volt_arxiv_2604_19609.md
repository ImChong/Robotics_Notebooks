## 原文核对摘录

### 1. 骨干（§3）
- 点云体素化，非空的 P×P×P 立方 patch 内缺失体素填零，展开后共享线性投影为 token；彻底空 patch 不入序列。
- 标准 pre-norm Transformer block + **全局 self-attention**；3D RoPE 将旋转频率按 x/y/z 三轴分配，保持相对位置与场景内米制相容性。
- 轻量 decoder：token 特征恢复至原体素/点特征，再使用线性分割头；不依赖复杂的 U-Net 多层编码器。
- **对 wiki 的映射：** [Volt 实体](../../wiki/entities/paper-volt.md) — 主流程与代码位置。

### 2. 训练配方（§4）
- 朴素训练比 PTv3 更易过拟合，加入 **强 3D 增广→DropPath/AdamW 等正则→3D U-Net 教师预测蒸馏→室内/室外各自联合训练**。
- ScanNet200 配方进展（mIoU）：Volt **31.0→32.9→34.1→36.2→38.1→40.0**，不能将不同训练阶段的结果混成同一设定。
- 蒸馏损失：**0.5×真实语义标签 CE + 0.5×教师 hard-label CE**；此论文是**监督语义分割**骨干，不等同 VINO 的无语义标签 SSL。
- **对 wiki 的映射：** [Volt 实体](../../wiki/entities/paper-volt.md) — 训练路径与 VINO 比较。

### 3. 评测与消融（§5）
- 多数据集联合训练 Volt-B 在 ScanNet、ScanNet200 室内验证集分别 **80.5/40.0 mIoU**；nuScenes **82.2 mIoU**（官方 README 的最终模型表）；Waymo Volt-B **73.7 mIoU**（README 的联合训练实验）。
- Volt-B 的 ScanNet 测试 **80.5**，ScanNet200 测试 **41.6**，数值应与 val 区分。
- 论文称在 ScanNet 上 Volt-B 相对 PTv3-S **2× 速度 / 38% 更少显存**，这取决于测量硬件与实现，不能泛化到任意硬件。
- patch 消融 P=3 / 5 / 7：ScanNet200 **37.7 / 36.2 / 33.5 mIoU**；运行时间 **67 / 27 / 26 ms**，精度-速度权衡。
- 3D RoPE 优于 Fourier 位置编码（ScanNet200 36.2 vs 28.6）。
- **对 wiki 的映射：** [Volt 实体](../../wiki/entities/paper-volt.md) — 原文数字及协议边界。

### 4. 代码核验（官方 main 分支，2026-11-13）
- [scripts/train.sh](https://github.com/YilmazKadir/Volt/blob/main/scripts/train.sh) 接收 -d/-c/-n/-g，拷贝代码到 exp 目录并启动 tools/train.py。
- [tools/train.py](https://github.com/YilmazKadir/Volt/blob/main/tools/train.py) 解析配置 → launch(main_worker) → 构造 trainer → trainer.train()。
- [pointcept/engines/train.py](https://github.com/YilmazKadir/Volt/blob/main/pointcept/engines/train.py) 的 Trainer.run_step 将 batch 传入模型并计算 loss/反向传播。
- [pointcept/models/default.py](https://github.com/YilmazKadir/Volt/blob/main/pointcept/models/default.py) 的 DefaultSegmentorV2 调用 backbone 及分类头、可选的 teacher 蒸馏分支。
- [pointcept/models/volt/volt_base.py](https://github.com/YilmazKadir/Volt/blob/main/pointcept/models/volt/volt_base.py) 的 Volt.forward：Tokenizer → RoPE / attention blocks → Decoder；[decoder.py](https://github.com/YilmazKadir/Volt/blob/main/pointcept/models/volt/decoder.py) 将 patch token 映回点特征。
