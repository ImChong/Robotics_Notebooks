- **标题：** FRoM-W1: Towards General Humanoid Whole-Body Control with Language Instructions
- **类型：** site / project-page

- **平台：** Unitree H1、G1

## 一句话摘要

FRoM-W1 将语言驱动的人体全身动作生成、机器人动作重定向、强化学习运动跟踪与 RoboJuDo 仿真/真机部署串成完整的人形全身控制流程。

## 项目页核查

- 官方页面与 [OpenMOSS/FRoM-W1](https://github.com/OpenMOSS/FRoM-W1) 仓库相互指向；论文与项目页链接可从官方仓库 README 找到。
- 项目仓库公开 H-GPT、H-ACT、初始模型检查点、数据处理与部署相关代码；受数据集许可限制，README 说明部分数据不能公开共享。
- 项目页将 [RoboJuDo](https://github.com/HansZ8/RoboJuDo) 作为独立的部署模块提供。RoboJuDo 自己的 README 也标明其属于 FRoM-W1 项目。
- 本项目属于**代码与模型部分开放**：论文工作流、代码及部分 checkpoint 可获取，数据并非全部开放。部署框架有独立仓库，模块和策略的具体支持状态以各自 README 为准。
