## 文章转述（微信文章，机器之心 2026-10-16）

> 以下为对文章原文的转述，标注「文章转述」，非论文原文。

- **文章转述：** FTP-1 归入「主线三：以触觉为锚」，被称作「这一判断最直接的验证」——触觉所隐含的操作过程（如拿杯子用多大力）与本体无关，可以成为跨本体学习的锚点。
- **文章转述：** 工作由清华大学、Sharpa、上海交通大学、伯克利、苏黎世联邦理工学院、复旦大学等机构共同完成，提出跨触觉传感器的通用触觉基础策略。
- **文章转述：** 难点是触觉传感器异构（有的输出图像，有的输出阵列，有的输出力和状态）；FTP-1 把它们映射到同一隐空间，由统一 Transformer 处理，在约 3000 小时、来自 21 种触觉传感器的数据上预训练。
- **文章转述：** 在预训练见过的传感器配置上提升 17.2%；在两种从未见过的传感器配置上成功率提升 31%；不含触觉数据的对照模型 NTP-1 在迁移任务上弱于 FTP-1，说明大规模触觉预训练学到了跨本体、跨传感器可复用的表征。
- **文章转述：** 文章把 EgoScale、T-Rex 并入同一主线，认为它们走另一条思路：不显式处理人机差距，直接用第一视角人类数据加成对人机数据做中期训练。

## 核心摘录（归纳，非全文）

1. **arXiv 摘要：** 现有触觉策略绑定固定本体与传感器配置，因为触觉信号跨硬件高度异构。FTP-1 用异构编码器把图像、阵列、状态三类触觉输入投影到统一的形态感知隐 token，由共享的触觉 Transformer 专家联合建模。
2. **arXiv 摘要：** 预训练数据约 3000 小时，汇集 26 个数据源、涵盖人类与机器人示范、21 种传感器；在跨 5 种硬件配置的下游微调实验中，已见传感器配置提升 +17.2%，并「出乎意料地」迁移到两种从未见过的触觉传感器配置，成功率提升 +31%。
3. **项目页：** 亮点自述 sensor-general、data-scaled、embodiment-transferable 三点；Teaser 写未见传感器配置上「+31.6% gain」；预训练配比约 20% 人类、30% 灵巧手、50% 夹爪；语言指令由外部大语言模型改写以增加多样性。
4. **项目页：** 架构为多专家基础策略——视觉语言专家、动作生成专家，以及跨传感器共享的触觉专家；MTTS 把三类触觉观测映射成语义对齐的 token，并加功能区嵌入。
5. **文章转述：** 「FTP-1 把这些不同形式的输入映射到同一个隐空间，再由一个统一的 Transformer 处理，在约 3000 小时、来自 21 种触觉传感器的数据上完成预训练。」

## 论文正文要点（PDF v1 与 v3 对读，自行阅读；数字均为论文自报）

> 此节取自论文 PDF 正文，不属于上面三类摘录来源，单列便于核对。Table 1–3 在 v1 与 v3 中数字一致；v3 新增第 4.3 节与附录 F。

- **MTTS：** 24 个功能区各用一个 token——槽位 0–14 为手内触觉功能区，15–20 为腕 / 指力矩信号，21–23 预留；平行夹爪两侧传感器映射到拇指尖槽（0）与食指尖槽（1）；所有传感器共享可学习功能区嵌入，左右手各用独立嵌入。
- **异构编码器：** 图像类用传感器专属轻量 ViT（深度 3、宽度 768）接共享的预训练 T3 Transformer 主干（深度 9、宽度 768），取 [CLS] 为触觉 token；阵列类用傅里叶编码 + 3 层 CNN + MLP；状态类用傅里叶编码 + MLP。
- **融合：** 基于 π0.5，触觉由独立的约 300M 参数 Transformer 专家处理（宽度 1024、深度 18）；v3 附录写明三个专家（视觉语言、触觉、动作）的块注意力掩码——动作专家可读两路感知，两路感知专家各自只看自己的流；本体状态经自适应 RMSNorm 注入；更复杂的 MoE 融合没有带来一致增益。
- **统一动作空间（UAS）：** 定长稀疏向量，含左右臂、头部与补充槽位，手部关节用 UniDex 的 FAAS 把功能相近的关节放到同一槽位，缺失维度在损失中掩码。
- **数据：** 26 个来源、21 种传感器（图像 7、阵列 5、状态 9）；新采 Sharpa North-FTP-1 约 4000 条长程灵巧示范；重采样后人类 / 灵巧手 / 夹爪约 20% / 30% / 50%，合计约 3000 小时。
- **训练：** 视觉编码器、分词器、视觉语言专家、动作专家用 π0.5 初始化，触觉编码器、触觉专家、AdaRMS 注入器、动作投影从零训；预训练 48 张 NVIDIA H20、50k 步、全局 batch 768、学习率 1e-4 衰减到 5e-5，论文称 50k 步后饱和；微调 8 张 A800、每数据集 20k 步、batch 64。优化器用 AdamW（Muon 收敛更快但真机泛化变差）。
- **评测协议：** 检查点分发给 5 个独立机构，共 4 种触觉传感器、14 个任务；仿真每任务 100 次、真机每任务 20 次；基线 π0.5、Tactile-VLA、FTP-π0.5（同架构、无 FTP-1 预训练），均基于 π0.5 代码库。
- **Table 1（UniVTAC 仿真，成功率 %，平均 / 去掉 Lift 两项平均）：** VITaL* 36.33 / 34.5；UniVTAC-ACT* 43.00 / 39.5；π0.5 49.16 / 31.5；Tactile-VLA 41.83 / 34.75；FTP-π0.5 45.16 / 42；FTP-1 **66.66 / 59.5**（*为原基准报告值；Lift Bottle、Lift Can 无触觉即可大部分解决，π0.5 分别 97%、72%）。
- **Table 2（真机已见传感器，成功率 %，平均）：** π0.5 45.3；Tactile-VLA 35.8；FTP-π0.5 41.6；FTP-1 **62.5**（Sharpa North 的 Draw Balloon / Fix Hand 撕贴纸 / Fix Hand 完成 / Twist Cap 为 45 / 80 / 40 / 65；Sharpa&Dexmate 的 Flip Book / Wipe Dish 为 85 / 60）。
- **Table 3（真机未见传感器，成功率 %）：** FlexivXense 的 Insert Hanoi / Insert USB、TactileUMI 的 Wipe Board——π0.5 为 25 / 0 / 20（平均 15.0）；Tactile-VLA 0 / 10 / 15（8.3）；FTP-π0.5 5 / 10 / 30（15.0）；FTP-1 **55 / 30 / 55（46.6）**。+31.6 是 46.6 与 15.0 的百分点差。
- **NTP-1 消融：** 同样预训练数据、去掉触觉输入与触觉相关结构，微调时再接入同样触觉结构；UniVTAC 平均 50.00（去 Lift 36.5）低于 FTP-1 的 66.66（59.5）；FlexivXense 上 FTP-1 比 NTP-1 高 37.5 个百分点（论文文字，图 7 数值本页未转录）。
- **v3 新增分析：** 匹配 VLA 预训练基线（π0.5 在同样机器人轨迹与预训练预算上继续预训练）UniVTAC 平均 57.0、去 Lift 44.0，FTP-1 高 9.7 / 15.5 个百分点；预训练预算联合缩放（数据与步数同比例）——0%、50%、100% 的平均为 45.2、59.0、66.7，去 Lift 为 42.0、46.0、59.5；冻结特征探测——slip F1 由 T3 的 0.725 升到 FTP-1 主干 0.780、tokenizer 0.786（参考 SPARSH-MAE 0.922），力估计 MAE 在 T1 上与 T3 相当（0.106 / 0.107 / 0.116 N）、在 FeelAnyForce 上反而更高（0.273 / 0.314 / 0.424 N，参考 0.041 N）。
- **局限（论文自述）：** 主要做通用触觉感知，尚未覆盖触觉 / 力伺服控制；预训练数据规模与多样性仍有限。
