## 项目内容

项目页提供论文 PDF、方法架构图、实验图表、技术参数和真实机器人演示视频。REDACT 用深度图感知四足运动，结合 teacher–student 训练、持续特征遮蔽和共识门控，目标是在训练未覆盖的深度图损坏下保留可用地形信息。

## 开源状态

**研究实现未公开。** 官方 GitHub 仓库 README 说明仓库内容是项目网站、论文、图片和演示视频；网页提供训练与门控的实现细节，但未提供算法训练或部署代码。仓库没有声明代码许可证。项目页的公开信息不能等同于完整可复现的研究代码。
