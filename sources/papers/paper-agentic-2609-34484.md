## 原文核对笔记

### 1. 研究背景与核心问题（§1–§3.1）

1. **进度奖励建模（Progress Reward Modeling）的难点：** 离线机器人轨迹常包含混合质量片段——成功轨迹里夹杂失败尝试，失败轨迹里也可能保留可复用的中间操作。准确估计每帧进度 $p_{0:T} = f(\mathbf{o}_{0:T}, l) \in [0, 1]^{T+1}$ 必须区分有效状态推进、失败尝试与任务无关动作。
2. **局部前瞻与语义错配：** 许多单步或局部片段（如手指靠近物体）仅凭截至 $t$ 的观测 $\mathbf{o}_{0:t}$ 存在歧义，需要借助后续帧确认是否真正抓起或完成放置；同时即便是专门训练的奖励模型，在简单两物体桌面场景中也会给错误物体的流畅操作赋予虚假高进度。
3. **ARS 定位：** 不做任何额外奖励模型训练，直接面向通用视觉语言模型（VLM）设计推理工作流（主实验采用开源权重 `Qwen3.6-27B`），在离线轨迹上通过自适应视觉检查、可编辑事件时间线与跨智能体独立验证来生成逐帧进度，并支持可选终局标签、多模态参考例与外部奖励曲线审计。

### 2. 核心架构与脚手架约束（§3.2–§3.7, Appendix A–B）

1. **自适应视觉检查（§3.2, `inspect_visual`）：**
   - 直接把整段长视频一次性喂给模型容易漏掉短暂状态跳变或混淆失败尝试与后续成功操作。
   - 智能体通过 `inspect_visual` 按当前未决问题自主选择时间窗口、采样密度与可选空间裁剪（返回视频片段或图像拼图及证据 ID/帧号），支持回溯后续帧来印证早期抓取是否成功。
2. **基于事件的时间线推理与覆盖门禁（§3.3）：**
   - 轨迹被表示为任务相关事件时间线（工具接口中称为 `observations`），每个事件记录起止帧区间、视觉证据驱动的状态描述、引用证据 ID 及 1–5 级置信度。
   - 脚手架（harness）强制两项不变量：（a）创建或修订事件时，引用证据必须完整覆盖该事件区间；（b）提案阶段结束前，事件集合必须无遗漏覆盖整条轨迹，否则调用被拦截并返回缺失区间提示重试（Appendix B 给出 `LIBERO` 520 帧轨迹的重试实例）。
3. **跨智能体独立验证（§3.4, Appendix A）：**
   - **子智能体（Subagent）：** 在独立上下文中浏览完整视频（若超输入上限则分段检查）并构建初始事件时间线。
   - **主智能体（Primary agent）：** 在**独立推理上下文**中仅接收提案时间线（不继承子智能体完整工具交互历史，在 LIBERO-Long 上使单次查询平均输入 token 从 57.6K 降至 41.4K，降幅 28.1%，见 Table 14），逐事件重新调用 `inspect_visual` 检查事件内部及前后相邻上下文，执行 `revise_observations` / `merge_observations` / `confirm_observations`。每次修订都会重置确认状态，强制重新核验。
4. **逐帧进度估计与曲线编辑（§3.5, Appendix A.2）：**
   - 内部进度以 $[0, 1000]$ 整数表示（对应 $[0, 1]$ 归一化进度）。
   - 主智能体基于已确认事件调用 `edit_progress_segments`（区间插值或局部点编辑，支持上升、平台保持与回退下降）与 `calibrate_progress_curve`（两锚点全局仿射校准），并用 `read_progress` / `summarize_progress` 检视跳变点与幅度，经 `validate_progress`、`write_summary`、`complete_stage` 顺序落盘。
5. **辅助信息接入与外部奖励审计（§3.6）：**
   - **终局结果标签（Terminal outcomes）：** 用轨迹级成败标签约束终点完成度，同时保持中间段落的真实波动（Appendix E.5 显示条件化后成功轨迹仍保留 21.45% 非递增区间，失败轨迹仍保留 23.38% 递增区间）。
   - **上下文参考（In-context references）：** 支持正/负图文示例澄清任务标准，无需数值进度标注。
   - **外部奖励审计（External reward auditing）：** 读取外部曲线（如 Robometer 预测）并针对可疑跳变/终值触发视觉复查与局部重写。
6. **进度引导的策略学习（§3.7）：**
   - 对长度为 $H$ 的动作块计算进度增量 $\Delta_t = p_{t+H} - p_t$，构造二值筛选指示 $I_t = \mathbb{1}[\Delta_t > \epsilon(p_t)]$，按均匀或分层采样优化二值加权行为克隆损失 $\mathcal{L}_{\mathrm{BC}}(\theta)$（Eq. 4）。
   - 两种阈值规则：零阈值 $\epsilon(p_t) = 0$（LIBERO-Long 仿真对比使用）；分阶段阈值（将 $[0, 1]$ 划分为 $B=8$ 个等宽分桶，每桶保留 $\Delta_t$ 前 $\alpha=30\%$ 的动作块，真实机械臂实验使用）。

### 3. 实验设计与核对数据（§4, Appendix C–G）

1. **语义错配基准（Semantic-Mismatch Benchmark，§4.1, ManiSkill）：**
   - 基于改造版 RL4VLA 在 ManiSkill 生成桌面两物体 pick-and-place 运动规划专家轨迹，共 25 类物体、**500 对轨迹（1,000 个样本）**，平均 **31.7 帧**；特权状态验证夹爪从未接近错配物体。
   - 指标：**VOC**（正确指令下的进度与时间 Spearman 秩相关）、**FPSR**（错配指令下无严格正增量的时长占比，Eq. 5，主指标容差 $\eta=0$）、**CMPG**（正确指令终值均值减错配指令单轨迹峰值均值，Eq. 6）。
   - Table 1 核心结果：ARS + Qwen3.6-27B 达 **VOC 0.995 / FPSR 0.918 / CMPG 0.904**（Table 10 显示 EPCR 为 **0.908**）；Robometer（4B）为 **0.983 / 0.240 / 0.366**，经 ARS 审计后提升至 **0.988 / 0.915 / 0.891**；TOPReward + Qwen3-VL-32B 为 **0.945 / 0.383 / 0.756**（概率尺度 CMPG）；R²VLM 为 **0.916 / 0.184 / -0.050**；SOLE-R1 为 **0.902 / 0.361 / 0.266**；LRM 为 **0.828 / 0.893 / 0.373**（但 Table 10 显示 EPCR 仅 0.159）。
2. **仿真策略学习（LIBERO-Long，§4.2, Table 2 & Table 13）：**
   - 固定行为策略采集 **4,096 条**轨迹（2,204 成功、1,892 失败，平均 **390.3 帧**），$\pi_{0.5}$ 预训练权重初始化，$H=10$，30k 梯度步，3 个随机种子，每任务 100 次评测（每检查点 1,000 次）。
   - 峰值成功率（Table 2）：Vanilla BC **44.2±0.3%**（保留 100.0%）；LRM **38.6±0.5%**（13.7%）；R²VLM **41.5±0.4%**（13.6%）；SOLE-R1 **44.8±0.4%**（52.6%）；Robometer **46.8±0.9%**（89.5%）；TOPReward-8B **43.1±0.5%**（77.0%）；TOPReward-32B **47.6±0.7%**（67.9%）；**ARS + Qwen3.6-27B 57.9±0.4%**（+13.7 pp，66.9%）；Success-only BC **52.6±0.7%**（38.5%）；**ARS + outcome 62.2±0.6%**（+18.0 pp，60.3%）；Privileged progress **66.5±0.8%**（57.2%）。30k 末检查点（Table 13）ARS 仍达 **51.6±1.4%**，高于 Robometer 的 **42.1±2.3%** 与 Vanilla BC 的 **40.1±1.8%**。
3. **消融与开销分析（§4.3, Table 3, Table 4, Table 14–17, Appendix F）：**
   - 同在 4B 参数量级下，ARS + Qwen3.5-4B 在语义错配基准达 **0.986 / 0.625 / 0.633**（在 LIBERO-Long 完成率为 99.19%，33/4096 因违反脚手架约束失败；而 Qwen3-VL-4B-Instruct 因工具调用合规失败未能完成流程）。
   - 固定 Qwen3.6-27B 的单轮提示基线（GVL-style）在语义错配基准仅 **0.637 / 0.900 / 0.354**（时间顺序），在 LIBERO-Long 上时间顺序保留 3.58% 块得 **0.0%**，打乱顺序保留 14.80% 得 **34.1±1.1%**（Table 16）。
   - 工作流组件消融（Table 4）：去掉检查与验证为 **45.4±0.3%**；保留检查去掉验证为 **52.3±0.8%**；单上下文自我验证为 **51.8±0.5%**；完整跨上下文 ARS 达 **57.9±0.4%**。相比 TOPReward-32B（390.3 次查询、2,866.3K 输入 token），Full ARS 仅需 **24.9 次查询**与 **980.6K 输入 token**（查询减少 **93.6%**、累计输入 token 减少 **65.8%**），但新增 **21.1K 输出推理 token**。
   - 关闭思考模式（Table 17）：LIBERO-Long 成功率为 **55.4±0.7%**，开启后为 **57.9±0.4%**，说明脚手架中的结构化时间线与证据链路本身已承担核心中间推理作用。
4. **真机工业装配验证（§4.4, Appendix G, Table 5）：**
   - 洗衣机背板三颗螺钉连续拧紧任务（工业产线全尺寸实验台），**2,574 条**演示 + **3,092 条**离线 rollout；$\pi_{0.5}$ 初始化，$H=50$，200k 步，1:1 分层采样，$B=8, \alpha=30\%$，单种子评测 200 轮完整任务（含人工终检确认）。
   - 结果：Demo + all rollouts BC **50.5%** → Demo-only BC **58.0%** → ARS **72.0%** → ARS + 视觉参考（2 正例 + 1 负例图文，无数值标注）**81.5%**（+23.5 pp）；叠加终局标签达 **84.0%**，但相对 81.5% 在 Fisher 精确检验下未达统计显著（$p=0.597$）。

### 4. 局限性（§5, Appendix B, Appendix F–G）

1. 相比单次前向推理模型（如 Robometer），多轮视觉检查与跨上下文生成带来较高推理延迟与输出 token 开销，当前主要面向离线数据筛选与审计而非在线高频控制。
2. 当前为离线非因果估计（依赖后续帧消除早期歧义），向因果在线奖励建模扩展仍待研究。
3. 底层 VLM 在细微操作起止边界定位上仍会受限（Appendix B 中虽将偏差从滞后 39 帧修正为提前 10 帧，仍偏早），且 4B 级别小模型在长程任务上存在工具合规失误风险；真机实验受评估耗时限制仅使用单个训练种子。
