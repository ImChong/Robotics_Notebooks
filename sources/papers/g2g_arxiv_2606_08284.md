## 核心论文摘录

### 1) 问题与动机（Abstract / 项目页）

- **核心任务：** 恢复 **两组图像（image groups）** 之间的 **相对 6-DoF 位姿**；支撑 **跨序列重定位（cross-sequence relocalization）** 与 **多相机 rig 里程计（multi-camera rig odometry）**。
- **组内几何已知：** 每组来自 VO、预建地图或 rig 标定，已有 **intra-group extrinsics**；预训练多视图基础模型（MapAnything / DINOv2）已把几何融进特征。
- **缺口：** 现有方法常把全部视图 **flatten 成无结构集合**，缺少 **跨组推理**；全量微调易 **collapse** 冻结骨干的 3D 表征。
- **对 wiki 的映射：**
  - [G2G 论文实体](../../wiki/entities/paper-g2g.md)
  - [State Estimation](../../wiki/concepts/state-estimation.md)

### 2) G2G 架构（Method / README）

- **冻结骨干：** MapAnything（DINOv2 ViT-L/14，539M）；仓库 **vendored v1.0.1 large/1024**（与 2025-12 后 giant 权重 **不兼容**）。
- **三组轻量可训练模块（共 ~32M，<6%）：**
  1. **Perceiver resampler** — 压缩组内 token；
  2. **Cross-group bridge** — merged self-attention 跨组交互；
  3. **Multi-frame pose head** — 回归相对位姿。
- **监督：** 仅 **relative pose**；不恢复全量原始多任务监督。
- **对 wiki 的映射：**
  - [SE(3) Representation](../../wiki/formalizations/se3-representation.md)
  - [UniSim-SLAM](../../wiki/entities/paper-unisim-slam.md)（同为多视图几何 + 位姿估计栈）

### 3) 两大任务设定

| 任务 | 输入 | 输出 |
|------|------|------|
| **Cross-sequence relocalization** | 不同时间采集的两段短序列（每组多视图 + 组内几何） | 对齐两序列的相对位姿 |
| **Multi-camera rig odometry** | 相邻时刻两帧 **刚性多相机 rig**（4–8 cam） | rig 间 inter-rig 运动 |

- **对 wiki 的映射：**
  - [Navigation·SLAM 栈总览](../../wiki/overview/navigation-slam-autonomy-stack.md)

### 4) 实验与数据集（项目页 / README）

- **四数据集 / 十权重：** HM3D（室内 sim）、TartanGround（户外 sim）、NCLT（真实跨季节）、ZJH（sim-to-real）。
- **Rig 配置：** HM3D 8-cam / 4-cam；TartanGround 4-cam；NCLT 5-cam（intra / cross-season）；ZJH 4-cam（sim + real）。
- **低重叠最难：** NCLT 跨序列 **FoV overlap median 0.24**；G2G 在低 overlap 区间相对 VGGT、LoMa、CoViS-Net、Reloc3R 等 **退化更缓**（项目页曲线）。
- **基线（项目页标注）：** VGGT（up-to-scale）、Reloc3R（Procrustes-aligned）、LoMa、CoViS-Net、MA-AB oracle 等；G2G 在四数据集两任务上报告 **SOTA 级** mean error（详见项目页 Table 1–2）。
- **对 wiki 的映射：**
  - [Glob3R](../../wiki/entities/paper-glob3r.md)（离线全局 SfM 对照）
  - [VGG-T³](../../wiki/entities/paper-vgg-ttt.md)（VGGT 系几何骨干对照）

### 5) 工程与复现（README）

- **环境：** conda python 3.12；CUDA 12.1 torch；`pip install -e ./third_party/mapanything` + `pip install -e .`
- **训练：** `scripts/train_reloc.py`（curriculum）、`scripts/train_rig.py`；4 GPU `torchrun`
- **评测：** `scripts/eval_reloc.py`、`scripts/eval_rig.py`；`examples/` sanity bundle
- **数据预处理：** HM3D 六步 pipeline（轨迹采样 → rig → 渲染 → overlap → window index → 可选 DINO 特征）
- **对 wiki 的映射：**
  - [sources/repos/g2g.md](../repos/g2g.md)

### 6) 局限

- **任务边界：** 估计 **组间相对位姿**，不是端到端 SLAM 前端/回环全栈；依赖 **已知组内几何** 与预构建 overlap/window 索引。
- **骨干钉死：** 必须用 **MapAnything large/1024** vendored 版本；官方 HF 新版 giant 不兼容。
