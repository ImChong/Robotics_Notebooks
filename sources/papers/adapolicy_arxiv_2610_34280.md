## 方法：从动作到动作的训练期预测

1. 观测图像经过冻结的视觉编码器（论文对照 DINOv3 / Qwen3-VL-2B）；Context Adapter 把视觉特征压缩为条件 token，并接入本体状态。
2. 在线 DiT / flow-matching 动作头同时预测当前动作块的速度场与演化潜状态。后者不是未来像素，而是面向后续动作的紧凑表征。
3. 使用**独立采样**的下一动作块噪声与 flow time，将演化状态输入 EMA 参数的展开头，预测真实演示中的下一动作块速度场。
4. 联合损失为当前块 flow-matching 损失加权下一块损失；下一块误差通过演化状态回传到在线头与上下文适配器，EMA 展开头不接收该分支的参数梯度。
5. EMA 权重在在线头优化步后更新。部署只运行在线动作头，不计算训练期下一块损失或展开头；“零推理开销”是**相对同架构基础策略无额外展开推理分支**。

## 实验与消融（论文报告；非本仓库复现实测）

| 设置 | 对照 | AdaPolicy | 读法 |
|---|---:|---:|---|
| MetaWorld 50 任务平均成功率 | 67.8% | 81.2% | +13.4 个百分点 |
| RoboTwin 2.0 Clean 50 任务 | 64.4% | 84.92% | +20.52 个百分点 |
| RoboTwin 2.0 Randomized 50 任务 | 64.5% | 84.04% | +19.54 个百分点 |
| LIBERO 平均成功率 | 92.1% | 95.2% | +3.1 个百分点 |
| 真机耳机装配 | 74% | 86% | +12 个百分点 |
| 真机穿鞋带任务（shoelacing） | 36% | 50% | +14 个百分点 |
| 真机 6 任务平均 | 77.0% | 86.3% | +9.3 个百分点 |

- MetaWorld 消融：基础策略 67.8%；只加未来特征预测 68.8%；下一块展开头冻结 72.0%；展开梯度截断 67.7%；完整 AdaPolicy 81.2%。说明“下一动作块损失透过演化状态回传”的机制重要，不能归因于单纯延长输出序列。
- 训练 FLOPs 开销：hidden size 512 时约 +6%，768 时约 +11%；对应训练显存 13.7→17.1 GB、18.7→23.9 GB。**不可把 FLOPs 增幅误写成显存或实际墙钟时间增幅**。
- 真机：PiPER 机械臂与双 RGB-D 相机；精细任务有纠偏示范，基线与 AdaPolicy 使用相同训练数据；论文列出各任务 rollout 和数据量，数字不应脱离任务协议横向比较。

## 局限及复现边界

- 方法是动作驱动的“预判”训练，不等于在推理时显式渲染未来画面，也不等于具有可用于任意规划的完整世界模型。
- 训练仍需要同一演示轨迹的下一动作块并多做一次展开前向，显存成本不可忽略；性能随训练权重、chunk 大小、机器人平台而变。
- 2026-11-09 官方公开仓库已包含 MetaWorld / RoboTwin 2.0 的训练评测代码；未在该仓库看到完整 LIBERO 或论文真机部署代码。**可复现范围不可等同论文所有表格。**
