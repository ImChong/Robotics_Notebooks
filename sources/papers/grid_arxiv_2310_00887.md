## 核心论文摘录（MVP）

### 1) 问题：专用栈、数据稀缺与缺机器人 Foundation Model

- **链接：** <https://arxiv.org/abs/2310.00887> §1
- **摘录要点：** 机器人 AI 常是 **单任务定制实现**，难泛化；真机多模态数据 **昂贵且稀缺**；缺少像 NLP/CV 那样的 **可复用 Foundation Model** 与配套工具链。
- **对 wiki 的映射：**
  - [paper-grid-general-robot-intelligence-development](../../wiki/entities/paper-grid-general-robot-intelligence-development.md) — 动机与 General Robot Intelligence 定义（learn / compose / adapt skills）

### 2) Foundation Mosaic + LLM Actor–Critic 编排

- **链接：** <https://arxiv.org/abs/2310.00887> §2.1
- **摘录要点：** **Foundation Mosaic** 将 SAM、GroundingDINO、MiDaS、TapNet 等 **现成模型** 与 **控制原语** 组合；**LLM** 选模块、融合多模态输出、**生成可部署代码**；**Actor–Critic 双 LLM** + 仿真反馈循环降低幻觉。
- **对 wiki 的映射：**
  - [paper-grid-general-robot-intelligence-development](../../wiki/entities/paper-grid-general-robot-intelligence-development.md) — 架构 Mermaid 与编排读法

### 3) 数据：AirGen 仿真与 Simulation Feedback

- **链接：** <https://arxiv.org/abs/2310.00887> §2.2
- **摘录要点：** **AirGen**（基于 Microsoft AirSim）面向 **航空** 场景，支持地理真实环境、域随机化、**无限轨迹** 合成；强调 **Simulation Feedback** 等机制把仿真与真机闭环。
- **对 wiki 的映射：**
  - [GRID（General Robotics）](../../wiki/entities/grid-general-robotics.md) — 与 Isaac Sim / AirGen 双仿真后端（现产品文档 v2.1）

### 4) 实验：零样本着陆、RGB 安全集、巡检轨迹

- **链接：** <https://arxiv.org/abs/2310.00887> §3
- **摘录要点：** H3 **视觉自主着陆**（GroundingDINO + TapNet + MiDaS）；H4 **仅 RGB** 的 TTC / 占用与安全速度；H5 **风机巡检**（分割 + 法线 + 路径规划 + 沿轨迹采图）。
- **对 wiki 的映射：**
  - [paper-grid-general-robot-intelligence-development](../../wiki/entities/paper-grid-general-robot-intelligence-development.md) — 结论与 demo 读法
