## 核心技术要点摘录

1. **SID-Set 基准数据集（300K）：**
   - 均衡涵盖三类：**100K 真实图像**（OpenImages V7）、**100K 全合成图像**（用 FLUX.1-dev 基于 Flickr30k/COCO 提示生成，经 5 位专家从 Kandinsky 3.0/SDXL/AbsoluteReality 等候选模型中盲选出拟真度最高者）与 **100K 局部篡改图像**（80K 整物体替换 + 20K 局部属性修改，结合 GPT-4o 抽名词、Language-SAM 取目标掩码、替换词典与 Latent Diffusion 重绘，并辅以过滤后的 MagicBrush 数据）。
   - 另含 **3,000 张三类均衡样本** 的 GPT-4o 辅助生成 + 5 位专家人工质控的多维度文字取证解释（光学/色彩、边缘像素、阴影透视、材质自然性）。
2. **模型架构与两阶段训练（基于 LISA-7B/13B + SAM ViT-H）：**
   - 在多模态词表扩展检测词元（论文记 `<DET>`，开源代码实现为 `[CLS]`）与分割词元 `<SEG>`（`[SEG]`），以 LoRA（`alpha=16`, `dropout=0.05`）微调 LISA，图像统一缩放至 $1024 \times 1024$，在双卡 NVIDIA A100 40GB 上训练 7B（48 h）/ 13B（72 h），数据集按 `7:1:2` 划分。
   - 提取检测隐状态 $h_{\mathrm{det}}$ 经三分类头 $F_{\mathrm{det}}$ 预测 `real / full_synthetic / tampered`（$L_{\mathrm{det}} = L_{\mathrm{CE}}$）。当判定存在篡改时，将 $h_{\mathrm{det}}$ 经线性投影 $F$ 对齐维度作为 Query、分割隐状态 $h_{\mathrm{seg}}$ 作为 Key/Value，通过 **单层 8 头交叉注意力 $\mathrm{MSA}(\tilde{h}_{\mathrm{det}}, h_{\mathrm{seg}}) + h_{\mathrm{seg}}$** 增强分割提示特征，再与冻结 SAM 图像编码器特征 $f$ 共同喂入可训练 Mask Decoder（$L_{\mathrm{mask}} = \lambda_{\mathrm{bce}} L_{\mathrm{BCE}} + \lambda_{\mathrm{dice}} L_{\mathrm{DICE}}$）。
   - **Stage 1** 仅联合优化检测与定位损失（$\lambda_{\mathrm{det}}=1, \lambda_{\mathrm{bce}}=2.0, \lambda_{\mathrm{dice}}=0.5$）；**Stage 2** 追加文字生成交叉熵损失 $\lambda_{\mathrm{txt}} L_{\mathrm{txt}}$ 在 3,000 条精细解释样本上微调 LoRA。
3. **关键定量实验结果：**
   - **SID-Set 三分类检测（Table 2）：** 整体 Acc / F1 上，`SIDA-7B` 达 **`93.5% / 93.5%`**、`SIDA-13B` 达 **`93.6% / 93.5%`**（其中 Tampered Acc/F1 为 `92.7%/91.0%` 与 `92.9%/91.2%`，Fully Synthetic Acc/F1 为 `98.7%/98.6%` 与 `98.5%/98.7%`）；对比重训前后的传统鉴伪基线（如 UnivFD 整体 `51.6%/60.0%`、LGrad 重训后 Tampered Acc 高但误报严重导致整体仅 `51.7%/60.7%`、AntifakePrompt `63.1%/74.2%`），SIDA 在三类混淆下显著领先。
   - **篡改定位（Table 3，Tampered AUC / F1 / IoU）：** `SIDA-7B` 取得 **`87.3 / 73.9 / 43.8`**，超越微调后的 `LISA-7B-v1`（`78.4 / 69.1 / 32.5`）、`PSCC-Net`（`82.1 / 71.3 / 35.7`）、`HIFI-Net*`（`64.0 / 45.9 / 21.1`）与 `MVSS-Net*`（`48.9 / 31.6 / 23.7`）。
   - **扰动鲁棒性与跨域泛化（Table 4 & Table 5）：** 未针对退化训练时，JPEG 70/80、0.5x/0.75x 缩放、高斯噪声（方差 5/10）下检测 Acc 维持 `86.9%–89.9%`、定位 IoU 维持 `41.0–43.5`（干净图 `43.8`）；在 DMimage 跨域基准上，`SIDA-7B` 取得 **`91.8%` Acc / `92.0%` F1**（优于 AntifakePrompt `90.3% / 91.8%` 与 UnivFD `67.2% / 74.8%`）。
   - **注意力融合消融（Table 6）：** 移除 `<DET>-<SEG>` 交叉注意力降为 Detection Acc/F1 `90.3 / 89.9`，替换为 FC 降为 `91.1 / 90.3`，完整 SIDA 达 **`93.5 / 93.5`**。
4. **原文显式局限（§6 & Appendix C）：** 全合成部分仅用单一 FLUX 生成器可能带来域偏置风险；局部篡改虽然有 100K，但在极细微像素级修饰上仍会出现漏出掩码或边缘贴合不足的失效案例（Figure 11）。
