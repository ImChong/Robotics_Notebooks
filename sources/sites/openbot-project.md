# OpenBot 项目页（openbot.org）

> 来源归档

- **标题：** OpenBot: Turning Smartphones into Robots
- **类型：** site（项目页）
- **URL：** <https://www.openbot.org/>
- **论文：** <https://arxiv.org/abs/2008.10631>（归档：[openbot_arxiv_2008_10631.md](../papers/openbot_arxiv_2008_10631.md)）
- **代码：** <https://github.com/ob-f/OpenBot>（归档：[openbot.md](../repos/openbot.md)）
- **开放状态：** 已开源。项目入口链接到公开 GitHub 仓库；仓库提供车体资料、应用、固件和策略训练代码，LICENSE 为 MIT。
- **核查日期：** 2026-10-25
- **一句话说明：** 以约 $50 的四轮车体承载普通智能手机，让手机提供感知、计算与通信，支持跟人和自主驾驶等研究教育任务。

## 项目内容

项目页将 OpenBot 定位为可负担的机器人研究与教育平台。实际复现入口在官方仓库 README：组装车体、烧录 Arduino 固件、安装手机端 Robot App，再按需运行遥控器、OpenBot Playground 或驾驶策略训练。
