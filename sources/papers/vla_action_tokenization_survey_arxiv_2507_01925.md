- **一句话摘录：** 从动作 token 化视角将 VLA 设计分为语言描述、代码、可供性、轨迹、目标状态、隐变量、原始动作和推理八类，分析表示到控制间的接口与取舍。

## 基于当前已核实原文的要点

- 统一视角：视觉和语言经 VLA 模块逐步形成可执行程度更高的动作 token。
- 八种类型是设计分类，不是必须按顺序执行的八阶段流水线。
- §7 将轨迹 token 细分为点轨迹、画面轨迹和光流；可用于定位高层输出对低层控制的接口。
- 边界：综述属于跨论文归纳，不是新 VLA 模型及可直接复现的算法。
