# RoboBench 论文通读（具身大脑 MLLM 认知评测层视角）

> 来源归档（原文通读 · 支撑 `wiki/queries/embodied-eval-benchmark-selection-loop.md`）

- **标题：** RoboBench: A Comprehensive Evaluation Benchmark for Multimodal Large Language Models as Embodied Brain
- **作者：** Yulin Luo, Chun-Kai Fan, ..., Shanghang Zhang（北京大学 / 北京智源研究院等）
- **类型：** paper / benchmark / mllm / embodied-reasoning / evaluation
- **原文：** <https://arxiv.org/abs/2510.17801>（2026-11 通过 arXiv PDF v2 获取全文，pdftotext 通读）
- **一句话说明：** 把 MLLM 当作双系统中的 System 2「具身大脑」，沿操作执行流水线设 5 维度 / 14 能力 / 25 任务 / 6092 QA，并用 MLLM-as-world-simulator 对长程规划打分，同时检验认知分数与下游 VLA 成功率的相关性。
- **核对范围：** 通读正文 §1–§6（含表 1–6、图 1–8）与附录 A–E（含 D.1 人评协议、D.2 评测器鲁棒性、D.3 隐式指令 CoT 消融、D.4 标注噪声鲁棒性、D.5 VLM→VLA 相关性、D.6 错误分类）；附录 F 案例图与 G 的各类 prompt 全文（图 16–31）只浏览了用途与结构，未逐字核对；参考文献列表未逐条核对。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **动机（§1–2）：** 现有具身认知基准三类缺陷：能力覆盖碎片化（只测感知 / 规划 / 反思之一）；任务真实度低（多依赖仿真，或用人类第一视角视频）；规划评测过于简化（多选、BLEU、LLM 打分，无法体现技能-物体依赖与执行顺序灵活性）。
- **五维度（§3.1）：** 指令理解（显式 / 隐式）、感知推理（机器人 / 物体 / 场景 / 任务中心）、泛化规划（跨本体 / 物体 / 视角 / 任务含导航）、可供性预测（静态接触点 / 动态轨迹 / 导航落点）、失败分析（低层执行错误 / 高层规划错误）。
- **规模（表 2）：** 4336 个条目、6092 问题；多选 1895；感知 / 可供性 / 失败为 1205 / 394 / 296；规划 Q1/Q2/Q3 为 1973 / 842 / 1192；Q1 平均 6.75 步。数据来自开源机器人数据与自采，经 MLLM 辅助标注 + 至少一轮人工复核，残余分歧 < 4%；用多数投票剔除"全模型答对"的题并人工复核"全模型答错"的题。
- **执行失败来自真实 VLA rollout（§3.2）：** 低层失败取自 RoboMIND 真实 VLA 回放并由专家标注；高层规划失败因真实数据稀缺，按 REFLECT 协议对正确计划注入扰动（错物体 / 缺步 / 错序 / 错条件）。
- **长程规划指标 Q1（§4）：** 人工标注依赖 DAG G=(V,E)；LongHorizon=(NodeCorrectness+TaskCompletion)/20；节点正确率 = 技能-物体-参数一一匹配比例 ×10；TaskCompletion 由 MLLM 做"世界模拟"四步 rollout（视觉约束分析 → 关键物体状态抽取 → 顺序与并发校验 → 逐步模拟），统计达成关键状态占比 ×10。Q2 次步规划：技能须完全匹配，物体 / 参数按合理性 {0,0.5,1}；Q3 任务状态估计用二分类准确率。
- **评测器可靠性（§5.3，附录 D.2）：** 与人评的 Pearson r=0.83，高于传统 LLM 打分基线的 0.73；4 个评审模型（3 家厂商）× 3 种 prompt 变体，节点级 ICC(2,k)=0.935–0.948，复合级 ≥0.85；标注噪声（修改 10% 节点）下排名保持，但"删除节点"会机械抬高完成率（D.4）。
- **主要结果（§5.1–5.2，表 3–6）：** 评 18 个 MLLM；闭源平均领先开源约 20 分；GPT-5.4 纯文本基线在感知 / 可供性上约 27.12 / 25.61，接近随机，证明题目依赖视觉落地；最佳感知均值 67.32（Gemini-3.1-Pro），可供性 85.70；隐式指令显著弱于显式（如最强模型 79.94→61.38），CoT 改写意图无稳定增益（附录 D.3，仅测前沿模型）；机器人视角理解与时序定位最弱（最佳 53.62 / 50.38）；执行错误诊断最难（最佳 43.71，人类也仅 47.30）而规划错误诊断可达 80.74。
- **规划失败构成（§5.3）：** 执行类 45%、识别类 24%、常识类 25%、模式特定 6%，指向"能写出合理推理、却难落成可执行动作"的感知-动作鸿沟。
- **认知分数与下游 VLA 相关（§5.3，附录 D.5，表 11–12）：** 按 VLM4VLA 协议把 8 个 VLM 微调为 VLA；CALVIN(ABC-D) 与感知推理强相关（物体中心 r=0.884，p=0.0035；场景中心 r=0.833，p=0.0103）；LIBERO-10 与静态+动态可供性相关（r=0.677，p=0.0652，未过 0.05）；导航可供性与 LIBERO 为负相关（r=−0.680）；低层执行错误与两者相关皆弱。论文自述"没有单一通用预测因子，相关性依赖下游环境"；样本仅 8 个模型。
