## 内容范围

仓库按示例类别组织，README 列出定位、建图、路径规划、路径跟踪、感知和课程。示例包含 EKF、UKF 与粒子滤波定位比较、LiDAR 栅格 / NDT 建图、A* / Hybrid A* / Dijkstra 等路径规划，并附带可视化仿真。

## 使用信息

- README 要求 Python 3.13.x，以及 NumPy、SciPy、Matplotlib；运行测试另需 pytest 与 pytest-cov。
- 仓库提供 Docker / VS Code Dev Container 环境说明和 pytest 测试脚本。
- 项目适合作为自动驾驶算法入门和可运行示例参考；其主题是自动驾驶车辆，和本知识库的人形机器人主线属于相邻领域。
