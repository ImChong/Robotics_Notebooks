## 摘录 1：四阶段管线（论文 §3 + 项目页）

| Block | 内容 |
|-------|------|
| 1 粗 avatar | NLF 估 SMPL + SAM3 可见性；DensePose UV 贴图 → FLUX inpaint → 多视角扩散得 4 canonical views → StyleUNet 学 canonical Gaussian maps |
| 2 幻觉监督 | Wan 2.2 + LoRA 身份微调；粗 avatar 结构化转身/坐姿序列渲染 → RF-Inversion 精炼为身份一致监督视频 |
| 3 全 avatar | pose-dependent Gaussian maps；**map pose**（共享）与 **LBS pose**（逐帧优化）解耦吸收扩散多视角不一致；FLAME 头部分路保身份 |
| 4 推理 | 新姿态驱动 + 手机视频重建 3DGS 场景合成（参考 AHA!） |

## 摘录 2：定量结果（Table 1–2，BEHAVE + 50 YouTube）

| 设定 | AHOY PSNR | 最强公开基线（LHM/IDOL 等） |
|------|-----------|------------------------------|
| YouTube 静态 / 遮挡输入 | **22.01** | LHM 19.12；IDOL 17.31 |
| YouTube 动画 / 遮挡输入 | **22.81** | LHM 19.03；IDOL 16.52 |
| BEHAVE novel view | **24.12** | LHM 18.21 |
| BEHAVE novel pose | **22.81** | LHM 16.93 |

消融（BEHAVE novel view PSNR）：完整 **24.12** vs 仅粗 avatar **16.10**；去 RF-Inversion **21.10**；去 map/LBS 解耦 **22.60**；去头身分路 **23.60**。

## 摘录 3：与相关路线差异

- 相对 **LHM / IDOL / MoGA** 等前馈单图 avatar：AHOY 是 **视频 + 重度遮挡** 设定，靠扩散幻觉补未见区域。
- 相对 **Vid2Avatar / GauHuman** 等优化式单目 avatar：假设主体基本可见；AHOY 面向 YouTube 桌挡、互挡等常态遮挡。
- 机器人语境：输出是 **可渲染 3DGS 数字人**，不是关节轨迹；若做人形控制仍需 SMPL → GMR 等下游链。
