## 核心摘录（均出自原文）

- **分层与分类依据：** 任务规划层 → 控制算法层 → 伺服执行层；算法层按建模方式、抗扰能力、数据依赖度分八类，并非平行并列，而是「经典到现代、解析到数据」的演进；前四类显式建模，后四类面向接触、约束、数据补偿、自主习得。
- **鲁棒 vs 自适应：** 鲁棒控制被动抵抗扰动 / 参数偏差（SMC 滑模面 + 高频切换、抖振问题；H∞ 最小化扰动到误差的最大传递增益；μ 综合处理多关节结构化不确定性）；自适应控制主动在线辨识参数（MRAC 参考模型 + 自适应律；A-CTC 在线更新质量 / 惯量；RLS 为基础辨识工具）。
- **CTC：** 前馈（动力学模型抵消惯性 / 科氏 / 重力）+ 反馈（如 PID）；缺点是依赖精准参数，模型失配时性能大幅下降。
- **力控：** 纯位置控制不适用于接触任务；阻抗调节末端等效刚度阻尼，导纳是对偶（力入、位置修正出），力位混合按任务坐标系解耦（自由方向位控、约束方向力控），直接力反馈直接闭环接触力。
- **优化型：** MPC 滚动时域，只执行第一步并重新优化，天然处理约束；ILC 利用上一批次误差做前馈，适合重复轨迹。
- **学习型：** 监督式补偿（NN、GP 带不确定度、模糊规则、聚类故障补偿）依赖标注数据；RL 无需标注，靠奖励交互试错，分支含值函数（Q-Learning/DQN）、策略梯度（PPO 为工业最常用、TRPO、A2C/A3C）、基于模型（PILCO、Dreamer）、分层、鲁棒 / 自适应 RL、模仿学习（BC/GAIL）预训练再 RL 微调。
- **融合与结论：** 工业臂「CTC + SMC + ILC」，人形「MPC + RL」；ML/RL 的成功建立在稳定伺服电流环和有效动力学补偿之上；「控制不是选择题，而是系统集成题」。
