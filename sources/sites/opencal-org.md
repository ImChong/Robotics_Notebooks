# OpenCAL — 官方项目与文档

- **标题：** OpenCAL: A Comprehensive Guide
- **类型：** project site / documentation
- **维护组织：** Computed Axial Lithography（UC Berkeley）
- **项目文档：** <https://opencal-org.readthedocs.io/en/stable/>
- **项目源码：** <https://github.com/computed-axial-lithography/OpenCAL>
- **论文：** <https://arxiv.org/abs/2509.02865>
- **入库日期：** 2026-10-23
- **一句话说明：** OpenCAL 是面向研究、教育与创客空间的开源计算轴向光刻（CAL）打印机项目，文档覆盖打印流程、硬件搭建、校准、树脂与软件操作。

## 项目页核查

项目文档与 GitHub 组织页面将 OpenCAL 指向计算轴向光刻打印机。官方源码包括 Raspberry Pi 5 打印机控制软件、硬件设计、Tomo 图形前端与 VAMToolbox 投影优化库。OpenCAL 论文介绍其低成本、模块化打印与后处理设计。

## 页面要点

- 树脂容器旋转，投影仪沿角度序列投射预先计算的图像；累积光剂量使目标体积固化。
- Tomo 用于将模型和打印参数转为打印投影视频；VAMToolbox 提供投影计算与优化。
- 构建文档介绍光学、机械、电子装配与校准。具体配置和材料参数应以当前项目文档为准。
