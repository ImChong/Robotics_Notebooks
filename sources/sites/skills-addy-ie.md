## 一句话摘要

Addy Osmani 维护的 **Agent Skills** 落地页：以 **DEFINE→PLAN→BUILD→VERIFY→REVIEW→SHIP** 生命周期映射 9 个 slash 命令，宣传 25 项可验证工程技能、anti-rationalization 与 `/ship` 多 persona 并行评审。

## 公开信息要点（截至入库日 2026-09-19）

- **一键安装：** `npx skills add addyosmani/agent-skills`（宣称兼容 70+ agents：Claude Code、Codex、Cursor、Copilot 等）。
- **生命周期命令：** `/spec`、`/plan`、`/build`（含 **`/build auto`** 单次批准全自动实现）、`/test`、`/constraints`、`/review`、`/webperf`、`/code-simplify`、`/ship`。
- **技能设计：** Process + Verification + Anti-rationalization 表；progressive disclosure（`references/` 按需加载）。
- **工程文化来源：** README 明示嵌入 Google 工程实践（Hyrum's Law、Beyoncé Rule、trunk-based、Shift Left 等）。
- **对照文档：** [docs/comparison.md](https://github.com/addyosmani/agent-skills/blob/main/docs/comparison.md) 与 Superpowers、mattpocock/skills 并排比较。
