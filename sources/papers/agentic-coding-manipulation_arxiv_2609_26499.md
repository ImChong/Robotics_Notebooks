# Generalizing Manipulation Skills with a Local Coding Agent

- **类型：** paper
- **arXiv：** <https://arxiv.org/abs/2609.26499>
- **项目页：** <https://rtalwar2.github.io/agentic-coding-for-robot-manipulation/>
- **入库日期：** 2026-09-23
- **索引来源：** [具身智能小站 12 篇盘点](../blogs/wechat_embodied_station_12_papers_collab_wm_2026-09-23.md)（<https://mp.weixin.qq.com/s/ZYnIkrJ-9H5KQw2z-AT0qQ>）
- **一句话说明：** 本地 Qwen3.8-27B + coding-agent harness 控制 UR3e，自行编写/调试代码；9 玩具任务 45 次试验完成 30 次泛化。

## 核心摘录

1. 本地 Qwen3.8-27B + coding-agent harness 控制 UR3e，自行编写/调试代码；9 玩具任务 45 次试验完成 30 次泛化。
2. 固定动作接口或训练策略换任务成本高；探本地 VLM 能否用已文档化 procedure 泛化到新颜色/尺寸/组合。
3. 15.8h 机器人时间；成功复做后时长与 token 约减半；平台/agent 代码明确不发布。
