| 数据 / 权重 | **不适用** — Mermaid 是绘图语法与渲染工具，不是模型或数据集 |

## 页面要点

- Mermaid 用 Markdown 风格文本描述图表，渲染器将定义输出为 SVG。
- Live Editor 支持即时预览；官方文档列出 flowchart、sequence、state、class、ER、Gantt、mindmap、timeline 等图类型。
- Mermaid 集成可用于 GitHub 等 Markdown 平台；具体渲染能力受宿主产品及其版本影响。
- 新官方入口为 mermaid.ai/open-source；旧 mermaid.js.org 首页提示迁移信息，归档时引用新文档 URL。
