## 核心论文摘录（MVP）

### 1) 问题：参数体 + LBS 是可动画 3D 人的表征瓶颈

- **链接：** <https://arxiv.org/abs/2606.31981>（§1 Introduction）
- **摘录要点：**
  - 单目可动画数字人仍大量依赖 SMPL 等参数体与 **Linear Blend Skinning (LBS)**。
  - 训练期用 LBS 把规范表示映到姿态空间做渲染监督 → 拟合误差污染规范学习。
  - 推理期单目 3D 姿态估计病态，关节误差放大成时序抖动与几何伪影。
  - LUNA 去掉参数体驱动，直接学 **2D → 3D 高斯形变**。
- **对 wiki 的映射：**
  - [LUNA 论文实体](../../wiki/entities/paper-luna-universal-3d-human-animation.md) — 问题设定与 LBS 瓶颈。
  - [SMPL-X](../../wiki/concepts/smpl-x.md) — 本库默认人体中间表征；LUNA 是对照的 LBS-free 外观动画路线。

### 2) 架构：Identity Encoder + 解耦 Implicit Neural Animator

- **链接：** <https://arxiv.org/abs/2606.31981>（§3 Method）
- **摘录要点：**
  - 输入：\(N=4\) 张未标定多视角身份图 + 一张 2D 驱动图（训练时随机抽 RGB / 关键点 / 草图）。
  - **Identity Encoder**：Sapiens 抽身份 token；\(K=8192\) 个模板顶点 query + 语义嵌入；MM-Transformer 融合成规范高斯 \(g=\{\mu,q,s,\alpha,c\}\)。
  - **Implicit Neural Animator**：DINOv3 抽运动 token（对非写实驱动更稳）；MLP 预测全局 \(R,T\)（旋转用连续三角函数，平移用数据集反归一化）；再预测 per-Gaussian \(\Delta\mu,\Delta q,\Delta c\)，尺度与不透明度固定。
  - 姿态高斯：\(\mu_p=R(\mu+\Delta\mu)+T\)。训练身份匹配，推理可跨身份、跨模态。
- **对 wiki 的映射：**
  - [LUNA 论文实体](../../wiki/entities/paper-luna-universal-3d-human-animation.md) — 流程总览与核心机制。
  - [2D→3D 语义提升 Gap](../../wiki/concepts/2d-to-3d-semantic-lifting-gap.md) — 2D 驱动直接抬 3D 形变的歧义与正则。

### 3) 混合监督：LBS 教师蒸馏 + 标注/无标注重加权

- **链接：** <https://arxiv.org/abs/2606.31981>（§3.3 Hybrid Supervision）
- **摘录要点：**
  - 先把 LHM 扩成多视角 **MV-LHM** 训 Identity Encoder，再训 Animator。
  - 全样本光度损失 \(\mathcal{L}_{render}=L_1+L_{mask}+L_{LPIPS}\)。
  - 有参数标注时，LBS 教师给 \(\hat\mu,\hat q,\hat c\) 做蒸馏；全局旋转直接监督，平移改用高斯中心 2D 重投影，避免深度轴误差主导梯度。
  - mini-batch 固定标注:无标注（如 \(1:5\)），\(\lambda_{distill}\) 与标注比例成反比（如 5）。去掉蒸馏会出现扁平塌缩。
- **对 wiki 的映射：**
  - [LUNA 论文实体](../../wiki/entities/paper-luna-universal-3d-human-animation.md) — 监督与消融。

### 4) 数据、训练代价与评测数字

- **链接：** <https://arxiv.org/abs/2606.31981>（§4 Experiments）
- **摘录要点：**
  - 四源：Video35K（野外，与 Sapiens 同源）、iPhone1K（专有）、Cloth10K（由 Video35K 条件生成、松衣）、Dome（200 相机棚拍 900 ID，专有）。合计 **>36k 身份、3.7M 帧**。
  - Stage 1：64×A100、30k iter、\(4\times10^{-4}\)；Stage 2：Dome、16×A100、\(1\times10^{-4}\)。模板用 **MHR**。
  - Cloth10K：LUNA PSNR **22.072** / LPIPS **0.131**，优于 MV-LHM 20.124 / 0.158 与优化式 ExAvatar 19.533。
  - NeuMan 紧身步行：LUNA 26.819，与 MV-LHM 26.832 相当；优化式 ExAvatar 31.270 仍更高。
  - 跨身份：LUNA 26.800 ≈ 自驱动 26.819；2D 关键点误差 **17.3%** vs LHM/MV-LHM **26.7%**。
  - 运动平滑：MSJ **0.0032** vs MV-LHM **0.0144**（约 **4.5×**）；MAE **0.0225** vs 0.0477。
- **对 wiki 的映射：**

  - [人形训练数据管线](../../wiki/queries/humanoid-training-data-pipeline.md) — 数字人外观数据层，不是关节参考运动。

### 5) 开源与机器人边界

- **链接：** <https://penghtyx.github.io/LUNA/>（2026-09-05 源码核查）
- **摘录要点：**
  - 项目页有注释掉的 `GitHub` 按钮（`href="#"`），无 Hugging Face / 权重入口；arXiv 按钮也未绑具体 abs。
  - 论文未给出可运行仓库。训练数据 Video35K / iPhone1K / Dome 为专有或同源受限集合，Cloth10K 为派生集。
  - 输出是 **posed 3D Gaussians + 渲染**，不是 SMPL/MHR 关节轨迹，不能直接喂 [GMR](../../wiki/methods/motion-retargeting-gmr.md)。
  - 局限：驱动视频强遮挡会抖；极端姿态或体型差仍会伤跨身份；无显式时序建模。
