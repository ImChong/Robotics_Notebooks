  2. *Learning Loco-Manipulation From SMPC Demonstrations With Sparse Offline-to-Online RL*（Schuck 等，RAI Institute / TUM / ETH，arXiv:2608.12063v2，2026-10-26，CoRL 2026）

## 核心摘录（均出自原文）

### 论文 1：MPC-RL（arXiv:2606.05687）

- **架构：** 训练时每个环境用质心动力学 MPC（CD-MPC，状态为 CoM 位置、线动量、角动量，输入为接触力 / 力矩，约束含接触旋量锥与摩擦金字塔）预测未来轨迹，把若干"预测地标"转成 PPO 的奖励；部署时只跑策略，**不跑 MPC**。
- **预测置信加权：** 取 5 个地标，权重按时域单调递减 α = {0.5, 0.25, 0.15, 0.07, 0.03}（近处更可信，远处受模型失配与积分误差影响更大）；奖励为单个指数项 exp(−Σα_ℓ‖e_ℓ‖²/σ²)。极限情形 α=(1,0,0,0,0) 退化为只跟下一步 MPC 预测，α 均匀则是时间平均的轨迹跟踪。
- **πⁿMPC 求解器：** 在 πMPC 的"时域并行 ADMM"基础上，改成速度形式（优化输入增量）加三变量拆分，使每个时域结点的更新可并行、无需组装稀疏 QP（"construction-free"）；PyTorch 与 JAX 实现。与 qpax、qpth、CusADi（符号编译约 1.5 小时，N=10 需 150 GB 内存）、consensus ADMM 对比：随并行环境数与时域增长扩展性更好，N=400（H=28 s）仍可行，其他方法或超时或显存不足。
- **训练设置：** rsl-rl PPO，mjlab，4096 环境；物理 200 Hz、控制 50 Hz；动作 29 维关节位置增量 + PD；演员只看本体感知 + 速度指令 + 步态相位时钟；评论家额外获得无噪声状态与 MPC 预测的 CoM / 角动量。训练到 15k 迭代 < 6 小时。PD 增益按有效惯量选取并有意取低自然频率（1–2 Hz，Themis 高惯量低减速比）。
- **结果（Themis V2 人形）：** N=10（一个完整步态周期）、10 Hz 更新为最佳配置——时域更长并不单调更好、更高 MPC 频率收益递减。论文文字称 MPC-RL 各变体在含分布外指令的速度跟踪上一致优于纯 RL、在所测各推扰方向的最大可恢复推力上也优于纯 RL（表 II 的 PDF 文字提取错位，逐格数值未核对）；表 III 中线速度跟踪 RMSE（vx / vy）基线 RL 0.161 / 0.157，tapered 加权 MPC-RL 0.132 / 0.128，next-step 加权 0.170 / 0.190 反而不如基线；约束满足：摩擦锥两者均 100%，CWC-y 纯 RL 57.2% vs MPC-RL 69.8–91.8%，CWC-x 92.0% vs 94.0–99.0%。与 CLF-RL、OGMP、next-step / averaged 地标对比，tapered 加权在速度与推扰上更优，且奖励进展更快。
- **loco-manipulation：** 同一框架加手部接触力参考，推 20 kg、摩擦系数 0.2 的箱子，纯 RL 一开始就停滞；真机推 290 kg 推车（体重的 829%，所需推力约 180 N）。
- **局限（作者自述）：** 依赖降阶质心模型与预设接触序列；数值求解器本身仍有规模限制；未来考虑非线性 MPC 与带神经网络的批量求解器。

### 论文 2：SMPC-to-RL（arXiv:2608.12063）

- **动机：** 复杂 loco-manipulation 的稠密奖励难调、每次改动要长时间训练；MPC 则可在仿真里"分钟级"调好，但在高自由度硬件上实时算不起。做法：仿真里用采样式 MPC（SMPC，类 Howell 等的随机采样 + 热启动，无需 MPPI）当"自动专家"生成大规模示范，再用**纯稀疏奖励**（到达目标 0，崩溃 −1/(1−γ)，其余 −1）训练改过的 FastTD3。
- **架构：** 高层策略输出速度 / 臂关节 / 躯干高度 / 俯仰的增量命令；低层是冻结的 ReLIC 全身稳定控制器（输出关节位置目标）。增量动作化便于限制最大加速度与速度，评论家输出按稀疏奖励的上下界做结构化限幅，作者称显著稳定训练。
- **离线到在线：** 训练初期把回放缓冲区中 50% 的转移替换为 SMPC 数据，成功率足够后课程式淡出专家数据。SMPC 在单张 RTX 5090 上约 0.5× 实时，每小时可生成约一百万样本；最难任务需约四百万样本、4 GPU 小时。
- **结果：** 5 个任务（Spot 到达 / 推箱 / 立轮胎 / 滚轮胎，G1 推箱）仿真成功率接近 100%（五个随机种子）；不加 SMPC 数据时稀疏奖励下什么也学不到。Spot 真机 10 次试验成功 10/10、9/10、10/10、8/10（Reach / 推箱 / 立轮胎 / 滚轮胎）。学到的策略任务耗时短于 SMPC 专家（部分超过 50%），时长标准差降 11–45%。
- **消融：** 数据量需求随任务复杂度增加；数据质量（SMPC 采样环境数）对最需协调的"滚轮胎"影响最大；**示范必须单模态**（多模态示范使策略完全学不会，需用额外代价项把行为收窄到一种模式）；直接用 SMPC 代价做稠密奖励 RL（FastTD3）、用 SMPC 数据做离线 RL（IQL）或模仿学习（Diffusion Policy），在复杂任务上成功率均 ≤ 10%，作者归因为与 SMPC 代价不兼容及数据缺少纠错样本。
- **局限（作者自述）：** 最优性是局部的，受示范分布约束；低层控制器冻结，无法适应任务特定扰动；真机依赖状态信息，非结构化环境需视觉。
