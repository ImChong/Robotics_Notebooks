## 研究问题与贡献

Aria Gen 2 智能眼镜提供重力对齐的 6-DoF 头部轨迹、相机标定的 RGB-D 和视野内手部/手指关键点，**并没有人体躯干/双腿轨迹**。人和 Unitree G1 在身高、臂展、三指 Dex3 形态上不同，直接复制掌心/脚步会出现碰撞、够不着和抓取穿透。

论文的贡献是**每条真实示范独立重建场景**（碰撞代理、纹理、动态物体及必要时的遮挡表面补全），在对象坐标系预测可抓接触带，规划机器人可行抓手与站姿，补齐不可见的全身动作，先做运动学检查再在物理引擎中用 RL 动态修正、筛选有效 rollouts，最终沿**被接受的同一条物理轨迹**渲染机器人摄像头图像和动作标签。

## 方法与关键判据（§III；附录 A–D）

1. **Agentic Real-to-Sim**：深度与标定在同一米制坐标系中融合；地面/支撑面拟合简化碰撞体，分离运动物体并在其局部坐标系做 TSDF 融合、贴图；对未观测表面做有界几何/颜色补全，标明推断与实测的来源差异。预测 reach/touch/grasp/lift/release 事件，定位接触带而非单点。
2. **Motion adaptation**：以头部地面投影生成根轨迹；根据手是否可见，将手目标分为跟踪段、生成段。发生物体接触时，目标为「物体位姿 × 规划抓手」，不是「人掌心姿态直接替代」；利用接触带约束 Dex3 指腹对向接触、腕姿与非穿透。双层站姿优化同时解决双臂可达、场景避障和接近人类头视点；窗口式全身生成器补齐行走与视野外动作。
3. **Kinematic correction**：在手出入视野附近做 0.6 s 平滑混合，运动学优化处理足滑、重心支撑、碰撞与关节平滑；抓握闭合后用动力学回放排除接触未保持/提前推物等轨迹。
4. **Dynamic correction**：RL 跟踪参考全身动作，冻结 SONIC 解码器接受 64 维全身 token 并输出关节目标；14 维双手 Dex3 指令另行执行。Agent 按语义/接触事件生成奖励，戴帽目标可使用相对头部位置奖励处理离开头部相机视野的阶段。只接受完成任务且姿态、头误差、关节速度/加速度、足滑等满足阈值的 rollout。
5. **Robot-view render**：通过重建场景的机器人相机投影，把静态背景、同一 rollout 中仿真物体的姿态、机器人自身肢体渲染到每帧。训练四元组为 `(I_i, s_i, ℓ, a_i)`：`s_i` 包含 43 个关节角与基座系重力，`a_i=(z_i, q_i^dex)` 是 64+14=78 维动作；GR00T N1.7（3B）仅以转化数据微调，无目标任务的真机示教。

## 数据与实验（§IV；Table I–II）

| 指标 | 论文结果 | 正确口径 |
|---|---:|---|
| 举瓶进入训练集 | 189 / 219 | 逐条重建、修正、物理筛选与最终复核 |
| 戴帽进入训练集 | 59 / 154 | 薄帽沿抓取易失效，大量轨迹在仿真前/回放时被淘汰 |
| 戴帽接触规划 vs 复制人掌心 | 穿透中位数 0.8 vs 1.8 cm | Table I，71 段戴帽记录，数值越小越好 |
| 戴帽手内平移 | 3.7 vs 6.6 cm | Table I，仅两条件成功 rollout 的比较口径 |
| 戴帽手内转角 | 22.9° vs 33.0° | Table I，规划抓手 vs 人掌心 |
| 戴帽接触可行性 | 57/71 vs 基线 0 | Table II，EgoHumanoid/EgoHumanoid-V2 的具体对照条件与样本数有别 |
| 举瓶真机成功 | 9 / 20（45%） | G1 自主执行，仍有到桌前/抓取失败 |
| 戴帽真机成功 | 5 / 20（25%） | G1 自主执行，抓取失败和视野外头部碰撞仍存在 |

**解释边界**：在 71 条抓取对照中，规划器物理 rollout 成功 56 条、复制人掌心成功 53 条；论文强调穿透/手内运动质量改善，不能把该对照表述成成功率大幅提升。Table II 的 EgoHumanoid-V2 full 仅有 n=6，不能当成 71 条全量测试。

## 局限与复现边界

- 质量、转动惯量与摩擦由 agent 根据视觉/先验估计；重物或偏心负载存在动力学域差。
- 刚体、参数曲面和铰链代理难覆盖衣物折叠、切面拓扑变化等任务。
- 只报告两项日常任务、少量 G1 真机尝试，远不是通用任务成功的证据。
- 项目主页在本轮工具访问失败；原论文提供项目链接，但未独立核查可运行训练/部署代码和权重是否公开。不得据此写源码运行时序或宣称可直接复现。
