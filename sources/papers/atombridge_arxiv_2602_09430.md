# AtomBridge（arXiv:2602.09430）

> 来源归档（paper）

- **标题：** AtomBridge: Agentic VLA Inference Plugin for Long-Horizon Tasks in Scientific Experiments
- **arXiv：** <https://arxiv.org/abs/2602.09430>
- **PDF：** <https://arxiv.org/pdf/2602.09430>
- **一句话说明：** 异步 VLA 换指令时旧动作仍在执行、状态已变；结合指令与任务历史选行为，Haar 子空间拆动作骨架与残差分阶段生成，Flow-DPO 在行为一致候选中调整，并推算真实交接状态以缩短接管间隔。
- **评测：** MuJooco + Autobio
- **机构（策展）：** 东南大学、同济大学
- **开源结论：** 待核实（2026-09-26）
