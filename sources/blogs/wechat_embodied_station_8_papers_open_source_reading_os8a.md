## 核心摘录（均出自该文）

- **主线：** 能力边界从单一策略扩展为闭环：多模态感知理解物理属性，价值函数与主动探索改进行动，结构化控制保证安全，开放代码 / 数据 / 清单加速复现。
- **01 Space Mining（2608.21358）：** 综述，六阶段架构（遥感选址、原位探测、小规模采样、多机器人挖掘、资源提取、原位建造或运输）；开放研究清单仓库。
- **02 ViTacPhys（2608.21355）：** 60 个物体的人类视触觉示范；已见物体质量 / 摩擦分类 97.2% / 98.8%，刚度 MAPE 5.51%；机器人抓取 ID / OOD 成功率 95.0% / 83.4%。
- **03 Q-Planning（2608.21204）：** 冻结 BC 策略 + 小型离策略 Q 函数；LIBERO-10 93%→99%，RoboTwin 83.8%→91.4%，真实叠杯 40%→90%、插钱包 25%→80%。
- **04 SRL-MPC（2608.21175）：** RL 在线调 MPC 参数，支撑函数几何特征 + 高阶控制屏障函数；文中无具体数值。
- **05 TOSS（2608.21083）：** 34 名参与者、204 条教学反应；Triggers / Objectives / Signals / Strategies；开放 OSF 数据。
- **06 PhysCaP（2608.21031）：** Code-as-Policy + 本体感觉估质量与刚度；Planner + Prioritizer 双代理；以更少交互获得可比表现。
- **07 GhostTac（2608.20817）：** 非接触 EMI 攻击；10 个传感模块、2 只灵巧手、15 种触觉传感器验证。
- **08 DreamHand（2608.20308）：** 视频扩散模型作确定性几何编码器；ARCTIC / HOT3D 的 MPJPE-p 降低 30% / 40%，含出画双手增益 46%–61%。
- **综合观察：** 价值是模块能否组合成可验证、可持续改进、对物理风险有感知的闭环，而非单点指标。
