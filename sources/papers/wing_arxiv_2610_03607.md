## 核心问题与贡献

第一人称人类视频提供规模较大的真实交互经验，但从连续图像重建得到的潜动作可能把头部/相机运动也编码进去；即便学到了交互本身，人类和机器人执行同一任务时的速度、停顿与动作节奏仍然不同。WING 分两步处理：

1. **WING-LAM（interaction-centric latent action model）**：用点跟踪与手物区域构造离线运动监督，估计背景主导的全局相机仿射变换，再把补偿后的局部残差作为交互运动。带特权运动线索的 teacher 分别预测 observer motion 和 interaction motion，并把 interaction latent 蒸馏给只接收 RGB 帧对的 student；部署端无需点轨迹或区域掩码。
2. **谱潜动作引导**：对连续潜动作沿时间轴做离散余弦变换（DCT），保留低频分量作为引导目标。当前图像、语言指令与可用的本体状态输入轻量 predictor，预测这些频率分量；引导 token 通过门控注意力残差注入动作模型。低频截断只作用于引导表征，机器人动作仍保留细粒度控制。

训练分两阶段：先用第一人称视频预训练视觉/视频专家与谱引导预测器（论文报告采用 Wan2.2、同预算 200 小时的预训练策略比较）；再用机器人示范联合训练 action expert 和引导预测器，WING-LAM 编码器保持冻结。机器人示范仍为可执行动作提供监督，ego 潜动作充当辅助引导而非直接替代动作标签。

## 评测与可解释读法

| 场景 | WING 结果 | 对照与读法 |
|------|----------|------------|
| LIBERO 四套件 | 平均成功率 99.20% | 表中高于该表报告的强基线均值；其中 LaWAM 为 98.60% |
| RoboTwin 2.0 | clean / randomized / 平均：94.56 / 93.04 / 93.80% | LingBot-VA 平均 92.20%，Fast-WAM 91.83% |
| RoboCasa-GR1（24 项） | 平均成功率 57.7% | 对照 LDA-1B 55.4%、Fast-WAM 复现 51.9% |
| 双臂真机（4 项任务） | 标准设置平均成功率 75.0% | 泛化设置平均成功率与 π₀.₅ 相近、平均进度略高；此处不应简化成“泛化 SOTA” |

真实机器人为 AgileX Cobot Magic 双臂平台，使用 3 台 Orbbec DaBai DC1（前置一台、腕部两台）相机，动作空间 14 维。四项真实任务是 Pack Objects、Stack Cups、Battery Insertion 和 Long-Horizon Battery Assembly；论文每任务收集 100 或 150 条示范，每种设置评估 20 次。成功定义要求最终条件持续至少 3 秒，另报告阶段进度分数，因此成功率与进度不可混为一谈。

消融结果支持两部分各有贡献：去掉 WING-LAM 或 DCT guidance 均降低 LIBERO 与真实场景平均指标；谱系数实验中 K=4 在四个 LIBERO suite 表现最好，K=2 过度压缩，K=8（全谱）引入更多高频信息但没有收益。

## 局限与开放状态

- **项目页核查：** [WING 项目页](../sites/wing-project.md)目前显示 **Code Coming Soon**；论文称部署代码后续发布，但本次未发现公开 GitHub 仓库。
- **数据/权重：** 页面未列下载数据或模型权重的链接，论文使用/整理的第一人称视频不能因此视为可公开获取。
- **运动解耦假设：** teacher 用单个全局仿射 warp 近似主要观察者运动；强视差、大深度变化或明显 3D 相机运动会削弱该近似，可能污染交互监督。
- **工程代价：** 潜动作预训练与谱引导增加训练成本和系统复杂度。
- **证据范围：** 仿真和真机结果来自论文作者的实验；真实评测仅四项双臂任务，泛化采用逐因素变化，不能直接外推到所有机器人、任务和复合场景。
