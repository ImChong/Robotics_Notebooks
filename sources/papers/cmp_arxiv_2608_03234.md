## 摘要级要点

- **问题：** 现有运动先验（AMP/SMP）从整库学一个任务无关先验，全程均匀用；异构或失衡参考下会给当前上下文灌入无关/冲突监督。
- **主张：** 可在**原参考空间**在线适配，无需技能标签、数据集切分或独立 skill discovery。
- **机制：** 对比相关度 \(R_\phi(c,x)\)（高优势 online 正样本 + \(\mathcal{L}_{\mathrm{demo}}\) 锚定参考支撑）→ 软权重 \(\bar{w}_\phi\) → 轻量上下文残差适配器（基座先验原目标不变）。
- **实例化：** CMP-AMP（残差加在判别器 logit）；CMP-SMP（残差加在冻结 denoiser 的噪声预测）。
- **任务：** Target Location / Steering / Trajectory Following / Dodgeball / Dribbling；同一 MimicKit locomotion 参考集，无任务专用 demo。
- **结果：** 五任务上相对 AMP/SMP 提高 test return；多数任务更快到达 80% 基线最终回报；行走 clip ×100 失衡时 AMP −11.5%、CMP-AMP 仅 −2.8%；附录 E 模拟 G1 上 CMP-AMP 同样全面占优。

## 核心摘录（面向 wiki 编译）

### 1) 上下文条件参考重权

\[
w_{\phi}(c,x)=\frac{\exp(\alpha R_{\phi}(c,x))}{\mathbb{E}_{x'\sim p_E}[\exp(\alpha R_{\phi}(c,x'))]},\quad
q_{\phi}(x\mid c)=w_{\phi}(c,x)\,p_E(x)
\]

minibatch 归一化后 clip 到 \([w_{\min},w_{\max}]\)；适配器损失用 `stop-gradient` 权重，只更新 \(\psi\)。

### 2) 对比相关度

\[
R_{\phi}(c,x)=\frac{f_{\phi_c}(c)^\top g_{\phi_x}(x)}{\|f_{\phi_c}(c)\|_2\,\|g_{\phi_x}(x)\|_2}
\]

- **Online：** \(\hat A_i>0\) 的 rollout 为 \((c_i,x_i)\) 正对，按 \(\rho_i=\sigma(\hat A_i/\beta_{\mathrm{adv}})\) 加权。
- **Demo：** 同一批上下文下，参考 clip 为正、rollout clip 为负，防止 query 漂出参考支撑。
- \(\mathcal{L}_{\mathrm{rel}}=\mathcal{L}_{\mathrm{on}}+\lambda_{\mathrm{demo}}\mathcal{L}_{\mathrm{demo}}\)。

### 3) 适配器实例化

- **AMP：** \(l_{\theta,\psi}(c,x)=\mathrm{sg}[l_\theta(x)]+\lambda_{\mathrm{res}}\Delta l_\psi(c,x)\)；参考侧加权 BCE、策略侧未加权负项；奖励 \(r=-\log(1-\sigma(l_{\theta,\psi}))\)。
- **SMP：** \(\hat\epsilon_{\theta,\psi}=\mathrm{sg}[\epsilon_\theta]+\lambda_{\mathrm{res}}\Delta\epsilon_\psi\)；冻结预训练 denoiser，仅训适配器。

### 4) 主结果（Table 1，test return / 三 seed）

| Task | AMP → CMP-AMP | SMP → CMP-SMP |
|------|---------------|---------------|
| Location | 408 → **467** | 376 → **437** |
| Steering | 299 → **480** | 496 → **512** |
| Trajectory | 184 → **302** | 252 → **268** |
| Dodgeball | 424 → **458** | 447 → **471** |
| Dribbling | 319 → **456** | 458 → **466** |

样本效率（达基线 80% 最终回报的 env steps，×10⁸）：CMP-AMP 在 Location 6.5→2.4、Trajectory 6.8→2.7、Dribbling 5.2→2.8；Steering 与 AMP 同为 1.2。

### 5) 失衡鲁棒（Table 2，Location，walking ×k）

| Walking × | AMP | CMP-AMP |
|-----------|-----|---------|
| ×1 | 408 | **467** |
| ×100 | 361 (−11.5%) | **454 (−2.8%)** |

### 6) G1（Appendix E，CMP-AMP）

五任务 return 与样本效率均优于 AMP；Dribbling 回报 294→467，达阈样本 10.1→2.9（×10⁸）。
