# PhAI Labs

> 来源归档（机构官网）

- **官网：** <https://phai-labs.com/>
- **项目稿：** [RSI-Anything](./rsi-anything.md)、[JEPA-Anything](./jepa-anything.md)
- **入库日期：** 2026-10-12
- **一句话说明：** 以模型与数据基础设施支持科学发现为定位的研究机构，公开 RSI-Anything、JEPA-Anything、ScienceBuddy、ScienceIDE 与 DFM 等研究项目。

## 公开定位与项目关系

官网将研究方向概括为面向真实科学发现的模型与数据基础设施。DFM（科学基础模型）在其说明中是研究范式和能力定义，不是单一模型或工程框架；JEPA-Anything、ScienceBuddy、ScienceIDE 是彼此独立的模块与实现，没有必须互相调用或依赖的关系。官网提出的未来组合属于愿景，不代表已经集成。

RSI-Anything 与 JEPA-Anything 是独立项目节点：后者提出跨世界预测模型结构，前者将 JEPA-Anything 作为世界模型基础来支持候选筛选和迭代改进。两者共享研究机构和部分作者，不应合并成一个项目实体。
