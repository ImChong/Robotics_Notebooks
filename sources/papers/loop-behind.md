## 原文要点

- §2–3、附录 A–B：Dory-4B 有 8 层输入块、20 层共享循环块和 8 层输出块。两种解耦实验都固定历史输出块 KV 为单轮版本，当前位置保留自身算出的 KV；独立改变当前读出深度与所读历史循环 KV。12 项基准均按论文子集、同提示和种子、每题一次生成，温度 1.0、top-p 0.95，最多 96K 上下文；报告的是逐基准准确率的平均。
- §3、图 2、表 2、附录 E：原生单轮与双轮平均为 40.5% 和 47.7%；单轮读历史第二轮 KV 为 47.3%，双轮只读历史第一轮 KV 为 41.3%。另选 20 道题、1,000 个原生单双轮的预测分歧位置，前一种干预与双轮预测分布的平均 KL 为 0.06，后一种为 0.29；这是有条件抽样，不等于从所有输出位置随机采样。
- §4、算法 1、附录 F：先用原生多轮完成默认提示预填充。每个解码步把旧 token 的待完成循环和新 token 的第一轮按位置合并，因果注意力在同一层读取刚更新的旧 KV；新 token 读出后，未完成循环另存状态到下一步。等价性证明针对顺序执行的后置循环参考，不是与原生多轮逐 token 输出相同。
- 表 3 / 8：Dory-4B，单 H100、8K 上下文、批量 32、同步调度，LB-4 平均 48.3%，原生四轮逐轮缓存 49.3%，原生四轮末轮缓存 48.5%。LB-4 每输出 token 的时间 11.15 ms，缓存 12.59 GiB（另有 47 MiB 待完成缓冲），预填充 10.65 s；原生单轮为 10.75 ms 和 4.05 s。
- §4.3、附录 G：异步、较高带宽利用率的表 9 扫描与同步表 8 不同；最快 2.56 倍对应 16K / 批量 32 的 LB-4 对原生四轮末轮缓存。宽批处理并不减少额外循环的 FLOPs；32B / 64B 变体用随机权重，只验证速度。
- §5、表 4、附录 C–D：Huginn-0125 在 16 轮总深度、第 8 轮读出时，报告 57.4%（与原生 16 轮持平）与单请求解码加速 1.75 倍。Ouro-1.4B Base 的两轮读取深层历史 KV 反而从 59.6% 降到 51.8%；其全栈循环前部跨轮 key 不对齐，因此作者没有在 Ouro 上应用 LB。
