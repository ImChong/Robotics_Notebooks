# GALA（arXiv:2609.21948）

> 来源归档（paper）

- **标题：** GALA: Geometry-Aware Latent Action Modeling for Vision-Language-Action Model Pretraining across Embodiments
- **类型：** paper
- **arXiv：** <https://arxiv.org/abs/2609.21948>
- **PDF：** <https://arxiv.org/pdf/2609.21948>
- **项目页：** https://puzhenyuan.github.io/GALA-website/
- **入库日期：** 2026-09-21
- **一句话说明：** UEMR 把 3D 末端几何运动纳入 latent action 预训练；RoboCasa-GR1 68.3%、真机四任务平均 75.5%，移除 UEMR 后真机降至 68.5%。
