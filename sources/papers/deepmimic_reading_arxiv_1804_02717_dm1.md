# DeepMimic 论文通读（示例引导的物理角色技能 RL）

> 来源归档（原文通读 · 支撑 `wiki/methods/deepmimic.md`）

- **标题：** DeepMimic: Example-Guided Deep Reinforcement Learning of Physics-Based Character Skills
- **作者：** Xue Bin Peng, Pieter Abbeel, Sergey Levine, Michiel van de Panne（UC Berkeley / UBC）；ACM TOG 37(4), Article 143（SIGGRAPH 2018）
- **类型：** paper / rl / motion-imitation
- **原文：** <https://arxiv.org/abs/1804.02717>（2026-11 通过 arXiv PDF v3 获取全文）
- **一句话说明：** 把参考动作作为"模仿奖励"并入 PPO 训练，配合参考状态初始化（RSI）与早期终止（ET），让物理仿真角色学会后空翻等高动态技能，并给出多片段整合与任务叠加的做法。
- **核对范围：** 通读正文 §1–§11（相关工作、概述、背景、策略表示、奖励、训练、RSI/ET、多技能整合、角色、任务、结果、消融、鲁棒性、局限）及补充材料 A–D（多步回报、离策略、PPO、学习算法超参）；补充视频、附带学习曲线未查看，参考文献未逐条核对。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **系统概览（§3）：** 输入为角色模型、参考动作（目标位姿序列 q̂_t）和任务奖励；策略 π(a|s,g) 输出各关节 PD 控制器的目标角度，再算力矩；总奖励 r = ω_I·r^I + ω_G·r^G，实验中 ω_I=0.7、ω_G=0.3；用 PPO 训练。
- **状态与动作（§5.1）：** 状态含各 link 相对根（骨盆）的位置、四元数朝向、线 / 角速度，均在角色局部坐标系；另加相位变量 φ∈[0,1]（循环动作到末尾重置为 0）；策略 30 Hz，球关节目标为轴角、转动关节为标量角。
- **网络（§5.2）：** 高斯策略，均值由网络输出、固定对角协方差；两层全连接 1024、512，ReLU；价值网络结构相同、输出单个线性单元；视觉任务加高度图卷积分支。
- **模仿奖励（§5.3）：** r^I = 0.65 r^pose + 0.1 r^vel + 0.15 r^end-effector + 0.1 r^com；各项为 exp(−k·误差)：位姿 k=2（关节四元数差的旋转角平方和）、速度 k=0.1（有限差分得参考角速度）、末端 k=40（四肢世界坐标位置误差）、质心 k=10。
- **训练（§6）：** PPO 裁剪目标；价值用 TD(λ)，优势用 GAE(λ)。作者强调初始状态分布与终止条件对探索至关重要，固定初始状态 + 固定时长 episode 对后空翻等动作常失败。
- **RSI（§6.1）：** 每个 episode 的初始状态从参考动作中均匀采样；固定起点会迫使策略顺序学习（后空翻中不会落地就得不到起跳回报），且奖励只在访问过状态后才可见；RSI 让智能体在早期就遇到高回报状态，可视为参考动作的另一条信息通道。
- **早期终止（§6.2）：** 躯干 / 头等指定 link 触地即终止，剩余步奖励为零；既是奖励塑形，也缓解"躺地上徒劳挣扎的样本占主导"的类别不平衡。
- **多技能整合（§7）：** （1）多片段奖励 r^I = max_j r_j；（2）技能选择器：one-hot 目标，随机目标训练；（3）组合策略：独立训练的单技能策略，用各自价值函数做 Boltzmann 选择 p_i ∝ exp(V_i/T)。
- **角色（§8，表 1）：** 人形（13 link、34 DoF、197 维状态、36 维动作）、Atlas（169.8 kg）、T-Rex、龙（79 DoF、418 维状态、94 维动作）；T-Rex / 龙使用美术关键帧而非 mocap。
- **任务（§9）：** 目标朝向、击打、投掷、地形穿越（混合障碍、密集沟、平衡木、台阶，先平地训练再加高度图渐进训练）。
- **结果（§10，表 2/3）：** 人形 / Atlas / T-Rex / 龙共 30 项技能，单技能约 41–191 百万样本；mocap 来自 CMU 与 SFU，每技能约 0.5–5 s；物理仿真 Bullet 1.2 kHz，稳定 PD 控制。表 2 中如 Walk 归一化回报 0.985、Backflip 0.729、Frontflip 0.485、Atlas Spinkick 0.477。
- **任务叠加（表 4）：** Strike-Spinkick：r^I+r^G 99%、仅 r^I 19%、仅 r^G 55%；Throw：75% / 5% / 93%（仅任务奖励会学出"抱球跑向目标"的不自然策略）。
- **重定向（§10.3）：** 直接复制局部关节旋转到 Atlas 后重新训练可复现技能；人形策略直接套到 Atlas 回报仅 0.013 / 0.014（跑 / 后空翻）；月球重力下 spinkick 0.792、cartwheel 0.688。
- **消融（表 5）：** RSI+ET / 仅 ET / 仅 RSI：Backflip 0.791 / 0.730 / 0.379；Sideflip 0.823 / 0.717 / 0.355；Spinkick 0.848 / 0.858 / 0.358；Walk 0.980 / 0.981 / 0.974。作者结论：ET 对多数技能关键，RSI 对飞行相长的动态技能关键。
- **鲁棒性（表 6）：** 骨盆受 0.2 s 外力，Run 前向可承受 720 N、Spinkick 侧向 600 N；训练中未加外部扰动，作者推测鲁棒性主要来自随机策略的探索噪声。
- **局限（§11）：** 需与参考动作同步、线性推进的相位变量，限制时序调整；多片段方法未在大动作库上验证；PD 增益需按形态手调；训练常需数天 / 每技能且各策略独立训练；奖励依赖人工定义的状态相似度与权重。
- **PPO 超参（补充 D）：** 批 4096 样本、minibatch 256、γ=0.95、λ=0.95、ε=0.2；价值步长 1e-2、策略步长 5e-5（人形 / Atlas）与 2e-5（龙 / T-Rex）；SGD 动量 0.9；单技能约 6000 万样本，8 核 CPU 约 2 天，无 GPU。
