## 一句话摘要

OmniVTLA / ObjTac 官方项目页：**56 物体 / 135K 三模态样本** 规格、Paxini Gen2 力阵列可视化、真机夹爪/灵巧手 demo，以及 **ObjTac 下载** 与 **OmniVTLA 代码待发布** 状态。

## 公开信息要点（截至入库日）

- **ObjTac 规格表：** 56 objects / 10 categories / 135K samples / Text+Vision+Tactile / 60 Hz / 720P 30 FPS 视频。
- **Tactile Visualization：** 刚性 / 纹理 / 可变形物体时序力阵列与合力曲线（全局 z 轴向下）。
- **Real-World Experiments：** 短罐（夹爪）、瓶（灵巧手）等 lift 视频；强调语义触觉 cues 稳定抓取与平滑轨迹。
- **页首导航：** Overview / Dataset Details / Data Examples / Tactile Visualization / Applications / BibTeX。
