# OpenCut（opencut.app）

> 官网归档：开源视频编辑器及其当前在线版本入口。

- **类型：** 官方项目网站 / 在线视频编辑器
- **官网：** <https://opencut.app>
- **重写版预览：** <https://new.opencut.app>
- **当前主仓库：** [OpenCut-app/OpenCut](../repos/opencut-app.md)
- **旧版仓库：** <https://github.com/OpenCut-app/opencut-classic>
- **源码：** 主仓库公开，MIT；旧版仓库已归档
- **核验日期：** 2026-10-16
- **一句话说明：** OpenCut 是定位为 CapCut（剪映）开源替代方案的视频编辑器；官网目前运行旧版，新的共享 Rust 核心版本仍在重写中。

## 官网与版本边界

官网介绍 OpenCut 为可在不同平台使用的开源视频编辑器。主仓库 README 明确说明：opencut.app 当前仍运行 classic 版本；新版将部署在 new.opencut.app，待准备好后再接替。官方路线图包括 Web、桌面和移动端共用 Rust 核心、第三方插件、Editor API、MCP server、无头批量渲染与脚本入口。

## 使用提示

用户提供的功能线索包括时间轴、蒙版、贴纸和导出。官网入口适合直接体验当前旧版；评估新版能力时应以重写版预览和主仓库 README 为准。订阅、导出限制及各平台功能可能随版本变化，使用前请查看官网当前页面。
