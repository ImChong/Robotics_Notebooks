## 核心摘录（均出自原文）

- **问题重框：** Ego 同时记录视线、手、身体、任务过程、遮挡、接触与临场决策；执行前的注意力与失败前的调整，对机器人可能比最终动作结果更重要。
- **中间处理链：** 人体轨迹重建、手部追踪、视角对齐、动作重定向、物理过滤、世界模型推演、任务意图抽取；视频不会自动变成机器人数据。
- **01 采集：** AoE 用颈挂式手机支架 + 移动端应用 + 云端自动标注 / 过滤，降低采集门槛，代价是画面抖动、手遮挡、动作不够标准；EgoLive 强调大规模、真实任务场景（家政、零售）、任务导向与多模态标注。
- **02 人→机：** EgoMimic 用 Project Aria 眼镜第一视角视频 + 3D 手部轨迹，与机器人遥操作数据共训；文中称增加人类手部数据对泛化帮助明显。EMMA 用人类移动操作数据 + 静态机器人数据共训，绕开大规模移动机器人遥操作。Gaze2Act 把人的 gaze 映射到机器人视角作为 VLA 的条件输入，视线补语言说不清的目标与接近区域。
- **03 世界模型：** Ego-Vision World Model 用本体感觉 + 第一视角深度图做人形接触规划（扶墙、挡物、低头过障）；WEM 把世界演化与自我演化拆开建模以缓解长时程 rollout 漂移。
- **04 Ego+Exo：** 第一视角看不到全身、易被遮挡、空间记忆不稳；EgoExoMem 研究同步 ego-exo 视频的跨视角记忆推理；E³C 在可控第一视角视频生成中引入 3D 环境记忆与 ego / exo 人体姿态控制。
- **结语：** Ego 不是具身智能的答案，但很可能是规模化数据的入口；未来数据系统更可能走向 Ego + Exo + 3D 环境记忆。
- **边界：** 文章为作者个人判断式策展，没有给出统一基准下的横向实验对比。
