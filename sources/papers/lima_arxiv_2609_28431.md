## 核心摘录

### 问题

- VLA 强语义但缺细粒度物理/空间；WAM 迭代生成 **延迟高** → 接触变化时 **意图与执行时间错位**。

### 方法三件套

| 模块 | 作用 |
|------|------|
| **Asynchronous Dual System** | Dreamer 周期更新长 horizon intent；Refiner 从最新观测做 dense 动作修正 |
| **Latent Schrödinger Bridge** | 以 Dreamer 结构意图为 prior，熵正则传输 refine 动作/视觉（非从零高斯噪声） |
| **Spatiotemporal Adaptive Modulation** | 想象未来视觉与 live 相机 view-aligned 融合；当前机器人状态 grounding 局部修正 |

### 真机表（项目页，20 trials/task，H100）

| Method | 六任务 SR 量级 | Latency |
|--------|----------------|---------|
| GR00T N1.6 | ~50–85% 分任务 | 270 ms |
| Cosmos-Policy | ~45–80% | **600 ms** |
| **LiMA** | **50–90%**；汇总 **70.8%** overall，PSR **78.5%** | **325 ms** |

- 相对 Cosmos-Policy 推理延迟 **降低 45.8%**（摘要/站页）。
