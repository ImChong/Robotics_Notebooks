## 一句话摘要

官方项目页展示 **57k 行人实例** 的多源驾驶场景行为数据集：SMPL 运动叠加、行为标签与文本描述示例视频，以及统计图；公开入口为 arXiv + Hugging Face Dataset。

## 公开信息要点（截至入库日）

- **作者机构行：** Texas A&M / Brown / Johns Hopkins / UT Austin；equal contribution 与通讯作者标注齐全。
- **页头链接：** arXiv · 🤗 HF|Dataset（无 Code 按钮）。
- **数据叙事：** Waymo + YouTube + 自采/付费行车视频；行为示例含 Talking/Crossing、Stroller、Bike、Using Phone、Motorcycle、Umbrella、Walking a pet 等。
- **开源边界：** **数据已开**（HF）；**训练/评测代码未在项目页公布**。
