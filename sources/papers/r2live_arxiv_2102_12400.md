# R2LIVE（arXiv:2102.12400）

> 来源归档（paper）

- **标题：** R2LIVE: A Robust, Real-time, LiDAR-Inertial-Visual tightly-coupled state Estimator and mapping
- **作者：** Jiarong Lin, Chunran Zheng, Wei Xu, Fu Zhang（香港大学机械工程系，HKU MARS）
- **类型：** paper
- **arXiv：** <https://arxiv.org/abs/2102.12400>（仅 v1，2021-02-24；v2/v3 URL 不存在）
- **PDF：** <https://arxiv.org/pdf/2102.12400v1>
- **发表：** IEEE RA-L 2021（RA-L 预印稿页眉：Manuscript received February 24, 2021; Revised May 21, 2021; Accepted June 15, 2021；卷期页码未核实）
- **RA-L 修订稿：** <https://github.com/hku-mars/r2live/blob/master/paper/r2live_ral_final.pdf>（README 称修正了 arXiv 版的笔误与错误，并感谢 narutojxl 指出）
- **代码：** https://github.com/hku-mars/r2live
- **入库日期：** 2026-11-11
- **一句话说明：** 在 FAST-LIO 与 VINS-Mono 之上，用误差状态迭代卡尔曼滤波（ESIKF）紧耦合融合 LiDAR、IMU、相机，再用滑窗因子图优化相机关键帧位姿与视觉路标；在 Livox AVIA 小视场 LiDAR 上验证。
- **核对范围：** 通读 arXiv v1 全文（摘要、§I 引言、§II 相关工作、§III 系统概览、§IV 滤波里程计含流形算子 / 运动学 / 离散 IMU / 传播 / 先验 / 迭代更新 / LiDAR 与视觉量测 / 更新、§V 因子图优化、§VI 实验 Exp-1 至 Exp-4 与运行时间 Table I、§VII 结论）及 v1 附录 A–D 的公式推导（Jacobian 推导只做浏览，未逐式复算）；再通读 RA-L 修订稿正文（含新增的 CamVox 对比、Table I 相对位姿误差表、Table II 运行时间）；修订稿所附 Supplementary Material 推导只浏览。另只读了 GitHub 仓库 README（构建 / 运行 / 致谢 / 许可），**未读仓库源码，也未运行**；参考文献未逐篇核对；补充视频（YouTube）与 rosbag 数据未看。为核对综述说法，另浏览了 R3LIVE（arXiv:2109.07982v1）引言对 R2LIVE 的描述。

## 版本差异（读后记录）

- arXiv v1 的 §VI-E 只给出 Vins-Mono / Fast-LIO / R2LIVE 三者的 RPE 中位数（Fig. 11：中位数 (0.35°, 3.84%) / (0.41°, 0.34%) / (0.27°, 0.21%)，顺序为 Vins-Mono、Fast-LIO、R2LIVE）；RA-L 修订稿改为 Table I，两条序列、六种子序列长度，并增加 CamVox 与 R2LIVE-LIO / R2LIVE-VIO / R2LIVE-LC 三个行。
- v1 的 Exp-3 为一条 876 m 轨迹自闭环；修订稿改为同一地点出发与返回的 5 条轨迹，约 900 m 后均闭合（Fig. 11）。
- 修订稿新增 Exp-4 的 D-GPS RTK 两条序列（旋转速度 130°/s 与 200°/s）；v1 为单一序列，最大角速度 130°/s。
- 修订稿注明对比对象有 CamVox（松耦合 LiDAR + 视觉）；Table I 中 “R2LIVE-LC” 一行在正文里**没有定义**，推测为 LiDAR-相机组合，属推测。

## 核心摘录（均出自原文）

1. **系统（§III，Fig. 2）：** 高频滤波里程计 + 低频因子图优化两部分。滤波里程计用 ESIKF 融合 LiDAR 点面残差、相机重投影误差与 IMU 传播；因子图“优化局部滑窗内的相机关键帧位姿与视觉路标”（§V）。
2. **状态（§IV-B/C/D）：** 21 维（IMU 姿态与位置、IMU-相机外参、速度、陀螺与加速度计零偏）；假设三传感器时间偏移已预标定，LiDAR-IMU 外参已知，**在线估计相机-IMU 外参**；全局系为首个重力对齐的 IMU 系，g=[0,0,9.805]（修订稿脚注 5，香港）。
3. **LiDAR 量测（§IV-G）：** 与 FAST-LIO 一致，提取平面特征点，IMU 反向传播去畸变，在地图中找最近平面点拟合平面，残差为点到平面距离。
4. **视觉量测（§IV-H）：** 提取 FAST 角点，用 KLT 光流在滑窗关键帧间跟踪；丢失或新点以最优相机位姿三角化为视觉路标；用重投影误差更新状态。
5. **更新（§IV-I）：** 先验、LiDAR 后验、视觉后验合并为 MAP，按 FAST-LIO 方式计算卡尔曼增益（式 22 / 修订稿式 36），迭代至收敛；修订稿注明迭代卡尔曼滤波等价于高斯牛顿优化。收敛后：LiDAR 点投到世界系加入地图；若为关键帧则三角化新路标；作为下一轮传播起点。
6. **因子图（§V，Fig. 5）：** 与 VINS-Mono 类似，但加入来自 ESIKF 的 LiDAR 位姿约束；包含 IMU 预积分约束；**图中 LiDAR 位姿固定，LiDAR 原始点不参与优化**，目的是保持后端轻量；同时标定相机与 LiDAR-IMU 子系统之间的时间偏移；实现基于 VINS-Mono 滑窗优化。
7. **设备（§VI-A）：** 手持设备 2.09 kg，DJI Manifold-2c（i7-8550U，8 GB），全局快门相机（v1 未给型号；修订稿为 FLIR Blackfly BFS-U3-13Y3C），Livox AVIA（FoV 70.4°×77.2°），相机 FoV 82.9°×66.5°；D-GPS RTK 作真值（仅 Exp-4）。
8. **Exp-1（§VI-B）：** 最大角速度约 300°/s，并故意遮挡相机与 LiDAR；估计轨迹平滑，无明显退化（Fig. 7、8，定性）。
9. **Exp-2（§VI-C）：** 香港港铁香港大学站，隧道最长 190 m，行人多、地面纹理重复；无 GPS 真值，将点云与站点街道图叠合，吻合紧；Vins-Mono 中途因特征跟踪失败停止；修订稿说明 R2LIVE 的 LIO / VIO 子系统在该场景明显漂移（Fig. 9c）。
10. **Exp-3（§VI-D）：** HKU 主楼室内外大场景建图；无回环检测，轨迹仍自闭环（v1：876 m；修订稿：5 条约 900 m）。
11. **Exp-4（§VI-E，修订稿 Table I）：** 序列 (a) 在 300 m 子序列处 RRE/RTE：VINS-Mono 0.44° / 3.76%，Fast-Lio 0.60° / 0.33%，Camvox 0.71° / 3.26%，R2LIVE-LIO 0.56° / 2.19%，R2LIVE-VIO 0.56° / 2.02%，R2LIVE 0.40° / 0.24%；序列 (b) 300 m 处：Fast-Lio 0.09° / 0.37%，R2LIVE-LIO 0.16° / 0.14%，R2LIVE 0.09° / 0.12%。50 m 子序列处 (a)：Fast-Lio 0.34° / 2.82%，R2LIVE 0.25° / 1.40%；R2LIVE-LIO 0.42° / 16.22%。
12. **运行时间（§VI-F，修订稿 Table II，台式机 i7-9700K / 车载 i7-8550U）：** LI-Odom 8.81–14.91 ms / 15.98–30.64 ms；VI-Odom 7.84–9.57 ms / 13.92–20.16 ms；FG-OPM 26.10–30.20 ms / 45.35–65.25 ms；因子图在独立线程运行，允许低于滤波频率。
13. **仓库 README（只读，未验证）：** ROS Kinetic/Melodic、Ubuntu 16.04/18.04，依赖 Ceres 与 livox_ros_driver；`roslaunch r2live demo.launch` 配 rosbag；致谢写明 LIO 子系统基于 FAST-LIO、VIO 子系统基于 VINS-Mono，另使用 ikd-Tree、BALM、loam-livox；GPLv2；自采数据需用其修改过的 livox 驱动对齐时间戳。
14. **作者自述的结论（§VII）：** 在大尺度、室内外、窄隧道、传感器失效与剧烈运动下“达到较高精度与鲁棒性”。
