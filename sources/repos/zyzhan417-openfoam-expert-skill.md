## 仓库说明

OpenFOAM source code expert skill for efficient retrieval, analysis, and understanding of the OpenFOAM codebase. Supports class inheritance analysis, boundary condition analysis, and physics model analysis with standardized modification suggestions.

## 文章中的定位

面向源码阅读而非自动跑算例：让代理沿 OpenFOAM 源码定位实现，分析类继承、边界条件、coded 条件、fvModels 与 fvConstraints；文章所述重点为 Foundation 13、Linux/WSL。

文章的选择、成熟度判断与演示描述属于作者的策展意见；本归档只将其作为来源线索，不视作独立性能评测。
