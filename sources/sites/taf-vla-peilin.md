## 一句话摘要

TaF-VLA 官方项目页：三阶段 **Data → TaF-Adapter → VLA policy** 管线动画、**TaF-Device** 实物与建模图、力感知操作数据集样例，以及果冻切片 / 镊子取砝码等 demo 视频。

## 公开信息要点（截至入库日）

- **Abstract 区块：** 触觉–力对齐范式、10M+ TaF-Dataset、TaF-Adapter VQ + 历史编码、7 任务 **+22%** 叙述。
- **TaF-Device：** 并行施力同步视触觉 + 6 轴 F/T + 压力矩阵；自动化采集演示视频。
- **Force-aware Manipulation Dataset：** 10K+ episodes / 20+ tasks；主从遥操；力感知语言指令。
- **Demo：** Jelly Slicing、Tweezer Weight Pick 等 fragile / precision 场景。
- **开源锚点：** GitHub 存在但 UI 标 Coming soon — wiki 宜写 **部分开源 / 待完整发布**。
