## 摘录 1：问题与核心主张

- **瓶颈：** 前馈几何基础模型（VGGT 等）通常假设 **全局坐标系**；长上下文/流式重建需维护任意时间原点，平移幅值随时间 **无界增长**。
- **R³ 解法：** **相对回归**——轻量 MLP 预测 **置信加权相对约束**；置信度统一用于 **训练 loss 加权** 与 **推理位姿聚合**。
- **双模式：** 同一权重支持 **full-context 离线** 与 **causal、bounded-memory 流式**。

## 摘录 2：机制（项目页 + README）

| 模块 | 要点 |
|------|------|
| **骨干** | **Depth Anything 3**；仅微调 cross-frame/global blocks 与相对相机 decoder |
| **位姿** | **成对相对位姿** 回归（非绝对）；目标随视频长度 **稳定** |
| **置信度** | 每边 **rotation + translation** 置信；驱动 loss 加权、位姿聚合、**keyframe bank** 管理 |
| **鲁棒门控** | 新帧对 active context 平均置信低于校准基线 → **抑制位姿**、作废 KV、跳过 keyframe 入库（防运动模糊/遮挡/场景切换污染地图） |
| **流式** | 有界 keyframe bank 保留历史视图；新帧可回连早期观测（**回环一致**） |
| **规模/速度** | **372M** 参数；**20+ FPS**（RTX PRO 6000）；支持 **数千帧** 有界内存 |
