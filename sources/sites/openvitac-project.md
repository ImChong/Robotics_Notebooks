# OpenViTac 项目页（fvl-repo.github.io/OpenViTac）

> 来源归档

- **标题：** OpenViTac: Learning and Benchmarking Visuo-Tactile Policies in a Unified Sim-and-Real Framework
- **类型：** site（项目页）
- **URL：** <https://fvl-repo.github.io/OpenViTac/>
- **论文：** <https://arxiv.org/abs/2610.10384>
- **代码：** 页面未列 GitHub、Hugging Face 或数据集链接，也无发布说明
- **入库日期：** 2026-10-12
- **一句话说明：** 复旦大学等提出的视觉-触觉策略统一仿真/真机基准，并给出 π0.5 + AnyTouch2 的 OpenVTLA。

## 页面结构

| 区块 | 内容要点 |
|------|----------|
| Overview / Benchmark | 11 个仿真任务、8 个配对真机任务、四类触觉能力、三类传感器、两种夹爪、8 个共享任务 |
| OpenVTLA | 以 AnyTouch2 编码触觉历史并前置到 π0.5 视觉序列；研究 4 种表征、5 种融合 |
| Results | 仿真 68.7%、真机 54.6%；页面写 Sim-Real Pearson 0.913（论文正文为 0.967）；500 条仿真示范使 USB 插入/齿轮装配平均真机成功率提高 15 点 |
| Citation | 标注 “Preliminary citation”，发表信息待补 |

页面署名机构：复旦大学、上海市多模态具身智能重点实验室、合肥工业大学、新加坡国立大学、新智具身智能（NeoteAI）、中国联通。
