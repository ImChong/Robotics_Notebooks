## 一手页面要点

1. 论文使用注视点（gaze）作为感知→意图→动作链的显式中间变量；主页正文也把内部框架命名为 **VLIA**。
2. 预训练聚合超过 150M 第一视角动作帧；示例覆盖真实机器人灵巧操作、长程任务及精细操作。
3. 项目页列出可人工改写意图的实验和仿真/现实定量结果；网页提供官方源码与数据处理入口。
4. 开源结论：**部分开源**。训练/数据预处理代码可见，但官方 README 的权重与评测流程仍待发布，无法据此声称完整复现。
