## 核心区分

- **Cognitive offloading（认知卸载）：** 委托执行、检索、生成等「怎么做」，但保留独立的理解、判断和修正权。
- **Cognitive surrender（认知投降）：** 在尚未形成独立观点时直接采用 AI 输出，连「应核对什么」都失去判断。
- **Comprehension debt（理解债）：** AI 生成或改造的系统超出人类可解释范围，持续累积后使事故恢复、回归分析和架构维护更难。

作者以「测试全绿但未真正审查 diff」「修复症状却不理解根因」「照搬模型给的架构选择」解释风险：**表面正确性不等于理解与系统正确性**。

## 可执行的校准措施

1. 读 agent 答案前，先写自己预期的机制或修复方向；对不一致处重新求证。
2. 以陌生同事的 PR 标准审查 diff，不以生成者或测试全绿代替判断。
3. 请模型给出反方论证，依靠独立证据而不是模型自信作最终判断。
4. 将可运行测试、截图、日志、trace、人工签署变成退出条件；缩小 PR 范围，避免一次产生难以理解的巨大变更。
5. 对陌生领域先做概念探询再自动生成；过度疲劳时停止审查高风险变更。
