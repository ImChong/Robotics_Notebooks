## README 的直接表述

项目英文标题为 CloudRobo-WM: A Simple Multi-Modal World Model for Robot Manipulation。

README 明确称它是联合预测未来视觉模态和机器人动作的多模态世界模型，仓库包含一张 overall_framework.png 结构图。README 同时明确提示 Work in progress，所有代码、数据、模型将来开放。仓库内当前只有 README、PDF、图像资源及 LICENSE，未见可运行训练/推理入口。

**不等价声明：** 个人仓库的 CloudRobo-WM 资料不自动证明已经发布 WM1.2 或 WM-1.0 的官方完整代码；该 PDF 也不能在尚未通读时拿来支持数值、训练规模和实验结论。
