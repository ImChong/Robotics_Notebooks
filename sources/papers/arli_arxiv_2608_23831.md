# ARLI（异步 VLA 的延迟感知 RL 后训练）

> 来源归档（ingest）

- **标题：** Learning to Act While Waiting: RL Finetuning of Generalist Robot Policies Under Inference Latency
- **类型：** paper
- **原始链接：** <https://arxiv.org/abs/2608.23831>（v2，2026-08-26）
- **作者：** Brian Zhu*、Momen Khalil*、E Harrison*、Emanuele Poggi*、Philipp Schmitt、Bernd Kast、Philine Meister、Pranav Atreya、Qiyang Li、Finn Ferchau、Cesar Colmenero、Yash Shahapurkar、Gokul Narayanan、Melih Erdogan、Kai Wurm、Georg von Wichert、Oier Mees、Eugen Solowjow、Andrew Wagenmaker、Sergey Levine（\*共同一作）
- **机构：** 西门子；加州大学伯克利分校；微软；苏黎世联邦理工
- **项目页：** <https://async-rl-intermediate-information.github.io/>
- **入库日期：** 2026-08-27
- **一句话说明：** 通才 VLA 的推理延迟会破坏异步执行下的马尔可夫结构，令标准 RL 完全学不动。**ARLI** 用已承诺中间动作 + VLM 完成后的中间观测给轻量 DSRL 噪声策略，在延迟窗口内尽量恢复近马尔可夫性。

## 核心摘录（MVP）

### 1) 异步隐藏延迟，却让 RL 面对非马尔可夫状态

- **摘录要点：** \(\pi_0\) 消费级 GPU 约 **100 ms**/步，更大开源 VLA 可超 **300 ms**。同步等推理会停顿；异步在上一 chunk 执行时就开始下一 chunk，但决策时看不到将要执行的真实状态。朴素 DSRL 只条件 \(s_{t-t_{\mathrm{delay}}}\)，标准 RL 完全失败。残差 RL 每步可改动作，但不如把噪声舵进冻结 flow/扩散专家。
- **对 wiki 的映射：**

  - [VLA 真机部署指南](../../wiki/queries/vla-deployment-guide.md) — 延迟与异步。
  - [Action Chunking](../../wiki/methods/action-chunking.md) — chunk + RTC 部署税。

### 2) 中间动作 + 中间观测 + 可选 RTC

- **摘录要点：** \(\pi_{\mathrm{rl}}\) 选 DSRL 噪声 \(w\) 喂动作专家。**ARLI actions：** 条件已承诺 \(a_{t-t_{\mathrm{delay}}:t}\)。**ARLI state：** VLM 骨干占延迟大头，RL 可在 \(t-t_{\mathrm{delay}}^{\mathrm{rl}}\) 再读一帧，不增加端到端延迟。RTC 用 inpainting 保 chunk 连续，但冻结旧动作可能伤反应性。理论：若环境满足 delayed oracle gap \(\omega_d\)，延迟 Q-learning 的次优有界。

### 3) Kinetix / Aloha / 双臂 UR5e

- **摘录要点：** 仿真：Kinetix `mjc_swimmer/walker/car_launch`（\(t_{\mathrm{delay}}=4\)）与 AlohaTransferCube 上 \(\pi_0\) 3.3B（\(t_{\mathrm{delay}}=20\)）。ARLI 相对 naive DSRL 收敛更高更快；RTC 单独不够，状态增广才是主因。真机双臂 UR5e、\(\pi_{0.5}\) 小演示微调、60 Hz、chunk 50；RTX 5090 上 \(t_{\mathrm{delay}}=10\)、\(t_{\mathrm{delay}}^{\mathrm{rl}}=7\)、执行 horizon 20。三任务（Assembly / Shoe-in-Bag / Bag-Placement）基线约 **40%**，ARLI **100–125 episode** 近 **100%**；同步 DSRL / DSRL+RTC 同预算难到 80%。无异步则基线差、RL 极慢或学不动。
