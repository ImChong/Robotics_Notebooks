## 原文核心要点（核自 arXiv:2408.14472v1）

1. **硬件平台与闭链主动踝关节（Section III-B, Fig. 2）：**
   - **XBot-S**：高 1.2 m、重 38 kg、26 个驱动电机（总 32 DoF，每腿 6、每臂 7、基座 6）。
   - **XBot-L**：高 1.65 m、重 57 kg、54 个驱动电机（总 60 DoF）。
   - **闭链 2-DoF 踝关节（Closed Kinematic Chain Ankle Mechanism）**：将两颗 36 N·m（XBot-L 为 50 N·m）踝电机上移至靠近膝关节处，通过闭链连杆驱动 2-DoF 踝关节以降低腿部转动惯量；因 Isaac Gym 不直接支持闭链机构，仿真中采用两个虚拟电机并在真机部署时重映射至实际电机（Section IV-C）。
2. **去噪世界模型与损失函数（Section IV-A, Table VI/VIII）：**
   - 把 sim2real 差距归纳为四类噪声：环境噪声、动力学噪声、传感噪声、掩码噪声（真实世界缺失线速度、接触力、高程图等）。
   - 编码器：`GRU(47 → 256) → Linear(256 → 256) → ELU → Linear(256 → 24)`，输出稀疏瓶颈潜变量 $z_t \in \mathbb{R}^{24}$；解码器 `Linear(24 → 64 → 184)` 重建完整状态 $\tilde{s}_t$。
   - 去噪损失：$L_{\text{denoise}} = \|\tilde{s}_t - s_t\|^2 + \lambda_r \|z_t\|_1$（$\lambda_r = 0.002$）；总损失 $L_{\text{DWL}} = L_{\text{denoise}} + \lambda_\pi L_\pi + \lambda_v L_v$（$\lambda_\pi = 5, \lambda_v = 5$）。
   - 观测 47 维（单帧），特权状态 184 维（含 96 维 Height Scan 与 1 维 Current Reward）；Actor 仅消费 24 维 $z_t$（`Linear(24 → 48 → 12)`，约 320,192 参数），Critic 消费 184 维 $s_t$（`512 → 512 → 256 → 1`）。
3. **五次多项式足端轨迹与奖励（Section IV-B, Appendix A–B）：**
   - 用五次多项式 $f(t)=\sum_{k\le 5} a_k t^k$ 在摆动相 $T=0.5\text{ s}$、最大抬脚高度 $h_{\max}=0.1\text{ m}$ 约束下生成平滑足端轨迹，引导轻柔着陆；配合周期性站立掩码 $I(t)$ 构造力/速度周期奖励。
   - 策略控制频率 **100 Hz**，内环 PD **500 Hz**（Table II 域随机化含 0–10 ms 延迟、[-5, 20] kg 载荷等）；12,288 并行 Isaac Gym 环境。
4. **真机与 Sim2Sim 评测（Section V–VI, Table III, Fig. 10–12）：**
   - **Table III（XBot-S 室内四类地形成功率）**：Slope 100%（PPO 80% / DWLp 被动踝 80%）、Stair-up 100%（vs 20% / 20%）、Stair-down 100%（vs 60% / 100%）、Irregular 100%（vs 20% / 40%）。
   - **户外与鲁棒性**：雪地、砖路、泥土稳定行走；行走中动态加包 15 kg、负重 20 kg、推动 60 kg 推车；多向抗推击（主动踝 $K_p=20, K_d=5$）。
   - **状态估计精度**：MuJoCo 60 s 前向线速度估计 MSE = 0.046，偏航角 MSE = 0.074；真机静态 IMU 偏航漂移降低约 **87%**。
