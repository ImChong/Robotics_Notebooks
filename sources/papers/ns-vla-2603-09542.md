## 原文核验要点
- **方法**：固定原语语法→单调阶段指针、最小停留/夹爪 gate→桥接子指令给低层 VLA→筛选成功 rollout 的 AWR/HJPO；不等于通用在线 LLM 规划。
- **数据协议**：四个 LIBERO 套件，每任务 5 条示范，Plus 1,200 个扰动配置；Long seed 7 的 VLA-Adapter 基线出现 0%，论文附录对此作说明。
- **作者结果**：LIBERO 76.5%、Plus 51.8%，实机 myCobot 320pi 60/100 vs baseline 40/100；与 README 的 1-shot 数值非同协议。
- **边界**：grammar 覆盖、夹爪事件、单调指针和真实任务安全性需要审查。
