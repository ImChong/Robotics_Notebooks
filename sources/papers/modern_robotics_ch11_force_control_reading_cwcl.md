- **作者：** Kevin M. Lynch, Frank C. Park（Cambridge University Press, 2017）
- **类型：** textbook / robot-control / force-control
- **原文：** <http://modernrobotics.org>（2017-05 预印本 PDF，2026-11 获取并 pdftotext 通读相关章节）

## 核心摘录（均出自原文）

- **力控（§11.5，式 11.48–11.54）：** 忽略速度加速度项后 τ = g̃(θ) + JᵀF_d；无力传感器时依赖重力模型与精确关节力矩；有六轴 F/T 时用带前馈的 PI 力控（式 11.51）。不用微分项：力测量含噪，且力控无需积分动力学。若无物可推，机器人会加速，故加速度阻尼项 −K_damp·V（式 11.54）。
- **力矩执行精度（§11.5、§11.8）：** 高减速比关节摩擦使仅电流控制的力矩精度下降，可用输出端应变片或 SEA 的弹簧形变测力矩；SEA 使关节天然柔顺、抗冲击，但高频运动更难控。
- **混合力位（§11.6）：** n 维任务空间中，运动与力共 2n 个量只能指定 n 个，环境决定另外 n 个；不可在「同一方向」同时指定力和运动。刚性环境 k 个方向受约束时，自然约束（环境给定）与人为约束（控制器指定）互补，如擦黑板：v_x=k1、f_z=k2<0。
- **投影控制器（式 11.55–11.61）：** 约束 A(θ)V=0，投影 P = I − Aᵀ(AΛ⁻¹Aᵀ)⁻¹AΛ⁻¹ 把广义力分为运动子空间（P）与力子空间（I−P）；总控制律 = P·运动控制（计算力矩）+ (I−P)·力控制 + 科氏/重力补偿，两子空间解耦，继承各自稳定性分析。
- **约束不确定性（§11.6）：** 实际难点是准确知道当前约束方向；对策包括基于力反馈实时估计约束方向、降低反馈增益使运动控制「变软」、结构上加入被动柔顺；关节与连杆柔性使被动柔顺不可避免。
- **阻抗与导纳（§11.7，式 11.62–11.66）：** 阻抗 Z(s)=F/X，导纳 Y=Z⁻¹；好的运动控制 = 高阻抗（低导纳），好的力控制 = 低阻抗（高导纳）。阻抗控制：感知运动、输出力，理论上应连接导纳型环境，常不配 F/T，靠精确关节力矩；导纳控制：用腕部 F/T 感知力、输出运动，理论上连接阻抗型环境。
- **适用边界（§11.7.1–11.7.2）：** 阻抗控制模拟大 K（硬环境）时，位置小变化 → 力矩大变化，叠加时延、量化与传感误差易振荡失稳，轻质可反驱机器人擅长模拟低阻抗环境；导纳控制模拟低质量环境时小力引起大加速度而不稳，高减速比机器人则擅长模拟硬环境；力读数需低通滤波。
- **其他（§11.9）：** 主动控制的弹簧行为只在低频成立（带宽受限）；变刚度执行器用机械方式提供被动阻抗以突破该带宽限制。
