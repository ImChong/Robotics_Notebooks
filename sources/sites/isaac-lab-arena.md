## 产品主张（页面摘要）

- 建立在 **Isaac Lab** 之上，无需从零搭底层系统即可快速原型化跨具身、物体、场景的复杂任务
- **模块化积木**：Scene / Embodiment / Task（及 Object + Affordance）组合；自然语言任务 authoring **即将推出**
- **大规模 GPU 并行评测**：数千同构环境并行；agentic 评测与根因分析 **即将推出**
- **社区 benchmark 统一核**：Lightwheel、RoboTwin、GEAR、Seattle Robotics Lab 等共建
- **部署形态**：本地工作站、云原生 CI/CD（OSMO）、LeRobot Environment Hub / leaderboard
