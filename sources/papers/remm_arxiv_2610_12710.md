# REMM 论文来源归档

## 元数据

- **题目：** REMM: Revisable Embodied Memory for Manipulation
- **作者：** Revanth Krishna Senthilkumaran, Ruwan Wickramarachchi, Alessandro Oltramari, Jonathan Francis
- **单位：** Carnegie Mellon University；Bosch Center for AI（第一作者工作完成于 Bosch Center for AI 实习期间）
- **预印本：** https://arxiv.org/abs/2610.12710 （cs.RO，v1，2026-10-08）
- **HTML：** https://arxiv.org/html/2610.12710v1
- **项目页：** https://revanthsenthil.github.io/remm/
- **代码：** 论文写 “will release” 实现、评测协议、控制器配置、结构化记忆轨迹和完整试验视频至项目页；截至 2026-10-12 项目页无 REMM 自身代码链接（见 [sources/sites/remm_project_page.md](../sites/remm_project_page.md)）
- **入库日期：** 2026-10-12

## 论文要解决的问题

长时程操作需要保留与任务相关的历史，同时在物理证据不再支持时撤回已得出的结论。仅存观测并不能说明扰动之后哪些“已完成条件”要撤销、哪些义务需要修复。REMM 是包在冻结 VLA 执行器外的监督式记忆层，不更新执行器。

## 方法与训练信息

1. **记忆状态 M_k=(L_k, F_k, D_k, Q_k)：** L_k 只追加的事件账本（候选事件须通过来源相关的门限才入账）；F_k 断言记录（状态为 active / superseded / invalidated）；D_k 有向支持图（每条派生记录需其所有父节点同时成立，即合取支持）；Q_k 有序技能队列。
2. **修订逻辑：** 某记录失效时其所有仍活跃的后代记录被作废；若已完成目标被作废，则生成修复技能：与当前指令共享实体则插到队首，否则追加到队尾。
3. **派发：** 技能执行中不改当前指令，修订后的指令只在“已验证的静止技能边界”下发。
4. **执行器与机器人：** 冻结的 G0.5（自回归 VLA，交错推理与动作生成），机器人为 Galaxea R1 Lite，共享相机；每次查询输出 J=16 个动作，15 Hz 执行。
5. **感知与 VLM：** 冻结的 Qwen3-VL-4B-Instruct 负责受限任务分解与视觉验证；OWLv2-base-patch16-ensemble 提供开放词表 2D 检测；视觉关系接受规则为落地身份、置信度 ≥0.80 且有两次不同观测一致，单纯漏检不撤回事实；T3 使用像素初始化的 MIL 跟踪（离线）。
6. 无训练：不更新执行器参数；依赖图来自任务编译器和固定谓词本体。

## 论文报告的结果

- **物理试验共 51 次**（含操作者协助的运行），任务：T1a 排队扰动、T1b 倒料后目的地变更、T2 有序回忆 + 被扰动的重复、T3 隐藏物体洗牌。
- 全部完成/部分/失败（F/P/X）：Vanilla G0.5 0/12/6（18 次）；HiMe 改编 2/10/4（16 次）；REMM 10/7/0（17 次）。各任务试验数不同，作者说明汇总计数仅为描述性。
- **记录的任务进度均值：** 干预恢复（T1）REMM 91%，最强基线 57%；序列回忆（T2）REMM 70%，最强基线 43%；T3 REMM 4 次全部完成，基线均无完整完成。
- **操作者协助：** 作者称协助“与结果分别记录”，不把完成的运行重标为自主；记录数（无协助/任务协助/未记录）：vanilla 12/0/6，HiMe 6/2/8，REMM 10/4/3；REMM 两次完整完成有记录的协助（T1b 推橙色方块；T2 帮助完成草莓拾取）。协助运行计入所有报告数字。
- **离线视频诊断（42 段，无运动策略）：** T2 的 12 段（LTX-Video 0.9.8 13B Distilled 生成）完整决策 REMM 8/12，RoboMME 风格 5，MemER 风格/HiMe/无记忆均 0；部分得分 86.1% / 73.9% / 55.0% / 54.4% / 38.9%。T3 的 30 段（VET-Bench 洗牌渲染）隐藏目标选择 REMM 30/30，MemER 风格 13，无记忆 11，RoboMME 风格 11，HiMe 10。
- **基线：** Vanilla G0.5；HiMe 改编（Qwen3-VL-4B 规划/哨兵、MiniLM-L6-v2 检索、8 帧工作上下文，非官方复现）；MemER、RoboMME 风格行同为改编。

## 复现与解释边界

- 依赖图来自编译器和固定谓词本体，REMM 不发现因果结构。
- 状态估计为保守的 2D 检测，非标定 3D 状态；只在静止技能边界纠正，不打断不安全的动作块，完全遮挡下不保证恢复。
- 单机器人、小型桌面物体集、受控干预、每条件样本少；视频诊断各方法的计算与观测路径不同。
- 作者承认完整系统对比不能把收益单独归因于图传播。
- 51 次试验 = 18+16+17，且含操作者协助，“记录进度”不等同完全自主成功率。
- 项目页提到基准的额外赛道不计入报告得分，完整基准发布还需盲评第二轮。
