## 核心摘录（通读 arXiv:2609.27449v2 全文）

- **三大设计原则（§1–§2）：** 针对传统仿真评测的「Sim2Real gap、分布窄、刷榜/数据泄漏」三痛点，提出 **Faithfulness / Diversity / Fairness** 三准则。
- **任务体系（§2.1）：** 共 **44 项层级长程任务**、覆盖 **10 个能力维度**：Reasoning 4 类（Generalization 7、Visual Understanding 7、Language Understanding 3、Memory 5）、Manipulation 5 类（Precision Operation 5、Bimanual Collaboration 4、Tool Usage 3、Dynamic Objects 1、Mobile Operation 3）及 Challenge 3 项（Stack Blocks Hard、Press Buttons Hard、Hanoi Tower）；每个任务均分解为 **Task DAG** 子任务有向无环图，由规则评估器判定阶段进展与成功率。
- **多轴随机化与训测隔离（§2.2–§2.3）：**
  - 三正交轴随机化：Appearance（41 个房间、92 种桌面材质、89 个 HDRI）、Task Setting（物体/干扰/规则/指令）、Embodiment（夹爪/相机/桌高）。
  - 训练采集与评测严格隔离：所有训练轨迹在对齐 ManipArena 的绿幕数字孪生环境收集，总计约 **300 小时**（Quanta X1 + ArtiXon Arm 158.1 h、Franka 16.6 h、ARX R5 15.6 h、Challenge 114.1 h），并自动打帧级子任务进展标签。
- **Mana 生态与 Policy Space（§2.4, §3）：** 基于 NVIDIA Isaac Lab-Arena 构建 **Mana** 仿真平台，以 **Physical DSL** 驱动 Task Design Loop 与 Rollout Analysis Loop；通过跨进程隔离的 **Policy Space** 协议（`initialize_episode` / `ingest_observation` / `infer_actions` / `finalize_episode`）统一对接异构策略服务（支持 RTC 与历史状态）。
- **核心实验结果（§4）：**
  - **Sim2Real 对齐与相关性（§4.1）：** 基于真实遥操作轨迹，使用 CMA-ES 校准仿真 StablePD 关节增益 $(K_p, K_d)$。用纯真机数据微调的 `Wall-OSS-0.5` 在 8 项 ManipArena 数字孪生任务上评测：一般操作 5 项线性相关达 **0.96（SR） / 0.99（Progress）**；全部 8 项（含 3 项精细操作，真机 70% 的放眼镜在仿真因镜腿折叠 OOD 掉到 0%）总线性相关为 **0.74（SR） / 0.84（Progress）**。
  - **桌面主榜（§4.2.1, Table 1, 分层宏平均 ID / OOD）：** `wall-oss-preview`（SR 53.90% / 34.26%，Score 67.25 / 56.63）> $\pi_{0.5}$（SR 26.12% / 16.13%，Score 46.19 / 37.75）> `DreamZero`（SR 4.85% / 3.45%，Score 34.21 / 32.12）> `Wall-OSS-0.5`（SR 4.08% / 3.20%，Score 17.85 / 14.10）。所有模型在 OOD 下均显著掉点，精细接触与长程保持是共同瓶颈。
  - **Coding Agent 对照（§4.2.2）：** `GPT-6-Astra`（xHigh 推理，10 episode/环境）OOD SR 36.15% / Score 53.74，在 Reasoning（SR 46.96% / Score 64.52）领先 `wall-oss-preview`，但在 Manipulation（SR 25.33% / Score 42.96）落后；且每次推理耗时 >30 s（仿真暂停等待），非实时闭环。
  - **移动操作与数据合成（§4.2.3, §4.3, Table 2–3）：** 3 项移动任务上 `wall-oss-preview` ID/OOD SR 为 58.33% / 5.00%（vs $\pi_{0.5}$ 29.17% / 0.83%）。在 `stack_blocks (hard)` 上，Task-DAG 自动合成 + 分阶段指令平均堆叠 4.40 层（最高 10 层），优于主从遥操作（2.05 层，最高 4 层）。
- **局限（§6）：** 仅支持刚体与铰接刚体（不含柔性体、流体）；任务设计仍需人工与智能体协作；当前采用标准夹爪且无触觉传感；评测流程仍偏静态。
