# JEPA-Anything 官方项目页

> 来源归档（项目页与发布说明）

- **标题：** JEPA-Anything: Learning Predictive Models across Different Worlds
- **项目页：** <https://phai-labs.com/news/jepa-anything/>
- **发布：** 2026-09-18
- **论文：** [arXiv:2609.20800](../papers/jepa_anything_arxiv_2609_20800.md)
- **代码：** <https://github.com/Gen-Verse/JEPA-Anything>（Apache-2.0；[仓库归档](../repos/jepa-anything.md)）
- **关联项目：** [RSI-Anything](./rsi-anything.md)
- **一句话说明：** 项目方以 orthogonal predictive factorization 描述跨领域 JEPA 预测结构，并报告七类领域的实验结果。

## 项目页所述结果与边界

项目页列出视觉、生物、临床轨迹、控制、分子动力学、物理场和天气七个领域，并总结十项动力学任务的指标改善、Interventional Pong 单次干预误差降低 34.8%、分子系统长程预测、生物干预验证及 Kepler 缩放结果。以上为项目方对论文的概述，各基准与外部验证的协议应回到论文核查。

页面另称有公开 Hugging Face 模型集合，但没有公开演示；这与 GitHub 仓库内不含领域数据集和训练权重的边界分开记录。

官方 DFM 页面把 DFM 作为研究范式/能力定义，并称 JEPA-Anything、ScienceBuddy 与 ScienceIDE 是独立模块；目前不应描述为已集成的单一科学系统。
