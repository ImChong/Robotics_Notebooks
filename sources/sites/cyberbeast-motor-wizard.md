## 已核实事实

- 手册第 16 页明确写出 `motorwizard.exe` URL，要求 Windows 默认安装。
- 在同页，厂家还提示通过 Zadig 为 CyberBeast Motor Driver Device (Interface 2) 配置 USB 驱动；此路径对应手册所述 USB 调试环境，**不能推定所有无 USB 座的出货版本可直接使用**。
- 下载服务是否仍可用、程序版本、程序二进制体积均未核实；本页不将“31 MB”作为事实。
