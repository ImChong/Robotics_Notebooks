# CodeGraph 项目页

> 来源归档

- **标题：** CodeGraph — Understand any codebase as a graph
- **类型：** 项目页
- **链接：** <https://colbymchenry.github.io/codegraph/>
- **代码：** <https://github.com/colbymchenry/codegraph>
- **许可：** MIT（以官方仓库为准）
- **入库日期：** 2026-10-14
- **项目页核查：** 页面介绍 CodeGraph 为本地优先的代码智能工具，强调 Tree-sitter 解析、MCP server 与调用影响分析；页脚链接到官方 GitHub 仓库和 MIT 许可。仓库公开源码可用。
- **一句话说明：** 将代码仓库构建为 coding agent 可查询的代码关系图，以符号和调用路径为中心提供上下文。

## 页面要点

- Tree-sitter 解析覆盖 20 多种语言，提取符号和结构关系。
- MCP 将图提供给 Claude Code、Cursor、Codex、OpenCode、Hermes、Gemini、Antigravity 和 Kiro 等 agent。
- 调用者、被调用者及影响半径用于帮助开发者在修改前理解可能波及的代码。
