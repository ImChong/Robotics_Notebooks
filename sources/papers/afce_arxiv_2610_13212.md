- **作者：** Min Lin, Bokai Zhou, Jianqi Lin, Kaiyuan Yang, Yicheng Chang, Junjie Yu, Xiaofan Liu, Jianhua Han, Rui Li, Shen Zhao, Xiaodan Liang（共 11 人，通讯作者 Shen Zhao、Xiaodan Liang）

- **预印本：** https://arxiv.org/abs/2610.13212 （v1，2026-10-09，cs.RO / cs.AI）

- **核对日期：** 2026-10-12

## 论文要解决的问题

VLA 策略主要学习预测动作块；动作只说明「要执行什么」，没有说明「执行后会达成什么物理效果」。AFCE 把「Effect」——由示范动作、机器人实际响应、稀疏视觉变化共同构成、仍可解码回连续动作的未来导向目标——作为策略的主要预测对象。

## 方法与训练信息

1. **Stage I：Effect 分词器（离线）。** 输入窗口 H=30 步：动作编码器（位置/旋转/手指分别投影）、响应编码器（掌心平移、相对朝向、指尖位移、手指关节变化，由观测状态和正运动学算出）、视觉编码器（冻结 DINOv3 特征，步长 5 加终止帧采样，最多 6 个动态区域 + 2 个参考区域，每区域 8 槽，描述子 136 维经 PCA 降到 64）。可学习的步查询对三路证据做交叉注意力（QueryFusion），再经时序 Transformer，输出 30×256（每步一个连续 Effect，**无离散码本**）。损失 L_I = L_A（分组 Huber，位置权重 2）+ λ_S·L_S + λ_V·L_V + λ_R·L_rot（SO(3) 弦距离）。训练 30,000 步、全局 batch 32、AdamW。
2. **Stage II：流匹配 VLA。** 从官方 π0.5 基座改造：动作输入输出投影换成宽 256 的 Effect 投影，保留视觉语言状态主干；PaliGemma 2B 用 LoRA（秩/alpha 16/16），300M 动作专家 32/32；流时间 τ=0.999ξ+0.001，ξ~Beta(1.5,1)；辅助动作损失 λ_GT=0.256（Huber）与手指差分 λ_Δf=0.05，仅在 τ∈[0.2,0.7] 生效。60,000 步、全局 batch 32；推理 10 步流积分产生 30 步 Effect 块，滚动时域重规划。
3. **状态条件解码器：** 4 层、8 头、FFN 1024，由 Stage I 初始化，与策略联合训练，训练与部署一致，将预测 Effect 加当前机器人状态映射成本体动作块。
4. **本体接口：** 单臂 22 维动作/23 维状态，双臂 44 维动作/46 维状态（每臂位置 3 + 旋转向量 3 + 16 个手指关节）；视觉编码、融合、时序与 Effect 主干共享，仅输入输出适配器按本体区分。论文提醒共享参数不等于证明学到本体无关表示。
5. **算力：** Stage II 两节点各 4 张 GH200（共 8 GPU）；Stage I 算力原文未写。

## 论文报告的结果（DexJoCo，仿真）

- 设置：Panda–Allegro 机器人，11 个任务（单臂 6：Pinch Tongs、Click Mouse、Fold Glasses、Hammer Nail、Pick Bucket、Water Plant；双臂 5：Unlock iPad、Hanoi、Assembly、Microwave、Photograph）；每任务 100 条示范，共 1,100 episode / 523,763 帧（30 FPS）；rand-obj 评测，每任务每种子 50 episode，种子 0/1/2，每方法 1,650 episode，每方法只用一个检查点，报告的 ± 来自评测种子。
- 总体成功率：UVT 35.76±0.56，π0.5 39.15±2.11，AFCE 50.97±1.65（+11.82 对 π0.5，+15.21 对 UVT）。单臂均值 UVT 53.44 / π0.5 63.67 / AFCE 62.33；双臂均值 14.53 / 9.73 / 37.33。AFCE 在 5 个双臂任务全部领先，整体 7 个任务领先。
- 代表任务（UVT / π0.5 / AFCE）：Microwave 41.33 / 32.00 / 81.33；Hanoi 0.67 / 5.33 / 29.33；Photograph 30.67 / 8.00 / 59.33；Hammer Nail 22.00 / 84.67 / 86.67；Pinch Tongs 1.33 / 43.33 / 5.33（最大退步，作者称为未解决的精度控制局限）。
- Effect 构造输入消融（单臂均值 / 双臂均值）：仅动作 57.22 / 30.93；去响应 48.67 / 25.47；去视觉 55.67 / 21.60；完整 62.33 / 37.33。
- Effect 维度（真值 Effect 回放，110 条训练示范）：d=256 位置误差 7.794 mm、回放成功 25/110；d=128 为 8.965 mm、23/110；d=64 为 11.585 mm、18/110。
- 读出诊断（训练集内）：真值 Effect 解码位置误差 8.30 mm，用预测 Effect 时 36.91 mm。

## 复现与解释边界

- 全部为仿真实验，**原文未报告真机实验**。
- 作者承认：需要时间对齐的动作、状态、未来图像来构造目标；视觉特征可能漏掉细微接触、受遮挡与视角影响；闭环成功率无法区分 Effect 预测、融合、解码各自的误差；离线构造目标增加训练成本。
- 仓库 README 记录的参考结果（种子 0、11 任务 × 50 episode）为 284/550=51.64%，与论文三种子均值 50.97% 是不同统计口径。
- 数据集、DINOv3 权重、π0.5 检查点、Effect 缓存、rollout 视频不随仓库发布，需自备。
