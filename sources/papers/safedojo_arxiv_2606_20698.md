## 核心摘录

1. **问题设定（§3.1）：** 把 VLA 的 MDP 扩成 CMDP，加安全代价 c∈[0,1]，约束 J^c ≤ d；「safe-success」要求完成任务且无碰撞代价。
2. **方法（§4）：** 4.1 基于 Wan 2.2 的动作条件视频世界模型，动作块 H=8 步、每步 7 维（6 自由度末端位姿增量加夹爪），采用 static-video 增强缓解曝光误差；4.2 任务奖励头（ResNet 成功分类器，作用于想象帧）与安全头（卷积潜变量编码器加动作条件 MLP，输出每步接触概率），代价按 top-M（M=16）聚合；4.3 拉格朗日约束 GRPO，Â_safe = Â^r − ηÂ^c，η ← [η + α(平均 c − d)]_+，d=0.2、α=0.05、G=16、β=0。
3. **仿真（§5.2，SafeLIBERO，基座 OpenVLA-OFT）：** 仅用 Level I 训练。Level I 平均 TSR 64.50 / SSR 53.25 / ETS 269.41（表 1），SSR 比最强基线 SafeVLA（45.00）高 8.25 个百分点；Level II 平均 TSR 57.00 / SSR 49.62 / ETS 277.00（表 2），SSR 仅领先 SafeVLA（49.50）0.12 个百分点。
4. **真机（§5.3、附录 H、表 8）：** Franka Panda，5 个任务（含 1 个双臂），每个方法每个任务 10 次试验，SafeDojo 平均 TSR 76.00 / SSR 70.00；次优 SSR 为 SafeVLA 36.00。
5. **消融（§5.4、图 4）：** 仅在 Level I Spatial Task 0 上，固定初始 η=0.3：去掉安全头 SSR 降到 38%，去掉任务奖励头 TSR/SSR 塌到 3%，去掉约束 GRPO 降到 40%/34%，去掉自适应拉格朗日 SSR 46%。η 扫描 0.1–0.6，0.2 最好（TSR 74、SSR 58、ETS 186.3）。
6. **局限（附录 B）：** 安全头只用二值碰撞标签；世界模型误差随 rollout 累积；只评估静态障碍的桌面操作；仅为训练期安全机制，无推理期硬保证。
7. **实现（附录 I、J）：** 世界模型在 1.5K SafeLIBERO 轨迹上微调 5000 步（只训 DiT，VAE 固定），策略训练用 32 张 A800-80GB；安全标签来自 SafeLIBERO 的接触碰撞审计；WMPO 与 SafeDojo 为每任务单独 checkpoint，WoVR 为每套件一个 checkpoint。
