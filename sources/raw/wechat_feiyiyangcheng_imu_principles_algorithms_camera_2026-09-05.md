# 图解 IMU：原理、算法与摄像头驱动协同

## 先从一台会晃动的相机讲起

一台相机向右转动，画面里的静止物体通常向左移动。仅观察图像，很难立即区分这是相机转动、物体运动，还是两者同时发生。IMU 提供另一条线索：它直接测量机身的惯性响应，让系统知道相机在何时、绕哪个轴、转得多快。

IMU 是惯性测量单元，常由三轴加速度计和三轴陀螺仪组成。加速度计测比力，可先理解为单位质量所承受的非重力作用；陀螺仪测角速度，也就是旋转的快慢。它们输出的是测量数据，姿态和位置还需要算法估计。1

| --- | --- | --- |
| 原理与组成 | 小芯片怎样感知运动？ | MEMS、六轴测量、温度与信号处理 |
| 数据与误差 | 数字的方向、单位和时间是什么？ | 采样率、量程、FIFO、零偏与标定 |

| 应用与验证 | 怎样确认补偿方向和效果正确？ | EIS、滚动快门、VIO 与异常排查 |

全文先用直观模型解释，再给出必要公式与具体例子。寄存器可以理解为芯片中的配置和数据格子；驱动是操作这些格子的系统软件；算法则把测量组合成姿态或图像补偿。三者职责不同，但必须使用一致的单位、坐标和时间。

> 本文统一采用右手坐标系，世界坐标系 W 的 Z 轴朝上。R\_WB 把机体坐标系 B 中的向量转换到 W。图形为原创原理示意，不按器件尺寸绘制；仿真曲线不代表某个具体芯片的实测性能。

摄像头章节以常见嵌入式 Linux 架构为例，同时说明可迁移到 RTOS（实时操作系统）的原则。具体引脚、寄存器、同步能力和回调函数，仍需对照芯片手册与目标系统版本。

## 六轴究竟是哪六轴？

把一块小电路板想象成一个具有方向的物体：它可以沿三个轴平移，也可以绕三个轴旋转。加速度计对应三个线性测量通道，陀螺仪对应三个旋转测量通道。“六轴”指六个测量通道，不是六个空间方向，更不是已经测出了六自由度位姿。

*图 1  三个方向的比力与绕三个轴的角速度。正方向按右手定则约定。*

| 器件 | 输出 | 常见单位 | 直接回答的问题 |
| --- | --- | --- | --- |
| 加速度计 | a\_x、a\_y、a\_z | g 或 m/s² | 各轴承受多大的比力？ |
| 陀螺仪 | ω\_x、ω\_y、ω\_z | °/s 或 rad/s | 各轴转得多快？ |
| 磁力计（可选） | m\_x、m\_y、m\_z | μT | 当地磁场指向哪里？ |

九轴模块通常在六轴基础上增加三轴磁力计。它提供磁场参考，并没有增加三个独立的空间自由度。温度读数、计步结果、四元数等也可能由模块输出，但这些附加量不属于“六轴”的计数。

角速度可以用度每秒，也可以用弧度每秒。完整一圈是 360°，也是 2π rad；1 rad 约为 57.3°。算法中的三角函数通常使用弧度，混用两种单位会把角度放大或缩小约 57.3 倍。

> IMU、AHRS 与 INS 并非同义词。IMU 负责惯性测量；AHRS 利用融合算法估计姿态与航向；INS 进一步传播速度和位置。具体产品可能将多个层次集成在同一模块中。13

## 加速度计：一块微小质量块的位移

MEMS 是微机电系统，可以理解为在芯片内制造出的微小弹簧、质量块和电极。常见电容式 MEMS 加速度计，可以抽象成“外壳＋弹簧＋质量块”。外壳跟着电路板运动，质量块由于惯性与外壳产生相对位移。质量块和固定电极之间的电容随间隙改变，检测电路便能把机械位移转为电信号。2

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqAibRO26bGaX4NoYiaVD5ty2QXkBxJ6fyt6XleBj975HvIWClMYVZ9ktWDkL0PbicY99bOQfYkiaPDbhg5NbIjS5vTW4BRGHXpovPIE/640?wx_fmt=webp&from=appmsg#imgIndex=1)

*图 2  电容式加速度计的简化结构。框架向右加速时，质量块相对框架偏向左侧。*

理想平行板模型：电容 C 与间距 d 成反比；实际芯片常使用差分和梳齿结构。

两侧电容一增一减，构成差分测量，即观察两路信号的差值，而不是只看其中一路。差分结构既能辨别方向，也能抑制一部分公共干扰。三轴器件利用多个敏感结构或相应的三维结构，获得三个方向的测量。

质量块并不会无限自由移动。弹性结构、阻尼（抑制振动的作用）、反馈电路和机械限位共同决定动态响应。超过量程的运动可能使数字输出饱和；过强的机械冲击还可能超出器件允许范围。

> “用弹簧测位移”是理解原理的模型。真实器件可能采用闭环力反馈、不同电极结构及复杂补偿，不能把简化示意图当成具体芯片的内部版图。

## 静止为何读到 1 g，自由落体却接近 0？

放在桌面上的设备没有运动加速度，但桌面支撑着它。加速度计检测到支撑造成的比力，理想读数模长约为 1 g。自由落体时，外壳和质量块一起下落；忽略空气阻力与旋转等影响，读数反而接近 0。

*图 3  四种状态下的理想读数。符号取决于轴向；匀速直线运动与静止的比力可以相同。*

f\_B 为理想比力；a\_W 为实际运动加速度；g\_W=(0,0,-g)。

当设备水平放置且机体 Z 轴朝上，a\_W=0，得到 f\_B=(0,0,+g)。把设备倾斜，读数会分配到不同轴上，但静止时三轴模长仍接近 g。要恢复世界坐标系中的运动加速度，需要反向变换并补回重力向量：

> 常见接口把比力字段命名为 accel 或 acceleration，这不改变其物理意义。部分融合模块另行输出去重力后的 linear acceleration；两种数据必须区分。14

重力补偿依赖姿态。若倾角误差只有 1°，重力在水平方向的错误投影也约为 g·sin(1°)=0.171 m/s²。后续积分会迅速放大这个误差。

## 陀螺仪：用振动感知旋转

常见 MEMS 陀螺仪内部有持续振动的微结构。结构沿驱动轴来回运动，整个器件发生旋转时，旋转参考系中的科里奥利效应会在另一方向产生响应。它可以理解为：在旋转的观察坐标中，运动方向会出现横向偏转趋势。检测该响应的幅度和相位（振动所处的周期位置），就能得到角速度。2

*图 4  简化的振动陀螺仪。图中以正向驱动速度和正向 Z 轴旋转，示意瞬时科里奥利力方向。*

这是旋转参考系中的科里奥利惯性力写法；幅度随质量、驱动速度和角速度变化。

陀螺仪输出角速度，而非已经转过的角度。例如绕单一固定轴以 90°/s 旋转 1 s，理想角度变化为 90°。停止旋转后，即使设备保持倾斜，陀螺仪也会回到接近零。

上式中 ω\_m 是测量角速度，b\_g 是零偏。若残余零偏为 0.05°/s，静止积分 60 s 就产生约 3° 的误差。实际还叠加噪声、温漂与轴间误差。

> 三维旋转存在顺序效应：先绕 X 转，再绕 Y 转，与反过来通常不同。不能简单把三个陀螺仪通道分别积分后，直接称为 Roll、Pitch、Yaw。

## 一颗 IMU 内部有哪些组成模块？

敏感结构只完成“运动到微弱电信号”的第一步。现代数字 IMU 还需要信号调理（把微弱信号放大并整理）、数字转换、滤波（限制不需要的频率成分）、缓存与通信。下面展示一种概念结构；具体芯片的转换顺序、反馈形式和滤波链会不同。

ADC 是模数转换器，把连续的电信号变成数字刻度；中断像一声通知铃，提醒处理器有数据或事件；FIFO 像排队区，先进入的样本先取出。温度通道用于记录芯片温度，帮助解释和补偿随温度变化的误差。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqAicZydsHc4gJYbEZsn1LpjGSGHJKsGLicKpOWicEsRsBB9gcxA3MibtHiaQzY3xgYr3j8ib6sDDMViaKCTkUuOJ7XOQWUCaxS4LsVJcIE/640?wx_fmt=webp&from=appmsg#imgIndex=4)

*图 5  IMU 的概念组成。抗混叠需要发生在相关采样或降采样之前；并非只在输出端加低通即可。*

| 模块 | 核心职责 |
| --- | --- |
| 敏感结构与模拟前端 | 检测位移或振动响应，放大、解调、抑制公共干扰 |
| ADC 与数字滤波 | 将信号转换为数字量，控制有效带宽、噪声与输出速率 |
| FIFO 与时间戳 | 缓存样本，记录或关联测量时间，减少主控读数开销 |
| 总线与中断 | 通过 SPI、I²C 或部分器件支持的 I3C 配置和读取数据 |
| 温度、时钟与电源管理 | 支持温度补偿、采样节拍以及性能和功耗模式 |
| 可选处理引擎 | 运动唤醒、计步、有限状态机或片上姿态融合 |

磁力计可以集成，也可以作为外部器件接入。它通过周围磁场提供方向参考。固定磁性偏置称为硬铁效应；材料造成的方向相关畸变通常称为软铁效应。两者可做标定，但随电机电流变化的干扰不能靠一次静态标定永久消除。3

例如 BMI270 提供 FIFO 与 Sensor Time；LSM6DSV 具有不同用途的数据处理通道。这些只是功能实例，寄存器、量程和时序必须以所用型号手册为准。56

## 坐标系与姿态：先统一语言，再讨论算法

IMU 轴向由芯片封装定义，电路板轴向由安装定义，相机轴向由成像模型定义。三个坐标系常常不一致。一个“绕 Z 轴旋转”的数值，只有同时说明坐标系，才具有可复现的意义。

右手坐标系可用右手三指想象：三根正轴按固定方向排列。姿态描述物体朝向；位姿则同时包含位置和朝向。外参是两个传感器之间固定的安装关系，内参是某个传感器自身的成像或测量参数。

## 采样率、带宽、量程与噪声不能混为一谈

ODR 是输出数据率，表示每秒输出多少个样本，带宽描述通道对多快的变化仍有响应。1 kHz 输出并不意味着能准确测量 1 kHz 的振动。若高频成分在采样或降采样前没有充分抑制，就可能折叠到低频，形成混叠。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqA8w8nicjvnQjNZ08aQb3iaTHMZAozykruCg0VicmTOjibmib5IhWrGicZRIwXVOQUr0NOEwFJExPicsHOMWF8ibj6WXdNwIqEArmicDdH7c/640?wx_fmt=webp&from=appmsg#imgIndex=6)

*图 7  教学仿真：800 Hz 信号以 1 kHz 采样，其样本与一个 200 Hz 的低频信号重合。*

量程决定最大可测值。超出量程时，数字输出被截顶；原始运动信息已经丢失，后端滤波无法完整恢复。灵敏度决定每个码值对应的物理量。量程越大，在同样编码位数下，每个 LSB（最低有效位，即一个数字刻度）通常代表更大的输入变化。

这里 S\_a 的单位为 g/LSB，S\_g 为 (°/s)/LSB；实际数值查型号手册。

噪声密度描述单位频带内的噪声；RMS 是均方根，可理解为波动的有效大小。对白噪声，输出 RMS 噪声与等效噪声带宽 B\_ENBW 的平方根成正比。截止频率与等效噪声带宽不是同一个量：

> 降低带宽通常能减小噪声，却也可能增加相位滞后（信号变化跟随得更晚）。控制和防抖应同时看噪声、延迟、饱和与抗混叠能力；“曲线更平滑”不一定意味着系统更准确。8

## FIFO 与时间戳：一批到达，不等于同时采样

主控可以在每次 Data Ready（数据就绪）中断时读取，也可以让 IMU 把数据先存进 FIFO（先进先出的数据队列），到达水位（设定的积累数量）后批量读取。后一种方式减少中断和总线开销，但会增加批量等待时间。传输批次与测量节拍是两个概念。

*图 8  1 kHz 采样、4 个样本一批的理想时序。到达时刻还会受调度和总线延迟影响。*

更可靠的方案使用芯片时间戳、样本计数或硬件同步事件。芯片时钟和主控时钟之间可先用 t\_host≈s·t\_sensor+b 建立映射：b 描述偏移，s 描述频率比例。还需处理回绕、时钟漂移和数据通道的滤波延迟。

| 驱动检查 | 错误后的表现 |
| --- | --- |
| 符号位、大小端、dummy byte | 幅值或符号明显异常 |
| FIFO 标签、通道 ODR、丢样状态 | 六轴错配、样本重复或时间断裂 |
| 数据一致性与自动地址递增 | 多字节或多轴数据混入不同采样时刻 |
| 中断语义与时间戳来源 | 高负载下融合和防抖效果波动 |

## 误差为何会被积分放大？

一个简单的陀螺仪测量模型包含比例与轴间误差矩阵 M\_g、零偏 b\_g 和随机噪声 n\_g。加速度计也可以使用相似形式描述。标定主要处理可重复的确定性误差，融合还要处理随时间变化的不确定性。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqAicXJtTtonrYVSmbpxvn0K2NtWCiaVaOt6aibCGO7FESmX1eFQht6yeQ1pT9pByuJHnWGskN88BDqjny4CCKrQ9jfHMWLrwJboXro/640?wx_fmt=webp&from=appmsg#imgIndex=8)

*图 9  教学仿真：零偏造成持续角度漂移；独立的恒定加速度误差造成二次位置增长。*

| 误差 | 直观表现 | 常见处理 |
| --- | --- | --- |
| 零偏与温漂 | 静止仍有输出，热机后均值改变 | 静态估计、温度模型、在线偏置状态 |
| 比例与轴间误差 | 转 90° 却估成 88°，单轴运动串轴 | 多姿态或转台标定、矩阵补偿 |
| 随机噪声 | 样本抖动，积分产生随机游走 | 合理带宽、噪声建模、传感器融合 |
| 振动与安装应力 | 电机转速或固定方式改变后误差变化 | 机械设计、抗混叠、实际工况验证 |

图中的 0.01 m/s² 恒定运动加速度误差，在 60 s 后对应 18 m 位置误差。这只是隔离单一误差源的计算，不是具体 IMU 的精度预测；实际还会叠加姿态、初值和噪声误差。

> Allan deviation（阿伦偏差）像一把可改变时间尺度的尺子，可从较长静态数据中识别不同时间尺度的随机误差特征。噪声密度、零偏不稳定性和开机零偏不是同一个指标，不能互相替代。8

## 读懂算法公式，只需要先认识几种符号

姿态算法里的公式并不是另一套物理规律，而是把方向、变化和可信程度写成可以计算的形式。先建立下面几个直观概念，后面的互补滤波与状态估计就容易理解。

| 术语 | 通俗解释 | 在 IMU 中的例子 |
| --- | --- | --- |
| 标量 / 向量 | 一个数 / 带多个方向分量的一组数 | 温度是标量；三轴角速度构成向量 |
| 模长 / 归一化 | 向量有多长 / 把长度改为 1 | f/||f|| 保留比力方向，去掉大小 |
| 矩阵 / 转置 | 一组线性变换规则 / 行列互换 | R 改变向量的坐标表达；旋转矩阵转置等于逆 |
| 叉积 | 由两个方向产生一个垂直方向 | 重力方向不一致时，提供旋转纠偏方向 |
| 积分 | 把每个很短时间里的变化累加 | 10°/s 持续 0.01 s，角度增加 0.1° |
| 残差 / 创新 | 实际观测减去模型预测 | 测量倾角 5°、预测 4°，差值为 1° |
| 协方差 | 描述误差大小及误差间关联的表 | 某方向越不确定，对应误差范围通常越大 |
| 梯度 | 误差评分上升最快的方向 | 沿相反方向小步调整，尝试降低方向误差 |

四元数可以理解为“记录三维朝向的四个关联数字”。它们必须满足长度为 1 的约束，只有三个独立旋转自由度。四元数相乘相当于组合旋转；乘法顺序有意义，不能像普通数字乘法一样随意交换。

滤波器中的“增益”表示修正的力度。“可观测”表示已有测量包含足够的信息，可以区分某个状态的不同取值。例如重力能帮助判断倾斜，却无法单独区分设备绕竖直方向转到了哪个航向。

> 读公式时先确认四件事：变量代表什么、单位是什么、在哪个坐标系中、对应哪个时刻。满足这些条件以后，才适合比较不同论文或代码中的符号和参数。

## 一个可运行的单轴融合示例

下面的 Python 示例只估计绕 X 轴的横滚角。输入已经过标定：角速度为 rad/s（弧度每秒），加速度为 m/s²，dt 为秒。首次初始化要求静止或低动态；返回值为 None 表示暂不具备初始化条件。

```
import math

class RollFilter:
    def __init__(self, tau=0.5, gyro_bias=0.0):
        if not math.isfinite(tau) or tau <= 0:
            raise ValueError("tau must be positive")
        if not math.isfinite(gyro_bias):
            raise ValueError("invalid gyro bias")
        self.tau, self.bias = tau, gyro_bias
        self.angle = None

    def update(self, gx, ax, ay, az, dt):
        vals = (gx, ax, ay, az, dt)
        if not all(math.isfinite(v) for v in vals):
            raise ValueError("non-finite input")
        if not 0 < dt <= 0.05:
            raise ValueError("invalid dt or data gap")
        g = 9.80665
        norm = math.sqrt(ax*ax + ay*ay + az*az)
        trusted = (abs(norm - g) < 0.1*g and
                   math.hypot(ay, az) > 0.2*g)
        ref = math.atan2(ay, az)
        if self.angle is None:
            if not trusted:
                return None
            self.angle = ref
            return ref
        pred = self.angle + (gx - self.bias) * dt
        if trusted:
            alpha = self.tau / (self.tau + dt)
            err = math.atan2(math.sin(ref - pred),
                             math.cos(ref - pred))
            pred += (1 - alpha) * err
        self.angle = math.atan2(math.sin(pred),
                                math.cos(pred))
        return self.angle
```

> 0.1 g、0.2 g 和 50 ms 是教学阈值，不是通用参数。模长检查只是一道基础筛选：持续线性加速度仍可能通过。强动态场景还需要残差检测、运动模型或外部观测；数据间断也应由上层明确处理。

把算法移植到 C 时，核心步骤保持不变：单位统一、真实 dt、偏置扣除、参考有效性判断、角度差环绕。浮点或定点选择应由算力、量程和数值精度共同决定。

## Madgwick：沿着误差下降的方向修正姿态

Madgwick 的原始算法同样使用四元数，但把方向一致性写成一个目标函数。目标函数是一种可以计算的误差评分，用来衡量“当前姿态预测的重力或磁场方向”与“实际测量方向”的差异，再沿目标函数下降的方向修正陀螺仪预测。13

β 控制校正强度。β 太小，参考修正较慢；β 太大，可能把加速度和磁场扰动带入姿态。计算时必须处理零梯度、无效加速度和无效磁场，更新后归一化四元数。

### 从输入条件选择算法，比只比较名字更有效

| 方法 | 关键思想 | 适用起点 | 主要注意点 |
| --- | --- | --- | --- |
| 单轴互补 | 角度预测＋参考回拉 | 倾角教学、受约束单轴运动 | 不直接推广为通用三维姿态 |
| Mahony | 方向叉积误差＋反馈 | 嵌入式三维姿态、在线偏置估计 | 坐标与反馈符号、积分饱和 |
| Madgwick | 四元数目标函数梯度下降 | 低计算量姿态融合 | β、归一化、动态观测拒绝 |
| EKF / ESKF | 状态和协方差预测＋观测更新 | 融合相机、GNSS、轮速等 | 模型、噪声、线性化与可观测性 |

Mahony 与 Madgwick 都可用于六轴或增加磁场参考的方案，但六轴版本不会凭空获得绝对航向。即便接入磁力计，也需要校准、倾斜补偿和磁干扰检测；磁北与真北之间还存在磁偏角。

## EKF / ESKF：连“不确定程度”一起估计

扩展卡尔曼滤波 EKF 不只保存姿态或位置，还用协方差描述当前估计的不确定性。IMU 使状态向前传播，外部观测提供纠正机会。观测能纠正哪些状态，取决于测量模型与当前运动，不是把传感器接上就全部可观测。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqA8YBNn9z7g8SNHoicJiaM5MDTDDD1NPKRYiaDSpzwTkhnmz7wXJlK73vYJ3aCCM5pCic0nG9gXmC9WgXtcicIdQDoxEqXDoP9EHwXLA/640?wx_fmt=webp&from=appmsg#imgIndex=13)

r 是创新，即观测与预测观测的差；H 是观测模型的局部雅可比，即描述“状态稍微改变，预测观测会怎样改变”的变化率矩阵；P 是状态协方差；R 是观测噪声协方差。这里的 R 表示噪声矩阵，与前文带坐标下标的旋转矩阵不同。K 决定如何把创新分配给状态修正。

仅估计姿态时，可以把姿态与陀螺仪偏置放入状态。惯性导航中常见状态为位置 p、速度 v、姿态 q，以及加速度计和陀螺仪偏置 b\_a、b\_g。误差状态 ESKF 用小旋转误差描述姿态不确定性，而由单位四元数保存名义姿态。

一次完整更新包括：用 IMU 传播名义状态和协方差；计算观测残差与一致性；求校正；将姿态小误差等注入名义状态；按所选误差定义重置误差状态与协方差。把四元数四个分量当作无约束普通变量，容易破坏几何一致性。

> EKF 不会自动理解传感器。时间偏差、错误外参、过小噪声参数、磁干扰或错误的静止假设，都可能使滤波器过度自信甚至发散。ESKF 的具体公式需与误差定义成套实现。715

## 硬件连接：图像和惯性数据各走哪条路？

图像 Sensor 内部的感光像素把光变成电荷，再读出像素值；IMU 的微机械结构把运动变成六轴数值。两者通常是独立芯片，固定成近似不变形的整体，也就是同一刚体后，IMU 才能稳定代表相机机身的运动。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqA9grQQYeDEDNT7VlkHKWl6NEIzQwnCXBsnIqQQicwS6tS5bicKFRv4yvn4KZsJ9iavdUarcSMK0cS3MgCdHD9eqcwMjOME0e1ol9k/640?wx_fmt=webp&from=appmsg#imgIndex=15)

MIPI CSI-2 是摄像头传输像素的高速串行接口，可理解为运送大量图像数据的通道。I²C 或 SPI 常用于读写寄存器；IMU 的数据量较小，也通过这类总线传输。RAW 是尚未完成完整颜色处理的原始像素，控制图像 Sensor 的 I²C 通常并不搬运整幅 RAW 图像。

GPIO 是可配置的通用引脚，常用于接收中断或同步电平。INT 是中断信号，通知主控“新样本已就绪”或“FIFO 已达到水位”。FSYNC 通常表示某种外部同步输入，但不同 IMU 可能只记录边沿、标记样本或调整内部时序，不能仅凭引脚名称认定它会立即触发采样。

> 是否可以把相机触发信号接到 IMU，取决于两端电平、边沿极性、频率范围及功能定义。VSYNC（帧或场同步信号）、外部触发、曝光有效和 CSI 帧开始包不同，不存在通用的直接接线规则。

硬件同步并不等于所有延迟都消失。传感器内部读出、数字滤波和总线传输仍有时间关系需要确认。没有专用同步线时，也可以用可靠硬件时间戳和时钟映射建立关联。

## 设备树：描述接线，不负责逐帧同步

设备树 Device Tree 是 Linux 用来描述板级硬件的一份数据结构，可把它理解为机器可读的接线说明。它告诉系统某个总线上有什么器件、器件需要哪些时钟与电源、引脚连到哪里。驱动根据这些信息找到并控制硬件。22

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqA9Yta5VF8zDnnhHX9qJCVVqicBGwuDwIHxdGZkibm9O0OsoSYZqTsk6oML2GMDy10rymm1mlXUG2m5Ioz6ZVbf1DqBQPh2X9ibLBQ/640?wx_fmt=webp&from=appmsg#imgIndex=16)

*图 17  设备树描述两类硬件资源；图像与 IMU 的时间关系由采集和同步逻辑建立。*

| 对象 | 通常需要核对的描述 | 它不会自动完成什么 |
| --- | --- | --- |
| 图像 Sensor | 型号匹配、总线地址、电源、时钟、复位 | 不会自动获得实际曝光时间 |
| CSI 视频端点 | 两端连接、数据通道、相关时钟参数 | 不会把 IMU 变成视频端点 |
| IMU | 总线、片选或地址、中断、供电及支持的属性 | 不会自动生成图像与样本的匹配关系 |
| 安装关系 | 适用时提供轴向或安装矩阵信息 | 不会保证驱动已把矩阵应用到每个样本 |

compatible 是用于匹配驱动的型号标识。endpoint 是视频接口的连接端点。binding 是描述哪些属性有效、类型是什么的规则。属性名称必须来自对应器件和版本的 binding，不能给任意 IMU 节点写入自创的 camera-sync 属性并期待通用驱动识别。

> 设备树片段必须与具体芯片、板卡和内核版本匹配。实现时应从目标内核已有的相机与 IMU binding 出发，按原理图填写，并分别验证两条采集链。具体实例可查 BMI270 与视频接口绑定。2425

## Linux 驱动分工：V4L2 管图像，IIO 管惯性

V4L2 是 Linux 视频采集框架，提供图像格式、视频缓冲区、帧序号和控制接口。IIO 是工业输入输出框架，常用于加速度计、陀螺仪等采样设备。框架可以理解为一套统一的接口约定，使上层不必直接操作每颗芯片的寄存器。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqAibpWrssVb2vC4kBCjpvMwicrhPxQRFy2ialPC0JrpbQOEiaHR5GEhjic2f4wVALzuKGg5lvpNeTTqGfvu1vlzeSkyolStPKen7v7HM/640?wx_fmt=webp&from=appmsg#imgIndex=17)

*图 18  一种典型分工。同步适配层消费两路数据；它不要求两类驱动合成一个驱动。*

图像 Sensor 通常作为 V4L2 sub-device（视频链中的子部件）注册，负责模式、曝光、增益和开关流等控制。CSI 接收器负责接收像素；ISP 是图像信号处理器，负责由颜色采样重建完整颜色、降噪等处理。SoC 是集成处理器与外设的片上系统，具体平台可能将 CSI、ISP 和缓冲管理组合在同一驱动中。1819

IMU 驱动负责寄存器设置、中断、FIFO 解析及采样时间。上层同步适配层像一个整理员：把相机帧说明与 IMU 样本放到共同时间线上，再交给防抖或视觉惯性算法。它可以位于系统进程、SDK（软件开发工具包）模块或固件中，位置取决于平台架构。

> Media Controller 描述视频部件之间的连接拓扑，相当于视频数据通路图；它不会自动完成惯性同步。摄像头驱动直接调用 IMU 驱动的私有函数，会增加生命周期和并发耦合，应优先使用清晰、可验证的数据接口。

## 从上电到关流，如何让两条链进入可用状态？

能读出芯片 ID 只证明基础通信成立。真正用于防抖前，两条链还需要建立稳定的采样、时间映射、模式信息和缓冲状态。下面给出一种工程启动流程，实际顺序仍需服从芯片和平台要求。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqAibfd9L0yaqgOfjj72J5VUNmNd4IrMRFqXgE3qyQIHxRr4PdFm5z7Z5vjAYSuZ0tnVwWiclMRWB0SBLw0nKlRHoEXtqJicozFRvic0/640?wx_fmt=webp&from=appmsg#imgIndex=18)

*图 19  启动与异常恢复的概念状态图。只有时间和数据都有效，才进入正常融合。*

probe 表示驱动识别并初始化器件。Runtime PM 是运行时电源管理：按需打开电源和时钟，不使用时释放资源。stream on/off 表示开始或停止图像流。Linux 相机文档要求驱动结合运行时电源管理处理资源，开关流接口也需匹配目标内核。18

一种常用设计是先启动 IMU，填充少量历史样本并确认时间连续；配置相机模式、缓冲与曝光控制，再开始图像采集。首帧到来后，仅在所需时间区间被有效 IMU 样本覆盖时启用补偿。这里的等待区间应依据算法需求设定，而不是固定休眠若干毫秒。

关流时，先阻止新的图像任务进入算法，再处理或取消已提交任务；在没有其他订阅者后停止 IMU。若 IMU 还服务姿态显示或运动检测，摄像头关流不应无条件关闭整颗 IMU。

> 模式切换、系统休眠、IMU 复位和计数器异常，都可能打断时间连续性。恢复后应重新确认配置及时间映射，并将旧模式数据与新模式数据区分，避免把两段不连续的历史硬拼在一起。

## 曝光寄存器中的“行数”，怎样变成时间？

曝光时间是像素积累光信号的持续时间。很多图像 Sensor 用“多少行时间”表示曝光粗积分值：所谓粗积分，是按整行计时的主要曝光部分；有些器件还提供细分时间和固定偏移。寄存器数值不能未经换算就当成微秒。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqA99DianibupKAlKcspscg0y8g5MhD3ZVfb2sGC24IoXAb8SdhbQYonaKCt2fX0ibzzyhH1KUr5zuyDIyGHrBTZTSl59U7JhqxhVpU/640?wx_fmt=webp&from=appmsg#imgIndex=19)

*图 20  简化扫描模型。行消隐与场消隐参与时序计算，但不都是可见图像像素。*

HBLANK 是行消隐，可理解为一行中有效读出以外的时序余量；VBLANK 是场消隐，即一帧中额外的行时序。pixel rate 是该时序模型中的像素速率，不能随意用 CSI 总线比特率或输出分辨率代替。21

教学算例：时序宽度 1920、HBLANK=280、像素速率 74.25 MHz，则一行约 29.63 μs；时序高度 1080、VBLANK=45，则一帧约 33.33 ms。若曝光粗积分为 300 行，在没有额外细分与偏移的简化条件下，曝光约 8.89 ms。

> 裁切、合并像素、跳行、HDR 和专有读出模式可能改变上述参数含义。实际曝光应按对应模式的手册公式换算。自动曝光设置也可能延迟若干帧生效；算法需要某一帧实际使用的值，不只是最近一次请求设置的值。

## 元数据：给每一帧附上一张准确的说明卡

元数据 Metadata 是“描述数据的数据”。图像像素说明拍到了什么；帧元数据说明何时拍、怎样拍、对应哪种模式。它可以与像素分开存放，但必须可靠地关联到同一帧。

| 信息 | 通俗含义 | 为什么需要 |
| --- | --- | --- |
| frame\_id / sequence | 这次采集中的第几帧 | 建立关联、发现跳号和重新开流 |
| timestamp + clock domain | 时间数值，以及是哪一只钟 | 避免混用不同计时起点和频率 |
| timestamp source | 记录的是曝光开始、帧结束还是其他事件 | 决定如何换算到曝光时间 |
| actual exposure | 这一帧实际采用的曝光时长 | 确定曝光区间和代表时刻 |
| line time / readout direction | 每行间隔及扫描方向 | 按行计算滚动快门姿态 |
| mode / crop / flip | 模式、裁切、镜像与旋转 | 选对内参、坐标和映射关系 |
| validity / error flags | 哪些信息有效，有无丢帧或异常 | 避免把缺失数据当成可信测量 |

V4L2 的缓冲区带有 sequence、timestamp 和相关 flags。MONOTONIC 描述时钟类型；SOE 表示曝光开始，EOF 表示帧结束。这是两类独立信息：知道时钟类型，仍需知道时间对应哪个事件。20

普通视频缓冲区并不保证包含所有上述元数据。实际曝光、逐帧控制生效情况和读出参数，可能来自嵌入式数据行、平台元数据接口或经过验证的控制延迟模型。框架不提供的字段，不能凭一个软件到达时间臆造。

> buffer index 是一块可循环复用的缓冲区编号，不是全局唯一帧编号；编码器可能重排帧，编码顺序也不一定等于采集顺序。为每次采集建立稳定帧标识，并维护它与处理输出的对应关系。

## 时间同步：先让两只钟能相互换算

相机事件可能由 SoC 硬件计时器记录，IMU 可能使用自己的计数器。即使两个数都写成纳秒，它们仍可能有不同的起点和走时速度。时钟域就是“这份时间属于哪一套计时系统”的说明。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqAicQAUkibhMjUMImp6rJqdRibLmI1bibN62gD7b7OYBh28Zsib2O4WpwDbMTAF1iaKHjg2TZpVhDpvOHLYpNYVicHpkyaibSw4iaN0hRs0Y/640?wx_fmt=webp&from=appmsg#imgIndex=20)

*图 21  教学计算：仅校正起点，无法消除走时速度差。20 ppm 频差在 60 s 后积累 1.2 ms。*

b 修正时间起点，s 修正计数单位和频率比例。ppm 是百万分之一：20 ppm 表示每秒约有 20 μs 的累计时间差。建立映射应使用可信的事件对应点；总线读取完成的时刻包含传输和调度变化，不能直接当作无误差的同步观测。

| 时间层次 | 需要单独确认的内容 |
| --- | --- |
| 时钟映射 | 计数单位、频率比例、起点、回绕和休眠行为 |
| 采样与滤波 | 时间戳标记的测量时刻，以及通道滤波延迟 |
| 相机事件与曝光 | SOF / EOF 与曝光开始、逐行读出的关系 |
| 到达与处理 | FIFO 等待、总线搬运、线程调度与算法缓冲 |

> 低通滤波器的群延迟，是某些频率成分经过滤波后表现出的时间滞后。它可能随频率和配置变化，不能一律当成任意场景下的固定常数。时间标定应对应实际通道、工作模式与算法频带。

## 逐帧匹配：寻找一个时间窗口，而非一个样本

相机若输出 30 fps，帧周期约 33.33 ms；IMU 若输出 1 kHz，样本间隔约 1 ms。平均每帧周期约有 33.3 个样本，单个周期中的数量可能是 33 或 34。实际应按时间选择，不能硬编码“每帧取 33 个”。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqA8YzJAmj6mJEMcg7qd8FpibzdJ8aeqLcF2482lr7iaj2bKDn8rBpv5FuPRPD5Lj8icGlBtAuY0DYBW21VZJuBOicKpg9LVDvItIF7Y/640?wx_fmt=webp&from=appmsg#imgIndex=21)

*图 22  帧间旋转估计使用时间区间；区间两端需要邻近样本，以便插值到准确边界。*

插值就是利用两侧已知样本估计中间时刻的值。对于足够短且变化平滑的间隔，可以对角速度作线性插值。积分则把这些细小角度变化累加。梯形积分用相邻两点的平均角速度近似这段区间的速度。

只估计两帧代表时刻之间的旋转时，可积分两个代表时刻之间的数据。滚动快门校正需要覆盖从首行到末行的相关时刻；轨迹平滑可能还需要更早或稍后的历史。具体窗口由算法定义，不能把帧周期、曝光时长和整帧读出跨度当成同一个量。

> IMU 样本不足时，应等待到有界的截止时刻，或返回“覆盖不足”。若中间存在丢样、饱和或时间跳变，应明确标记。跨越长空洞直接插值，会制造看似连续但没有测量依据的运动。

环形缓冲区是一块按时间循环存放样本的内存。保留长度至少覆盖算法历史需求、图像处理延迟和允许的调度余量；删除旧样本时还需保留下一次插值所需的边界点。

## 一个带边界插值的帧间角度示例

下面的可运行示例只计算单轴角度增量，用来说明时间窗口、边界插值和缺口检测。时间先换算到共同参考附近的相对秒，角速度已标定为 rad/s；max\_gap 是根据采样率与容错要求配置的最大间隔。

```
from bisect import bisect_left, bisect_right
import math

def integrate_axis(samples, t0, t1, max_gap=0.003):
    # Samples: [(time_seconds, angular_rate_rad_s), ...]
    if not all(math.isfinite(v) for v in (t0,t1,max_gap)):
        raise ValueError("non-finite bounds")
    if t1 <= t0 or max_gap <= 0 or len(samples) < 2:
        raise ValueError("invalid interval")
    if not all(math.isfinite(t) and math.isfinite(w)
               for t,w in samples):
        raise ValueError("non-finite samples")
    ts = [s[0] for s in samples]
    if any(b <= a for a,b in zip(ts, ts[1:])):
        raise ValueError("timestamps must increase")
    left = bisect_right(ts, t0) - 1
    right = bisect_left(ts, t1)
    if left < 0 or right >= len(ts):
        raise ValueError("insufficient coverage")
    if any(ts[i+1]-ts[i] > max_gap
           for i in range(left, right)):
        raise ValueError("sample gap")
    def interp(t):
        j = bisect_left(ts, t)
        if ts[j] == t:
            return samples[j][1]
        a, wa = samples[j-1]
        b, wb = samples[j]
        return wa + (wb-wa)*(t-a)/(b-a)
    knots = [t0] + [t for t in ts if t0 < t < t1] + [t1]
    rates = [interp(t) for t in knots]
    return sum(0.5*(rates[i]+rates[i+1]) *
               (knots[i+1]-knots[i])
               for i in range(len(knots)-1))
```

> 若角速度恒为 100°/s，窗口为 2.4 ms 到 12.4 ms，结果应为 1°，无论两端是否恰好落在采样点上。通用三维姿态应在小区间内组合四元数增量；不能把三个独立轴的积分结果直接当作欧拉角。

生产代码还需处理时间映射版本、样本状态和并发缓冲访问。本例对输入显式拒绝缺口，避免在没有测量覆盖时静默返回一个貌似合理的结果。

## 空间标定：相机看到的方向与 IMU 的轴要一致

IMU 的 X 轴可能朝右，相机模型的 Z 轴通常指向光轴方向。先要通过安装旋转把陀螺仪向量转到相机坐标系。原始轴交换与符号修正只适合已知的离散安装关系；一般安装误差需要旋转外参。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqA9UmledueJXzfK1fCTQ8c9KFQ6UDVic0Y7sF6WiaDKCY0yibRVvdnHibRD5zIvXpicrbwegpzJpnv3Z3scdBqNJVTaIm8us93kXEvSg/640?wx_fmt=webp&from=appmsg#imgIndex=22)

*图 23  三种变换各有作用：IMU 安装旋转、相机内参、输出图像的裁切与翻转。*

内参可以理解为相机的“投影刻度”：焦距决定空间方向变化对应多少像素，主点描述光轴在图像上的参考位置。外参描述相机和 IMU 的固定旋转与平移。时间外参则常指两套测量之间的时间偏移。

镜像、90° 旋转、裁切和缩放发生在图像坐标域；它们与三维刚体安装旋转不是同一类操作。单次镜像具有反射性质，不能随意塞进合法旋转矩阵或四元数。应更新输出图像的投影与映射约定，并确认算法补偿针对哪一级图像。

若相机与 IMU 不在同一个点，转动时两点的线加速度可能不同，这就是杆臂效应。纯旋转角速度变换不需要把平移加到角速度上；涉及平移、加速度或 VIO 时，才需要在相应刚体模型中处理位置间隔。

> 机械柔性连接会使安装关系随时间改变。相机与 IMU 应可靠固定；标定数据需要足够的多方向运动，并避免过度模糊。联合标定工具可估计时空关系，但不能补救错误单位、错帧和严重时间抖动。17

## 电子防抖：把机身旋转转成图像补偿

在基于陀螺仪的电子防抖中，IMU 提供相机旋转轨迹。算法把轨迹平滑成期望运动，再计算原始画面到期望视角的映射。图像处理单元按照该映射进行重采样和裁切，输出更平稳的视频。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqA9lGWPDzXiaAGSesXldz6sGWCgYDECpcDpQM5hYPKyICXpbXnGG7hsf4R4B2Bxo90BPbwDnrV3uluj5ia46sg9OeDZEQZIQMpMN8/640?wx_fmt=webp&from=appmsg#imgIndex=23)

*图 24  EIS 的两个数据支路。图像与惯性数据经过时间和坐标对齐后，共同决定输出画面。*

纯旋转针孔模型：K 为相机内参，R\_rel 为源视角到目标视角的相对旋转。

上述关系假定已妥善处理镜头畸变。真实系统还会受平移、近景视差、动态物体、曝光模糊和裁切边界影响。陀螺仪能帮助描述机身旋转，却不能仅凭三个角速度恢复任意深度场景的全部图像运动。

EIS 通常需要预留裁切空间，平滑未来轨迹还可能引入缓冲延迟。OIS 则通过机械执行机构移动镜片或感光元件，在曝光过程中进行光学补偿。两者同时工作时，机身 IMU 旋转与实际成像变化之间还需要考虑 OIS 的运动。

> EIS 图像重映射主要处理几何变化，不能仅靠旋转校正恢复曝光期间已经丢失的运动细节。防抖效果应结合运动模糊、视场损失、延迟和画面形变一起评价。16

## 滚动快门：一帧图像具有多个曝光时刻

滚动快门传感器逐行开始曝光。相机旋转时，上下行对应的姿态不同，因此直线可能弯曲或倾斜。以单个姿态代表整帧，只能做有限近似；更精细的补偿会按行或图像分块使用对应时刻的旋转。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/I1K1qRMFqAicSwjU6CkykZwlibRddfoHQVJevp0qgwXmwLfhMvAjzJ43EvibIYDDL3PggZpFv9qgiaXavYNx7rrPOBj7ricLCNNVdoV0Qj2ypicOE/640?wx_fmt=webp&from=appmsg#imgIndex=24)

*图 25  简化曝光时序。每行曝光窗口依次平移；IMU 样本需覆盖相关曝光区间。*

t\_0 为第一行曝光开始；假设各行曝光时长相同，y 从 0 开始。

帧到达、CSI SOF（接收端看到帧开始）、曝光开始、曝光中点与编码 PTS（播放时间戳）是不同概念。它们的对应关系需要结合图像传感器模式和驱动时序确认。IMU 还可能有内部滤波延迟，不能只对齐主控收到数据的时间。

量级估算：角速度 100°/s、时间偏差 2 ms，对应旋转误差 0.2°。若焦距为 1000 像素，近光轴、小角度近似下，像素误差约为 1000×0.2×π/180≈3.5 像素。这是计算示例，不是某个系统的实测指标。

空间方面，陀螺仪数据先经旋转外参转换到相机坐标系。涉及平移和线加速度时，还要考虑 IMU 与相机之间的杆臂距离，即两颗传感器测量位置之间的间隔。时间偏移、旋转外参、内参及滚动快门参数应按实际模型标定。

> Kalibr 可估计相机与 IMU 的空间及时间关系，并强调时间戳质量。固定时差标定不能替代长期时钟漂移处理，也不能修复丢样、错误曝光语义或不稳定延迟。17

## 把防抖接到图像流水线：时间正确还不够

防抖算法输出的可能是一个变换矩阵，也可能是网格映射。网格映射把图像分成许多小区域，分别说明应从原图哪里取像素；它适合表达镜头畸变和随行变化的补偿。实际接口由 ISP、GPU 或平台图像处理模块决定。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqAibqvMOD4WCVlAJcPlCXShsaWhJFtSrRP1pn8TWXzkb49sciahO24Sq90bKySPgJgxatU3zZDF7uiaDMuPzRypOhgiaibcoZ51hgqBA/640?wx_fmt=webp&from=appmsg#imgIndex=25)

*图 26  图像缓冲的所有权流转示意。计算补偿参数与持有像素缓冲是相关但不同的任务。*

DMA 是直接内存访问，可理解为硬件搬运数据而不让 CPU 逐字节复制。DMA-BUF 是共享一块内存的机制，多个设备可以通过句柄使用同一份图像。但零拷贝不等于零等待，也不保证不同设备已经完成访问。

fence 是完成通知，可理解为“这块图已经写完，可以继续处理”的凭证。缓存一致性确保 CPU 与设备看到正确的数据副本；完成同步确保访问发生在正确先后顺序。两者不是同一个问题，相关接口需按平台要求使用。23

算法进程通常接收帧缓冲、元数据和相应 IMU 窗口，输出补偿参数后提交图像处理。只有当所有处理单元完成读取，才能把原图缓冲交回采集队列复用。提前复用可能造成撕裂、花屏或偶现错帧。

> 硬中断中宜只做必要的确认和事件记录；允许睡眠的总线传输应放在线程化处理等合适上下文中。复杂融合和图像变换不应阻塞关键采集路径。低延迟依赖合理队列和调度，而不是在中断中塞入更多算法。

## 为什么一开防抖反而更抖？按现象定位

防抖失败不一定来自滤波参数。下面是一条按数据链定位的路径：先核对轴向和物理单位，再检查时间语义与窗口覆盖，然后检查图像模式、内参和补偿方向，最后评价轨迹平滑参数。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/I1K1qRMFqAibI6rMyQYKkrfXofJBqoYzUpBeGL3bE3dLzgb0N4ACfwwTy6vDGlGY0f1xbiaAmfJDATkZqqVzvEaZGBwSf77CB4vxDKJfw4mwk/640?wx_fmt=webp&from=appmsg#imgIndex=26)

*图 27  诊断分支示意。先验证可直接测量的事实，再调整算法参数。*

| 现象 | 优先检查 | 一种有效验证 |
| --- | --- | --- |
| 只在某个转动方向恶化 | 轴向、符号、旋转外参 | 分别绕三根轴做已知方向转动 |
| CPU 负载高时明显变差 | 到达时间替代采样时间、FIFO 丢样 | 比较负载变化前后的样本时间差 |
| 切换分辨率后失效 | 行时间、内参、裁切、映射配置 | 逐项核对新模式元数据 |
| 长时间运行后逐渐失配 | 温漂、时钟频差、计数器回绕 | 画出温度与时差随时间的曲线 |
| 偶现花屏或半幅错位 | 缓冲所有权、完成同步、格式步长 | 记录每个缓冲的提交与释放时刻 |

> stride 是内存中相邻两行起点的间隔，它可能大于可见行宽对应的字节数。像素格式、stride、裁切与算法输入尺寸必须一致；画面几何错误与内存读取错误，需要分别排查。

## 把算法接进系统：一条可检查的数据链

一套能够解释清楚、验证清楚的系统，需要在芯片测量、驱动采集、时间映射、算法计算和图像内存之间建立明确约定。算法输出有误时，每一层都应能独立记录证据，而不是只观察最后的视频是否平稳。

| 阶段 | 输入与动作 | 完成判据 |
| --- | --- | --- |
| 通信与启动 | ID、复位、配置载入、量程、ODR、滤波 | 寄存器可回读，模式与手册一致 |
| 连续采集 | 中断、FIFO、时间戳、温度、状态位 | 样本数量正确，时间连续，无隐藏溢出 |
| 数值标定 | 符号、单位、偏置、比例、温度模型 | 静态模长合理，已知转角验证通过 |
| 坐标与同步 | 安装旋转、时钟映射、曝光关联 | 单轴方向正确，残差不随负载异常变化 |
| 算法融合 | 初始化、预测、观测拒绝、状态更新 | 静态与动态均有参考误差统计 |
| 异常恢复 | 断流、饱和、温变、重配置、休眠唤醒 | 状态有效性可见，恢复行为有明确定义 |

### 一组有意义的验证动作

静止多姿态：检查加速度模长和陀螺仪均值。单轴缓慢旋转：检查轴向、符号与短时积分。快速往返运动：检查饱和和动态误差。长时间运行：检查温漂与时钟映射。增加 CPU 和总线负载：检查到达时间抖动是否错误进入样本时间。

评价算法应记录角度误差、收敛时间、最大动态误差、延迟、丢样率和失效恢复表现。可用转台、外部姿态参考或几何标定场景建立真值；只看输出曲线平滑程度，无法证明准确性。

> 配置切换应视为数据链事件。修改量程会改变换算系数；修改 ODR 或滤波器可能改变时序和延迟。对应的 FIFO 清理、时间映射和融合状态处理需要一起设计。

外部接口至少应声明：传感器坐标系、物理单位、样本时间语义、通道有效性、饱和与丢样信息。把这些约定写清，通常比在后端反复调整滤波参数更能减少集成问题。

## 常见误解与术语速查

轴向、单位、时间戳、元数据和状态标志分别约束数据的方向、刻度、时刻、采集条件与有效性。把这些基础概念对应到实际接口，才能判断测量结果是否足以支持后续算法。

| 常见说法 | 准确理解 |
| --- | --- |
| 静止时加速度应该全为零 | 普通加速度计输出比力；静止受支撑时模长约为 g |
| 陀螺仪能直接读出角度 | 它主要输出角速度，角度需要积分或融合 |
| 六轴意味着直接获得六自由度位置 | 六轴是测量通道，位姿需要额外估计与约束 |
| 九轴一定比六轴准确 | 磁场异常时，错误的航向参考反而会恶化结果 |
| 采样越快就越准 | 还要考虑带宽、抗混叠、噪声、总线和功耗 |
| 低通可以消除所有漂移 | 零偏是低频误差，单纯低通不能恢复绝对参考 |
| 读到的数据同时刻就是同一帧 | 批量到达不等于同时采样，通道也可能不同步 |
| 用了卡尔曼滤波就不会漂 | 模型、观测和可观测性决定能修正哪些误差 |

| 术语 | 含义 |
| --- | --- |
| Bias / 零偏 | 没有对应输入时仍存在的输出偏置 |
| Scale factor / 比例系数 | 输入变化与输出变化之间的比例 |
| ODR / 输出数据率 | 数字样本输出频率 |
| FIFO / 先进先出缓存 | 按采样顺序暂存数据的片上缓冲 |
| AHRS / 姿态航向参考系统 | 融合惯性与方向参考得到姿态和航向 |
| VIO / 视觉惯性里程计 | 联合图像与 IMU 估计相对运动 |
| EIS / 电子防抖 | 通过数字图像变换补偿相机运动 |
| Extrinsics / 外参 | 传感器之间的旋转、平移等空间关系 |

IMU 的工程价值来自一条完整链路：物理结构提供测量，标定控制可重复误差，时间与坐标赋予数据统一含义，融合算法引入可用约束，应用再把估计转为控制或图像处理。每一层都具有明确的职责与适用条件。
