# Learning by Cheating 论文通读（特权教师 → 感知学生）

> 来源归档（原文通读 · 支撑 `wiki/methods/teacher-student-dagger-training.md`）

- **标题：** Learning by cheating（CoRL 2019）
- **作者：** Dian Chen, Brady Zhou, Vladlen Koltun, Philipp Krähenbühl（UT Austin / Intel Labs）
- **类型：** paper / imitation-learning / privileged-learning
- **原文：** <https://arxiv.org/abs/1912.12294>（v1，2019-12-27）
- **入库日期：** 2026-11-07
- **一句话说明：** 把视觉驾驶的模仿学习拆成两阶段：先训练能读取真值环境信息的"作弊"特权智能体，再让它当教师（可在任意状态给出监督，配合 DAgger）训练只用相机的感知运动学生。
- **核对范围：** 通读摘要、§1 引言、§2 方法（特权智能体、感知运动智能体、控制器）、§3 实现细节（网络、训练）、§4 实验设置与消融文字部分。表格中的具体成功率数值、与其他方法的逐项对比和基础设施细节只浏览，没有逐格核对；没有运行官方代码，也没有读被引的 DAgger 之外的原文。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **动机（§1）：** 直接从专家轨迹学视觉驾驶，同时要学会"看"和"做"。拆成两阶段后：特权智能体（读取真值鸟瞰图与交通参与者位置）只需学"做"；感知运动学生主要学"看"。
- **三点优势（§1）：** ①特权智能体工作在紧凑中间表示（鸟瞰图）上，学得更快、泛化更好，并且便于数据增强；②训练好的特权智能体可在**任意状态**被查询，而不仅是原轨迹访问过的状态，因此可以自动实现类 DAgger 的训练——按学生的在线 rollout 自适应地收集监督，把被动的专家轨迹变成在线的、自适应的教师；③特权智能体是"白盒"，可一次性给出每个高层指令（左转 / 右转 / 直行 / 跟车道）对应的动作，并行监督学生的所有分支。
- **方法（§2）：** 特权智能体输入真值地图 M（二值通道：物体、道路特征、红绿灯）与速度 v、指令 c，输出每个路点和指令的热图，经 soft-argmax 得到路点，再由低层 PID 控制器输出转向、油门、刹车；用专家轨迹的 L1 路点损失做行为克隆；通过对地图做旋转 / 平移的几何扰动来模拟轨迹噪声（离线增强）。学生输入单目前向 RGB 图 + 速度，结构与教师相似，用 L1 损失模仿教师，并在相机坐标系下预测路点后再投影到车体系。
- **训练流程（§2、§3）：** 先用专家轨迹训特权智能体；再在同一批状态上离线行为克隆学生（所有指令分支）；最后用 DAgger 在线训练学生，以特权智能体为 oracle。作者说明只做第二阶段（不预训）最终精度一样好，但在线 DAgger 更慢，所以预训加速；并按 Bastani 等的做法对高损失的关键状态过采样。
- **设置（§3–§4）：** CARLA 0.9.5 / 0.9.6；100 条训练轨迹，约 157K 帧（0.9.6 为 174K）、约 4 小时驾驶；Town1 训练，Town2 测试；基准为 CoRL2017 与 NoCrash；教师用 ResNet-18，学生用 ImageNet 预训练的 ResNet-34。
- **结果（摘要、§4）：** 在原 CARLA 基准所有任务上首次达到 100% 成功率；NoCrash 最难的密集交通条件上比此前最好高 18 个百分点；违规频率相对 CILRS 至少降低一个数量级（多数条件）。消融：白盒监督与在线（on-policy）轨迹两者各自都显著提升性能，合起来达到 100%。
- **sim2real 的说法：** 训练依赖仿真才能读取特权信息，但最终的感知运动策略不依赖特权信息，不受限于仿真，"可借助任一 sim-to-real 方法迁移到真实世界"（作者的主张，论文没有真车实验）。
