## 核心摘录

1. **系统设想（第 2 节）：** 桌面级四足—五旋翼可变形机器人；四条相同的 locomotor 腿各 3 个关节（髋外展 / 内收、大腿屈伸、膝屈伸），每个关节一个舵机；每条腿小腿上装 1 个 90 mm 涵道风扇（EDF），机身中央另有 1 个 120 mm EDF，即“五旋翼”。地面模式下 EDF 不工作，只是额外重量。
2. **模式切换（第 2.1 节）：** 起飞为放下起落架、四腿向上折叠、EDF 起转、再收起落架；降落反向。切换靠起落架支撑，不是空中变形。
3. **整机运动学（第 3.1 至 3.3 节）：** 非标准 DH 参数（表 1，以前右腿为例）；12 个驱动输入对应 6 自由度浮动基座；表 2 几何参数 l = 0.19 m、w = 0.14 m、h1 = 0.04 m、h2 = 0.05 m、s1 = 0.11 m、s2 = 0.14 m。逆运动学用几何法得到闭式解（式 2 至 14）；式 15 至 19 把基座滚转 / 俯仰 / 偏航折算进足端坐标。
4. **闭环腿（第 3.4 节）：** 膝关节电机装在靠近机身处，经两个闭环四杆（回路 ABCDA 与 EFGAE）驱动实际膝关节 G；DH 只适用于开链，所以拆成 4 条开链（表 3 至表 6），再用向量闭环方程（式 20 至 23）约束；解得 a2、a3、a7、a8（式 24，系数见附录 A）；膝角 θ3 = a3 − θ2 + π（式 36）。附录 B 给出杆长：AB 0.0478 m、BC 0.04 m、DC 0.05787 m、AD 0.045 m、AE 0.045 m、EF 0.098 m、FG 0.04 m、AG 0.11 m。
5. **雅可比（第 4 节）：** 执行量 q_act = [θ1, θ2, a6]；传动矩阵 T_loop = −Jcd⁻¹ Jci（式 31 至 32）；T_leg（式 41）；J_leg = J_parent · T_leg（式 43）。
6. **工作空间与奇异性（第 5 节）：** 只在 θ2 与 θ3 平面里扫描，分辨率 0.5°，θ1 不入闭环所以未展开；路径 A-B-C 中 θ2 从 170° 到 340°、θ3 从 114° 到 29°（论文称“伪摆动相”），C-D-A 为“伪支撑相”。回路奇异条件 a2 − a3 = nπ 或 a7 − a8 = nπ（式 45），即 EF-FG 或 AD-DC 共线。用 σmin 评估整腿，图中 σmin 在 0.03 至 0.1 之间，靠近工作空间下左边界处趋近 0；θ2 = 235°、θ3 = 29° 附近 EF 与 FG 近共线，但被几何硬限位避开（图 21、22）。论文说两个四杆都不满足 Grashof 条件，驱动件是曲柄，所以能脱离 toggle 锁死。
7. **硬件（第 6 节）：** 单腿台架，PLA 与碳纤维复合丝 3D 打印连杆，Dynamixel MX28T 舵机，U2D2 串口通信，TTL 菊花链；台架一只有 θ2、θ3 两个电机，台架二加髋电机 θ1 与（未通电的）90 mm EDF。滑动基座在本文中锁定。
8. **步态（第 6.2 节）：** 在点云上用最近点 + MATLAB PCHIP 插值拟合足端轨迹，椭圆参数方程取 150 个点。Crouch：xc = 0.008 m、zc = −0.18 m、a = 0.06 m、b = 0.014 m。Trot：a = 0.08 m、b = 0.035 m、xc = 0.02 m、zc = −0.21 m。Squat：xc = 0.02 m、zmin = −0.22 m、zmax = −0.14 m，加 0.002 cos³(t) 的小扰动。作者说把 trot 椭圆再下移会进入 σmin 更小的区域，实际舵机运动出现抖动。
9. **变形序列（第 6.3 节）：** 四阶段：(1) θ1 = 0°、θ2 = 180°、θ3 = 114°；(2) 髋转到 90°；(3) θ1 = 90°、θ2 = 270°、θ3 = 29°；(4) 三电机同时卸载，θ1 = 0°、θ2 = 235°、θ3 = 29°。
10. **结论与后续（第 7 节）：** 本文是第一阶段；后续做含 EDF、地面接触与接触力学的完整动力学，并上整机。

## 作者自述与读者判断

- **作者自述：** 本文为后续系统“奠定基础”；验证了工作空间边界与三种步态可在单腿台架上执行。
- **读者判断（推测）：** 工作空间验证是定性的，图 26 的叠加轮廓由人工逐帧跟踪足端得到，作者自己说含噪声；论文没有给跟踪误差、重复精度、负载或耗电数字。
