## 摘要级要点

- **痛点 1：** 深度端到端人形行走训练贵、深度 sim-to-real 隙大。
- **痛点 2：** elevation map 路线依赖多传感器与定位，延迟/漂移/遮挡（如缝隙底部）脆弱，且常靠手写可通行规则补盲区。
- **主张：** 把「结构化地形推理」与 RL 绑成一体——重建模块吃第一人称深度+本体历史，策略吃重建高程（训练时对重建误差与延迟做端到端微调），深度合成管线进 RL 环而非离线离线采数。
- **三组件：**
  1. **Terrain-Aware Policy with Blind Backbone** — 预训练盲骨干提供前进驱动力；视觉调制器改关节目标、步态相位与速度命令；多地形专家 → 学生 L2 蒸馏 + PPO。
  2. **Multi-Modality Cross-Attention Transformer** — 本体 query、深度 key/value；粗高程 + 条件 U-Net 精炼。
  3. **Realistic Depth Images Synthetic Method** — GPU 射线（含机器人自遮挡）+ Kinect 风格轴向/横向噪声与边缘 dropout。
- **关键数字：** 真机重建 MAE **3.25±0.56 cm**（相对 ResNet 基线 5.31、CNN 6.47；摘要称相对重建误差降 **>30%**）；感知更新约 **30 Hz / ~20 ms**（对照 elevation map：20 Hz LiDAR + ~30 ms 建图开销）；楼梯 10 级累计绊脚 **4/10**（无端到端微调 **8/10**）。

## 核心摘录（面向 wiki 编译）

### 1) 交叉注意力地形重建（§IV-A）

| 符号 | 含义 |
|------|------|
| $s^{\mathrm{perc}}_{t-50:t}$ | 本体历史 |
| $d^H_t$（$H=5$） | 时序深度 |
| $z^{\mathrm{fused}}=\mathrm{Attn}(Q=z^{\mathrm{prop}},K=z^{\mathrm{depth}},V=z^{\mathrm{depth}})$ | 跨模态融合 |
| $\hat{H}^{\mathrm{rough}}\to\hat{H}^{\mathrm{refined}}$ | MLP/解码器粗预测 + 条件 U-Net 精炼 |
| $\mathcal{L}=\|\hat{H}^{\mathrm{rough}}-H^{gt}\|_2^2+\|\hat{H}^{\mathrm{refined}}-H^{gt}\|_1$ | 粗 MSE + 精 L1 |

- GRU 保时序一致性；消融显示去掉 GRU / 去掉条件深度 latent 会抬高各地形 MAE（Table II）。

### 2) 现实深度合成（§IV-B）

- **几何：** 600×480 针孔射线；静态地形 mesh + 按刚体位姿变换的机器人 visual mesh；取最近正交点 → 相机系 $z$。
- **域随机化：** 边裁剪重采样；轴向噪声 $\sigma_z(z,\theta)$（随距离二次增长）；横向扰动；不确定性驱动 dropout + Sobel 边缘 80 分位阈值的结构孔洞。
- **相对先验 [4]：** 深度合成进入 **RL 闭环**，策略对重建误差与延迟做端到端微调，而非仅离线训重建再冻结。

### 3) 盲骨干 + 多教师策略（§IV-C）

| 项 | 设定 |
|----|------|
| 高程窗 | 机器人前方 **1.0 m×1.0 m**，**5 cm** 分辨率，相对浮动基座 |
| 盲骨干 $\pi_{\mathrm{blind}}$ | 无高程；输出 20 维关节目标 |
| 感知策略 $\pi_{\mathrm{perc}}$ | 吃盲动作 + 高程；输出调制动作 + $\delta\phi$ + $\delta v^x$ |
| 混合 | $a^j=(1-\alpha)a^{\mathrm{mod}}+\alpha a^{\mathrm{blind}}$ |
| 控制 | 策略 **100 Hz**，底层 PD **1 kHz** |
| 训练 | 分地形专家（特权全状态）→ 学生在 **重建噪声高程** 上 L2 蒸馏 + PPO；含 AMP（SFU/CMU mocap） |

### 4) 关键评测数字（§V）

| 设置 | 指标 | 结果 |
|------|------|------|
| 仿真重建（Table II） | 七类地形 MAE (cm) | Ours 多数最低（如 Rough Slope Up **2.29**；Stairs Up **4.51**） |
| 真机重建消融（Table III） | MAE (cm) | Origin 16.07 → Ours **3.25**；w/o Noise 4.48；ResNet [4] 5.31；CNN [22] 6.47 |
| 感知延迟（Fig. 6） | 更新间隔 | ~**20 ms @ 30 Hz** vs elevation map 更高延迟与方差 |
| 楼梯绊脚（Table IV） | 10 级累计 | 端到端微调 **4/10**；无微调 **8/10** |
| 消融（Fig. 2） | success / traversing | 去掉 multi-teacher / blind backbone / gait-command adaptation 在 gap/hurdle 等高难度显著掉点 |
| 真机场景（Fig. 7–8） | 定性 | 上下楼梯、连续缝隙、斜坡下台阶、**训练未见可动平台** 踏步 |

### 5) 局限（归纳自正文）

1. 截至入库 **无官方代码/项目页**，复现需自建 Isaac Gym 深度射线与噪声管线。
2. 单前向深度，**非**多向/双向行走主战场（对照 [RPL](../../wiki/entities/paper-rpl-robust-humanoid-perceptive-locomotion.md)）。
3. 平台为 **TienKung Ultra**，与仓库内大量 G1 结果不可直接数字横比。
4. 缝隙底部等遮挡区靠学习重建推断，极端几何/传感器失效仍可能崩。
