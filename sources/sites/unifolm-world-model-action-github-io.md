## 一句话摘要

UnifoLM 系列下的 **World-Model–Action** 官方项目页：世界模型既可作 **交互式仿真引擎** 生成数据，也可接动作头做 **策略增强**；展示 Open-X 微调视频生成、决策/仿真双模式架构、动作可控与长程交互生成，以及 Z1/G1 真机部署 GIF。
