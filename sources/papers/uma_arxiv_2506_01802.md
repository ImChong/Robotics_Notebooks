## 摘录 1：问题诊断与贡献

- **动机：** 近年把隐式/3DGS 附着到可驱动人体模板（骨架、参数人体、可变形模板）已把 avatar 保真度推到新高，但在 **4K+ 变焦** 下仍难保住细纹理与纱线级图案。
- **根因主张：** 不是外观网络容量本身，而是 **表面跟踪不准**——深度错位（depth misalignment）与表面漂移（surface drift）迫使外观模型去补偿几何误差。
- **贡献（论文归纳）：**
  1. 可驱动超精细 avatar：**骨骼运动 + 相机 → 高保真几何与外观**（论文称推理约 **1620×3072 @ 18 fps**）。
  2. **Per-frame latent** 建模无法仅由骨骼解释的随机衣物动力学（训练有 \(z_f\)，测试用零 latent）。
  3. **Avatar-guided 多级表面对齐**：以基础 2D 点跟踪器为监督，在顶点与纹素级建立 3D 对应。
  4. **新数据集**：5 名被试、各约 10+ 分钟、**40 路标定 6K 相机**，含挑战性纹理与丰富褶皱动力学。
- **关键词：** human rendering、performance capture、3D Gaussian Splatting、surface alignment、telepresence。

## 摘录 2：表示 — 可驱动模板 + 运动感知 Gaussian 纹理

- **数据假设：** 分割多视角视频 + 标定相机 + 商业无标记 mocap 骨骼姿态；用隐式重建（NeuS2）得逐帧 GT 几何（**无跨帧对应**）。
- **粗几何：** 人物特异模板 \(\bar{\mathbf{V}}\) → 嵌入式变形图 \(\mathcal{F}_{\mathrm{eg}}\) + 逐顶点位移 \(\mathcal{F}_{\mathrm{delta}}\) → Dual Quaternion 蒙皮得 \(\mathbf{V}_f\)（沿 DDC / Habermann 线）。
- **细外观：** UV 空间 **Gaussian textures**（ASH 式）——纹素存 3DGS 参数；几何/外观由两个 CNN 解码器从位姿纹理预测。
- **渲染：** **Analytic Splatting**（抗锯齿积分）服务超高分辨率监督。
- **深度对齐：** 在模板网络输入拼接 **可学习帧级 latent \(z_f\)**，缓解「骨骼→衣物动力学」一对多；测试时用 \(\mathbf{z}_0\)。

**对 wiki 的映射：** 实体页「核心原理 / 流程总览」。

## 摘录 3：多级表面对齐 + 纹素超分

- **顶点级：** 用 CoTracker 等在 **栅格化模板图 vs GT 图** 上跟踪 2D 点；经可见性级联过滤，多视角抬升并聚合为 3D 对应 \(\tilde{\mathbf{P}}_{f,i}\)，监督模板顶点（相对整段长序列盲跟踪或可微渲染光度损失更稳）。
- **纹素级：** 在更密的纹理空间建立对应，继续细化表面与外观一致性。
- **纹素超分 \(\mathcal{E}_{\mathrm{sr}}\)：** 轻量 UNet 预测 Gaussian 纹理残差，上采样以恢复纱线/微图案；论文称开销小（wo SR ~21 fps → full ~18 fps）。
- **应用：** VR telepresence（Unity + gsplat 预计算）、UMA-Viewer 运动编辑、跨角色运动重定向、一致纹理编辑。

**对 wiki 的映射：** 实体页「核心原理 / 工程实践 / 结论」。

## 摘录 4：数据集与定量结果

- **UMA Dataset（项目页 Table 1）：** Subject_0..4；每被试独立 train/test 序列；40 相机；含 Rigged / Masks / GT Meshes / Pose / Hand / SMPL Params。
- **仓库元数据：** 每被试 `metadata.zip` 同时含 **DDC character** 与 **SMPL-X character**（`smplx_train_merged.npz` 等）+ `cameras.calib`。
- **Table 2（全序列平均，论文）：** Training Pose — Ours PSNR **37.15** / SSIM **0.9681** / LPIPS **35.02** / Cham **0.876**；Testing Pose — PSNR **27.68** / LPIPS **84.12**；相对 ASH、Animatable Gaussians、TriHuman、DDC 等全面占优，尤其感知指标。
- **局限（论文 §6）：** 单层人物特异模板 → 不支持换装；无外力/物体交互物理；暂无重光照材质估计；控制主为身体/手，表情未覆盖。
