## 核心摘录

### 1) 行为意图 vs 动作克隆 / 未来实现监督

- **摘录要点：** 常规行为克隆（BC）只监督具体动作指令，未来帧/潜观测/轨迹/光流监督则绑定某一种物理实现（同一局部目标可对应多种可行轨迹，而相似观察前缀也可服务不同局部目标）。Indi 将 **behavior intent** 定义为当前语言指令下、接下来短窗口行为所要达成的 **局部语义目标**。

### 2) 教师目标构造与解码器蒸馏三机制（§3、Appendix A/C）

- **摘录要点：**
  1. **教师意图目标（§3.2）：** 冻结 `Cosmos-Reason2-8B` 读取 `E_t = (o_t, l, c_A(W_t), vid_{t:t+H})`（窗长 ~1.6 s：Bridge 为 H=8@5 Hz，RoboCasa 与真机 SO-101 为 H=32@20 Hz；均匀采样 16 帧；动作轨迹按第 1/99 分位离散化为 10 桶文本摘要），生成 `<think>`（<=4 句）与 1 句 30–50 token 目的描述 `S_t`；从 `Cosmos-Reason2-8B` 第 18/36 中间层截取输入证据 span 隐状态并均值池化为 `K_I=8` 个意图槽 `I*_t`（`d_T=4096`），末层取 `S_t` 均值池化 `K_R=8` 得文本目的表征 `R*_t`，另用冻结 `Cosmos-Reason2-2B` 视觉编码器对未来末帧 `o_{t+H}` 提取多相机 64->16 池化视觉终点特征 `V*_t`（`d_V=2048`，Bridge `K_V=16`、RoboCasa `K_V=48`）。
  2. **解码器中间层瓶颈恢复（§3.3）：** 在动作解码器中插入可学习 intent queries `Q_I`，于中段（GR00T-N1.7 第 16/32 块、π0.5 第 9/18 层）预测 `\hat{I}_t` 对齐 `I*_t`（Smooth L1）；并通过仅针对上下文+Q_I 的分支在非对称注意力下与终点视觉/文本目的分支共同流匹配训练。仅加 `+46.4M`（+1.3%，3.455B→3.502B）与 `+23.1M`（+0.64%，3.617B→3.640B）参数，推理时去除教师与对齐头，单步查询在 1x B200 上仅增加 `56.1→61.5 ms`（GR00T-N1.7）与 `24.4→29.7 ms`（π0.5）（Table 7）。
  3. **意图使用保障（§3.4）：** 二值上下文门控 `\alpha ~ Bernoulli(0.5)`（训练随机遮蔽原始上下文强制经由 `\hat{I}_t`，推理固定 `\alpha=1`）+ 意图错配铰链损失 `L_mis = max(0, m + D_right - D_swap)`（`m=0.05`；总损失权重 `\lambda_I=\lambda_V=\lambda_R=0.5, \lambda_mis=0.1`）。

### 3) 仿真、真机、消融与局限（§4–§5、Appendix B/D/E）

- **摘录要点：**
  - **SimplerEnv-Bridge（Table 1，3 轮 x 50 ep/任务）：** GR00T-N1.7 64.3% → +Future sup 68.0% → **+INDI 84.7%**（其中 Eggplant-in-Basket 从 36.0% 升至 96.0%）；π0.5 52.3% → **58.8%**。
  - **RoboCasa Kitchen（Table 2，24 任务 x 100 demo/task）：** GR00T-N1.7 64.1% → +Future sup 65.8% → **+INDI 70.3%**（接近论文引用的 3000 demo/task GR00T 参考点 70.8%）；π0.5 34.9% → **41.4%**。
  - **真机双臂 SO-101（Table 3，4 任务 x 100 demo，每条件 50 trials）：** GR00T-N1.7 在 ID clean（71.0→76.0%）、Held-out objects（62.0→68.0%）、Distractors（53.0→62.0%）均提升，三条件总均值 **62.0% → 68.7%**（Drawer Storage 三条件均值 +10.7 pp，Cross-Bin Stacking +7.3 pp）。
  - **严格对照消融与因果干预（Tables 6, 9–19）：** 固定评测 run 下 Base 61.5%、仅 Groundings 60.0%、自由 Latent 57.0%、Future sup 68.0%、仅 Intent 76.0%、Intent+V 81.0%、Intent+R 79.5%、Full INDI **85.5%**；去瓶颈 70.0%、去错配损失 74.0%、去上下文门控相关置零仅 45.5%；因果干预将意图置换为同目标同类动作维持 84.5%，跨目标置换跌至 45.2%，高斯破坏跌至 1.0%；早/晚期置换仅剩 7.3%/5.5%；换弱教师（Qwen3.5-9B → 54.5%，Qwen3-VL-8B → 73.5%，Cosmos-Reason2-8B → 85.5%）说明教师时空推理质量直接决定增益上界。
  - **Appendix D 局限：** 依赖教师 VLM grounding 质量且无闭环自我纠错；确定性预测单一意图不支持多步持续保持或外部规划器/人工显式切换；当前仅在成功示范单窗切分上监督，未建模层次化长程与失败恢复示范。
