## 页面要点

- 作者为 Kyoungin Baik（Yonsei AI）与 Youngwoon Lee（SNU CSE）。
- 资源入口包含论文、GitHub、SimVLA 数据与资产集合。
- 页面展示 35 个任务、100 个程序化房屋和多个 embodiment；真机部分突出 Anubis 在 mock kitchen、pantry、真实家庭的零样本测试。
- 场景管线结合 Scene Synthesizer、Objaverse 与 Isaac Lab，任务由技能 API 组合并通过运动规划执行。
- 训练分为 SimAction + SimVQA 仿真预训练，以及 SimAction + SimDeploy rollout 后训练。
- 页面展示的跨场景平均任务进度约 54.4%；该数值应结合论文中的场景定义与对照条件理解。
