## README / 结构要点（归纳，2026-08-31）

- **定位声明：** 为 **software engineering**（非 frontend / full-stack 专轨）大厂技术面试准备；前端/全栈指向 [roadmap.sh](https://roadmap.sh/)。
- **前置：** 少量编程经验 + 耐心 + 时间；作者自述曾全职学习数月（勿机械照搬强度）。
- **核心路径（Topics of Study）：** Big-O → 数组/链表/栈/队列/哈希 → 树/BST/堆 → 排序 → 图 → 递归/DP/设计模式/概率/NP → 计算机系统片段（缓存、进程线程、网络等）→ Final Review。
- **求职段（Getting the Job）：** 简历、投递、面试流程、反问、入职后建议。
- **可选加深：** System Design（4+ 年经验段）、编译器、安全、并行、高级数据结构等 **Everything below optional** 区块。
- **刷题：** 明确推荐 LeetCode / HackerRank 等外部 OJ；含「边学边刷」「Anki 闪卡」等方法论。
- **语言建议：** C/C++/Java/Python 择一主攻；面试语言与日常练习语言应对齐。
- **完整 CS 自学：** README 指向 Kamran Ahmed [Computer Science Roadmap](https://roadmap.sh/computer-science) 作更完整自学补充。
- **社区：** 极高 star 的策展仓库；`translations/` 含简体中文等多语言 README。
