# ROBOTIS MINI

**ROBOTIS MINI**（[GitHub](https://github.com/ROBOTIS-GIT/emanual)，[相关链接](https://github.com/japonophile/darwin)）是 [GitHubStore《19 款能自己造的开源人形机器人》](https://mp.weixin.qq.com/s/UUwUAcKdVrlo-N60Oar3Xg) 的第 14 项，文章标价 约 $540。

## 一句话定义

**ROBOTIS MINI 在文中被描述为基于 DYNAMIXEL XL-320 的紧凑人形套件，官方设计文件（STL/STP）与文档位于 ROBOTIS-GIT/emanual 的 mini 页面。**

## 英文缩写速查

| 缩写 | 英文全称 | 简要说明 |
|------|----------|----------|
| XL-320 | DYNAMIXEL XL-320 | ROBOTIS 小型舵机 |
| STP | STEP file | CAD 交换格式 |

## 为什么重要

- 属于文章按成本从低到高排列的「能自己造」清单；横向对比见 [能自己造的开源人形机器人 19 款：按成本与形态排序的阅读坐标](../overview/open-source-buildable-humanoids-19-technology-map.md)。
- 价格为文章标价（约 $540），入库日未核实。

## 文章说法核对

- **文章：** 文章称提供设计文件、编程工具与详细文档，社区有 ROS 等二次开发，社区示例为 japonophile/darwin。
- **README / 核查：** ROBOTIS-GIT/emanual 与 japonophile/darwin 经 git ls-remote 均可达；darwin 仓库 README 为「Darwin Mini」的 CoppeliaSim（V-REP）场景搭建说明，MIT 许可，最近提交 2020-06-20。emanual 为大型文档仓库，本次未克隆、未核对 mini 页面内容。
- **差异与保留：** 官方设计文件的开放范围与许可未核实；darwin 仓库是 Darwin Mini 仿真示例，是否等同于 ROBOTIS MINI 的社区示例以文章为准。
