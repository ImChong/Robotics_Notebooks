## 摘录 1：方法

- 问题：POMDP 下四足在线链式目标导航，目标变化有「重定向到已有目标」与「出现新目标」两类，无显式切换信号；探索与回访对记忆的需求冲突（附录梯度冲突分析）。
- 分层：高层策略输出机体系速度指令，冻结的低层运动控制器转关节动作。
- 空间：局部高度图 + 可见性掩码；全局为 LSTM + 投影地图构建 + 目标条件自注意力，辅助头预测高度 / 可见性 / 置信度。
- 时间：局部短时速度与目标观测；全局三份轨迹记忆（当前目标、累积、转换快照）；目标转换由规则或学习 MLP 检测。
- 训练：共享 actor-critic PPO（RSL-RL），MLP [512,256,128]，1500 次迭代；探索 / 回访使用分离的目标条件编码器与奖励。

**对 wiki 的映射：** 核心原理。

## 摘录 2：结果

- 仿真（Isaac Lab，迷宫 / 立柱 / 坑 / 多层楼梯），5 目标、路径 4–15 m：GLST SR 79.2%、SPL 0.70；SRU 64.2%、PCGrad 55.3%、Transformer 49.1%、LSTM 48.9%；4–20 m：64.6% 对 SRU 50.3%。
- 参数量：GLST 5.69M；SRU 11.8M。
- 消融（4–15 / 4–20 m）：去全局空间 74.0 / 54.1；去局部空间 55.7 / 49.6；去时间 60.6 / 46.2；去奖励 70.7 / 51.3。
- Spot 真机：Jetson Thor，36 次 / 方法，GLST 86.1%，比 SRU 高 11.1 个百分点，速度 0.61 对 0.62 m/s。

**对 wiki 的映射：** 实验与评测。

## 摘录 3：局限（作者自述）

依赖高度图质量（大俯仰 / 横滚会漂移）；记忆设计主要经验性，梯度冲突分析未严格评估；冻结低层使失败归因困难；仍有 sim-to-real 差距（椅子桌子感知、悬垂物）。
