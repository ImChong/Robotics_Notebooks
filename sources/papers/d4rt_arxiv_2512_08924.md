- **一句话说明：** 统一前馈 transformer：ViT-g 编码器（~1B）+ 轻量 cross-attention 查询解码器（~144M），对任意时空像素探针输出 3D 位置，联合深度 / 相机内参 / 动态 3D 跟踪与全像素 4D 重建；相对 VGGT / MegaSaM / SpatialTrackerV2 **18–300×** 跟踪吞吐，TAPVid-3D 与多深度基准 SOTA 级。

## 摘录 1：问题与范式

- **痛点：** 动态视频 4D 理解常被拆成单任务模块（单目深度 + 运动分割 + 测试时优化，如 MegaSaM）或多解码头（VGGT），**难以对动态区域建立统一时空对应**；SpatialTrackerV2 等多阶段迭代，慢且非单阶段统一。
- **D4RT 主张：** 从「逐帧稠密解码一切」转为 **按需查询（query-on-demand）**——编码一次 Global Scene Representation，解码器对独立查询并行回答「源像素在目标时刻、目标相机系下的 3D 位置」。
- **灵感：** Scene Representation Transformer（SRT）式解码接口 + VGGT 式交错 local/global ViT 编码。

**对 wiki 的映射：** 升格 [`wiki/entities/paper-d4rt.md`](../../wiki/entities/paper-d4rt.md)。

## 摘录 2：架构与查询接口

- **输入：** 视频 $V \in \mathbb{R}^{T \times H \times W \times 3}$，训练常用 **48 帧 @ 256×256**。
- **Encoder $\mathcal{E}$：** ViT-g，40 层，时空 patch $2{\times}16{\times}16$；交错 frame-wise 与 global self-attention；宽高比 token。
- **Decoder $\mathcal{D}$：** 8 层 cross-attention（~144M）；查询 $\mathbf{q}=(u,v,t_{\text{src}},t_{\text{tgt}},t_{\text{cam}})$ **互不 self-attend**，可大规模并行。
- **Local patch：** 查询附加 $(u,v)$ 处 **9×9 RGB patch embedding**（消融显著）。
- **下游统一：**
  - 变 $t_{\text{tgt}}=t_{\text{cam}}$ → **3D point track**
  - 固定 $t_{\text{cam}}$ 查询全像素 → **holistic point cloud / all-pixel 4D**
  - $t_{\text{src}}=t_{\text{tgt}}=t_{\text{cam}}$ 取 $\mathbf{P}_z$ → **depth**
  - 网格查询 + 针孔假设 → **intrinsics / pose**

**对 wiki 的映射：** 实体页「核心原理 / 流程总览」。

## 摘录 3：训练与实现

- **实现：** Kauldron 框架；AdamW；**64 TPU**，local batch 1，**500k steps ≈ 2 天**。
- **监督：** 每 batch **2048 随机查询**；主损失为归一化 3D 点 $L_1$（mean-depth 归一 + log 压缩）；辅助：2D 重投影、法线 cosine、可见性 BCE、运动向量、confidence。
- **数据混合：** BlendedMVS、Co3Dv2、Dynamic Replica、Kubric、MVS-Synth、PointOdyssey、ScanNet++、ScanNet、Tartanair、VirtualKitti、Waymo Open 等（含内部集）。

**对 wiki 的映射：** 实体页「工程实践 / 局限（未开源）」。
