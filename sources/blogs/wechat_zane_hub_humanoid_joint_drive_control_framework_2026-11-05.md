## 文章要点（作者表述）

- **三层框架：** 电流环（kHz 级，τ ≈ K_t·i_q）→ 力矩环（把「电流环＋电机＋减速器」视作力矩执行器）→ 阻抗层（τ_cmd = K_p·e + K_d·ė + τ_ff）；带宽逐级留 5–10 倍裕量。
- **被控对象：** 无框力矩电机、谐波 / 低比行星 / 行星滚柱丝杠、电机端 + 输出端双编码器、驱控一体板；折算惯量随减速比平方增长（N² 关系）。
- **力矩来源三条路：** 电流估计、双编码器差分（把传动柔性当力矩传感器）、输出端应变片；另有广义动量观测器做碰撞检测。
- **1 kHz 循环：** EtherCAT 分布式时钟同步，读编码器 → 阻抗律 → 限幅 / 摩擦前馈 → 电流环；电流环与 PWM 同步，不按 1 kHz 跑。
- **脏活：** Stribeck / LuGre 摩擦 + 双编码器电子消隙；两质量系统谐振 ω_r ≈ √(k_s/J_l)，陷波 / 自适应陷波 / 加速度反馈；绕组电阻测温 + 磁钢耐温 + 液冷，峰值 / 持续扭矩 3–5 倍。
- **路线：** TSA / SEA / QDD 三类，下肢主关节偏 QDD、上肢与腕部偏高比谐波；趋势：驱控一体、GaN、TMR 磁编码器、学习型前馈。

## 一手资料核对（我做的）

- **MIT Cheetah 执行器（Wensing 等，*Proprioceptive Actuator Design in the MIT Cheetah*，IEEE T-RO 2017；论文 PDF 已读）：**
  - 「5.8:1 行星」✓：论文写单级行星、1:5.8。
  - 「整腿开环力带宽实测 103.7 Hz」✓：论文图中标注 Leg System Bandwidth: 103.7 Hz（100 N 阶跃测试）。
  - 「电流环闭环带宽约 400 Hz」**未找到依据**：论文写电机电流控制频率为 **20 kHz**（custom motor drivers），「400 Hz」只在一页讲义式片段里作为「要完整控制 400 Hz 带宽，控制频率应为 4 kHz（5–10 倍）」出现，不是电流环带宽。文章该数字可能是误读，**推测**。
- **Berkeley Humanoid（Liao 等，arXiv:2407.21781）：** 论文执行器表四类型号齿轮比均为 9:1 ✓；最大一类峰值扭矩 81.1 N·m ✓（对应文章的 81.1，但是否即膝关节未逐项核对）。「行星」字样在论文中有出现，未逐项核对四类是否都是行星。
- **Mini Cheetah「6:1 行星、单模块峰值 17 N·m」：** 库内节点只确认到 6:1（见 [mit-mini-cheetah](../../wiki/entities/mit-mini-cheetah.md)），**17 N·m 未核实**。
- **未核实（行业口径 / 厂商数据）：** 执行器占整机成本「五成上下」、Optimus 14+14 执行器与各档扭矩 / 推力、宇树 H1 / G1 膝关节峰值（H1 360、G1 120 N·m）、35 N·m/kg 扭矩密度、产品目录参数（70 / 140 mm 模组）、钕铁硼 SH / UH 温度、80 °C 润滑脂边界、TMR ±0.025°。这些页面只作「作者表述，未核实」转述。
