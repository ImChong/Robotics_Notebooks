- **脚本仓库：** `shreyashampali/ho3d` 公开 MANO 补丁脚本、2D/3D 可视化工具、预测提交模板与本地评测脚本（2024-11-03 补齐 v2/v3 测试集 GT，支持离线执行 `eval.py`）。

## 核心技术要素摘录

1. **数据集演进与规模：**
   - **HO-3D v1（CVPR 2020 论文）：** **77,558 帧**（66,034 训练 / 11,524 测试，共 13 段测试序列含未见受试者与未见物体），**68 段序列**（16 段单相机刚性/近刚性抓取 + 52 段 5 相机约 5ms 同步采集），**10 名参与者**，**10 个 YCB-Video 物体**，640×480 RGB-D。
   - **HO-3D v3（2021-07，arXiv:2107.00887）：** 扩展至 **103,462 帧**、改进位姿精度，并将 RGB 从 PNG 改为 JPG 压缩存储。
   - **H2O-3D v1（2022-03，Keypoint Transformer）：** 同管线采集双手与物体交互，共 **76,340 帧**。
2. **HOnnotate 自动标注联合优化机制：**
   - 状态参数化：51-DoF MANO 手部姿态（45 维轴角直接关节限位，不用 PCA 压缩 + 6 维手腕平移旋转，加每人 10 维体型 β）+ SE(3) YCB 物体位姿。
   - 联合目标函数 `E_D + E_C` 含多相机可微渲染轮廓掩码误差 `E_mask`（前景分割由合成 10 万张手+YCB 图训练的 DeepLabv3 提供）、鲁棒 Tukey 深度残差 `E_dpt`、21 关键点 2D 热图误差 `E_j2D`（CPM 先在 1.5 万半自动帧+Panoptic 预训练）、最近顶点 3D 点云误差 `E_3D`、关节角限位 `E_joint`、网格排斥防穿模 `E_phy` 与零阶/一阶时序平滑 `E_tc`。
   - **单相机策略：** 在 20 帧子集 `Ω` 上先求解恒定抓取相对位姿 `p_{h:o}`，跟踪物体 `p_o^t` 后再多帧联合精细化；**多相机策略：** 以 batch size=20 做 Adam 优化。
   - **标注精度验证：** 多相机平均关节误差 `< 8 mm`（0.77 cm，AUC=0.79）；单相机与多相机网格差手部 0.77 cm、物体 0.45 cm。
3. **官方脚本接口：**
   - `setup_mano.py`：复制并修补 MPI `MANO_RIGHT.pkl` / `MANO_LEFT.pkl` 的 Python 2/3 pickle 与相对导入。
   - `vis_HO3D.py` / `vis_H2O3D.py`：通过 `utils/vis_utils.py` 加载 RGB-D 与 `.pkl` 标注，经 `forwardKinematics` 计算 21 关节与 778 顶点（OpenGL 坐标系，手位于负 z 轴），支持 Open3D 3D 与 Matplotlib 2D 投影/接触热图渲染。
   - `pred.py` & `eval.py`：迭代 `evaluation.txt` 生成 `pred.json`（关节 + 顶点列表），`eval.py` 沿用 FreiHAND 指标计算未对齐、Procrustes 对齐与尺度-平移对齐（`align_sc_tr`）下的 MPJPE / Mesh Error / AUC 及 F@5mm、F@15mm，并输出 `scores.txt` 与 `scores.html`。
