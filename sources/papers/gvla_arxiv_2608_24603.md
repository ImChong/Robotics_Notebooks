## 核心摘录（面向 wiki 编译）

### 摘录 1：问题 — 夹爪不变性假设 vs 策略级差异

- 现有 VLA 隐含 **gripper invariance**，但平行夹爪 vs 吸盘等同任务需 **不同接触/接近/执行策略**（例：薄盒侧推抓取 vs 顶吸）。
- OXE、DROID、Bridge V2 等数据集 **parallel-jaw 主导**，缺少跨夹爪 **strategy divergence** 监督。
- 中心问题：VLA 能否学习 **embodiment-dependent** 的多夹爪策略？

**对 wiki 的映射：** [paper-gvla-gripper-aware-vla](../../wiki/entities/paper-gvla-gripper-aware-vla.md)、[VLA](../../wiki/methods/vla.md)、[manipulation](../../wiki/tasks/manipulation.md)

### 摘录 2：MiGA 数据集

- **103K** 轨迹、**36** 任务、**5** 类夹爪（parallel-jaw / 3-finger / soft / vacuum / dexterous hand）、**5** 机器人平台；sim（Isaac Lab）+ real（xArm7 / Franka / UR5）。
- 每任务 **≥3** 种夹爪演示；**132** gripper–strategy 对 + 自然语言；约 **5%** 失败轨迹；RGB-D + 子步骤分解。
- 任务四类：**Singulated / Stacked / Constrained / Semantic**；强调 morphology-dependent solution。
- HF 发布：LeRobot schema；`state` 8D、`actions` 7D delta+夹爪、`gripper_id` 字段。

**对 wiki 的映射：** [MiGA 数据集归档](../datasets/miga-dataset.md)

### 摘录 3：GVLA 方法

- **Multi-gripper tokenizer**：三级 soft prompt — platform \(P^{(r)}\)、type \(P^{(g)}\)、instance \(P^{(u)}\)；prepended 到观测 token；相对 MLP/VQ-VAE/语言 prompt 聚类更清晰（Fig. 2）。
- **Dual Mixture-of-Adapters**：platform router + gripper router；Top-K 专家 bottleneck adapter 残差注入 **action expert 最后一层**（layer probing 显示 type sensitivity 末层最高）。
- **损失**：\(\mathcal{L}=\mathcal{L}_{action}+\lambda_g \mathcal{L}_{gripper}+\lambda_{LB}\mathcal{L}_{LB}\)；action 为 flow matching（\(\pi_0\) 系）；辅助 gripper-type 分类 + load balance。
- **骨干**：默认 **\(\pi_{0.5}\)**；亦报告 \(\pi_0\) 版 GVLA。

**对 wiki 的映射：** 实体页流程图；对照 OpenVLA、π₀.₅ 等同骨干 VLA（正文链接，非 source 映射）

### 摘录 4：实验要点

| 方法 | Flat | Stacked | Constrained | Semantic | Avg |
|------|------|---------|-------------|----------|-----|
| OpenVLA-OFT | 41.0 | 52.5 | 24.0 | 50.0 | 41.88 |
| \(\pi_{0.5}\) | 52.5 | 71.0 | 57.5 | 52.5 | 58.38 |
| **GVLA (\(\pi_{0.5}\))** | **53.0** | **76.0** | **62.5** | **72.5** | **66.00** |

- Tokenizer 消融：GVLA PE **0.032**、CAPD **1.34**、GCS **0.249** — 优于 MLP/VQ-VAE/LP。
- 零样本 cross-object 与 few-shot task/gripper/mixed-gripper 适应均优于基线。
- **真机**：UR5 + Robotiq 2F-85；**10 demo + 20k FT** 跨域新任务；GVLA > \(\pi_{0.5}\)（Fig. 10）。
- 失败模式：intra-type 对齐误差、物理夹爪极限、运动学不可达无恢复。
