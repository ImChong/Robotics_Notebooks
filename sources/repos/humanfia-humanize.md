## 要点

Humanize 是编排 coding agent 的工作流系统，提供终端界面、Web 界面和命令行 flow。CLI 需要 Python 3.12+、uv 和已登录的 agent CLI；README 示例包括 Claude Code 与 Codex。上游明确提示 agent 运行时绕过审批，建议先在临时仓库试用。
