## 摘录 1：问题与传感器配置（§1–§3.1）

- **痛点：** 纯 IMU 方案缺绝对位置 → 漂移、脚滑、穿地；后验物理优化仍依赖 IMU 接触推断；仅鞋垫 IMU+压力的方法难重建上身与全局轨迹。
- **传感器：** 4 IMU（双腕 + 双鞋垫内嵌）+ 简化鞋垫输入（每脚 vertical GRF、CoP、前/后掌二值接触）；全局坐标系下的加速度与朝向。
- **主张：** observer–controller 分解——先估 kinematics，再用 **State Difference**（估计态 vs 仿真 humanoid 残差）喂给 **DynamicsNet** 在物理仿真中跟踪。

**对 wiki 的映射：** 升格 [`wiki/entities/paper-grip.md`](../../wiki/entities/paper-grip.md)；与 [PHC](../../wiki/entities/phc.md)（DynamicsNet 奖励框架与共同作者 Zhengyi Luo）、[OpenCap Monocular](../../wiki/entities/paper-opencap-monocular.md)（互补：实验室/手机视觉 vs 可穿戴稀疏传感）互链。

## 摘录 2：KinematicsNet 与 State Difference（§3.2–§3.3）

- **KinematicsNet：** 四阶段 unidirectional LSTM——LP（叶关节位置）→ FP（全身 24 关节 SMPL 位置）→ FA（6D 关节角）→ KV（6 个 key 关节全局速度）；MSE 分模块训练再联合微调。
- **State Difference：** 不用积分全局位置（避免漂移直传 humanoid）；用 key 关节速度 + root-relative 关节位置差异统一表示；分 **key**（叶关节旋转/角速度/朝向 + 6 key 线速度差）与 **full**（24 关节位置差）。

**对 wiki 的映射：** 实体页「流程总览」Mermaid 与「核心原理」表。

## 摘录 3：DynamicsNet、PRISM 与主要结果（§3.4–§4）

- **DynamicsNet：** PPO 策略（MLP → 目标关节角 → PD 力矩）；观测 = 传感器 + State Difference + humanoid 自状态 + 1.5 m 局部 height map；奖励 = **PHC 式** AMP + imitation + energy penalty；**无 floating base / 无 residual force**；推理时有 **fall recovery**（history buffer 重置根位置与姿态）。
- **PRISM：** 6 被试、1275 条 × 10 s（~3.5 h）、100 Hz；日常/运动/人–物交互；同步 IMU、鞋垫、光学 MoCap、环境模型；SMPL 标签经 MoSh 拟合。
- **评测（Table 1）：** 三数据集 PRISM / UnderPressure / PSU-TMM100 上 **MPJPE 全局最优**；**FP（脚穿地）最低**；相对 GlobalPose 等在 PEL/PA 指标上因 IMU 数更少略逊，但全局轨迹与物理一致性更好；4 IMU + 压力相对仅 IMU 显著提升成功率（Table 3：Succ. Rate 88.58% → 94.49%）。
