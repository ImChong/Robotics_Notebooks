# Perceive, Predict, and Plan: a Unified World Action Model for Egocentric Dexterous Manipulation

> 来源归档（paper）

- **标题：** Perceive, Predict, and Plan: a Unified World Action Model for Egocentric Dexterous Manipulation
- **中文标题：** 感知、预测与规划：面向第一视角灵巧操作的统一世界动作模型
- **类型：** paper
- **arXiv：** <https://arxiv.org/abs/2610.22363>
- **入库日期：** 2026-10-21
- **线索来源：** [公众号综述（33 篇 Manipulation）](../raw/wechat_senlanke_manipulation_33_papers_2026-10-12_16.md)（具身运控lab，2026-10-20）
- **一句话说明：** 统一的世界动作模型（P³-WAM），三种模式完成 3D 手部感知、动作条件预测与规划。
- **沉淀到 wiki：** [`wiki/entities/paper-p3-wam-egocentric-dexterous.md`](../../wiki/entities/paper-p3-wam-egocentric-dexterous.md)

## 摘要要点（arXiv 摘要页）

- 预训练视频 DiT 上的 MoT 结构，三种模式共享基础参数，并以双向视觉–动作注意力交换信息。
- 随机模态可见性使视频与三维动作既可作条件也可作目标。
