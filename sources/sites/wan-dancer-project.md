## 页面内容要点

- 五类舞种 demo（中国古典舞 / K-Pop / 街舞 / 踢踏 / 拉丁）
- Minute-scale（>1 min，项目页样例可达约 2–3 min）
- LoRA 定制：单曲多参考 / 单参考多曲
- Creative keyframes：换装、手动关键帧控运动
- 与 X-Dancer 定性对照；Ethics 声明素材来源
