# WeVisOne-VL: Unified Visual Perception from Objects to Pixels

- **类型：** paper；arXiv 预印本
- **机构：** 腾讯微信视觉团队
- **论文：** <https://arxiv.org/abs/2610.31329>（v2，2026-10-24）
- **代码：** <https://github.com/Tencent/WeVisOne-VL>
- **入库日期：** 2026-10-27

## 资料摘要

- 统一检测、指代定位、计数、OCR、分割与抠图；以结构化 next-token prediction 表示点、框和缺失目标。
- 特殊 OBJ token 与轻量像素解码器生成实例掩码或 alpha matte；训练包含三阶段监督微调与混合任务强化学习。
- 在多个视觉基准报告领先表现；对缺失目标的拒答仍应在实际场景单独验证。
