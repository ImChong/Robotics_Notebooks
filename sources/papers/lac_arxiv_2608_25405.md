> 来源归档（ingest）

- **标题：** LAC: Linear and Angular Compliance for Humanoid Whole-body Control
- **类型：** paper
- **原始链接：** <https://arxiv.org/abs/2608.25405>
- **作者：** Yang Liu、Zhongkai Gu、Wei Zhu、Mitsuhiro Hayashibe
- **机构：** 日本东北大学 Neuro-Robotics Laboratory
- **项目页：** <https://lac-humanoid.github.io/>

- **一句话说明：** 单策略同时执行上身线刚度与角刚度命令：用被动运动链虚拟力矩驱动角导纳，再 teacher–student RL 跟踪增强轨迹；G1 真机可调拧腕 / 托物 / 遥操作 loco-manip。

## 核心摘录（MVP）

### 1) 线 / 角刚度必须能独立命令

- **摘录要点：** 拧门把手要低角刚度 + 高线刚度；托物要高角刚度。现有 SoftMimic / GentleHumanoid / CHIP 主要做线柔顺，角通道缺实验证据。LAC 给五维刚度命令：左右臂各 (K_L, K_θ)、躯干仅线刚度。
- **对 wiki 的映射：**
  - [LAC](../../wiki/entities/paper-lac.md)
  - [阻抗控制](../../wiki/concepts/impedance-control.md)
  - [GentleHumanoid](../../wiki/entities/paper-gentlehumanoid.md)

### 2) 柔顺运动增强：外力 + 被动链虚拟力矩 → 导纳 → IK

- **摘录要点：** 从 OMOMO / Inter-X 重定向接触帧；力事件沿接触法向、力偶独立采样。角通道不把力矩当自由刚体，而是用关节 PD 刚度把扳手映成 Δq，FK 得被动转角，再换成虚拟力矩驱动角导纳。mink + MuJoCo 解全身 IK。数据集 **378,051** 条、约 **1,050 h**。
- **对 wiki 的映射：**
  - [LAC](../../wiki/entities/paper-lac.md) — 流程总览
  - [导纳控制](../../wiki/methods/admittance-control.md)

### 3) RMA 式 teacher–student + 真机单调调制

- **摘录要点：** Isaac Lab 四卡 × 8192 env；特权编码器看外扳手与残差，部署只留 64 帧本体历史估计器。仿真：线刚度升则 CoM 位移单调降、姿态几乎不变；角刚度升则姿态变化单调降。真机拧手 10→100 N·m/rad 对应 **84°→15°**；4 kg 托物低角刚度掉落、高角刚度稳住。对照 SoftMimic / GentleHumanoid / FALCON：仅 LAC 在手 / 肘 / 躯干三场景位移都随刚度单调。
