## 页面内容（归纳）

- **定位：** 策展的设计工程技能目录，服务于构建 UI 的设计师、开发者与编码代理。
- **浏览入口：** 按 accessibility、motion、systems、visual、interaction、performance 等主题探索技能。
- **CLI / MCP：** 官网说明 CLI 查询和 MCP 接入；CLI 安装后可列类别、按类别过滤与读取单项技能，MCP 提供目录列举及获取技能正文的工具。
- **面向代理的路由：** 项目提供根级 UI Skills 技能，引导代理根据主题、技术栈和意图选择最小的一组具体技能。
- **Playbook：** 页面提供布局位移、文字平衡、等宽数字、触控目标等设计工程实践主题。
- **支持的 agent 文档：** 官网提供 Claude Code、Cursor、OpenClaw、Codex、GitHub Copilot 等接入说明。

## 源码与数据边界

官网目录中的技能来自多个发布者仓库。项目仓库本身开放，但第三方技能内容的来源、许可证、更新节奏和适用性应回到各发布者页面分别确认。项目的测试和构建脚本验证仓库实现；它们不是外部技能质量的独立评估。
