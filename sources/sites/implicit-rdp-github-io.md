## 页面公开信息

- 将 ImplicitRDP 描述为单一端到端视觉–力 diffusion policy；causal attention 处理异步视觉和力 token。
- VRR 使用 compliance 关系下的 virtual target 作为辅助表示目标，用于避免模型 modality collapse。
- 页面比较 Box Flipping 与 Switch Toggling：DP 0/20 与 8/20；RDP 16/20 与 10/20；ImplicitRDP 两项均为 18/20。
- 页面提供论文、代码与实验资源入口；代码可运行性以仓库当前公开配置为准。
