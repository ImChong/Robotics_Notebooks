# MosMos 官方产品页

- **类型：** 官方产品页
- **标题：** MosMos — We speak faster than we type
- **链接：** <https://mosmos.io/>
- **公司链接：** <https://mosi.cn/>
- **核查日期：** 2026-10-22
- **一句话说明：** MOSI 生态的桌面语音输入与会议记录工具，可将语音整理成不同场景下的文字，并生成会议摘要和待办事项。

## 官方页面摘录

- **语音输入：** macOS 上用 Fn、Windows 上用 Right Alt 快捷键启动录音，将讲话转成文字并粘贴进当前应用。
- **风格调整：** 支持按聊天、邮件、文档、提示词、代码与终端等场景调整表达；提供 Basic、Standard、Advanced 三种改写程度。
- **关键词：** 可添加专有名词、同音词和姓名以帮助识别及保留。
- **会议记录：** 支持多人转写、说话人识别、会议摘要及待办事项整理。
- **平台：** 官网列出 macOS 15+（Apple silicon）和 Windows 10/11 下载；iOS 标注即将推出。
- **与 MOSS-Image 的边界：** 这是独立的桌面产品。官方页面没有说明它使用 MOSS-Image，也不应把它作为图像生成模型的组件。
