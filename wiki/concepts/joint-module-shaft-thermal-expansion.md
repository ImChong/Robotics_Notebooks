# 关节模组轴的径向热膨胀校核

> 数值为作者表述，未核实；本页只整理原文方法，不含站外补充。

## 一句话定义

关节模组里电机转子、减速器输入端、轴承内圈、编码器磁环都装在同一根轴上，温升使轴径增大几微米到几十微米，与过盈量、轴承游隙同量级；用 **Δd = α·d·ΔT** 在图纸阶段手算，再回到过盈 / 游隙 / 预紧尺寸链里校核。

## 英文缩写速查

| 缩写 / 符号 | 英文全称 | 简要说明 |
|------------|----------|----------|
| α | Coefficient of linear thermal expansion | 线膨胀系数，1/K，须注明温度区间 |
| ΔT | Temperature rise | 稳态温度 − 装配温度（通常取 20℃） |
| dm | Mean bearing diameter | 轴承平均直径 (d + D)/2 |
| E | Young's modulus | 弹性模量，钢约 210000 MPa（原文取值） |
| F 级绝缘 | Insulation class F | 许用 155℃，绕组温升按此限制 |

## 为什么重要

- 典型故障：常温装配和短时测试都正常，连续运行后摩擦力矩上升、异响、编码器信号波动，甚至轴承抱死；逐项排查常发现零件本身没问题，是热态尺寸链没算。
- 热膨胀不是公差链里的小尾巴，而是与配合公差同量级的主项。

## 热源与 ΔT 的取法

- 三处热源：电机铜损 / 铁损（绕组最热，稳态常见 80~120℃）；减速器摩擦（谐波、摆线等，损失约占输入功率十几到三十个百分点，热落在壳体与输入轴附近）；轴承摩擦（预紧越大、转速越高越热）。
- 稳态下轴温介于绕组与壳体之间，靠近轴承内圈处常见 50~85℃。
- **ΔT 的基准是装配温度（通常 20℃），不是环境温度**；冬夏装配、南北发货会使 ΔT 不同，按最不利组合取。
- 轴不是等温体：优先用热电偶实测一次稳态温度分布；无数据时按轴承内圈温度保守估。

## 公式与材料系数

Δd = α · d · ΔT（金属各向同性，径向与长度方向同一公式；轴向伸长用 α·L·ΔT）

- 体积膨胀系数约 3α，配合计算只用线膨胀系数。
- α 随温度略变，轴承钢在 20~200℃ 可按常数；带镀层 / 渗氮层的轴以基体为准。
- 同一计算中相关零件的 α 取自同一来源（不同来源可差百分之几）；批量设计以材料证明书为准。

| 材料 | 位置 | α（10⁻⁶/K，20~100℃ 典型） |
|------|------|------|
| GCr15 / 100Cr6 轴承钢 | 轴、轴承内外圈 | 12.0 |
| 42CrMo（AISI 4140） | 调质轴 | 12.2 |
| 17-4PH | 高强耐蚀轴 | 10.8（21~93℃） |
| 440C | 耐蚀轴与轴承件 | 10.2 |
| 304 | 防锈结构件 | 16.6~17.2 |
| TC4 | 轻量化轴 | 8.6 |
| 6061 铝 | 壳体、轮毂 | 23.6 |

要点：铝约为钢的两倍，铝壳 / 铝轮毂与钢轴的差胀是后述配合问题的根源。

## 手算示例

**1. Ø20 轴自身膨胀**：GCr15，α = 12×10⁻⁶，20℃→80℃，ΔT = 60 K：Δd = 12×10⁻⁶ × 20 × 60 = 14.4 μm（半径方向各 7.2 μm），与 k5 / m5 轴段过盈（几 μm 到十几 μm）相当。

**2. 热装温度（公式反用）**：ΔT = (δ + Z)/(α·d)。d = 25 mm，设计有效过盈 δ = 15 μm，装配最小间隙 Z = 10 μm：ΔT = 25/(12×10⁻⁶×25) ≈ 83 K，加热到约 105℃。

- 上限：开式轴承加热不超过 120℃（轴承钢经 150~160℃ 回火，超过则硬度与尺寸稳定性受损）；带密封件 / 防尘盖的轴承建议不超过 80℃。
- 加热要均匀，感应加热优于电热板。

**3. 6205 轴承热态游隙**（d = 25，D = 52，dm = 38.5 mm）：

| 项目 | 公式 / 假设 | 结果 |
|------|-------------|------|
| 温差减游隙 | Δr_temp = 0.012·ΔT·dm（μm），内圈比外圈热 30℃ | ≈ 14 μm |
| 过盈配合减游隙 | 有效过盈 × 系数（实心钢轴约 0.7，精确值查厂商图表）；k5、有效过盈 8 μm | ≈ 6 μm |
| 合计 | | ≈ 20 μm |

若初始径向游隙为 20 μm，热态剩余游隙趋近零，属临界。再选小一档游隙组，或启动瞬态内外圈温差大于稳态（原文称轴承厂商有提示），游隙变负即成预紧：摩擦力矩↑ → 温度↑ → 游隙↓ 的正反馈，直至异响、保持架应力异常、抱轴。

铝壳的另一面：座孔膨胀比外圈快，外圈与铝座的过盈热态会变松，出现蠕动与微动磨损；故外圈在铝座中通常按间隙配合加防松结构，热态同样要校核。

## 三个坑

- **过盈配合是双刃**：轴比内圈热则过盈增大、配合应力上升；铝轮毂（磁环、同步带轮）α 是钢轴两倍，热态可能变松也可能变紧。方法：分别算两个件的直径变化，取最不利组合校核保持力与应力；传扭轮毂优先用钢或 α 与轴接近的材料，必须用铝时按热态过盈下限校核。
- **编码器**：磁环 / 码盘直径热胀仅几 μm，对磁极节距的影响可忽略；要查的是轮毂与轴的热态过盈，以及读数头与磁环的轴向间隙（磁编码器间隙窗口通常仅零点几 mm，轴向伸长几十 μm 即可占去可观比例，按热态留裕度）。
- **轴向热应力**：两支轴承都轴向固定、中间无补偿时，σ = E·α·ΔT = 210000 × 12×10⁻⁶ × 60 ≈ 150 MPa，直接叠加到轴承轴向负荷，预紧失控。常见处理：一端固定一端游动，或用波形弹簧留轴向弹性裕度。

## 五个工程做法

1. 温度场比公式重要：实测稳态温度，比纠结 α 更有价值。
2. α 取自材料证明书 / 权威手册并确认温度区间（原文提到 GB/T 4339-2008，修改采用 ASTM E228，推杆膨胀计原理）。
3. 公差与温度一起校核：「最大过盈 + 最大温升」「最小间隙 + 最大温升」两组最不利组合各算一遍。
4. 空心轴不要照抄实心结论：外径膨胀量公式不变，但薄壁件配合应力与热态松紧变化更快，热装加热与冷却时间按壁厚重估。
5. 用装配过程反验：热装时记录加热温度与套装前后千分表读数，与公式对照，相当于对 α 与 ΔT 做一次实物标定。

## 设计清单

1. 定材料 α（注明温度区间）与各部位 ΔT（实测或同类模组数据）
2. 算轴与各安装部位径向膨胀 Δd = α·d·ΔT
3. 校核热态最不利组合（最大过盈 + 最大温升、最小间隙 + 最大温升）
4. 校核轴承热态剩余游隙大于零，并给启动瞬态温差留裕度
5. 校核铝轮毂与轴的热态过盈下限、编码器读数头热态间隙
6. 核对热装加热温度与 120℃ 上限（密封轴承 80℃）
