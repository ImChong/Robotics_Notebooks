## 核心摘录（面向 wiki 编译）

### 1) 核心问题与统一动作空间

- **物理可解释统一动作空间（128D + 128D 可用性掩码 = 256D）：** 为跨 46 个异构数据集预训练而不丢失物理量纲语义，RDT-1B 定义 128 维向量统一编码右/左臂关节位置与速度、夹爪、末端位置/6D 旋转/线角速度及底盘速度（单臂默认映射到“右臂”槽位），不强制缩放到 `[-1, 1]` 而是统一物理单位（m, rad, m/s, rad/s），并拼接 128 维 0-1 掩码区分“物理零值”与“填充缺失”，从而消除异构构型冲突。
- **反捷径设计：** 仅输入当前低维本体 $z_t$（剔除历史本体 $z_{i<t}$）与控制频率 $c$，配合 $T_{\text{img}}=2$、3 视角 RGB（前视、右腕、左腕，$384\times 384$ 补齐），防止策略依赖低维历史记忆而忽略视觉推理；训练时以 10% 概率对各模态独立掩码。

### 2) 架构与模型规格

- **规模与编码器：** 主体 1.2B 参数（28 层、hidden size 2048、32 注意力头）；语言采用冻结 **T5-XXL**（4096D）+ 2 层 GeLU MLP 适配器，视觉采用冻结 **SigLIP**（`siglip-so400m-patch14-384`, 1152D）+ 多维时空位置编码 + 2 层 MLP 适配器，低维输入（本体、噪声动作 chunk $T_a=64$、频率 $c$、扩散步 $k$）由 MLP 编码后拼接为序列。
- **三大 DiT 改造：**
  1. **QKNorm & RMSNorm：** 抑制机器人物理量数值极值引发的梯度爆炸，且避免 LayerNorm 中心化破坏时间序列对称性（Fig. 4a 显示去掉 `*N` 时 60K 步内损失发散）；
  2. **非线性 MLP 解码器：** 替代线性投影头以捕捉接触与关节非线性动力学（Fig. 4b：Dexterity 任务去掉 MLP 从 `32%` 降至 `12%`）；
  3. **交替条件注入（Alternating Condition Injection, ACI）：** 各层交叉注意力在图像 token 与文本 token 之间交替注入，防止图像 token 数量远多于文本导致指令被淹没（Fig. 4b：Pour Water-L-1/3 指令遵循准确率去掉 ACI 从 `62.5%` 降至 `12.5%`）。

### 3) 训练与推理超参

- **预训练与微调：** 46 个数据集共 **1M+ 轨迹（21TB）**，48 张 H100 80GB 上以 `batch_size=32×48`、`bf16`、`AdamW lr=1e-4` 预训练 1M 步（约 1 个月）；微调选用 **500K 步预训练检查点**（调度原因），在自采 **6K+ 轨迹 / 300+ 任务 / 3M+ 帧** Mobile ALOHA 双臂数据集上再训 130K 步（3 天）。微调禁用 Classifier-Free Guidance（App. F 指出 CFG 未提效反而导致真机机械臂动作不稳定）。
- **采样加速：** 训练采用 DDPM 1000 步 + `squaredcos_cap_v2`；推理用 **DPM-Solver++ 5 步**采样，在板载 RTX 4090 24GB 上达 **6 action chunks/s（381 actions/s）**。

### 4) 实验结果与消融（Fig. 1, Table 2, Table 3）

- **总体成绩（Fig. 1）：** 跨 5 维（未见物体、未见场景、指令遵循、少样本学习、灵巧操作）共 7 项 ALOHA 真机任务综合成功率 **RDT-1B 68.2%**（vs `RDT from scratch` **34.8%**，预训练增益 `+33.4%`；vs ACT `12.2%`、OpenVLA `1.7%`、Octo `1.6%`）。
- **Table 3 分任务总成功率：** `Wash Cup`（seen/unseen1/unseen2）`50% / 75% / 50%`；`Pour Water-L-1/3 | R-2/3` `100% / 87.5%`（手/量对准分别达 `100%` / `75%`）；`Pour Water` 3 个未见房间 `62.5% / 100% / 62.5%`；`Fold Shorts (1-shot)` **68%**（scratch 40%）；`Handover (5-shot)` **40%**（scratch 16%）；`Robot Dog (Dexterity)` 总分 **76%**、走直线 **48%**。
- **Table 2 消融（Unseen Object / Unseen Scene / Instruction Following）：** 完整 RDT `50% / 62.5% / 100%`；去掉扩散改为确定性回归 `RDT (regress)` 降至 `12.5% / 50% / 12.5%`；缩至 166M `RDT (small)` 为 `37.5% / 62.5% / 25%`；无预训练 `RDT (scratch)` 为 `0% / 25% / 62.5%`。
