## 核心摘录（面向 wiki 编译，均核对自 v3 全文）

### 1) 三分布形式化与三种错位（§I、§III-A）

- 定义真机成功轨迹流形 $P_{\mathrm{real}}(\tau)\propto \mathbf{1}\{\tau\in\mathcal{G}\}$；训练轨迹分布 $P_{\mathrm{train}}$ 由人类演示集 $\mathcal{D}$ 诱导，策略归纳偏置 $Q_{\mathrm{model}}\triangleq \pi(a|s;\hat\phi)$，真机部署轨迹分布 $P_{\mathrm{test}}(\tau)$ 由 $Q_{\mathrm{model}}$ 经推理算子 $\mathcal{I}(\tilde{a}_t|a_t, s_t)$ 复合真实动力学 $\tilde{T}(s_{t+1}|s_t, a_t, \xi)$ 产生（Eq. 1–2）。
- 对应三类系统级失效：
  1. **覆盖不足（Coverage Deficiency）：** 有限演示 $P_{\mathrm{train}}$ 欠采样高维服装流形，导致 $Q_{\mathrm{model}}$ 过拟合窄模式；
  2. **时序错配（Temporal Mismatch）：** 长时程阶段间视觉相似但语义不同态引起误动作或卡死（$P_{\mathrm{train}}\leftrightarrow Q_{\mathrm{model}}$），以及推理-执行时延导致动作断层（$Q_{\mathrm{model}}\leftrightarrow P_{\mathrm{test}}$）；
  3. **失败级联（Failure Cascade）：** 静态演示缺少恢复轨迹，$P_{\mathrm{test}}$ 一旦偏离即不可逆崩溃。

### 2) 三支柱管线（§III-C–E，Algorithm 1，App. C）

| 阶段 | 模块 | 关键机制 |
|------|------|----------|
| 覆盖不足 | **Model Arithmetic (MA)** | 数据切为 4 个不重叠子集各自微调 $\{\theta_i\}$，权重插值 $\theta_{\mathrm{merged}}=\sum_i \alpha_i \theta_i$（$\alpha_i\ge 0,\sum\alpha_i=1$）；**用 DAgger 恢复轨迹作 OOD 验证集** 选 $\alpha$，消融 average / inverse-loss / gradient descent / greedy（**greedy + OOD 最稳**） |
| 时序错配 | **Stage Advantage (SA)** | 放弃 $A=V(s')-V(s)$（方差与噪声放大、跨阶段多值），改用 VLM 帧对直测 $A_{\mathrm{stage}}(s,a,g)=f_\theta(s,s'|g)$（随机时间间隔 $\Delta$，阶段标量 $g\in\{0,\dots,(S-1)/S\}$）；Task A/B/C 分别拆 2/4/3 阶段；取前 $\epsilon=0.3$ 为正样本做 advantage-weighted BC |
| 部署间隙 | **Train-Deploy Alignment (TDA)** | **Heuristic DAgger**（人工直接摆入错抓、半掉落等失败态采恢复，免等在线失败）+ **时空增强**（水平翻转 + 左右臂互换、跳帧速度变换）+ **Temporal chunk-wise smoothing**（Algorithm 1：按消费索引 $k$ 截断 $d=\min(k, d_{\max})$，若旧缓存短于 $m_{\min}$ 则末值填充，重叠段按 $w_i=1-i/\max(L-1,1)$ 线性混合；可与 RTC 正交叠加） |

### 3) 数据、训练与评测（§IV，Table I–II，App. D–E）

| 项 | 内容 |
|----|------|
| 数据规模 | Task A（T恤展平折叠，Easy）2668 eps（均 30.41 s）；Task B（条件分拣，Medium）3519 eps（均 34.40 s）；Task C（挂衣，Hard）2988 eps（均 39.01 s）；30 Hz 采集（含较短 DAgger 干预片段） |
| 控制与模型 | 全参微调开源 $\pi_{0.5}$（辅以 $\pi_0$）；chunk $K=50$，底层控制 100–200 Hz（Table I 标 100 Hz） |
| 优化器 | AdamW，lr $2.5\times 10^{-5}$，80k steps，cosine decay 10k，batch 128，grad clip 1.0，噪声水平 $\sigma\in[0.001,1.0]$ |
| 评价指标 | 10 trials × 3 服装类型：SR（成功率）、TP（吞吐量，任务/时）、Retry Cost（每局重试次数）、Average Score（Table II 里程碑加权分，满分 100） |
| 关键发现 | (1) MA 全变体优于 single-best 与全量联训（提示 VLA 全参微调存在显著参数冗余）；OOD 验证降标准误。(2) SA 在 Smooth Frame Ratio (SFR) 与 MSTD 上稳于自实现 $\pi_{0.6}^*$-style RECAP；Task C 非分阶段且缺预训练挂衣先验时 Direct+Stage 收益减弱。(3) TDA 中 Heuristic DAgger 逼近标准 DAgger 且更省时；chunk 平滑多数设置优于 temporal ensembling 与单独 RTC，与 RTC 叠加再升。(4) **负基线（App. A Q2）：** GO-1、X-VLA、DexVLA、UniVLA、OpenVLA 在同 20 h 数据与调参下训练损失收敛但真机 SR 接近 0。(5) **压力测试：** 任意初态 **24 h** 连续自主运行。(6) **数据效用与失败模式（App. A Q5–Q6）：** 提出「开环重放可行性（replay-ability）」作数据质检门槛；主要失败仍集中在空间抓偏与策略死循环（尤其展平阶段）。 |

### 4) 与近邻工作对照

| 工作 | 关系 |
|------|------|
| $\pi_0$ / $\pi_{0.5}$ / openpi | 骨干与训练/推理底座；本文是后训练对齐与部署配方（App. A Q6 强调 $\pi_0/\pi_{0.5}$ 的微调可塑性） |
| $\pi^{*}_{0.6}$ / RECAP | SA 的数值稳定性对照（值差 → 阶段条件成对直测 advantage） |
| LeHome / Learning to Fold | 同属叠衣；LeHome 偏竞赛 SO-ARM101 + 异步 AWR/RECAP；χ₀ 偏双臂协同长时程生产稳健 |
| STEAM | 另一条 advantage 路线（离线自监督 ensemble）；χ₀ 用手标阶段 + 在线/启发式 DAgger |
| RTC / ACT ensembling | 推理侧 chunk 对齐；本文提出 temporal chunk-wise smoothing（可与 RTC 叠加） |
