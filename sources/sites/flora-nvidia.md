- **标题：** Flora: An Open Model Suite for Scaling Robotics Data Engines
- **官方项目页：** <https://research.nvidia.com/labs/gear/flora/>
- **论文 PDF：** <https://research.nvidia.com/labs/gear/flora/assets/paper/flora.pdf>

- **代码：** 项目页未提供 GitHub 源码入口；公开模型权重见 HF collection，不能据此推断完整数据引擎代码可用

## 页面核查

页面介绍时间戳字幕、过程/结果奖励与 rubric 评分。HF collection 包含 Flora-Captioner、Flora-TempSeg、Flora-Rewarder。论文声称开源数据引擎，但当前可见项目入口未链接实现仓库，后续如出现官方代码链接应更新此记录。
