# Ropedia W0 项目页

> 来源归档（site / project-page）

- **标题：** Ropedia W0: Scaling Loco-Manipulation World Models across Embodiments with Human Experience
- **项目页：** <https://ropedia.github.io/ropedia-w0/>
- **论文：** <https://arxiv.org/abs/2610.26855>
- **官方代码：** <https://github.com/Ropedia/ropedia-w0>
- **模型：** 项目页提供模型入口；仓库 README 将更多 checkpoint 列为待发布
- **一句话说明：** 以人类经验扩展跨人形、机械臂等 embodiment 的 loco-manipulation 世界模型。

## 开源状态

官方仓库公开，包含推理脚本、模型代码、示例与工具；README 的待办清单仍包含 5B/A14B checkpoint、Xp-Teleop 数据、评测和后训练代码。仓库许可证标注代码 Apache-2.0、模型权重 CC BY-NC 4.0、Xp-Teleop 数据 CC BY 4.0；基础模型和示例源数据仍受其各自许可约束。
