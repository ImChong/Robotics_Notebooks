## 核心摘录

1. **环境（§2.1，表 2）：** MuJoCo；高自由度拟人手装在 UR5e 上，25 个手指关节 + 2 腕关节 + 7 臂关节；自由刚体笔以三指握（tripod）放入，无虚拟抓握辅助；控制频率 25 Hz。
2. **任务（§2.1，表 6）：** 3 个保持任务（静止 / 运动 / 接触涂写）、3 类描摹（线 / 圆 / 形状）、手写数字 / 大写字母 / 英文词 / 中文字；训练含 10 个数字、26 个大写字母、15 个英文词、118 个汉字；零样本测试加 20 个未见英文词、10 个四字成语、122 个至少 7 画的汉字。
3. **双分支 actor（§2.2，式 3，表 3）：** 抓握 MLP 与书写 MLP 各为 217→256→256（tanh），固定 mask 取手指动作自抓握分支、臂 / 腕 / 停止动作自书写分支；输入 137 维状态 + 16 个轨迹样本×5 维（x,y,高度,力,时间的 5D 光标，步长 2）；输出 34 维物理动作 + 1 个停止输出（阈值 0.5）；critic 独立 217→256→256→1。
4. **训练三阶段（§2.3，图 2，附录 A.1）：** ① 抓握：240 条示教 episode 做 BC，再用 PPO 在静止 / 运动保持与环境驱动涂写上训练 8M 步（据已落地 checkpoint 的记录）；② 全任务书写 BC：IK 控制臂 / 腕、学到的抓握控制手指，干净 + 噪声（σ=0.01, 0.02，DART 式注入但保留干净 IK 标签）示范，逆方差加权 MSE（式 1/4）；③ 全任务 PPO：抓握分支均值冻结、观测统计冻结，书写均值与高斯 log-std 可训练。
5. **奖励（§2.3 式 2，附录 A.2 式 5，表 5）：** 有序覆盖（1 mm 内）增量、脱靶墨迹、力 MAE、归一化时间、朝「按压深度引导点」前进的距离差，减掉掉笔 / 提前终止惩罚 D_t；权重 λC=1000、λP=500、λE=200、λτ=300、λq=5000；奖励中没有 BC / IK 时序项。
6. **RL 设置（表 3，附录 A.2）：** 512 环境×1024 步 rollout；PPO clip 0.2；Adam 1e-5 线性衰减；近似 KL 目标 0.03（经验预算，非硬保证）；γ=1，GAE λ=0.95；共 39,845,888 个 transition，最终 RL 一次运行 193.8 分钟。
7. **主结果（§3.1，表 1）：** 50 个匹配种子 / 任务，八个主任务均值：完成度 IK 92.0% / BC 91.3% / RL 94.8%；精度 80.6% / 79.0% / 87.6%；力 MAE 0.537 / 0.773 / 0.362 N；耗时 8.11 / 8.19 / 7.67 s。RL 相对 BC 力误差降 53%（0.773→0.362 N）。
8. **零样本（表 1 右三列，§3.1）：** 未见英文词完成度 IK 87.7 / BC 87.2 / RL 91.6%；成语 92.1 / 91.6 / 92.9%；未见汉字 87.7 / 86.9 / 91.6%；力 MAE RL 分别为 0.433 / 0.454 / 0.402 N。
9. **例外与诊断（附录 C.2/C.3）：** 线任务 RL 完成度 97.5% 低于 IK 的 98.2%；种子 26254 在 BC 与 RL 下都零墨迹并保留在均值里；BC→RL 过程非单调，早期评估可能先掉完成度或形状质量。

## 作者自述与笔者判断的边界

- 作者自述：RL 相对 BC / IK 提升完成度、精度、力、效率；对未见英文与中文内容无需微调即泛化（摘要、§3.1）。
- 论文自己承认的口径问题：附录 A「评测套件变更」与 B 说明当前代码已把 cursive 并入 word，故当前任务集是 7 个书写任务，而主表是 8 任务；当前源码目录不代表归档 checkpoint 在后续任务变更后重训过（附录 B 开头）。
- 笔者判断（推测）：主表所有数字来自单次最终 RL 运行（附录 A 的 Data and checkpoint provenance 说明中间评估是同一次运行的快照），论文未报种子间方差或置信区间。
