## 一句话摘要

DGIST 提出的 **LT-Mem** 官方站点：**波动性感知** 三层记忆（Live / Delta / Meta）支撑终身场景理解；多会话 SLAM + LT-VQA 时间问答基准。

## 公开信息要点（截至 2026-10-02 核查）

- **机构：** DGIST Robotics and Mechatronics Engineering（Yumin Lee、Hyoseok Ju、Giseop Kim†）。
- **记忆策略：** 按对象动态性选择覆盖 / 保持 / 多假设；确定性证据评分维持跨会话身份。
- **LT-VQA：** 3 环境、30 会话、80 QA；[Google Drive 下载](https://drive.google.com/drive/folders/1rrwXxJDqJO9P9-wf_-JENX6FP1v9AThC)。
- **代码（步骤 2.5）：** 页内仍标为 **Code (TBD)**，没有可点击 GitHub 仓库链接；记忆系统代码尚未发布。
- **交互演示：** [Interactive Demo](https://lt-mem.github.io/DEMO/) 展示跨会话点云、对象位置轨迹和 Live / Delta / Meta 记忆卡。
- **数据下载：** 项目页链接至 [Google Drive 数据集](https://drive.google.com/drive/folders/1rrwXxJDqJO9P9-wf_-JENX6FP1v9AThC)，包含 RGB、深度、标定、IMU、里程计及对齐点云 / 姿态 / 时间戳。
