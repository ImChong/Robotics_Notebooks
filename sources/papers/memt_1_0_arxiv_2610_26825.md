# MemT-1.0: Towards Memory-Native Evolution（arXiv:2610.26825）

> 来源归档（paper）

- **标题：** MemT-1.0: Towards Memory-Native Evolution
- **类型：** paper（technical report）
- **arXiv：** <https://arxiv.org/abs/2610.26825>
- **代码：** <https://github.com/MemTensor/MemT-1.0>
- **入库日期：** 2026-10-20
- **一句话说明：** 将持续演化的记忆纳入模型计算，通过 Gated DeltaNet-2、Mixture-of-Storage 和两阶段训练构建 MemT-1.0-Nano / Flash。

## 核心摘录

1. **问题：** 常见参数化记忆方法难以同时积累历史信息、在推理时使用记忆并维持可扩展状态；完整上下文 KV cache 随历史增长而增大。
2. **架构：** MemT-1.0 将动态 local memory 与可训练 hyper memory 纳入模型计算；生成时读取当前记忆，轮次或片段结束时以稳定的 Gated DeltaNet-2 机制逐 token 更新状态。Mixture-of-Storage（MoS）用于扩展原生记忆容量。
3. **训练：** 先进行 backbone preparation，再以 continued pre-training 与 post-training 两阶段训练；报告称使用 34B tokens 数据及专门训练、推理基础设施。
4. **模型族：** Nano 基于 Qwen3.6-35B-A3B；Flash 基于 DeepSeek-V4-Flash。模型卡列出的总参数分别为 36B 和 288B。
5. **评测：** 报告覆盖 11 项记忆基准。作者称两款模型在所比较的参数化记忆方法中分别排名第一、第二；总体上，强文本记忆系统仍领先，尤其是需要从长历史检索细粒度证据的任务。
6. **效率与应用：** 在 128K 历史长度下，报告称 Nano 相对完整上下文 KV cache 达到约 1.86×端到端推理加速、持久存储减少约 66×；程序性经验还被用于长程 agentic coding 任务。

## 需要保留的边界

- 以上性能数字是论文所述实验配置下的结果，不应外推为所有模型、硬件或机器人任务上的保证。
- 论文展示的是记忆基础模型与 coding-agent 应用；机器人任务级记忆的适配仍需针对目标环境验证。
- 模型权重、数据和仓库软件采用不同发布条款，按各自发布页面核对。
