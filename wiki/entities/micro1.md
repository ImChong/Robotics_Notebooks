# Micro1

**Micro1** 是面向 **前沿 AI 实验室与 physical AI 团队** 的 **数据标注与评测** 服务商（非上市公司）。LeoInAI Substack（2026-09）引用 CEO Ali Ansari 观点：采集规模爆炸后，**识别人类示范里哪些片段真有用** 比单纯堆时长更缺人。

## 一句话定义

**数据飞轮的瓶颈正在从「采不到」变成「采太多但不知道哪段该学」。**

## 英文缩写速查

| 缩写 | 英文全称 | 简要说明 |
|------|----------|----------|
| QA | Quality Assurance | 人类筛选与一致性评测 |
| IL | Imitation Learning | 下游模仿学习 |
| RL | Reinforcement Learning | 部分客户提供 RL 数据需求 |
| FM | Foundation Model | 服务对象含基础模型团队 |
| API | Application Programming Interface | 非核心；标注平台多为 B2B 交付 |

## 为什么重要

- 与 [Appen](./appen.md)「质检差异化」叙事一致，补全 Substack **投资/产业** 链条的「标注层」节点。
- 区别于 [Shift](./shift-app-nyc.md) **自己采数据**；Micro1 偏 **第三方 curation**。

## 核心信息

| 项 | 内容 |
|----|------|
| **定位** | 数据实验室 / 标注与评测外包 |
| **客户** | 前沿模型实验室、physical AI 构建者 |
| **公开信息** | 以 CEO 社交媒体与行业报道为主；**无上市财报** |
