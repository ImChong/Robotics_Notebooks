## 核心摘录（归纳，非全文）

### 测试难在哪（四类）

| 难点 | 文内读法 |
|------|----------|
| **自由度规模** | ~30+ DoF，单点背隙/刚度/温升缺陷被整机动力学放大 |
| **动态平衡** | 双足持续近跌倒边界；推扰、踩空、落地冲击、载荷突变难量化 |
| **AI 不确定性** | 端到端策略不可枚举；版本回归与失效统计是必备环节 |
| **标准滞后** | 产品月迭代 vs 标准年制定；企业内控规范先行 |

### 六级递进链路（测试左移）

`L0 仿真 → L1 部件台架 → L2 关节模组 → L3 子系统 → L4 整机 → L5 场景化/可靠性验收`

| 级别 | 对象 | 核心产出 |
|------|------|----------|
| **L0** | MuJoCo / Isaac Lab 等 | 动力学预检、控制预验证、域随机化训练 |
| **L1** | 减速器、PRS、电机、编码器、力传感、电池 | 可复现部件数据（背隙、效率、寿命） |
| **L2** | 旋转/直线一体化关节模组 | 峰值/持续扭矩、扭矩密度、齿槽转矩、带宽、耐久 |
| **L3** | 多关节、通信、热、感知–控制 | 总线抖动、联动包络、85/85 应力、传感器标定/同步 |
| **L4** | 整机 | 动态性能、环境适应、电气安全、EMC、功能安全 |
| **L5** | 中试/真实场景 | 长跑、失效模式库、数据闭环 |

**成本账：** 整机换关节模组代价可能是台架阶段数十倍。

### L1–L2 部件与模组要点

- **谐波减速器（肩肘腕）：** 背隙 ≤20 角秒级、扭转刚度、传动误差、效率 69%–96%、疲劳寿命；**腿部冲击勿沿用上半身谐波**（寿命可降至数千小时级）。
- **腿部/直线：** 行星/摆线或 **行星滚柱丝杠**（线接触，寿命可达同规格滚珠丝杠 ~15×）。
- **轴承寿命：** \(L_{10} = (C/P)^\varepsilon\)（球 ε=3，滚子 ε=10/3）。
- **一体化关节：** 峰值/持续扭矩、峰值密度（文内头部 ~189 N·m/kg）、齿槽转矩 ≤5‰ 额定、定位/重复定位、扫频带宽；堵转温升 ΔT = T稳态 − T环境。
- **认证：** CR-3-05TS:2025 等把齿槽转矩、扭矩密度等八维纳入第三方考核。
- **灵巧手：** 指尖力、0.01 N 级力分辨率、1 kHz 采样；腱绳 vs 连杆耐久大纲分设。
- **电池：** 循环/倍率/低温/安全（GB 31241-2022、UN 38.3）；续航须定义行走/待机/作业占空比。

### L3–L4 子系统与整机

- **子系统：** 满负载总线同步抖动、上肢包络防干涉、髋膝与驱动舱热谱、IMU/力矩/相机/LiDAR 标定与时间同步；85/85 宜在子系统阶段介入。
- **整机动态：** 稳态行走、上下楼梯、越障、负载行走、抗推扰、急停；悬吊保护架 + 测步跑台；可叠 GB/T 12642-2013 再增双足项（天工 134 级台阶、亦庄半马 21 km 为公开极端工况参照）。
- **环境/可靠性：** IEC 60068-2、MIL-STD-810H；IP 实测；MTBF 与威布尔 \(R(t)=\exp[-(t/\eta)^\beta]\)；**稳态-only 大纲会高估寿命**（落地冲击 >> 稳态）。
- **电气/EMC/安全：** 绝缘/耐压/泄漏/接地（模组阶段初测、整机复核）；GB/T 17799.2、IEC 61000-6；对标 ISO 10218-1/-2:2025、ISO 13482:2014；ISO 18646、GB/T 38124 服务机器人性能。
- **智能/交互：** 定位、动态避障、任务成功率；sim2real 后 **按软件版本回归**；从「跑通」转向任务成功率 + 失效根因统计。

### 标准四层与基础设施

| 层级 | 代表 |
|------|------|
| 国际 | ISO 10218、ISO 13482、ISO 18646、IEC 60068-2、IEC 61000 |
| 国标 | GB 11291.1、GB/T 12642、GB/T 38124、GB 31241 |
| 团标/认证 | T/CEEIA 558—2021、T/CAMETA 001067—2025、CR-3-05TS:2025 |
| 顶层设计 | 《人形机器人与具身智能标准体系（2026版）》；2026 版产业标准体系建设指南（征求意见，目标 2028 ≥100 项关键标准）；五级安全分级；《人形机器人试验方法》国标编制中；北京全尺寸中试平台 ~9700 m² |

**务实策略：** 安全类对标强制/准强制；性能类先企业规范再随国标对齐。

### 工程细节（五条）

1. 台架工装刚度、温升环境/姿态须与实机一致，否则数据不可比。
2. 加速寿命按部件失效机理分别解读，留保守余量。
3. 动态冲击工况必须进大纲（谐波选型验证含冲击谱）。
4. 台架→整机统一数据留痕 + 失效模式库。
5. **研发测试**（可探索性破坏）与 **验收测试**（冻结版本/固定判据）分离。
