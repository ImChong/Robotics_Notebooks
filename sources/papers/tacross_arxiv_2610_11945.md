# TACROSS 论文来源归档

## 元数据

- **题目：** TACROSS: An Efficient and Low-Cost Scalable Human Touch System Across Heterogeneous Tactile Sensors for Dexterous Robot Learning
- **作者：** Bo Chen, Huanzhang Hu, Junyang Ma, Bo Yue, Fangdi Yu, Haijier Chen, Xianxin Lai, Shuyu Pan, Zhen Yang, Xiaoquan Sun, Wenze Cui, Zhongliang Jiang, Shaopeng Liu, Jiayu Chen（14 人）
- **单位：** 据项目页：香港大学、香港中文大学（深圳）、中国海洋大学、武汉大学、武汉纺织大学、INFIFORCE。
- **预印本：** https://arxiv.org/abs/2610.11945
- **HTML：** https://arxiv.org/html/2610.11945v1
- **版本：** v1，2026-10-08，cs.RO（交叉 cs.LG）
- **项目页：** https://tacross-touch-project.github.io/ （归档见 sources/sites/tacross-project.md）
- **代码与数据：** 项目页标注代码/硬件/数据“Planned release”，无仓库链接；截至 2026-10-12 未发布。

## 论文要解决的问题

机器人触觉数据昂贵且慢；用低成本人手触觉手套大规模采集是出路，但人手手套与机器人触觉传感器的传感原理、点位布局、分辨率和时间响应不同，原始信号无法直接对齐。TACROSS 在“接触事件”层面而非原始读数层面对齐两路信号。

## 方法与训练信息

1. **手套硬件：** 五层压阻式：两层图案化铜镍电极、压敏层、掌侧/背侧织物封装；285 个传感点（掌部 12x15=180 加五指各 3x7=105），覆盖约 200 cm2；矩阵复用 + 12-bit ADC + 腕部控制器，约 150 Hz 串口/BLE 输出每帧 256 值。BOM 成本 10.86 美元（控制器 6.58、材料 4.28）。量程 0-20 N，重复性 1.38% F.S.，非线性 8.26% F.S.，迟滞 11.65% F.S.；手套小于 50 g，系统小于 85 g。
2. **机器人：** Revo2 触觉灵巧手（电容式触觉，六个主动控制通道）+ 七关节机械臂（型号未指明），触觉采样 30 Hz，纯机器人采集系统约 12,000 美元。
3. **触觉对齐管线：** 规范化器（canonicalizer）把原始信号映射为按解剖区域的区域场（接触概率、相对强度、强度变化、持续时间、面积、压力中心、不稳定度代理、标定置信度，含有效性掩码；四档强度、六个因果相位）；人/机各一套浅层残差适配器产生区域 token（域标识只用于选适配器，不进入共享编码器）；共享编码器为因果时间 Transformer + 跨指 Transformer 各两层，窗口 16 帧 @15 Hz（16x5=80 token）；可学习手 token 输出 256 维、归一化的共享触觉潜表示。七项对齐损失权重 (1, 1, 0.5, 0.5, 1, 0.2, 0.1)：手潜表示对比、接触预测、相对强度回归、强度档位、相位分类、时间正则、域对抗。
4. **策略学习：** 机器人执行动作是唯一真值动作标签；人类数据一方面训练触觉表征，另一方面通过 HaMeR 估计 21 个 3D 手关键点，经标定几何重定向到 Revo2 目标，作为置信度加权、带有效性掩码的辅助伪标签（置信度公式原文未给）。策略为 ACT：三路 240x320 RGB + 本体感知 + 由 256 维投影到 512 维的触觉潜表示，预测 15 Hz 下 60 步动作块；触觉编码器先冻结 20,000 步再以较低学习率微调；部署时只用机器人观测。
5. **任务：** T1 定点点胶、T2 烧杯间液体转移、T3 精确移液、T4 连续水果取放。

## 论文报告的结果

- 采集效率：纯机器人约 40 条/小时；Ego-R（Rokoko 动捕）约 112 条/小时；Ego-V（视觉 IK）约 140 条/小时，140/40 = 3.5 倍；设备成本 520 美元对 12,000 美元，降低 95.7%（Ego-R 2,150 美元，降低 82.1%）。
- 匹配时间预算下四任务平均成功率：纯机器人 92.2%、Ego-R 93.5%、Ego-V 91.5%。
- 消融（四任务平均）：A 仅 30 条机器人示范 51.3%；B 人类数据无触觉（1:5）73.1%；C 无对齐 49.4%；完整（30 机器人 + 150 人类）91.9%；16 机器人 + 160 人类 88.1%（正文写 88.3%，与表内平均不符）。
- 人类数据规模：固定 15 条机器人回合，人类示范由 0 增至 90 条/任务，平均成功率 32.5% 升至 85.6%；纯机器人 105 条为 88.1%，成本 14.00 美元对 2.14 美元。T4 数据预算：92 条纯机器人 95.0%；50 机器人 + 50 Ego 92.5%；25 机器人 + 75% Ego 90.0%；10 机器人 + 90% Ego 85.0%；估计用时 158.8 分钟降至 110.3 分钟（-30.6%）。
- 数据集：共 183.95 小时（人类 159.09 h、机器人 24.86 h），24,913 条记录、22,486 条有效（摘要写“150 小时以上”；项目页写 21,412 条有效人类示范）。

## 复现与解释边界

- 迁移仍依赖机器人示范与针对具体本体的重定向和标定；评测只覆盖 Revo2 一种手、四个任务，作者计划扩展到其他手与跨本体共享潜表示。
- 手套迟滞与非线性不小；3.5 倍效率和 95.7% 成本是作者估算口径（采集吞吐与设备价），不含手套外的算力与标注。
- 开源均为将来时承诺，设计文件据称在项目页，但本次未见可下载仓库。
