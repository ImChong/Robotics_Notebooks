# VaM 论文来源归档

> 来源归档（ingest）

## 元数据

- **题目：** Value as Memory: Online Value-Guided Post-training for General Robot Policies
- **作者：** Wenye Yu、Yijin Chen、Kaiyi Xiong、Wenbo Han、Wendi Chen、Yang Jin、Han Xue、Jun Lv、Cewu Lu、Chuan Wen
- **机构：** 上海交通大学、上海创智学院、Noematrix
- **预印本：** <https://arxiv.org/abs/2610.22368>
- **项目页：** <https://virlus.github.io/vam/>
- **代码：** <https://github.com/Virlus/vam>
- **版本：** v1，2026-10-15
- **入库日期：** 2026-10-19
- **一句话说明：** 将近期价值预测作为策略的进度记忆，并用在线真实机器人强化学习持续吸收部署经验。

## 核心论文摘录

### 问题与方法

部分可观测下，单次图像难以判断长程任务进度；离线后训练又无法及时吸收部署中的新经验。VaM 将最近的 value 预测缓存为记忆，并将其提供给动作策略。训练从离线 RL 热启动，再组合离线示范、离策略人工干预与在线策略 rollout，进行稀疏奖励下的自主在线改进。

### 评测与结果

- 任务覆盖可变形物体和接触丰富操作的长时程场景。
- 论文摘要报告：加入 value caching 后平均成功率绝对提升 29.4 个百分点；在线自主学习相对匹配预算的离线训练提升 32.8 个百分点。
- 同梯度步预算下，在线调度完成 8 倍策略迭代；并行采集与训练使记录的每梯度步耗时降低超过 2 倍。
