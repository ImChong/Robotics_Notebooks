# DexPort 项目页

- **项目页：** <https://amberxie88.github.io/dexport/>
- **论文：** <https://arxiv.org/abs/2610.32969>
- **作者：** Amber Xie、Jiawei Fu、Xiaofeng Guo、Carmelo Sferrazza、Guanya Shi、Haozhi Qi
- **核查日期：** 2026-10-27
- **一句话说明：** 介绍可手持采集高自由度灵巧手示范的 DexPort 接口、真实任务视频与实验结果。
- **开放状态：** 页面公开方法与结果，未发现代码仓或可下载完整数据集入口。

页面说明同一 Wuji 20-DoF 手部模组在采集和机器人部署时复用；1,617 段实验室演示与 1,007 段野外演示合计 2,624 段。作者强调记录的关节指令与测量状态在接触时不同，并报告使用指令作动作标签时任务平均成功率 64%，状态作动作标签基线为 11%。
