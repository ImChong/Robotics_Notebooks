## 核心贡献（按原文）

1. **双轨分析：** Track A 是给定配置下的机器人任务执行、感知与纠错；Track B 将跨 episode 的经验用于能力候选更新与保留。一次任务内的临时状态 `z_t` 不能等同于跨任务学习。
2. **配置元组：** `C_k = (θ_k, H_k, M_k, S_k, T_k, E_k)`，分别表示神经参数、执行 harness、记忆知识、可调用技能程序、工具接口、实验资产；不同更新通过不同执行界面生效。
3. **五种执行接口：** 集成推理-动作、技能/策略调用、程序化编排、空间目标与约束、增量运动指令。
4. **经验到能力：** 交互轨迹 → 诊断 → 候选构造 → 验证晋级门 → 跨 episode 保留和部署；归因需追踪经验、修改对象、后续调用接口与物理结果。
5. **证据标准：** 不能把构造 artifact、持久化、后来使用、测得增益、独立重复获取混成同一概念；L5 还要求迁移、旧任务保持和明确人工/物理恢复成本。

## 量化核对（§6，表 4、6、7）

| 证据等级 | 文中最高证据端点 | 研究数 |
|---|---|---:|
| L1 | 只有 agent 操作执行证据 | 9 |
| L2 | 构造/适配能力 artifact，未同时证实保留与后用 | 18 |
| L3 | 跨 episode 保留并后续调用 | 70 |
| L4 | 对冻结比较基线测得操作收益，声明了获取与评测隔离 | 65 |
| L5 | 独立获取历史、受保护最终评测、迁移、旧任务保留、低人工依赖与完整成本核算同时成立 | 0 |

- 合计 **162** 项主要机器人操作研究，作者采用目的性选样，并非机器人领域所有研究的普查。
- **Conquer（仿真）：** 3 次独立、每次 14 任务的获取流程；最终成功率 95.6±0.6%，Scratch 对照 89.2±0.6%，文中前向迁移 11.3%、反向迁移近零；不因此自动满足物理硬件上的 L5。
- **RoboHarn-Evo：** 3 次仿真独立空知识库获取流程；另列的真机 41.7%→62.5% 不能视为已经做过 3 次独立真机获取实验。
- **RSI refrigerator-stocking：** 报告了可复用的局部操作技能，但整任务 rollout 成功率为 0%，说明局部通过不代表长程组合成功；报告涉及 113 次人工 harness 修复。
- **ENCORE：** plate 扰动条件下成功数从 50/50 降至 0/50（K0→K3）；是特定测试条件的严重退化，不能扩充成所有环境的总体退化率。

## 实验边界与工程启示

- **归因：** 固定 actor、工具、重试预算、评测分割等基线条件；只看 end-to-end 分数不能归因到某个更新部件。
- **保留：** 构建成功的技能必须验证前置条件、后续技能可接续的终态、旧任务回测和变化后的现场物理状态。
- **重复性：** 多次执行同一冻结 artifact 不是多次独立重新获取能力。
- **成本：** 人工总耗时需包括示教、准备、工程、标注、reset、rescue 和评测，另计硬件、时间与算力；软件 rollback 不等于实体环境 reset。
- **分级限制：** 本文 L1–L5 是证据审计等级，并非通用自治等级；与本仓库现有「能力增量 L1–L4」口径不同，不得直接对应。
- **综述限制：** 来源报告不完整标为未决证据，不得由未报告直接推断不存在；L5=0 只是本综述的联合准则下未发现满足全部要求的链条。
