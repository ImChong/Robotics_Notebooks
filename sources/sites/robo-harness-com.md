## 一句话摘要

华为诺亚等团队的 **RoboHarness** 官方站点：主张具身智能从「追逐万能模型」转向 **异构策略编排**——按动态能力边界分解任务、路由子任务，并用 Memory Bridge 稳定策略交接。

## 公开信息要点（截至入库日 2026-08-03）

- **核心叙事：** There is no universally best model — only the policy best suited to the situation；VLA / RL / TAMP / WAM / MPC 各有边界，系统增益来自能力感知分解与交接。
- **结果卡片（与论文一致口径）：** LIBERO Original **98.7%**；LIBERO-Plus 平均 **93.2%**；LIBERO-LoHo 进度 **97.5%** / 成功 **95.2%**；真机演示含缺块拼桥等。
- **资源链接：** Paper → arXiv；Code → `markli1hoshipu/RoboHarness`；站内含框架图、Memory Bridge 图、扰动路由图、消融与真机结果图 / 视频。
- **机构署名：** Huawei Noah’s Ark Lab / UBC / University of Toronto / McGill / 2012 Labs。
