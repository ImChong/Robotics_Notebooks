## 摘录 1：问题与主张（§I）

- **痛点（capture–consumption support gap）：** Real-to-Sim 场景常由标定多视角 + 神经/高斯表示重建；**稠密采集**损害「每环境真实图像采集效率」，而 **稀疏人类便捷采集** 与 **行为范围内机器人相机** 在位姿、可见面、遮挡上不一致，导致行为相关 ego 视角视觉/结构支持不足。
- **生成可用性的双重要求：**（1）查询侧——相机序列须在声明的行为范围内由具身机器人可执行；（2）证据侧——生成须以捕获锚定结构为条件（仅相机控制不足以决定稀疏未见区域的布局/可见性/遮挡）。
- **主张：** **R2S-EGO** 耦合 **仿真导出的 robot proxy**（行为范围可执行查询域 + 当前资产赤字定位）与 **捕获锚定 geometry proxy**（结构条件 + 轮间刷新的碰撞面）；固定预算选择「赤字高且几何可用」的候选；生成帧作低权重伪观测同化进视觉资产，真实捕获保持锚点；机器人动力学与控制栈固定。
- **贡献三点：** 问题表述（针对行为范围可执行视角而非全局补全）；双代理方法；冻结机器人视角外观 + 受控真机 G1 下游策略验证。

## 摘录 2：双代理机制（§III）

- **几何代理：** 三角化碎片 \(\mathcal{M}_{\mathrm{obs}}\) + SAM 3→SAM 3D 物体先验对齐（相似变换固定跨轮）+ 非先验区 NKSR；渲染路径提供布局/可见性/遮挡条件；融合几何兼作场景碰撞面并每轮刷新。
- **机器人代理：** 每轮用固定行为控制器 \(\mu_{\mathcal{B}}\) 重跑（重采样初始/参考，丢弃失败）至 12 次成功 rollout；FK + 相机挂载得候选 ego 位姿流；得分 \(s_l(t)=u_l(t)\,g_l(t)\)（资产不可渲染比例 × 几何可渲染比例），时间 NMS + TopK 得预算 \(K\) 关键帧。
- **联合生成与同化：** ViewCrafter 接收真实参考、相对相机运动与几何条件序列（\(N_f=25\)，仅保留终点帧）；VGGT 相对真实参考估计生成帧位姿；\(w_{\mathrm{syn}}=0.5\)、\(w_{\mathrm{real}}=1\) 联合优化 3DGS；\(L=3\) 轮、每轮 \(K=12\)、3DGS 5k/轮共 15k steps。
- **边界：** 不引入新仿真器或策略学习器；离线资产构建，非实时。

## 摘录 3：评测（§IV / Table II–IV）

| 设定 | 要点 |
|------|------|
| 外观（48 冻结 G1 视角 × 3 Replica） | 六视角 R2S-EGO：**19.062** dB PSNR / 0.757 SSIM / 0.273 LPIPS；最强报告 R2S 基线 GaussGym：**14.226** dB |
| 采集效率（office_2） | R2S-EGO@6：**19.674** dB；基线至 **45** 真实视角仍未追上（GaussGym@45≈13.458） |
| 消融（Table III） | 去 ego 视频 → 13.417；去 robot-proxy 分配 → 16.182；去 SAM 3D → 16.384；去迭代 → 17.508 |
| 真机坐姿（5 配对策略种子） | 同 SONIC/WBC + 同碰撞网格；仅换训练视觉资产。Sim：GaussGym 87.2% vs R2S-EGO 97.6%；**Real-G1：10.0%±10.5% vs 82.5%±6.8%**（4/40 vs 33/40） |
| 局限（§V） | 先验补全几何为结构假说、未独立评 metric/碰撞精度；robot proxy 覆盖声明行为而非学得策略占据；伪观测可能传播生成误差；硬件仅为坐姿 PoC |

**对 wiki 的映射：** 结论节突出「稀疏六视角 + 行为范围支持」相对「堆真实视角 / 通用生成–重建反馈」的读法；注明未开源。
