# ECoT（具身思维链推理）

> 来源归档（ingest）

- **标题：** Robotic Control via Embodied Chain-of-Thought Reasoning
- **类型：** paper
- **venue：** CoRL 2024
- **原始链接：** <https://arxiv.org/abs/2407.08693>
- **项目页：** <https://embodied-cot.github.io/>
- **机构：** 加州大学伯克利分校（UC Berkeley）；斯坦福大学（Stanford）；华沙大学（University of Warsaw）
- **作者：** Michał Zawalski、William Chen、Karl Pertsch、Oier Mees、Chelsea Finn、Sergey Levine
- **代码：** <https://github.com/MichalZawalski/embodied-CoT>
- **权重 / 数据：** <https://huggingface.co/Embodied-CoT>
- **入库日期：** 2026-09-09
- **一句话说明：** 正式提出 Embodied Chain-of-Thought（ECoT）：VLA 在输出动作前自回归生成计划 / 子任务 / 运动与视觉接地特征（bbox、夹爪位姿等）的多步推理链；合成数据管线 + OpenVLA 骨干。

## 核心摘录（MVP）

### 1) 问题：朴素 CoT 不足以驱动机器人策略

- **摘录要点：** 标准 VLA 训练样本过于简单，纯语义子任务 CoT 无法把推理接地到观测与机器人状态。ECoT 要求 VLA **先** 生成多层次文本推理（高层 plan/subtask + 低层 move/gripper/bbox），**再** 预测动作。
- **对 wiki 的映射：**
  - [ECoT](../../wiki/entities/paper-ecot.md) — 奠基框架。
  - [VLA](../../wiki/methods/vla.md) — CoT 增强的 VLA 范式。

### 2) 合成 ECoT 数据管线

- **摘录要点：** 用多个基础模型从机器人演示中提取特征，组装为结构化推理链；在 **Bridge V2** 上生成训练标注。推理标签含 TASK / PLAN / SUBTASK / MOVE / VISIBLE OBJECTS / GRIPPER POSITION 等模块。
- **对 wiki 的映射：**
  - [ECoT](../../wiki/entities/paper-ecot.md) — 数据生成。
  - [OpenVLA](../../wiki/entities/paper-openvla.md) — 骨干与对照基线。

### 3) 评测与增益

- **摘录要点：** 14 项真机泛化任务（新物体 / 新指令 / 空间关系）；300+ trials/策略。ECoT 相对 **OpenVLA、Octo、RT-2-X** 最佳；使 OpenVLA **绝对成功率 +28%**（无额外机器人训练数据）。支持自然语言纠错式 human-in-the-loop；可迁移到未见本体（未见推理标注的 embodiment 上仍能生成依赖本体的特征）。
- **对 wiki 的映射：**
  - [ECoT](../../wiki/entities/paper-ecot.md) — 结论读法。
