## 核心摘录（arXiv:2603.29844v2）

1. **核心问题（§1）：** 现有端到端 VLA 多把预训练 VLM 当多模态编码器直接映射到低层动作，造成高层推理能力闲置、训练不稳定与语义退化；即便加入辅助世界模型损失（如 FLARE/SEER），若缺乏硬结构瓶颈，策略仍可通过捷径绕过 VLM 意图。
2. **双系统潜在意图瓶颈（§3.1–3.3）：**
   - **System-2（Brain）：** 骨干为 `Qwen2.5-VL-3B`，在图像块与语言指令 `l_t` 后追加 `N=64` 个可学习 query token，经 LLM 与 MLP 投影头预测未来 `H` 步的潜在意图 `x_t`，用冻结 VLM 原生 ViT 提取的未来特征 `Enc_ViT(o_{t+H})` 做 MSE 监督（`L_world`）。
   - **System-1（Cerebellum）：** 共享同一冻结 ViT 提取当前帧 `Enc_ViT(o_t)`，经 4 层 self-attention 融合当前特征与 `x_t`（对齐同一隐空间流形），通过 cross-attention 条件化 16 层 DiT 动作解码器（输入本体状态 `q_t` 投影 token 与噪声动作块），用 flow-matching 损失 `L_fm` 生成 `H=16`（或真机多阶段 `H=50`）动作块。
3. **两阶段训练（§3.4）：** Stage 1 解耦热身（System-2 单独优化 `L_world`，System-1 以真值 `Enc_ViT(o_{t+H})` 替代 `x_t` 做 golden bridge 训练，防止后验坍缩）；Stage 2 端到端联合优化（`L_total = L_world + L_fm`，动作梯度经 `x_t` 回传细化 VLM 骨干与可学习 query，ViT 与文本嵌入层全程冻结）。
4. **仿真与消融结果（§5.1–5.3）：**
   - **RoboCasa GR1 Tabletop（24 任务 × 50 ep，47 维状态/动作）：** 全量数据（24,000 轨）DIAL 平均成功率 **70.2%**（Pick & Place 68.9%，Articulated 74.3%），高于 FLARE（55.0%）与 GR00T-N1.6（47.6%）。
   - **Few-shot（10% 数据，2,400 轨）：** DIAL 达 **58.3%**，已超过全量训练的 FLARE（55.0%）；同设置下 GR00T-Qwen2.5 冻结为 21.8%、LLM 微调（-FT）30.6%、+SEER 49.6%、+SEER-EV 47.2%、+FLARE 51.9%、DIAL-DINO 47.2%（证明共享 VLM 原生 ViT 隐空间的关键性）。
   - **人类数据协同（EgoDex `basic_pick_place` 27,419 轨）：** Few-shot Pick & Place 56.0%→60.8%，三大 OOD 平均 **46.2%→51.2%**（Unseen Object Types 34.8→41.1%，Combinations 53.0→58.7%，Appearances 50.7→53.8%）；Articulated 任务因 EgoDex 缺铰接交互无提升（65.3% vs 62.0%）。
5. **真机与局限（§5.4–6）：**
   - **IRON-R01-1.11 真机（50 维状态/动作，含 3-DoF 头部）：** 去掉解耦热身使 ID 平均成功率从 **77.5%→57.5%**、OOD 从 **58.3%→30.0%**；去掉人类数据使 OOD 降至 **26.7%**。多阶段协作（Handover & Shelving、Trash Collection & Emptying，H=50）显著减少子阶段循环卡死。
   - **局限与未来方向（§6）：** System-1 DiT 骨干规模仍较小；当前冻结 VLM ViT 以保持特征空间稳定（未来拟探索 EMA 编码 + 潜在 token 压缩微调）；需进一步扩展到大规模无动作人类视频预训练。
