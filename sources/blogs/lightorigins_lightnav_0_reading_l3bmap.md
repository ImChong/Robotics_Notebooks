## 核心摘录（均出自原文）

- **数据引擎：** 2,000+ 互联网真实场景 → 统一仿真接口 → 4,000+ 小时 VLA 经验；相机视场角 90–130°、高度 0.5–1.5 m、俯仰 ±15° 以覆盖不同本体。
- **三阶段：** ER 中期训练（36 个数据源，点定位占 35.14%；LightNav-ER 八项具身推理基准均分 67.4，四项第一、四项第二）→ 具身 SFT（77.6% 导航/动作 + 22.4% VQA；16 个导航源 + 33 个推理源）→ 在线 RL（GRPO，沿用 RVQ 动作 token）。
- **标注管线：** Molmo2 开放集点定位 → 深度反投影 → 多视角三维合并（>=2 视角、离散度 < 0.6 m）；模板或 Seed2.0 视频 VLM 生成指令，再做语义与终点画面验证。路线先于指令生成。
- **ER 初始化消融：** 八项评测全部提升，平均 SR 60.8 → 63.1，SPL 39.0 → 40.0。
- **Point CoT：** 每次决策只增两个图像点 token（目标点 + 可通行点）；消融八项全升，平均 SR +8.4、SPL +5.7。部署时只需 RGB + 语言，无需深度/定位/地图。
- **RVQ 动作 token：** 十个 SE(2) 路径点 → 3 个 token，三级码本各 256 项，平均位移误差 0.72 cm；三级为精度所需最小配置。
- **规模化：** 在测试范围内增加训练环境最稳定提升；加数据收益递减；模型超过 4B 后有升有降（2B/4B/8B）。
- **在线 RL：** EVT-Bench 干扰跟踪 SR 由 SFT 的 74.4 升至第 120 步的 82.6 后趋稳。
- **评测：** 十项单目评测均第一；纳入全景/多相机后仍有四项第一。INSIGHT-Bench：1,683 训练场景 / 53,090 片段，评测 210 场景 / 1,097 片段，五类指代 x 五类场景。
- **零样本：** 四种真机本体（含 Lightbot 0、Unitree Go2、LimX TRON 1），体素/驾驶/第一人称虚拟世界闭环，运动视频开环预测。
- **发布：** 模型、代码、技术报告、INSIGHT-Bench 评测工具。
