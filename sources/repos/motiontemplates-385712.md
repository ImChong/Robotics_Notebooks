## README 与模板指南摘要

- 仓库提供 Kinetic Tech 风格（银色金属字、琥珀色灯光、机械动效）及中英文模板下载入口、可编辑源文件、预览与示例。
- .motion 被格式规范定义为 ZIP 封装，组合动画工程源文件、可替换参数、素材说明、依赖、预设和许可证；规范目前标注为候选 / draft。在线生成服务属于可选集成，格式本身面向本地检查、适配与渲染。
- 包内 00-START-HERE.md 和 CREATION.md 规定从用户主题/文案生成内容参数，先生成计划与预览，再渲染并检查输出；无额外音频要求时使用模板自身的动作音效。
- 示例模板按内容意图组织文本场景（解释关键词、列点、比较观点、总结行动）。具体可用场景和约束应以模板包内 schema 与 catalog 为准。
