- **通读：** 已完成

## 主要内容与限制

- **主工作流：** 用户描述页面 → 选择设计系统 → 使用本地 coding agent 或云模型生成原型 → 预览、人工反馈和迭代 → 导出或交接工程。
- **工作产物：** 产品页面、App UI、仪表盘、演示文稿及媒体内容；官网将团队分享与评论列为协作场景。
- **模型接入：** Local CLI 使用本机已配置的 agent；BYOK 使用自备模型密钥并由相应提供商计费；Hosted 依 OpenDesign 账户及方案提供额度。
- **限制：** 官网 FAQ 提醒原型转为生产应用仍需要工程工作；BYOK 与本地文件编辑能力不同。平台支持及价格可能变化，均以官网当前公告为准。
