- **一句话说明：** 从 **单条** 重定向物体搬运参考出发，用 **DCRR** 把源 clip 的 **终止段** 拼接到中间搬运状态，经 **冻结 tracking teacher** 闭环回放与 **achieved-goal relabeling** 构造距离条件监督，再 **BC 蒸馏 + PPO RLFT** 得到无参考策略；**Unitree G1**、**Isaac Sim** 训练，四模式真机可调运输距离。

## 摘要要点

- **问题：** 固定参考 motion tracking 只能复现源 clip 终点；中间位移是 **passage** 而非 **termination-complete** 结局 → **termination-versus-passage gap**。
- **方法：** Distance-Conditioned Reference Recomposition（DCRR）：截断主动搬运、重定位 demonstrated termination segment；frozen teacher 闭环 replay；按 achieved object placement relabel；DCRR-BC + RL fine-tuning（frozen-BC anchor + DAPG-style demo loss）。
- **任务：** Carry、Kick-Push、Crouch-Push、Drag（各 **1** 条 OmniRetarget 式源 motion；源运输距离约 1.44 / 1.30 / 0.80 / 1.10 m）。
- **结果：** DCRR-BC 四模式 macro-average 归一化距离 MAE **0.15** vs Src-BC **0.28**；RLFT 改善命令响应与 fall rate；硬件 1 kg 物体、第三人称 marker + 自相机对齐方向。

## 方法要点

- **命令：** 归一化 $d=D/D_{\max}$；策略观测含 **object-to-goal** 相对向量，**不**单独输入标量 $d$。
- **Teacher：** PPO；OmniRetarget 式 robot/object tracking + goal-reaching term；训练时对终点沿运输方向 ±30% 及正交方向扰动（Parallel+Orthogonal 提升短距 replay 有效率 75.7%→95.4%）。
- **Recomposition：** 在 detected transport support 上枚举 splice；选 residual transport 近最小的 termination tail；平面旋转/平移对齐后拼接；$\delta=0.02$、$\lambda_s=0.05$。
- **Student：** 512–256–128 ELU MLP，29 DoF 关节目标；1 帧 joint history；BC 后 PPO，$\lambda_{\mathrm{anc}}=10$，$w_k=\max_t |A^{\mathrm{raw}}_{k,t}|$；奖励无 reference tracking。
- **域随机：** 物体质量 [0.1, 2.0] kg，摩擦 [0.1, 1.0]；RLFT 命令 $d\in[0.1,1.2]$。

## 实验与数字

- **对比（Table II 总体 MAE / Fall%）：** DCRR-BC **0.15 / 9.07**；Src-BC 0.28 / 14.34；HS-BC 0.44 / 15.17；AMP-Body+Object 0.21 / 0.08（Drag MAE 0.53）；DCRR Teacher 0.10 / 0.01。
- **Achieved vs nominal label（Table III）：** overall MAE 0.17→**0.16**（同轨迹，仅改 goal label）。
- **RLFT（Table IV 训练仿真）：** fall 8.83%→**2.22%**；sim2sim MuJoCo 1 kg：fall 17.78%→**8.50%**。
- **硬件（Table V）：** 四命令 $d\in\{0.4,0.7,1.0,1.2\}$，每命令 5 trial；macro mean $\hat d$ 约 0.30 / 0.60 / 0.90 / 1.04。
