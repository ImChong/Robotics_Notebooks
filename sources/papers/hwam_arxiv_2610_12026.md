## 论文要解决的问题

层级人形系统里，高层策略输出的是参考动作，低层全身控制器要经过平衡、动力学和接触才执行，实际身体响应与参考动作存在“动作–执行差距”。普通世界动作模型（WAM）只生成动作与未来视觉，不显式建模执行后的本体状态。HWAM 把“执行后本体状态”作为显式预测目标，与参考动作联合生成。

## 方法与训练信息

1. **骨干：** 冻结的因果 Wan VAE 产生当前/未来视觉 latent（§4.2 为 Wan2.2）；WanVideoDiT 作视频专家；ActionDiT 作状态–动作专家，每个时间 token 把执行后状态与动作在特征维拼接后投影；语言用 UMT5-XXL；两专家参数独立，用依赖路径的掩码交叉注意力交互。
2. **三条训练路径（均匀采样，权重 λ = 1）：** FDM（正向动力学：由动作与执行后状态预测未来视频，只加噪并监督未来视频 token）；IDM（逆向动力学：由视觉转移重构联合状态–动作轨迹）；Policy（仅条件于当前观测、语言与本体感知，隐藏未来视频 token，只对状态–动作 token 去噪）。损失 L = ⅓(L_F + L_I + L_P)，flow-matching MSE，无额外加权。
3. **推理：** 预测状态参与联合去噪，但只有动作发送给低层控制器；OLI 诊断用 4 步去噪。
4. **平台：** LimX OLI 全尺寸人形，全身 31 维动作空间，双 7-DoF 臂 + BrainCo 灵巧手，头部与腕部 RGB 相机；低层为全身跟踪控制器（细节未给）。
5. **数据：** Candy Picking 1,783 条（另 422 条留出验证）、Object Collection 4,220 条、Plush-Toy Picking 404 条；不使用额外机器人数据预训练。
6. **训练：** 6 epoch，AdamW lr 1e-4，全局 batch 128，16 张 A800。
7. 未给出：时域长度 H、状态/动作维度 d_s、d_a、token 数、噪声调度（仅 τ ∈ [0,1]）。

## 论文报告的结果

- **OLI 真机成功率（%）：** HWAM 70.6 / 46.7 / 73.3（Candy / Object Collection / Plush-Toy）；π0.5 62.5 / 45.0 / 60.7；GR00T N1.5 40.5 / 42.5 / 60.0；Fast-WAM 43.3 / 0.0 / 60.0；DiT4DiT 52.5 / 15.0 / —；Cosmos3-Edge 15.8 / 0.0 / 56.7。π0.5、GR00T N1.5、Cosmos3-Edge 带机器人预训练，Fast-WAM、DiT4DiT、HWAM 不带。
- **Candy Picking 试验数（95% Wilson 区间）：** HWAM 84/119 [61.9, 78.0]；π0.5 75/120 [53.6, 70.6]；Fast-WAM 52/120；GR00T N1.5 49/121。区间假定试验独立、不含种子方差。其余两任务的试验数原文未报告。
- **Candy Picking 分方向：** CH 82.8、CV 63.3、X-P 76.7、X-S 60.0；**分工作区：** L1 83.3、L2 95.8、C 66.7、B2 65.2、B3 41.7。
- **Plush-Toy 消融：** 目标 Action + VGM/Policy 60.0；联合状态–动作 + VGM/Policy 45.5；Action + FDM/IDM/Policy 55.0；联合状态–动作 + FDM/IDM/Policy（HWAM）73.3。即联合目标在不含 FDM/IDM 时反而降低，需配合三路径训练。
- **开环诊断（Candy Picking 留出集）：** 32 步 chunk、31 关节动作 MAE：HWAM 3.816°，仅动作 FDM/IDM/Policy 4.024°。未来视频 PSNR 在预测条件下无优势（HWAM 20.501，范围 20.345–20.844），真值条件下 23.336 vs 20.559。
- **动作–执行差距（MAE，度）：** OLI 直接 4.420、稳态 2.885；ALOHA 直接 0.648、稳态 0.402。
- **ALOHA 叠衣：** HWAM 86.00，GR00T N1.5 78.75，π0.5 77.00，Fast-WAM 66.25，π0 65.00，GR00T N1.7 58.75，SmolVLA 51.25（640 条示范，任务专用训练）。

## 复现与解释边界

- 未显式建模低层动力学，预测的状态不回传控制器；消融不区分各路径或架构选择各自的贡献。
- 成功率来自实物试验，置信区间不含种子方差；论文自称结果为“observed”。
- 无公开代码、数据、视频；对比基线的预训练条件不同，不能把差距全归因于方法。
