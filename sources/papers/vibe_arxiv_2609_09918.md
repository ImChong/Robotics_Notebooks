# ViBe: Visual Behavior Adaptation for Perceptive Humanoid Whole-Body Control（arXiv:2609.09918）

- **arXiv：** <https://arxiv.org/abs/2609.09918>
- **项目页：** <https://lok-i.github.io/vibe-control>
- **机构：** 南加州大学（USC）
- **开源状态：** 未开源（截至 2026-09-11 项目页无 GitHub / 权重链接）
- **入库日期：** 2026-09-11
