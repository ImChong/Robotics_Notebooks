# MS-Human-700 官方项目页

- **类型：** 官方项目页
- **标题：** Self Model for Embodied Intelligence: Modeling Full-Body Human Musculoskeletal System and Locomotion Control with Hierarchical Low-Dimensional Representation
- **链接：** <https://lnsgroup.cc/research/MS-Human-700>
- **论文：** [arXiv:2312.05473](../papers/ms_human_700_arxiv_2312_05473.md)
- **模型仓库：** <https://github.com/LNSGroup/MS-Human-700>
- **训练环境：** <https://github.com/LNSGroup/msgym>
- **机构：** 清华大学 LNS Group
- **核查日期：** 2026-10-27
- **一句话说明：** 全身人体肌骨模型及高维肌肉运动控制研究，项目页概述模型规模与 ICRA 2024 论文。

## 项目页摘录

- 模型包含 90 个身体节段、206 个关节和 700 条肌腱单元。
- 工作使用分层低维表示与深度强化学习控制肌骨系统，并以真实人体运动数据在仿真中验证。
- 项目页的模型入口仍显示 “coming soon”；模型文件和资产目前可从 LNSGroup 官方 GitHub 仓库获取。

## 开源状态

- **已开源：** LNSGroup 模型仓库公开 MuJoCo XML、资产与 Apache-2.0 许可证；关联 msgym 仓库提供 Gymnasium 环境和 DynSyn-SAC 训练代码。
- **注意：** 原始论文、模型仓库和后续训练环境是有关联的不同材料；复现实验时需按目标任务区分具体模型和配置。
