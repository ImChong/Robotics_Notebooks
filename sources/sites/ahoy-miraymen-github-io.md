## 一句话摘要

从重度遮挡的单目 YouTube 视频重建完整可动画 3D Gaussian 数字人：用身份微调视频扩散 + RF-Inversion 为未见身体区域生成幻觉监督，再学 pose-dependent Gaussian maps。
