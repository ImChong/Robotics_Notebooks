# ACE Teleop（项目页）

> 来源归档（ingest）

- **标题：** ACE: A Cross-Platform Visual-Exoskeletons System for Low-Cost Dexterous Teleoperation
- **类型：** site / project-page
- **官方入口：** <https://ace-teleop.github.io/>
- **论文：** <https://arxiv.org/abs/2408.11805>
- **代码：** <https://github.com/ACETeleop/ACETeleop>
- **硬件：** <https://github.com/ACETeleop/ACE_hardware>
- **入库日期：** 2026-07-28
- **一句话说明：** UC San Diego 的低成本视觉—外骨骼遥操作系统，以手前相机捕获手指、编码器与 FK 捕获腕部，并通过 IK/重定向适配不同机器人。
- **开源状态（2026-07-28 核查）：** **源码与硬件文件已公开**；软件包含 server/controller/simulation 入口，硬件仓库含 STL 与装配说明，但软件仓库未声明标准 SPDX 许可证，复用前需核对授权。
