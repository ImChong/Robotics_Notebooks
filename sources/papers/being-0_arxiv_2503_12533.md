## 摘要与核心贡献

1. **三层分层人形具身智能体**：面向全尺寸人形机器人（Unitree H1-2，共 41 DoF，配双侧 Inspire 灵巧手与 2-DoF 主动云台颈部 + ZED-mini 双目相机，机载 Jetson AGX Orin 运行除云端 GPT-4o 之外全部模块），将任务划分为：
   - **Foundation Model（FM，云端 GPT-4o / Cradle 范式）**：高层常识推理、工具/技能调度与长程记忆规划；
   - **Embodied Connector（机载 ~1s 延迟）**：基于 VideoLLaMA2 + SigLIP 微调（300K grounding 数据 + 3,177 第一视角图像 / 38,380 VLU 问答 + 771 AP 样本），承担第一视角视觉-语言理解（VLU）、导航/操作目标检测定位与可中断闭环行动规划（AP）；
   - **Modular Skill Library**：50 Hz 鲁棒 RL 躯干-下肢行走策略（支持速度指令与主动转头目标跟踪）+ 10 Hz ACT 灵巧操作策略（每技能 50–200 条人类遥操作演示）。
2. **真机实测结果**：
   - 五项长程复合任务成功率：Fetch-bottle `0.90`、Deliver-basket `0.80`、Prepare-coffee `0.75`、Make-coffee `0.90`、Deliver-coffee `0.87`（对比无 Connector 基线分别仅 `0 / 0 / 0 / 0.90 / 0.33`）；
   - Embodied Connector 将平均导航推进速度提升 **4.2×**（`9.6 cm/s` vs `2.3 cm/s`），避免每步调用云端 VLM 的高延迟瓶颈。
3. **显式局限**：不包含深蹲/坐姿/跳跃等下肢高动态技能；仍依赖云端大模型推理。
