# mwondering/echo-bfm：ECHO 项目展示网站源码

- **类型：** repo（论文项目展示站；不是算法仓库）
- **地址：** https://github.com/mwondering/echo-bfm
- **项目页：** https://mwondering.github.io/echo-bfm/
- **论文：** https://arxiv.org/abs/2611.25778
- **核查日期：** 2026-11-23

## 已公开内容

- README 指明这是 ECHO website source，`index.html`、`templates/`、`scripts/build.py` 用于生成站点；目录还包含 `site.json`、`.github/`。
- 展示站的图片/视频引用上游网站媒体资源，仓库主要用途为构建和发布 GitHub Pages。
- **没有从仓库 README 或目录发现 ECHO-PRE、CRA 的训练、策略推理、G1 部署入口或 checkpoint**；不能将网站 build 命令写成模型运行命令。
