## 核心摘录

### 1) 问题与贡献
- **Vidu S2** 包含 **Vidu S2-Avatar**（实时交互数字角色）与 **Vidu S2-Editing**（实时视频编辑）。
- 探索 **Vidu S2-Avatar / S2-Editing** 上 **实时 spatial video generation** 的可行性。
- 相对 **Vidu S1**：Avatar 侧 **540p→720p**、**动态参考图**（流中可更新）、更强 **指令跟随**（如跳舞）；Editing 侧支持对 **视频流** 连续编辑。

### 2) Vidu S2-Avatar
- **在线 Avatar**：实时语音对话、可打断、双向感知；语音指令驱动复杂动作（如跳舞）。
- **参考图交互**：物体 / 服装 / 背景三类参考图 + 指令 → 拿取展示、换装、换背景。
- **离线 Avatar**：单图 + 音频/文本异步生成口型对齐 talking video。
- **输出**：720p+ 数字人视频。

### 3) Vidu S2-Editing
- 持续接收 **视频流**（摄像头 / 视频 / 图像输入），实时输出编辑结果；中途可切换参考图不中断流。
- 能力：**风格渲染**、**人物替换**、**背景替换**、**虚拟试衣**（服装参考图）。

### 4) 实验（摘要）
- 论文称 **Vidu S2 优于全部 baselines**（细节见 PDF）；提供 **可玩在线 Demo**。

### 5) 开源核查（步骤 2.5，2026-09-20）
- **项目页（vidu.com/vidu-stream）：** 交互 Demo、FAQ、Popular Cases；**无 GitHub / 权重下载** 链接。
- **API 平台：** `platform.vidu.com/vidu-stream/doc`（S2-Avatar / S2-Editing quick-start）— **商业 API 集成**，非开源训练栈。
- **结论：** **未开源**（截至入库日无可运行官方代码仓）；产品侧 **Demo + API** 可用。
