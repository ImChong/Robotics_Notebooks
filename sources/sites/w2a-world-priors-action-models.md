# W2A 项目页

> 来源归档（site）

- **标题：** W2A: Distilling World Priors into Action Models for Real-Time Robotic Control
- **类型：** site
- **链接：** https://misaka0502.github.io/W2A
- **arXiv：** <https://arxiv.org/abs/2611.02600>
- **入库日期：** 2026-11-04；代码开放状态复查：2026-11-16
- **一句话说明：** 训练时压缩视频扩散中间表征，部署时移除视频模型，降低世界动作模型推理负担；兼顾仿真和真机，速度比较仍需对齐骨干、硬件与推理配置。
