## 原文核对摘录

### 1. 基线与非对称视图（§3.1–3.2，Tables 1–2）
- 将 Sonata 的 PTv3 改为 Volt：ScanNet200 冻结编码器线性探测 **28.3→29.6 mIoU**。
- 教师取未施加强几何破坏的干净全局视图；学生取强扰动局部视图，单项消融 **28.9→31.3**。
- 教师目标头与学生预测头解耦，教师原型用跨全局视图对应关系和 Sinkhorn–Knopp 平衡分配训练；继续提高至 **32.8**。
- **对 wiki 的映射：** [VINO 实体](../../wiki/entities/paper-vino.md) — 局部预测、目标头机制。

### 2. 掩码预测与几何捷径（§3.3，Tables 3、11–12）
- 稀疏 3D 的 mask voxel 即便被替换为 mask token，只要保留空间占据位置，就泄漏被遮挡区域几何。
- 在学生编码器前**删除** masked tokens；只用 visible tokens 编码上下文；masked queries 通过 **cross-attention-only** 从上下文预测对应教师原型，无查询间 self-attention。
- ScanNet200：局部预测 **32.8**，加掩码目标 **35.6**，处理特征伪影后 **35.9**。掩码块 **80 cm**、mask ratio **55%**；含查询间 attention 降至 **34.2**。
- **对 wiki 的映射：** [VINO 实体](../../wiki/entities/paper-vino.md) — 流程图与掩码预测直觉。

### 3. 第二阶段 2D→3D 蒸馏（§3.4、Appendix A.2）
- 先以纯 3D 自监督目标预训练，再保留 SSL 目标并加入冻结 DINOv2 的 2D 教师监督。
- 相机位姿与深度确定跨视角同一表面对应；在 2D 特征空间学习视角一致的原型 soft assignment，避免直接回归视角依赖的 DINOv2 特征。
- ScanNet200：从一开始对齐 **37.2**；直接回归 embedding **38.6**；两阶段、视角一致原型 **40.4 mIoU**。
- **对 wiki 的映射：** [VINO 实体](../../wiki/entities/paper-vino.md) — 2D 教师的使用边界。

### 4. 实验与外推（§4、Appendix A.3–A.7）
- **3D-only 冻结线性探测**：ScanNet200/ScanNet/ScanNet++/nuScenes/SemanticKITTI/Waymo = **35.9/76.9/42.4/76.7/70.7/68.6 mIoU**；优于文内 3D-only 比较基线。
- **增加 2D 监督后**：同一六基准 = **40.4/77.9/48.2/80.6/71.1/70.6 mIoU**；不得把此行称为“纯 3D 无辅助教师”。
- **全模型微调**：同序列 = **42.7/81.8/52.6/83.2/75.2/72.9 mIoU**，与 frozen linear probe 属不同设置。
- 附录 Table 13：换 SPFormer 实例分割头，ScanNet200 mAP50 从 supervised 初始化 **48.4** 提升到 VINO **55.7**，不是线性探测指标。
- **对 wiki 的映射：** [VINO 实体](../../wiki/entities/paper-vino.md) — 区分评测协议与解读。
