## 页面结构（维护索引）

| 区块 | 内容要点 |
|------|----------|
| 价值主张 | Graphs that teach > graphs that impress；AI 辅助人而非替代 |
| 对比叙事 | 典型 code graph（节点/边无释义）vs 业务域视图（Auth / User Lifecycle / Data Layer） |
