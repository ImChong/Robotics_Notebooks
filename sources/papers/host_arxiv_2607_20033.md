## 核心摘录（面向 wiki 编译）

### 摘录 1：推理时习得，而不是再训一遍

- 现有 IL / VLA 新技能仍走「采集遥操作 → 离线微调」；慢、贵，且覆盖已掌握技能。
- HOST 把新技能改写成 **推理时过程**：一条人类视频指定行为，**不更新参数**。
- 平均 **29 秒**（含录示范）拿到可执行技能；八任务对照子集成功率 **62%**。

**对 wiki 的映射：** [paper-host-one-shot-human-video](../../wiki/entities/paper-host-one-shot-human-video.md)、[机器人 In-Context Learning](../../wiki/concepts/robot-in-context-learning.md)

### 摘录 2：两个结构错位

- **时间不同步：** 人与机进度速度不同，固定时钟偏移会把预测目标与示范脱钩。
- **状态差：** 本体、视角、外观不同，不能从高维人视频直接回归低维动作。

对策：把人/机轨迹映到共享 **任务进度流形**，再按示范的未来进度重写每个预测目标。

**对 wiki 的映射：** [paper-host-one-shot-human-video](../../wiki/entities/paper-host-one-shot-human-video.md)、[World Action Models](../../wiki/concepts/world-action-models.md)

### 摘录 3：自接地级联 + 两阶段预训练

- 级联：先估计机器人在示范中的进度 → 把即将到来的进度译成 **机器人自己的未来观测** → 再从预测观测导出动作。
- 对齐模块：Qwen3-VL-Embedding-8B + TCC + Smooth DTW。
- 策略：双专家自回归扩散；视频专家初始化自 Wan2.2-TI2V-5B；与动作专家共享注意力（MoT）。底座实现继承 [Fast-WAM](https://arxiv.org/abs/2603.16666)。
- Stage 1：同任务机器人–机器人配对 **193,462** 条 / **229** 任务；Stage 2：再适应 **5,847** 条自采人视频配对。

**对 wiki 的映射：** [paper-host-one-shot-human-video](../../wiki/entities/paper-host-one-shot-human-video.md)

### 摘录 4：评测

- 平台：双臂 **ARX R5**，每臂平行夹爪；三路 RGB（双腕 + 第三人称）；双臂动作 **20 维**。
- **50** 个未见操作任务，每任务 **20** trial，均能从单条人视频拿到可执行技能。
- 八任务对照：HOST **62%** vs Vid2Robot **16%** / AWDA **19%** / \(\pi_{0.5}\) **11%** / Wall-OSS **17%** / HOST-base（纯语言）**4%**。相对最强零样本语言基线约 **+45 pt**（摘要口径）。
- 相对 50 条遥操作 SFT：演示少 **50×**，习得快约 **507×**（HOST ~29 s vs \(\pi_{0.5}\)+SFT-50 ~4 h）；Wall-OSS+SFT-50 仅 **56%**。
- 已掌握七任务：HOST 保留约 **99%**；同预算 SFT 最低保留约 **22–43%**。
- 扰动：光照 / OOD 物体 / 换场景 / 执行中人为干扰，相对 62% 默认分别 −1 / −4 / −6 / −9 pt。
