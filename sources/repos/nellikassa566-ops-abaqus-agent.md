## 仓库说明

I built an AI Agent workflow for Abaqus to automate finite element modeling, meshing, boundary setup, job submission, and result extraction. Users describe simulations in natural language, and the Agent generates Abaqus scripts, executes tasks, fixes errors, and improves CAE efficiency.

## 文章中的定位
