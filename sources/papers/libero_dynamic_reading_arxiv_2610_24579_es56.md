# LIBERO-Dynamic 论文通读（支撑具身智能小站 11-01 期技术地图）

> 来源归档（原文通读 · 支撑 `wiki/overview/embodied-station-2026-11-01-56-papers-technology-map.md`）

- **标题：** LIBERO-Dynamic: Benchmarking Robotic Manipulation in Dynamic Environments
- **作者：** Shaojie Ren, Jingwen Sun, Zezhi Liu, Hongjin Chen, Xin Jin, Wei Zou, Zhibo Chen
- **类型：** paper / benchmark / dynamic-manipulation
- **原文：** <https://arxiv.org/abs/2610.24579>（2026-11 通过 arXiv PDF v1 获取全文，pdftotext 提取）
- **一句话说明：** 把目标物体运动与按实测推理延迟推进的物理世界放进同一 LIBERO 评测循环，并给出静态到动态的示范转换与动态微调结论。
- **核对范围：** 通读摘要、§1 引言、§2 相关工作、§3 基准（任务与运动族、接触驱动运动、示范转换、执行协议、指标）、§4 实验（跨模型、执行策略、动态微调、真机验证）、§5 局限、§6 结论；附录通读 A.1（构造细节）、A.2（指标）、A.3（示范生成与严格校验）、A.7（执行协议实现与延迟标定）、A.11–A.12（微调配置与最佳结果表）；附录 A.4–A.6、A.8–A.10、A.13–A.14 的完整扫描表与真机硬件细节仅浏览标题与关键数字，未逐项核对。未阅读公众号以外的其他 55 篇论文原文，技术地图其余条目仍为公众号转述。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **设定（§1、§3）：** 覆盖全部 40 个 LIBERO 任务；3 类轨迹族（线性往复、Catmull-Rom 闭合曲线、折线 zigzag）x 每族 5 个有效变体 x 3 档速度（0.03 / 0.06 / 0.09 m/s），共 1,800 个固定回合 / 每个模型–执行配置。
- **接触驱动运动（§3.2）：** 在目标下放隐形刚性平台，经 MuJoCo 接触摩擦带动目标，而非直接改写位姿；控制 20 Hz，实测延迟 tau 量化为 D = ceil(tau * fc) 步，推理期间物理世界继续推进。
- **静态转 动态示范（§3.3、A.3）：** 回放已验证静态示范，按式 (1) 在目标当前坐标系内保持末端–目标相对关系并加有界平滑平移修正；严格校验后得 9,000 条动态轨迹；评测与训练按运动相位分离（共享任务、路径、速度，故衡量的是条件匹配的适配，不是对新任务的泛化）。
- **执行协议（§3.4、A.7）：** 同步保持、异步队列（LeRobot 式，剩余动作数不超过 ceil(0.5K) 时触发下一次请求，新旧重叠按 0.3 / 0.7 混合）、RTC（按已承诺动作与预期延迟条件化）、VLASH（状态前推，独立检查点，仅作系统参照）。
- **跨模型（§4.1，表 2）：** 6 个预训练策略在异步最佳 K 下动态成功率 27.3%–57.8%（pi0.5 JAX 57.8%、FastWAM-Joint 40.6%、VLA-JEPA 35.7%、FastWAM 32.1%、pi0 31.5%、OpenVLA-OFT 27.3%）；速度从 0.03 升到 0.09 m/s 使每个模型下降 4.7–16.3 个点；静态成绩不单独决定动态排名。
- **执行策略（§4.2）：** 同一 pi0.5（PyTorch）检查点下，Async / Sync / RTC 最佳 SR 为 48.4% / 43.1% / 37.8%；同步每次重规划约 147 ms 停顿，K=2 时与零延迟差 25.3 个点；异步在 K=1、4 时稳态欠载（underflow）为 828.3、329.5 / 千步、SR 0.0%、23.9%，K=6 欠载归零、SR 达峰 48.4%，此后随 K 增大降至 39.3%（K=16）。结论限定于该有限扫描。
- **动态微调（§4.3，表 8）：** pi0.5 静态 / 仅动态 / 混合为 57.8 / 59.6 / 69.3%；单帧 Joint 40.6 / 49.4 / 43.8%；五帧历史 Joint 45.4 / 67.1 / 66.8%；历史帧使动态微调增益从 8.8 点增至 21.7 点（匹配 3,000 步配方）。pi0.5 两种配方步数不同（1,500 / 3,000），不能孤立归因于数据配比。
- **真机（§4.4）：** Franka Research 3、15 Hz，传送带交接、打地鼠、小车追踪（平滑 / zigzag）；K=4 时 Async 在三项操作任务上均高于 RTC；K 升至 8 的效果随模型与任务而异，规模小、单平台，仅作补充证据。
- **局限（§5）：** 轨迹规定、延迟固定标定，未覆盖延迟抖动与复杂不可预测运动；最佳 K 来自有限扫描；真机仅有限任务、单平台。
