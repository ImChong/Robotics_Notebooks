## 摘录 1：问题与主张（Abstract / Introduction）

- **场景：** 事件相机序列稀疏、时间分辨率高，适合 **逐事件低延迟检测**；现有 **异步事件神经网络** 仍有两瓶颈：(1) RNN 类架构难在长序列上高效并行训练；(2) 提精度往往增加 **per-event 计算与延迟**。
- **线性注意力吸引力：** 支持 **并行训练 + 循环推理**；但标准线性注意力对每个事件更新 **全局稠密状态**，检测又需要 **细粒度空间状态** → 精度–效率权衡差。
- **核心挑战：** 在保留训练并行性的同时，引入 **利用事件空间稀疏性的状态级稀疏激活**。
- **SSLA 做法：** **Mixture-of-spaces（MOS）状态分解** + **scatter–compute–gather** 训练流程 → 状态级稀疏 + 训练可并行。
- **SSLA-Det：** 端到端异步线性注意力检测器；Gen1 **0.375 mAP**、N-Caltech101 **0.515 mAP**（异步方法内 SOTA 表述）；相对最强异步基线 **per-event 计算 >20× 降低**。

## 摘录 2：方法结构（仓库 + 论文概念）

| 组件 | 说明 |
|------|------|
| MOS 注意力 | `layers/mos_attention.py`、`layers/mos_lstm.py` — mixture-of-spaces 状态 |
| 稀疏线性注意力 | `layers/linear_attention.py`、`layers/async_sparse_module.py` |
| 检测头 | `layers/yolox_head.py` — YOLOX 风格 |
| 骨干 | `model_mos.py`（MOS_B/M/L/S 多尺度配置） |
| 数据 | `dataset/gen1.py`、`dataset/ncaltech101.py`；Gen1 目录 `data/{train,val,test}` + `bbox/` |
| 训练 | `python train.py --train_cfg=configs/train_cfg_gen1_*.yaml` |
| 评测 | `python test.py --test_cfg=configs/test_cfg_*.yaml` |
| 效率 | `python compute_flops.py --model_cfg=... --dataset=...` |

## 摘录 3：基准与对照读法

| 数据集 | SSLA-Det（论文） | 备注 |
