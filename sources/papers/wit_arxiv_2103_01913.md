## 核心技术要素摘录

1. **数据集规模与图像不重叠划分：**
   - **总规模：** **37.6M** 图文元组（`rows`）、**11.5M** 唯一图像，覆盖 **108 种语言**（每语种至少 12K 元组；其中 53 种语言超过 100K 图文对，约 50M+ 跨语种图文对覆盖 3.1M 图像）。
   - **按唯一图像严格隔离划分：** Train 37.13M 行（11.4M 图）/ Val 261.8K 行（58K 图）/ Test 210.7K 行（57K 图）。
   - **三类图注与上下文：** Reference Text 17.2M（16.7M 唯一）、Attribution Text 35.2M（10.9M 唯一）、Alt Text 5.4M（5.3M 唯一），另附页面/章节上下文描述 119.8M 条。
2. **17 列 TSV Schema（`DATA.md` 核对）：**
   - `language`、`page_url`、`image_url`、`page_title`、`section_title`、`hierarchical_section_title`、`caption_reference_description`、`caption_attribution_description`、`caption_alt_text_description`、`mime_type`、`original_height`、`original_width`、`is_main_image`、`attribution_passes_lang_id`、`page_changed_recently`、`context_page_description`、`context_section_description`。
3. **Flume 过滤管线与人工质量评测：**
   - 从 ~1.24 亿维基页面（279 语种）提取 ~1.5 亿原始元组 → 文本过滤（长度 ≥3，去除 `.png`/`.jpg`/`icon`/`stub` 等泛化 alt 文本，attribution/alt 仅保留 JPG/PNG 关联图像）→ 图像过滤（尺寸 ≥100×100 像素，过滤地图/占位符/图标，仅限 CC/开放许可，对国旗、徽标、地图等高频类别大幅下采样）→ 安全过滤（仅丢弃 <0.2%）→ 仅保留 ≥12K 元组的 108 个语种。
   - **人工评估（7 语种约 4.4K 图文对、13K 次标注）：** 整体语境一致性达 **98.5%**（`Yes`+`Maybe`；其中 Reference 图注 96.6% EN / 97.0% 非 EN，语境相关 99.4% EN / 98.4% 非 EN）。
4. **实证发现（§4 检索实验）：**
   - 双塔词袋对比编码器在 `ref + attr` 组合上取得最优；WIT 预训练模型在 WIT-All 检索（zero-shot R@1 **0.346** vs Conceptual Captions 0.048）及 Wikipedia Page Title 检索上大幅领先，**但在 Flickr30K / MS-COCO 上低于 CC 训练模型**。
   - 论文揭示原因：WIT 词汇高度稀疏长尾——72.02% unigram 频次 ≤3（CC 仅 43%），约 450 万维基实体中超 80% 出现 ≤3 次，且维基图注偏向专有实体/地点/人物全称而非日常粗粒度上位词（hypernyms），导致与日常物体描述数据集之间存在较大 JS 散度（JSD）。
