# Lyra 2.0 — 长时可探索三维场景与几何回访

- **类型：** paper / 原论文 HTML 与官方源码核对
- **论文：** <https://arxiv.org/abs/2604.13036>
- **代码：** <https://github.com/nv-tlabs/lyra>
- **版本：** arXiv 2026-04-14
- **核对范围：** arXiv HTML 的引言/方法/数据/实验/局限与主要实现附录，结合官方 README 和运行入口核对；未复现实验与 GPU benchmark。
- **通读：** 已完成

## 问题与方法

Lyra 2.0 区分空间遗忘与时间漂移：为每帧保留深度、相机和点云的独立缓存，不把噪声深度硬融合成全局地图；依据目标视角的可见性召回历史关键帧，通过重投影提供对应关系。训练时引入自身生成的退化历史来修正长期 drift。生成探索视频后，以 VIPE 位姿估计和 DA3 深度将视频 lift 为 3DGS/网格。

## 输入、输出与复现路径

- **输入与输出：** 一张起始图、配套文本 caption、指定相机轨迹；生成探索视频，随后输出 `reconstructed_scene.ply` 三维高斯点云。
- **实际入口：** Lyra-2/lyra_2/_src/inference/lyra2_zoomgs_inference.py、vipe_da3_gs_recon.py
- **官方复现：** 官方推理入口 `PYTHONPATH=. python -m lyra_2._src.inference.lyra2_zoomgs_inference --input_image_path assets/samples --sample_id 4 --checkpoint_dir checkpoints/model --prompt_dir assets/samples --output_path outputs/zoomgs`；再运行 `python -m lyra_2._src.inference.vipe_da3_gs_recon --input_video_path outputs/zoomgs/videos/4.mp4`。超过 500 帧建议 `vipe_da3_chunked_gs_recon` 分块重建。

## 实验观察与适用边界

- **作者报告：** README 在 1×H100 80GB 上报告生成 80 帧约 9 分钟，使用 DMD 可约 35 秒；这些是离线生成时间，不等同实时交互延迟。论文示例可把重建资产导入 Isaac Sim 做环境探索。
- **论文/实现局限：** 论文的主场景是静态环境，不显式模拟动态物体；训练数据光照变化可传入生成结果，损害 3DGS 重建。代码 Apache-2.0，但模型权重使用 NVIDIA Internal Scientific Research and Development Model License，不应误称可任意商用。
