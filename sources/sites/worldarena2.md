# WorldArena 2.0 官方项目页

> 来源归档（WorldArena 官方网站）

- **标题：** WorldArena 2.0: Extending Embodied World Model Benchmarking on Modality, Functionality and Platform
- **类型：** site（项目页）
- **URL：** <https://world-arena.ai/>
- **论文：** <https://arxiv.org/abs/2605.17912>
- **代码：** <https://github.com/WorldArena2/WorldArena-2.0>
- **榜单：** <https://huggingface.co/spaces/WorldArena/WorldArena2.0>
- **核查日期：** 2026-10-26
- **一句话说明：** WorldArena 2.0 将具身世界模型评测扩展至视触觉、在线 RL 环境和模拟/真机平台。

## 页面要点

- 项目页将扩展概括为模态、功能和平台三个维度。
- 视触觉维度涵盖接触、力、滑移和材料交互；功能维度将模型作为在线 RL 环境；平台维度把评估延伸到真实机器人。
- 项目页列出 RoboTwin 2.0、LIBERO 与 AgileX split-type ALOHA 等评测平台。
- 榜单托管于 Hugging Face Space；其中收录 Xiaomi-Robotics-U0 作为参评模型。
- WorldArena 2.0 是独立 benchmark，榜单收录小米模型不代表基准归属小米。
