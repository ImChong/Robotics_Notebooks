## 摘要级要点

- **问题：** 多数 WAM 在成功演示上训练未来预测，测试时坏动作仍被配对 success-biased 未来；失败数据若直接当模仿目标会污染策略。
- **主张：** 把「学什么动作」与「学动作后果」分开——失败轨迹应监督 **后果**，而非行为。
- **方法：** token 序 \(P\|A\|G\|V\|I\)；世界支路 teacher-force 干净动作 \(G\)；失败样本 \(\mathcal{L}_{\mathrm{act}}\) 掩码，保留 value / future-video；推理 Stage1 出动作、Stage2 可选 value / 视频；value 可对 \(N\) 候选打分。
- **结果要点（项目页 / 论文）：**
  - RoboTwin 50 任务平均：无失败 **85.6%** → 含失败 **87.5%**（接近 Motus 87.8%，部署约 **3×** 更快）
  - 真机 seen：失败共训 **82→89%**，+ scoring **92%**（无大规模机器人预训练）
  - 失败想象诊断：坏动作下未来 PSNR **+6.4 dB**，成功未来不变
- **局限：** 失败数据主要来自模型 rollout；评测主轴为双臂桌面操纵；可选 scoring 增加 Stage2 开销。

## 核心摘录（面向 wiki 编译）

### 1) 因果「先动后想」

共享因果扩散 Transformer 联合去噪 action / value / future-video；value 与未来只看干净动作槽 \(G\)，noisy \(A\) 不可见 \(G\)。

### 2) 失败感知损失

- 成功：\(w_a\mathcal{L}_a+w_v\mathcal{L}_v+w_I\mathcal{L}_I\)
- 失败：仅 \(w_v\mathcal{L}_v+w_I\mathcal{L}_I\)，进度目标下调 \(\lambda_{\mathrm{fail}}\)

### 3) 复现入口（README）

```bash
bash setup_env.sh && conda activate fact
python -m scripts.prepare_robotwin --robotwin_root ./datasets/RoboTwin ...
python -m scripts.train --config world_action_model.configs.robotwin.config
python -m scripts.inference_server --transformer_path ./models/fact-wam/transformer ...
```
