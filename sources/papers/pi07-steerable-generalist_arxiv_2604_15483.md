- **一句话说明：** π0.7 是 Physical Intelligence 的约 5B 参数 VLA，核心思想是训练时给每个样本配「多样化上下文」（子任务指令、子目标图像、片段元数据、控制模式），随机 dropout 各分量，使一个模型能吃下次优自主数据、失败数据、人视频与网页数据，测试时再用提示选择策略与质量。

## 论文要点（作者自述，带章节）

### 方法

- **上下文 C = {ℓ, ℓ̂, g, m, c}**（§V-E，Algorithm 1）：任务指令 ℓ、子任务指令 ℓ̂（来自高层语义策略或人类，沿用 π0.5，§V-A）、多视角子目标图像 g（§V-B）、片段元数据 m（§V-C）、控制模式 c ∈ {joint, ee}（§V-D）。完整提示示例形如 `Task: peel vegetables. Subtask: pick up the peeler. Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint.`。
- **元数据**（§V-C）：整体速度（episode 步数，按 500 步分箱）、整体质量（1 到 5 分）、错误标记（人工粗标注片段是否出错）。
- **子目标图像**（§V-B）：由轻量世界模型生成，初始化自 14B 的 BAGEL（混合 transformer，可理解 / 编辑 / 生成图像，附录 C），沿用 SuSIE 思路；训练目标为流匹配损失，目标是片段末帧；数据为带高质量子任务标签的子集。
- **Dropout**（§V-E）：子目标图像只加到每个 batch 25% 的样本；有子目标图像的样本里 30% 丢弃子任务指令；元数据整体 15% 丢弃，速度 / 质量 / 错误各自再 5% 丢弃；控制模式不 dropout。论文称给子目标图像后训练明显更快，因为动作预测近似逆动力学问题。
- **架构**（§IV、§VI-B、Fig.2）：Gemma3 4B VLM（含 400M 视觉编码器）+ MEM 式视频历史编码器 + 860M 流匹配动作专家，约 5B 参数；最多 4 路相机，每路最多 6 帧历史（步长 1 秒），最多 3 张子目标图（不含后视），图像缩放到 448x448；历史帧压缩为单帧等量 token；块因果注意力；本体状态用线性投影（π0.6 为离散文本 token）；动作专家固定 50 个动作 token，用 adaptive RMSNorm 注入流匹配时间步；训练时 RTC 模拟 0 到 12 步延迟（50Hz 下最大 240ms）。训练沿用知识隔离（KI）：VLM 用 FAST token 监督，动作专家梯度不回传 VLM（§III）。
- **子目标训练采样**（§VI-C）：真实未来帧 25% 取片段末帧、75% 取未来 0 到 4 秒均匀采样，另混入大量世界模型生成的子目标图像以缓解训练 / 测试分布差。
- **运行时**（§VII）：速度设为该任务 episode 长度的第 15 百分位，质量恒为 5，错误恒为 false；子目标在 ℓ̂ 变化或 Δ=4 秒后刷新，异步生成；5 步去噪生成 50 步动作块，执行 Ĥ ∈ {15, 25} 步；对元数据做 classifier-free guidance，β ∈ {1.3, 1.7, 2.2}。
- **数据**（§VI-A）：多机器人演示、自主评测数据、评测中的人类干预、开源机器人数据、第一视角人视频、网页辅助任务（物体定位、属性预测、VQA、纯文本、视频字幕）。使用 π0.6* 的 RL 训练 rollout 作为额外样本，论文称这相当于把 RL 专家「蒸馏」进通才（§VI-A）。脚注 1：泛化评测任务的自主数据不进训练。
- **推理耗时**（附录 D）：单 H100 上，最小变体 38ms（3 相机、5 去噪步、训练期 RTC），开启 MEM 视觉编码器并加子目标图像最坏 127ms；子目标生成用 4 张 H100 张量并行、8 比特量化与改版 SageAttention，25 去噪步（含文本与图像 CFG）1.25 秒。

### 实验结果（均为作者自述）

- **§IX-A 开箱灵巧任务（Fig.6、Fig.7）：** 单个 π0.7 对照 π0.6* RL 专家（咖啡、折衣、造箱）与 π0.6 SFT 专家（其余灵巧任务），论文称各任务「competitive」，在 diverse laundry 与 box building 上吞吐高于 RL 专家。消融：去元数据与去评测数据均更差，差距主要在吞吐（Fig.7，仅有图示）。记忆任务（Fig.8）与 MEM 论文的微调专家相当或更好。
- **§IX-B 指令跟随（Fig.9 至 Fig.11）：** 4 个未见厨房与 2 个未见卧室、14 个场景、每个 3 到 6 步指令序列，π0.7 显著优于 π0.5 与 π0.6；复杂指代指令（如「pick up an object I would use to eat soup」）上子目标图像进一步提升；反数据偏置任务 Reverse Bussing 与 Reverse Fridge to Microwave 上 π0.7 优于前代，后者子目标图像「critical」。
- **§IX-C 跨本体（Fig.12、Fig.13、附录 F）：** 简单摆放任务多个模型都能迁移；更大形态差距（UR5e 与静态双臂互转、Shirt Bagging）上 π0.7 明显优于 π0.5 / π0.6；折叠毛巾与 T 恤在从未收集过叠衣数据的双臂 UR5e 上成功，并出现与源机器人不同的抓取策略（垂直抓取）。人类受试者研究：10 名 top 2% 经验操作员（平均约 375 小时，每人 3 次，共 30 次试验，无热身），人类任务进度 90.9%、成功率 80.6%；π0.7（GC）任务进度 85.6%、成功率 80%。
- **§IX-D 组合泛化（Fig.14 至 Fig.17）：** 短任务（压法压壶、舀米、擦拭、旋转铰接物体）开箱可做；长任务（空气炸锅装 / 卸、烤贝果）用逐步语言「coaching」完成，再用 coaching 数据训练高层策略得到全自主策略（Fig.16），表现接近人在环 coaching。
- **§IX-E 数据多样性（Fig.18）：** 叠 T 恤任务按质量与速度分 4 个桶（前 30% / 50% / 80% / 全部）各训有 / 无元数据共 8 个模型：无元数据随低质量数据增多可能变差，有元数据持续提升；去掉任务多样性最高的 20% 数据显著差于去随机 20%。

### 作者承认的局限与讨论（§X）

- 零样本泛化成功率低于分布内：已见任务常超 90%，未见任务或未见任务 - 机器人组合在 60% 到 80%。
- 难以确定哪些任务真的「未见」：数据极大，相关技能可能以别的标签或附带形式出现，泛化可能主要来自「重混」；作者认为这就是组合泛化的本质。
- 未来方向：利用可 steer 性，在测试任务上用更细语言 coaching 或自主 RL 提升。
- §II：作者声明不是提出新架构，而是提供让 VLA 利用更多样数据的方法论与实证。
