## 核心摘录

1. **问题与动机（摘要、§1）：** 多相机 VLA 每步处理数百视觉 token；作者认为存在两类互补冗余：许多视觉 token 空间上无关，且保留 token 上的注意力分配不当（摘要）。OpenVLA 式设置下 224x224 图像产生 256 个 patch（§1）。
2. **阶段一：分割引导且保留位置的剪枝（§3.1）：** 用 SigLIP 文本-patch 余弦相似度（按词性加权，式 1）粗定位；取 K_init=50 个最高分 patch，DBSCAN（eps=2.0）取最大簇，再取 8 个正提示与 3 个最低分负提示送入 EfficientTAM-S 生成掩码；掩码覆盖某 patch 像素超过 30%（tau=0.3）则保留；保留 token 沿用原 RoPE 位置 ID，作者称重新编号会使成功率塌到接近零（§3.1）；掩码每 5 次 VLA 调用异步更新。
3. **阶段二：显著性引导的注意力偏置（§3.2）：** 每个任务开头对指令做 Integrated Gradients（n_steps=5，pad token 基线），前 30% token 记为显著；以式 2 的加性偏置（beta=2.0）只作用于动作 token 查询、仅在中间层 8–23；偏置位置为显著文本 token（按 IG 加权）与保留视觉 patch（按 SigLIP 相似度乘 0.5）。
4. **主结果（§4.1，表 1，LIBERO-Spatial，OpenVLA-OFT）：** 基线 97% / 107.5 ms；T3R 剪掉 85% 场景相机 token，96% / 92.5 ms；TeamVLA 约 15% 缩减，94% / 102.6 ms；同为 85% 缩减时 FastV 14%、ADP 66%；ADP 原生工作点缩减 33.5% 时 97%。
5. **时延口径（§4.3）：** 85% 缩减使每次 VLA 调用从 107.5 降到 92.5 ms（14%，1.16x）；LLM 前向 58.9 到 36.1 ms 与整体节省相比有 7.8 ms 余量，作者归因于剪枝与偏置施加，并说明未分离各部件；分辨率上升时 LLM 前向最高 3.3x（768 px）；基于 L40S 实测 LLM 成本加固定 48.6 ms 非 LLM 成本的**投影**端到端为 T3R 100/115/132 ms 对基线 144/182/327 ms（384/512/768 px），768 px 处 2.47x。
6. **鲁棒性（§4.4，图 4）：** 对物体摆放加高斯位置噪声（0–5 cm，21 档，每任务 10 回合），T3R 在 4 cm 处领先基线最多 7 pp，>=4 cm 平均 +4.8 pp；TeamVLA 退化最快。
7. **消融（§4.6）：** 仅剪枝 90%，仅偏置 98%，完整 96%，基线 97%；偏置层位扫描：中间层 98%、早期 95%、后期 92%、全部层 93%（均为 LIBERO-Spatial，无剪枝）。
8. **跨骨干（§4.5，表 2）：** CogACT + SIMPLER（单相机）：T3R（保留 60%）Google Robot 67.7 对基线 73.2，WidowX/Bridge 10.4 对 10.4；pi0.5 + RoboTwin（三相机，零样本）：50% 保留率 33.3 对基线 33.3，62.5% 保留率 38.3。两者均为零样本且无微调检查点，绝对成功率低（§4.5）。
9. **论文自述局限（§4.8）：** LIBERO-Object 上 82% 低于 TeamVLA 的 86%；多阶段任务（LIBERO-Long）相关区域会随阶段变化而相似度不随之更新；依赖可提示分割模型；IG 有一次性开销；单相机几乎无收益；全部为仿真，实机与异步执行、能耗与边缘设备未验证；遮挡与光照对分割的影响未单独检验。
