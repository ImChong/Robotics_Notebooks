- **主页：** <https://themodernsoftware.dev/>
- **课程日历：** <https://docs.google.com/document/d/1W11sWBigWIsi9wVIhhFx3wajIEnP0Qfb-ei8Ecf5VKU/edit?usp=sharing>

- **定位：** 以课程、作业、开源贡献和期末项目学习 AI 原生软件开发。主页列出 3 units、CS111/CS161 同等编程经验，推荐 CS221/229。

## 官方日历概览

1. 编程智能体内部结构与系统提示词；拆解 Claude Code。
2. 上下文工程、规范驱动开发、MCP 与工具调用；构建 MCP server。
3. Agent skills 与 CLI；编写一个 skill。
4. 用 CLAUDE.md、AGENTS.md 和 hooks 定制智能体与仓库；提交项目技术规格。
5. 让代码库适合智能体使用：结构、文档与检查；整理杂乱仓库。
6. 智能体辅助代码审查；提交 agent readiness 报告。
7. 安全与开源贡献；项目 alpha 与任务清单。
8. 异步后台智能体及开源贡献。
9. AI 原生团队；产业嘉宾分享。
10. 大团队中的 coding agents、MCP portals、模型路由与成本；软件工厂。
11. 期末项目与展示。
