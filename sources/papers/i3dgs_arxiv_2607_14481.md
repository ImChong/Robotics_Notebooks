## 核心摘录

### 1) 问题与动机
- **3DGS** 已成场景重建与实时渲染首选，但高质量采集常混合 **连续视频帧** 与 **乱序补拍** 以扩大覆盖。
- **离线 SfM / COLMAP** 可重建此类数据，但需 **全部图像就绪** 且计算昂贵，无法边拍边看。
- **增量 SLAM 系 3DGS**（MonoGS、GS-SLAM 等）能即时反馈，但依赖 **时序输入**，难以处理乱序补拍与跨段回环。
- 本文目标：**乱序输入 + 即时反馈 + 全局一致** 的 radiance field 捕获，并支撑 **大场景**（数千张图）。

### 2) 方法要点
1. **乱序快速匹配：** 复用 **视觉地点识别（VPR）** 模型 + **共视性图（covisibility graph）**，在无序序列中快速建立帧间关联；并高效选取 **高连接关键帧**，有序序列上亦提升质量。
2. **即时局部重建：** GPU 优化 + 谨慎的高斯原语放置，在 radiance field 重建场景下实现 **快速局部 3DGS**。
3. **聚类式回环闭合：** 再次利用共视性图，提出 **不依赖时序输入** 的 cluster-based loop closure，修正漂移、保证全局一致。
4. **渐进式层级：** 面向大场景引入 **progressive hierarchy**，在不牺牲效率的前提下扩展至大型环境。
5. **产品关联：** 项目页注明该算法为 Inria GraphDeco 衍生公司 **[OnTheFly](https://onthefly3d.com)** 的核心技术。

### 3) 实验（论文/项目页摘要）
- 多个数据集上展示 **即时 3DGS 重建** 与 **良好视觉质量**；输入规模可达 **数千张图像**。
- 评测协议：`train.py --test_hold N` 留一评测；`scripts/train_eval_all.py` 复现 Table 1/2。
- 交互：**live / network viewer**（基于 [graphdecoviewer](https://github.com/graphdeco-inria/graphdecoviewer)）可在优化过程中浏览场景与位姿。

### 4) 开源核查（步骤 2.5）
- **项目页（2026-09-09）：** Paper、Slides、**Code**（GitHub）、Group Publ. Page 均已列出；无单独 Hugging Face / 数据集托管链接。
- **GitHub [`graphdeco-inria/i3dgs`](https://github.com/graphdeco-inria/i3dgs)：** **已开源** — Python + PyTorch 2.7.1 / CUDA 12.8；`train.py` 主入口、`scripts/download_datasets.py` 拉评测集、`gaussianviewer.py` 交互浏览。
- **许可：** Inria **Immediate3DGS license** — **研究与评测用途**；商业/专利限制需联系 [OnTheFly](https://onthefly3d.com)。
- **结论：** **已开源**（训练/推理/viewer 可跑）；许可 **非宽松 OSS**（非 MIT/Apache）；预训练 checkpoint 首次运行自动下载。
