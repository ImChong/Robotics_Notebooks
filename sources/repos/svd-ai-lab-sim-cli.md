## 仓库说明

Turn existing CAE files into structured text an agent can use — COMSOL, Abaqus, Fluent, HFSS, Icepak, FloTHERM — plus solver detection, script linting, and live solver sessions. Strong coverage for electronics thermal and advanced packaging.

## 文章中的定位

不直接启动求解器，而是将既有 `.mph`、`.inp`、`.cas.h5`、`.aedt`、`.mechdb`、`.tzr` 文件解析为结构化文本，提取材料、边界、网格和求解设置，并支持 lint、版本检测及会话功能。

文章的选择、成熟度判断与演示描述属于作者的策展意见；本归档只将其作为来源线索，不视作独立性能评测。

## 访问与复现边界

仓库源码公开，GitHub 未标记为 archived。仓库 API 显示许可证为 Apache-2.0。 README 和运行入口以仓库当前默认分支为准；涉及商用求解器的项目还需用户本地安装软件并具备有效授权。
