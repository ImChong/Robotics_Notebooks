## 文章要点

文章把 Skill 界定为写给编码代理读取的工作流程说明，通常以 `SKILL.md` 形式存在，并强调它本身不等于求解器或软件接口。Skill 可指导问题定义、建模、验证和报告；需要实际操作专业软件时，还要有相应 MCP/CLI、软件安装与许可证。

文章按资源目录、OpenFOAM/CFD、结构 FEA、商业软件 MCP、CAD/网格/可视化及窄域设计研究六类介绍仓库。其工程选择标准侧重可调用性、验证闸门、失败处理和清楚写出边界。作者提醒：残差下降不等于收敛；网格、单位、边界、壁面分辨率、守恒量和物理合理性需要联合检查。对可执行任意 Python 的 MCP，建议限制在可信环境，并保护求解器安装目录。

## 项目节点映射

本篇涉及的项目逐个整理为独立知识节点，且每个项目保留自己的源码归档。两个同名仓库（例如两版 `ansys-mcp-server`、`freecad-automation-skill`、`freecad-ai-skill`）按不同 GitHub 身份分别建页；同一仓库内的多个技能包仍归到该仓库节点。
