一岁会抓东西，七岁才可能自己过马路。

孩子一岁左右，已经很会抓东西了。

奶瓶、积木、遥控器、眼镜，尤其是手机，只要被他发现，几乎没有幸存的可能。小手一伸，目标锁定，动作完成。这个过程看起来非常智能，仿佛孩子体内安装了一个高性能目标识别系统。

但到了七岁，很多孩子仍然不能独自过马路。

这似乎有些不公平：抓住一个杯子，需要手眼协调；过一条马路，也不过是左看看、右看看，再左看看。为什么前者一岁就能做，后者却要等到七岁，甚至更久？

因为"抓东西"主要是动作问题，而"过马路"是一套完整的认知系统。

孩子要看见车辆、信号灯、斑马线和行人；判断车辆的距离、速度和方向；预测司机下一步可能做什么；知道绿灯亮了也不能马上冲；还要抑制自己急着回家的冲动。

更关键的是，他要理解一件非常反直觉的事：

世界不会因为我学会了规则，就自动按照规则运行。

司机可能分心，电动车可能闯红灯，车辆可能被遮挡，旁边的大人也可能判断失误。

这正是人形机器人今天面临的核心问题。

它们已经越来越会"抓"，但距离真正会"过马路"，还差着一整套对现实世界的理解。

# 人形机器人已经会做什么？

过去几年，人形机器人最明显的进步，不是外形越来越像人，而是从"预先写好动作"开始走向"根据环境现场决定动作"。

传统机器人通常只擅长固定任务：在工厂里反复拧螺丝、搬箱子、焊接零件。工作台、物品位置、动作流程都被严格规定，机器人只需要把流程执行得稳定。

新一代具身AI则试图把视觉、语言和动作连起来。

人类说一句"把桌上的杯子放进柜子"，系统需要完成：看见杯子；理解"杯子""桌子""柜子"的关系；规划走过去、伸手、抓取、转身、开门和放置；根据杯子的重量、材质和位置调整力度；如果柜门没打开，还要重新规划。

这类系统通常被称为VLA，也就是视觉—语言—动作模型。它们不只是回答问题，而是把视觉和语言输入转换成真实世界的电机控制。

目前公开展示的进展已经相当惊人。

Google DeepMind公开介绍的 Gemini Robotics 2，目标是让模型适配双臂机器人和完整人形机器人；Gemini Robotics ER 2负责空间理解和多步骤规划，On-Device 2则强调在机器人本地运行。Google宣称其系统支持全身控制、灵巧操作、多机器人协作和陌生任务适应。不过这些能力仍主要来自厂商展示和合作测试，距离普通家庭长期稳定使用还有很大距离。

Figure的Helix系统则采用了很有代表性的"慢脑子＋快身体"结构：

一个较慢的视觉语言模型负责理解场景和任务，另一个高速控制模型负责实时调整动作。Figure公开介绍，Helix的高层模型运行在约7至9赫兹，低层控制可以达到200赫兹，并控制手腕、手指、躯干和头部等多个部位。它还展示了双机器人协作、陌生物品抓取和自然语言控制。

NVIDIA的Isaac GR00T N1.7则把重点放在开放的通用VLA模型上。它支持视觉、语言、机器人状态和动作数据，尝试在不同形态的机器人之间迁移技能，并加入了大量人类视频数据。Physical Intelligence发布的π0.7，也开始展示跨机器人、跨场景和跨任务的组合泛化：机器人不仅执行训练过的动作，还可以根据语言提示把已有技能重新组合，用来尝试新电器、新工具和新任务。

这些进展说明了一件重要的事：人形机器人正在从"动作库"变成"技能模型"。

以前是"会做十个动作"；现在是"理解任务后，尝试组合已有技能"。

这是巨大进步，但它距离七岁孩子的状态仍然很远。

# 会抓住杯子，不代表知道杯子里是热水

一岁孩子抓杯子时，主要解决的是"杯子在哪里"和"手该怎么伸"。

七岁孩子看到杯子时，脑子里还会自动带出一串问题：杯子里装的是什么？是不是热水？这是别人的东西吗？拿起来会不会打翻？旁边有没有小朋友？

机器人目前最缺的，也正是这些隐藏在动作背后的常识。

它可以识别一个杯子，却不一定理解杯子在家庭中的意义；可以把锅端到桌上，却不一定知道锅刚从炉子上拿下来；可以把药递给人，却不一定确认药品、剂量和对象是否正确。

机器人最大的短板，不是没有视觉，而是缺少"情境中的意义"。

现实世界不是物体分类大赛。

同一个动作，在不同场景里，风险完全不同。把一个塑料杯递给成年人和把一杯热咖啡递给幼儿，动作形式相似，责任却完全不同。

# 达到"七岁状态"，至少需要八种能力

这里的"七岁状态"不是指机器人真的拥有七岁孩子的全部心理能力，也不是说七岁孩子都能安全独自过马路。它只是一个比喻：机器人能够在有限监督下理解环境、遵守规则、处理变化，并在不确定时停下来。

要达到这个状态，至少需要以下能力。

# 第一，持续而不是瞬间的感知

目前很多机器人演示，是在一个短视频里完成一个任务。

但孩子的感知是连续的。他不会只看一帧画面，而是持续观察：那辆车是不是正在靠近，那个门是不是被人打开了，地上的东西是不是刚刚被移动过。

机器人需要建立稳定的三维环境模型，持续追踪物体、人物、速度和意图，而不是每隔几秒重新"看一眼世界"。

# 第二，能够处理看不见的东西

孩子知道球滚到沙发底下并没有消失，妈妈走出房间也仍然存在。

这叫物体恒常性和部分可观测环境理解。

机器人需要记住物体的位置、人的位置和任务进展，即使它们暂时不在摄像头里。Physical Intelligence在2026年公开的多尺度具身记忆研究，已经尝试让机器人用短时视觉记忆和长时语言记忆完成最长约15分钟的任务。

这是一个起点，但家庭任务往往不是15分钟，而是数小时甚至数天。

# 第三，真正的长期记忆

机器人不能每次都像第一次进家门一样。

它需要知道：药箱通常放在哪里；这个老人走路比较慢；这只杯子容易滑；上次开这个抽屉时卡住了；这个孩子不喜欢突然靠近。

记忆不是简单保存录像，而是要提炼出可使用的经验，同时避免把错误经验永久固化。

# 第四，因果推理和反事实思考

七岁孩子会问："如果我现在跑过去，会不会被车撞？"

这其实是一种反事实推理：比较"现在走"和"等十秒"两种未来。

机器人也需要在行动前想象后果：

如果我打开这个抽屉，里面的物品会不会掉出来？

如果我抓住这个瓶子，瓶盖会不会松开？

如果我从这个方向经过，会不会碰到旁边的人？

今天的机器人已经能做一定程度的规划，但在开放环境中进行可靠的因果预测，仍然困难。

# 第五，失败恢复

孩子第一次系鞋带失败后，会重新尝试，或者主动求助。

机器人不能把任务理解成"一次成功或彻底失败"。它需要知道自己哪里做错了，判断失败是否可恢复，并采取补救动作。

例如：杯子没有抓稳，要重新调整；柜门没开，要换一个抓取位置；物品掉在地上，要重新定位；当前任务风险太高，要停止并通知人类。

真正有用的机器人，不能只展示成功视频，还必须能把失败处理得体面。

# 第六，风险意识和不确定性表达

这是从"会做"到"可靠"的关键一步。

机器人需要知道自己什么时候看不清、什么时候没有把握、什么时候环境超出训练范围。

它应该能够说："我不确定这个瓶子是不是药品，请确认。"

"前方有人经过，我先暂停。"

"地面湿滑，我需要改变路线。"

"我无法确认炉火是否关闭。"

一个只会自信行动的机器人，比一个经常请求确认的机器人危险得多。

成熟的智能，不是永远给出答案，而是知道什么时候不能贸然给答案。

# 第七，理解人的意图和边界

七岁孩子已经能理解一些社会规则：别人正在睡觉时不能大声说话，别人手里拿着东西时不能硬挤过去，陌生人靠近时要保持距离。

机器人也需要基本的社会认知。

它要理解"帮我收拾一下"并不是把所有东西随便塞进柜子；"把这个给我"需要确认"这个"到底指什么；"快一点"也不能成为碰撞人的理由。

未来人形机器人能否进入家庭，很大程度上取决于它们能不能理解这些没有写进说明书的规则。

# 第八，稳定的身体和可靠的硬件

再聪明的模型，也需要一副不会突然失控的身体。

机器人需要更好的触觉传感器、柔顺关节、灵巧手、足底感知、抗摔结构和电池系统。它还要能应对地毯、台阶、积水、狭窄走道和被孩子撞到等情况。

人类摔一跤，通常只是疼一下；一台几十公斤的人形机器人摔倒，可能损坏设备，也可能伤到旁边的人。

"会走路"只是运动学问题，"在有人、有家具、有宠物的环境里稳定走路"则是安全工程问题。

# 目前真正缺失的是什么？

表面上看，缺的是更多数据和更大的模型。

实际上，缺口至少有五层。

第一是真实世界数据不够。互联网视频能教模型看懂厨房，但不能直接告诉机器人如何在每种厨房地面上安全迈步。机器人数据昂贵、危险、速度慢，家庭中的长尾情况更难采集。

第二是长时任务数据不够。很多实验持续几分钟，而真实家庭任务经常包含几十个子步骤。清理厨房、准备晚餐、照料老人，都需要长期保持上下文。

第三是从语言到动作之间仍有断层。语言模型擅长表达和推理，控制模型擅长快速移动，但二者之间仍需要稳定的中间表示。机器人必须把"把桌子收拾干净"拆成一系列可验证的动作，并理解完成标准。

第四是安全评估体系不成熟。机器人不能只用"任务成功率"评价。还要统计误抓率、碰撞率、误操作率、恢复时间，以及在陌生环境中的最坏情况。

第五是硬件、软件和责任边界没有完全准备好。机器人出了问题，究竟是模型、传感器、机械结构、网络连接，还是使用者指令有问题？如果没有清晰的日志、权限和紧急制动，商业化会非常困难。

# 一个简单但残酷的数学问题

假设一个家庭任务包含100个连续动作。

即使每个动作的成功率达到99%，整项任务一次完成的概率也只有：

0.99¹⁰⁰，约等于36.6%。

这就是为什么机器人在演示中"偶尔做得很好"，不代表它已经能够长期工作。

如果希望100个动作组成的任务整体成功率达到90%，平均每个动作的可靠性要接近99.9%。

家庭机器人面对的还不是100个固定动作，而是不同房间、不同物品、不同光线、不同家庭成员和不断变化的任务目标。

所以，下一阶段的竞争重点，不是再拍一段更精彩的视频，而是把机器人从"演示成功"推进到"连续数周稳定工作"。

# 接下来几年，可能会发生什么？

未来的发展大概率不会从"不会做"直接跳到"完全像人"，而会沿着场景逐步扩展。

第一阶段，机器人会在工厂、仓库、商场后场和实验室里承担更多半结构化工作。这些地方物品相对固定、路线相对明确，出了问题也有工作人员在旁边。

第二阶段，机器人会进入酒店、养老机构和部分家庭，完成收拾、递送、搬运、简单清洁等任务，但仍需要远程监控和人工接管。

第三阶段，机器人能够根据语言和示范快速学习新技能，并在不同房间和不同物品之间迁移。它不再只是"执行命令"，而是能够理解任务目标、拆分步骤、检查结果。

再往后，才可能出现真正意义上的家庭通用机器人：可以在陌生环境中行动，记住长期上下文，理解人的习惯，主动规避风险，并在复杂情况下请求帮助。

至于"达到七岁孩子那种有限自主状态"，我认为关键不在于某个具体年份，而在于是否同时实现三件事：

长时记忆、可靠世界模型和可验证安全控制。

缺少任何一项，机器人都可能只是一个动作很漂亮、判断却不稳定的"大孩子"。

# 还需要做哪些工作？

接下来最重要的工作，不是单纯继续堆参数，而是建立一套完整的具身智能工程。

一是建设覆盖真实生活的多模态数据集，记录的不只是成功动作，还包括犹豫、失败、碰撞风险和人工接管。

二是发展具身记忆，让机器人能够记住环境、人物、物体和经验，并且知道哪些记忆值得相信。

三是训练能够预测后果的世界模型，让机器人在行动前比较不同方案，而不是边走边试。

四是让高层推理模型和低层控制模型形成稳定闭环。高层负责目标、规则和计划，低层负责毫秒级的平衡、触觉和动作修正。

五是建立"暂停优先"的安全机制。遇到遮挡、异常、陌生物体和意图不清时，机器人应该主动停下，而不是为了完成率继续猜。

六是发展高质量仿真和现实数据闭环，让机器人在虚拟环境中大量练习，再通过真实世界反馈修正模型。

七是建立统一的长时任务评测标准。不能只测试"能不能把杯子放进柜子"，还要测试它连续工作一天、一周、一个月后是否仍然可靠。

八是解决隐私、权限和责任问题。家庭机器人会看到家庭成员、房间布局、健康状况和生活习惯。它必须有明确的本地处理、数据隔离、操作授权和审计机制。

# 最后，别被"像人"骗了

人形机器人最容易让人产生错觉。

两条腿、两只手、一个脑袋，再配上一句自然语言，我们就会下意识地认为它已经理解了世界。

但外形只是接口，不是智能本身。

一岁孩子会抓东西，说明他开始控制自己的身体；七岁孩子逐渐能够在大人有限陪同下理解过马路，说明他开始理解规则、他人、风险和后果。

人形机器人今天已经会抓、会走、会搬、会听懂一些指令，也开始学会把不同技能组合起来。但它们仍然缺少一套稳定的现实感：知道什么东西不能碰；知道什么时候不能走；知道别人可能犯错；知道自己可能判断错；知道任务没有完成时应该停下来求助。

会抓住目标，是能力。

会把目标变成动作，是具身智能。

知道什么时候不能伸手、不能迈步、不能继续执行，才是接近人类认知的开始。

人形机器人真正要学会的，不是像人一样挥手，而是像一个逐渐长大的孩子一样，明白这个世界并不总会配合自己。
