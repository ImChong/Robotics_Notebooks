- **一句话说明：** FAH 直接估计 2D/3D 手关节与表面对应点，以独立参数化拟合得到 MANO/MHR-Hand 网格，并可选输出部位分割、手-物接触、因果视频轨迹和世界系手部位置。

## 问题、方法与关键区别

1. **检测与视觉骨干：** 手部实例检测后进行裁剪；以 SAM 3D Body 的手分支提供蒸馏监督，使用 DINOv3 不同尺寸骨干提取手部视觉特征。
2. **关键点与稠密表面：** 不把 MANO 参数回归当作唯一训练目标；预测 21 个关节、骨骼点及稠密表面对应点的 2D/3D 坐标，结合 Laplacian 表面基表达可用于拟合的手形。
3. **网格拟合：** 将点预测送入独立的 MANO/MHR-Hand 参数化拟合（初始化与阻尼 Gauss–Newton 优化），而不是强迫图像编码器一次性预测所有网格参数。
4. **下游扩展：** 共享几何与视觉信号供部位分割、接触概率估计使用。接触监督的构造阶段利用手-物几何，部署推理不要求物体 CAD/网格。
5. **视频与世界系：** 因果时序细化改善单帧抖动，世界模式另外估计相机运动/尺度，再将相机系手坐标变换到世界系；离线相机路线与因果路线成本不同。

## 论文结果（均为作者报告，不是本站复现实测）

| 指标/配置 | 论文报告 | 读法 |
|---|---:|---|
| HOT3D，FAH-L 单帧 PA-MPJPE | **4.31 mm** | Procrustes 对齐后关节误差，不是绝对世界坐标误差 |
| RTX 4070 Ti SUPER，FAH-L | **65 FPS** | TensorRT、包含网格拟合；不含可选分割/接触 |
| FAH-L，加部位分割 | **54 FPS** | 官方 README 实测配置 |
| FAH-L，加部位分割和接触 | **49 FPS** | 不能将 65 FPS 用于全功能模式 |
| FAH-L 因果视频 | **59 FPS** | 不等于世界坐标估计的速度 |
| 同一网络：直接回归 MANO 参数 → 预测点后拟合 | **6.79 → 4.09 mm** | PA-MPVPE 网格顶点误差，非 PA-MPJPE |
| HOT3D FAH-L 接触顶点 F1 / AP | **0.80 / 0.85** | 使用作者定义的 10 mm 近接触标签/测评协议 |

其他模型：FAH-S 5.25 mm / 101 FPS、FAH-B 4.57 mm / 89 FPS、FAH-H 4.12 mm / 27 FPS（HOT3D 单帧 PA-MPJPE，所列速度口径见官方模型表）。论文使用 HOT3D、ARCTIC、HACO 等数据，需区别协议与指标。

## 限制和边界

- **65 FPS 不是「所有模态、世界系端到端」速度**；开启分割、接触或世界相机估计，吞吐明显不同。
- PA-MPJPE 经过刚体 Procrustes 对齐，不能用 4.31 mm 证明世界空间绝对追踪达到同等毫米精度。
- 世界系结果高度依赖相机轨迹和尺度，遮挡时接触概率有歧义；「无需物体网格」限**推理阶段**，训练标签仍由物体几何生成。
- 官方公布代码、推理入口与权重，但外部 MANO、SAM 3D Body、数据集遵循各自授权；代码 Apache-2.0 不代表权重可商业使用。
