- **一句话说明：** Datawhale 面向中文学习者整理的 LLM 全栈实作课程，包含中文章节与 6 项代码作业，覆盖分词器、模型训练、GPU 优化、分布式训练、数据工程、推理、对齐与评测。

## 课程结构

依仓库 README，内容包括 BPE 分词器、Transformer 结构与训练细节、MoE、GPU 高性能编程、分布式训练、Scaling Laws、推理、数据处理、模型对齐、可验证奖励强化学习及多模态模型。6 项作业从手搓语言模型延伸到系统优化、扩展定律、数据处理、模型对齐和评估。

README 给出的先修要求包括 Python、PyTorch / 深度学习基础、线性代数、概率统计与微积分；GPU 编程基础是可选项。

## 与机器人学习的关联

它不直接教授机器人算法，但数据工程、Transformer、强化学习对齐、模型推理与多模态章节可作为 VLA / 具身基础模型的选读前置；具体路径应结合 [VLA 学习路线](../../roadmap/depth-vla.md)。
