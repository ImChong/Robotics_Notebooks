# 机器人关节方案选型

> 来源为作者个人观点的工程随笔（[原文](https://mp.weixin.qq.com/s/H6lbynQorK_kmf7oh5BHvw)，2026-10-03）。**数值为作者表述，未核实**；表中数值是作者给的行业典型区间，具体以厂家样本为准。

## 一句话定义

关节方案选型就是：先把负载谱、运动谱、精度与交互要求定义清楚，再从旋转、直线、力控三条线里挑出力学边界匹配的传动与集成方案；原理上不匹配的传动链，控制算法补偿不回来。

## 英文缩写速查

| 缩写 | 英文全称 | 简要说明 |
|------|----------|----------|
| RV | Rotary Vector（RV 减速器） | 行星一级加摆线针轮二级的两级减速器，刚性高 |
| QDD | Quasi-Direct Drive | 准直驱，低减速比（6:1~10:1）配高扭矩密度电机 |
| SEA | Series Elastic Actuator | 串联弹性执行器，靠测弹性体形变测力 |
| RMS | Root Mean Square | 均方根转矩，决定连续（热）工作能力 |
| GB/T | 国家推荐性标准 | 文中引用的减速器与台架试验标准前缀 |

## 为什么重要

关节同时承载动力、传动、感知与控制，整机运动性能、能效、重量和成本结构，很大程度在方案锁定时就定了。作者认为选型失败多半不是零件质量问题，而是输入没先定义清楚。

## 选型的三个输入与三类约束

| 输入 | 内容 | 对应约束 |
|------|------|----------|
| 负载谱 | 峰值转矩、连续转矩、加减速频率、占空比 | 转矩约束 |
| 运动谱 | 输出转速、加速度、循环次数、单循环转矩分布 | 热约束（热平衡与寿命，也关系反驱性） |
| 精度与交互 | 重复定位精度、空程、扭转刚度、力控带宽与精度 | 刚度与精度约束 |

只覆盖其中一条约束的计算是不完整的；常见现场故障是只算峰值转矩、把峰值当额定。精度与交互要求最容易被过度要求，也最容易被忽略。

## 四类旋转传动

- **谐波**：波发生器、柔轮、刚轮；柔轮比刚轮少两齿，波发生器转一圈输出前进两个齿距。单级 50:1~160:1，空程典型 ≤15 角秒，同减速比下最轻最小，杯形/礼帽形柔轮天然中空便于走线。代价：柔轮交变应力下疲劳是主导失效，额定寿命约 6000~10000 h，轻载效率明显偏低、重载约 70%~85%；不宜承受持续冲击，连续高速要单独核算温升与润滑脂寿命。作者结论：选谐波看精度与重量，不看转矩容量。
- **RV**：行星一级加摆线针轮二级。刚性极高、抗冲击强、同规格转矩容量高于谐波，回差 ≤1 角分，效率约 85%~92%，寿命 8000~15000 h；结构复杂、笨重、几乎不可反驱，摆线轮磨齿依赖专用设备（成本门槛，也是国产化最难一环）。工业六轴机型的 1/2/3 轴长期用 RV：大倾覆力矩与频繁启停，精度靠刚性而非控制补偿。
- **行星**：太阳轮、行星轮、齿圈，多行星轮分载。结构简单、效率 95% 以上（工业级约 97%）、成本低、寿命 2 万小时以上（四类最高）、供应链最成熟；短板是回差（普通约 8 角分，精密磨齿可压到 3 角分内），单级仅 3:1~10:1，高减速比需多级串联而变大。作者特别强调其反驱效率最高，是柔顺控制的基础，随力控需求与成本压力上升，行星在人形下肢方案中的位置在前移。
- **摆线针轮**：相当于只取 RV 的第二级，少齿差传动。减速比约 11~87，效率 90%~94%，过载能力可达额定转矩 5 倍；比同规格谐波重 30%~50%，适合重视刚性/承载/过载、不在意重量的位置。

| 类型 | 单级减速比 | 空程/回差 | 效率 | 典型寿命 | 反驱性 | 抗冲击 |
|------|-----------|-----------|------|----------|--------|--------|
| 谐波 | 50–160 | ≤15 角秒 | 70%–85% | 6000–10000 h | 低 | 中等 |
| RV | 30–260 | ≤1 角分 | 85%–92% | 8000–15000 h | 极低 | 优 |
| 行星 | 3–10（单级） | 3–8 角分 | 95%–97% | 20000 h 以上 | 最高 | 优 |
| 摆线针轮 | 11–87 | 1–3 角分 | 90%–94% | 10000 h 以上 | 低 | 优 |

读表原则：不要挑「参数最好的一列」，而要先确定该关节最不能牺牲的一项——底座不能牺牲刚性，腕部不能牺牲重量，下肢不能牺牲抗冲击与反驱性，其余指标在满足底线后可交换。

## 关节模组的集成层级

1. **无框力矩电机加自定义结构**：只有定子转子，集成自由度与扭矩密度最优，但壳体、轴承、散热、走线、工艺全自己做，周期最长。
2. **准直驱（QDD）**：减速比约 6:1~10:1，大尺寸高扭矩密度电机配低减速比；转子惯量不被大幅放大，反驱好、力透明度高、响应快；代价是单位重量输出转矩偏低、电机更大、热设计更重。
3. **一体化动力模组**：电机、减速器、编码器、驱动器、抱闸同壳，减速比多在 10:1 以上；开发量最小、可靠性验证充分、部署快，但结构自由度受限、单件成本高。

取舍是研发投入、单件成本、迭代速度三者；常见务实路径是原型期用一体化模组验证运动学与算法，量产期把关键关节换成定制方案。

## 力控关节的三条路

- **准直驱**：不用力矩传感器，靠电流环开环估计交互力。结构最简、带宽高、成本可控；力估计受摩擦、齿槽转矩、温漂影响，长时间保持姿态时电机持续发热。
- **SEA**：电机与负载间串弹性元件，测形变得力。力控精度高、抗冲击与缓冲好；代价是谐振、带宽下降、模型更复杂、长度增加。
- **刚性传动加关节力矩传感器**：精度最高、力控最好，但成本、结构复杂度、标定量最大，协作机器人关节长期走此路线。

判断依据是力控要求落在哪一档：只需碰撞检测与简单柔顺，准直驱足够；需要精确力跟踪与交互力控制，选 SEA 或刚性加力矩传感器。精度提高后成本非线性增长。

## 直线关节：丝杠取舍

- **梯形丝杠**：成本最低、可自锁，效率低、精度差。
- **滚珠丝杠**：精度与效率高，工业自动化成熟；承载集中在少数钢球，抗冲击有限。
- **行星滚柱丝杠**：多根滚柱分载，接触点远多于滚珠，推力密度、刚性、抗冲击更高，导程可更小，小电机即可出大推力；代价是滚柱齿形、螺纹磨削一致性、装配预紧都要求高工艺，价格是人形供应链里最难下压的环节之一。
- **反向式**（螺母旋转、丝杠直线运动）可使执行器更短更紧凑，适合空间受限的腿部。作者提到公开资料显示 Tesla Optimus 旋转关节用谐波、直线关节用行星滚柱丝杠（作者提及，未核实）。

直线关节优势：推力大、能耗低、部分方案可自锁，适合髋、膝、踝等承重关节；劣势：行程有限、冲击直接作用在螺纹副、反驱差、润滑防尘要求高。

## 七步选型计算链路

```
τ_load = m·g·L·cosθ + J_load·α + τ_friction
τ_peak,req = τ_load,peak × S_f            （S_f 建议 1.5 ~ 2.0）
i_opt ≈ sqrt(J_load / J_m);  J_reflected = J_load / i² + J_m
τ_m,peak = τ_peak,req / (i·η)  ≤ τ_m,peak,rated
τ_rms = sqrt( Σ(τ_k²·t_k) / Σ t_k );  折算到电机侧 τ_m,rms ≤ τ_m,cont
L ≈ L_rated × (τ_rated / τ_eq)³
```

1. **输出侧需求转矩**：含重力项、惯量项、摩擦项，再乘安全系数 S_f；S_f 不是越大越好，会推高电机与减速器规格和重量。
2. **减速比与惯量匹配**：让负载惯量折算到电机侧后与转子惯量同量级。减速比越高折算惯量越小，但反射刚度与反驱性变差；惯量比过大易超调振动，过小浪费电机转矩能力。
3. **电机峰值转矩校核**：效率随负载率、转速、温度变化，轻载低效是常态，不能用固定值长期近似。
4. **热校核**：连续能力由 RMS 转矩而非峰值决定，决定能否长时间保持姿态或连续往复。
5. **寿命校核**：谐波按输出转矩三次方近似换算寿命，作者称输出转矩每超额定 10%，寿命损失约 30%。
6. **回代刚度与精度**：算传动链总扭转刚度与折算空程，确认末端定位误差满足需求；谐波与摆线针轮空程可取样本值，行星多级需累加误差。
7. **热与润滑**：算连续运转稳态温升，确认润滑脂温度上限与寿命；多数早期失效与高温下润滑脂流失或变质有关。

## 台架验证与失效模式

- **标准（作者列举，未核实）**：GB/T 35089-2018（机器人用精密齿轮传动装置台架试验方法）；GB/T 30819-2024《机器人用谐波齿轮减速器》（2025-04-01 实施，代替 2014 版）；GB/T 37718-2019《机器人用精密行星摆线减速器》；GB/T 36491-2018《机器人用摆线针轮行星齿轮传动装置通用技术条件》。
- **台架六项**：空载摩擦转矩、传动误差曲线、空程与背隙、扭转刚度滞回曲线、效率与温升、振动与共振频率。其中刚度滞回曲线最能反映装配预紧状态，也是判断一致性的可靠依据。
- **失效对照**：

| 失效 | 成因 |
|------|------|
| 柔轮疲劳裂纹 | 冲击或长期超额定转矩；杯底裂后整机失效、不可修 |
| 齿面磨损、精度丧失 | 润滑脂高温流失、密封失效、粉尘侵入 |
| RV 摆线轮/针齿磨损 | 预紧不当或过载，回差随时间持续增大 |
| 行星级点蚀、断齿 | 齿面接触应力超限，多见多级串联末级过载 |
| 丝杠回程间隙增大、滚柱打滑 | 预紧衰减、润滑不足、侧向载荷超限 |
| 低速爬行、定位抖动 | 编码器分辨率不足、空程过大、增益与刚度不匹配 |

把这些失效模式提前写进验证大纲，比样机上反复试错便宜。

## 按关节部位的配置建议

| 关节部位 | 首选 | 备选 | 主要约束 |
|----------|------|------|----------|
| 工业机器人底座、大臂 | RV | 大规格摆线针轮 | 刚性、抗倾覆、抗冲击 |
| 工业机器人前臂、腕 | 谐波 | 精密行星 | 重量、精度、走线 |
| 协作机器人关节 | 谐波加关节力矩传感器 | SEA | 安全性、力控精度 |
| 四足与人形下肢旋转关节 | 行星、准直驱 | 谐波 | 抗冲击、反驱性、能效 |
| 人形直线承重关节 | 行星滚柱丝杠加无框电机 | 滚珠丝杠、梯形丝杠 | 推力密度、自锁、结构高度 |
| 灵巧手与小关节 | 微型行星、空心杯电机加行星 | 微型谐波 | 体积、成本、响应速度 |

同一台机器混搭是常态：全尺寸人形上肢用谐波保精度，下肢用行星或准直驱抗冲击，直线关节用行星滚柱丝杠换推力密度，是按工况分配重量与成本预算的结果，不是妥协。

## 三个常见的坑

1. **按峰值转矩选型，忽略占空比与热校核**：演示能出大峰值不等于能连续工作；热约束往往比转矩约束更早触顶。
2. **精度指标无限拔高**：末端精度需求决定回差与编码器分辨率的合理档位；过高则成本升而收益有限，过低则控制补偿吃掉开发资源。
3. **忽视反驱性与力控需求**：反驱性由传动原理决定，事后无法靠算法补救；凡将来可能涉及人机交互、柔顺装配或动态运动的关节，反驱性应在选型阶段作为一票项。

结论（作者）：关节方案没有最优解，只有与工况匹配的解；先定义负载谱、运动谱、精度要求，再让传动方案去满足，返工概率低于先定路线再找理由。
