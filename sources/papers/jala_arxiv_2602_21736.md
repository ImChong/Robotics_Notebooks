## 摘要与核心贡献

1. **绕开像素重建的荒野人类视频隐动作对齐（JALA）**：针对传统隐动作方法多依赖 VQ-VAE/光流帧间像素重构（易被背景/相机抖动主导）或无法融合显式 3D 动作标注的问题，基于 **InternVL3-2B** 提取第 19 层中间隐藏表征作为预测语义基底，使无动作标注的自然人类视频（in-the-wild）与实验室标注手部动作在同一隐动作空间内联合对齐。
2. **三大协同预训练机制（MCP + LAP + LSP）**：
   - **Masked Chunk Prediction（MCP）**：对带标注轨迹屏蔽动作块，学习标准手腕/关节预测表征；
   - **Latent Action Perceiver（LAP）**：利用强空间视觉编码器（DINOv3 / V-JEPA2）从起止边界帧 $(v_t, v_{t+\delta})$ 抽取结构化交互变化，通过 Perceiver 交叉注意力生成跨视角不变的连续/离散隐动作目标；
   - **Latent State Perceiver（LSP）**：引入 **非对称 EMA 目标编码器**（动量系数 $\alpha=0.999$）对齐未来隐状态预测与观测表征，完全摆脱像素级未来图像解码开销。
3. **UniHand-Mix 数据与 DiT 下游微调**：在 **UniHand-Mix（7.5M 样本：5M+ 实验室标定数据 + 2.5M Ego4D 野外第一视角视频，含 10% HaWoR 伪姿态）** 上预训练后，接 **16 层 DiT Flow-Matching 动作头**微调部署。
4. **实验效果**：
   - LIBERO 双视角 **96.9%** / 单视角 **92.3%**；RoboCasa Human **35.42%** / Syn **27.58%**；GR1 **26.33%**（大幅领先 Being-H0 `12.91%` 与 LAPA† `13.50%`）；
   - 真机 Franka FR3 + Inspire Hand 在 Wipe-Board Seen / Unseen 分别达 **83.3% / 80.0%**。
