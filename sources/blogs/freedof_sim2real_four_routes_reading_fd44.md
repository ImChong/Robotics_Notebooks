## 核心摘录（均出自原文）

- **四种立场（§1）：** 系统辨识正面求解可辨识性；DR 放弃辨识、以保守性换鲁棒；在线适应把推断推迟到运行时；残差学习不强求参数辨识、拟合修正项。省真机数据通常要用保守性去换；四者非严格互斥。
- **辨识（§2）：** 辨出的是任务相关「有效参数」；基参数只能成组辨识；腿足单关节线性化闭环模型中，惯量 / 阻尼 / PD 增益等可共同缩放而响应不变，正则化治不了根，常规做法是把 PD 增益设为已知；破尺度还可用力矩传感或称重 / CAD 惯量。PACE 参数集仅 5N+1 维（按文中描述：每关节 4 项 + 全局延迟），用 CMA-ES 拟合；四条实验约束（固定基座、避免接触、激励带宽、小 PD 增益）；PACE 报告 CoT 降 32%，该数字依赖具体配置。
- **DR（§3）：** 期望最优不等于 min-max；PACE 显示覆盖执行器 gap 所需随机范围随步频快速增长；闭环收窄（SimOpt）、后验采样（BayesSim）、贝叶斯优化、课程式扩展；PolySim 跨引擎随机化（MuJoCo 动作跟踪成功率比单引擎高 52.8%）；引擎接触模型差异会造成无法调参消除的误差。
- **在线适应（§4）：** UP-OSI / RMA / Transformer 历史；特权教师—学生；可辨识性被放松但未消失，估计失效时静默退化为 DR；教师—学生不消除动力学 gap。
- **残差（§5）：** 力矩层（执行器网络、残差网络、UAN 以 RL 学修正力矩）与动作层（Residual RL、ASAP delta action，跟踪误差最多降 52.7%，基线为作者自实现、仅动作跟踪）；残差只在训练数据覆盖分布内有效；MOSAIC 加性残差用于接口适配。
- **组合与查表（§6）：** 先辨识、再窄 DR、最后残差 / 适应；顺序不能反；组件越多验证越难；给出八行症状—对策表。
- **判据与监控（§7）：** 六条读论文判据；RAPT 部署期 OOD 检测（TPR 比最强基线高 37%，真机 89% TPR）；离线指标与硬件表现可能脱钩。
- **旁支与成本（§8–§9）：** 视觉 gap（SplatSim、GaussGym）、可微仿真（Schwarke，首个完全可微仿真训练并零样本迁移的腿足策略）；单张 4090 上 15 分钟训出人形 locomotion 策略，低敏捷任务上可用算力换辨识工作。
- **附录：** 电流仅对应电机侧力矩，不能当关节力矩真值；PACE 五条前提（运动学正确、驱动 LTI、温度依赖弱、非线性温和、结构刚度足够）。
