# Berkeley Humanoid 论文通读（开源人形硬件设计视角）

> 来源归档（原文通读 · 支撑 `wiki/entities/open-source-humanoid-hardware.md`）

- **标题：** Berkeley Humanoid: A Research Platform for Learning-based Control
- **作者：** Qiayuan Liao, Bike Zhang, Xuanyu Huang, Xiaoyu Huang, Zhongyu Li, Koushil Sreenath（UC Berkeley）
- **类型：** paper / humanoid-hardware
- **原文：** <https://arxiv.org/abs/2407.21781>（2026-11 通过 arXiv PDF v1 获取全文）
- **一句话说明：** 面向学习控制定制的 16 kg、0.85 m 中型人形：去除弹簧与闭链、QDD 执行器直接当关节，使仿真简单、sim2real 差距小。
- **核对范围：** 通读 §1–§7 正文（含 Table 1–3 平台/执行器/成本对比）与附录 A–D（奖励、跌倒次数、关节范围、域随机化表）；参考文献列表仅浏览，未逐条核对。未访问项目网站与视频。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **定位（§1–§2）：** 将人形按尺寸分为全尺寸 / 中型（儿童大小）/ 微型；全尺寸多用谐波减速器，为模型控制优化的弹簧连杆设计不利于学习；中型平台需要更高扭矩重量比与抗冲击性。
- **系统（§3.1）：** 16 kg、全电驱，躯干 + 双 6 DoF 腿（大腿 220 mm、小腿 180 mm、身高 0.85 m）；4 种自研执行器（5013 / 8513 / 8518 / 10413，行星减速 9:1，峰值扭矩 9.7 / 45.3 / 62.6 / 81.1 Nm）；EtherCAT 通信，1–4 kHz，延迟 0.5–2 ms；两条 4 DoF 臂设计过但本文未装。
- **仿真友好（§3.2）：** 去掉弹簧 / 阻尼 / 闭链；交叉滚子轴承使执行器可直接作关节，转子惯量用 armature 建模；仅 FFE 用线性连杆；在 A4500 GPU 上仿真 >90,000 步/秒。
- **可靠低成本（§3.3，Table 3）：** 7075 / 6061 铝 + SKD11 钢；空心轴走线减少线缆磨损；用约 1 美元级 ICM42688 IMU；无臂整机总成本约 9,955 USD（取整 ~10K）；计算机为 Intel i7-1255U，电池 DJI TB50。
- **实验友好（§3.4）：** 16 kg 使室内实验仅需 1 名操作员。
- **拟人（§3.5，附录 C Table 5）：** 每腿 6 DoF（含踝滚转）；关节范围对人体覆盖率 77.8%–100%。
- **控制器（§4.1）：** 极简 RL：无历史、无相位、无参考动作；MLP [512,256,128]+ELU，PPO，Isaac Lab；策略 50 Hz、状态估计 1 kHz、PD 25 kHz。
- **sim2real（§4.2，附录 D Table 6）：** 用 CAD 与单执行器摩擦实验得到窄范围域随机化（6 项动力学 + 8 项噪声）；不随机化电机强度 / PD 增益。
- **实验（§5）：** 全向行走、多种户外地形、平均 20° 陡坡山路、4 cm 台阶；校园步行 10 分钟 364 m；跟踪误差仿真 / 真机：前向 0.051 / 0.058 m/s，侧向 0.086 / 0.1156 m/s；双腿与单腿跳跃；全项目记录 38 次跌倒（附录 Table 4），仅 2 次损伤（螺丝松动与胶失效），多数 3–5 秒内复位。
- **局限（§6）：** 无手臂；关节范围、背隙、重量、强度待迭代；饱和扭矩附近的转矩–电流非线性需更细辨识，电机工作区与热保护应入仿真。
- **Table 1 对比：** 与 TORO / LOLA / Digit / H1 / G1 等对比腿长、重量、价格、扭矩与传动复杂度；本机 ~16 kg、~10K USD（无臂）。
