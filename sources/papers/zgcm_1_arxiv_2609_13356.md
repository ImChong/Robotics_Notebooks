## 已核实的初步信息

- 作者报告模型为从零训练的 7.39B 稠密模型，目标是数学推理与工具辅助搜索，上下文长度 256K。
- 仓库 README 描述约 4.19T token 预训练、约 600B token 中期训练，以及监督微调；最终发布模型使用 256K SFT checkpoint。
- 官方报告指出闭卷知识、严格指令遵循、通用软件工程与终端任务仍有限制；搜索与工具调用还依赖环境和协议稳定性。
