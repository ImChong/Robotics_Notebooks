# P-BFM: Perceptive Behavioral Foundation Models for Humanoid Control via Unsupervised Reinforcement Learning

- **类型：** paper
- **作者：** Xue Wang、Yitang Li、Yiming Zhang、Siqin Wang、Junhan Sun、Zhihao Liu、Yaojie Shen、Jingbo Yuan、Hao Zhao、Qingdu Li
- **机构：** 上海理工大学、清华大学、RoboPartyLab、浙江大学、哈尔滨工业大学

  - <https://arxiv.org/abs/2610.15833>

- **一句话说明：** P-BFM 用 forward–backward 表征编码跨地形共享的行为意图，再以深度感知策略在不同地形中实现同一意图；Explicit Root Instructions（ERI）额外给出朝向与平面速度指令，补足无监督学习中全局位移监督较弱的问题。

## 核心论文摘录（MVP）

### 1) 问题与主张：行为意图相同，不意味着执行动作相同
- **链接：** <https://arxiv.org/html/2610.15833v1#S1>
- **要点：** 传统 BFM 擅长复用全身行为，但在真实地形上，相同的意图（如向前走）需要随台阶、斜坡、障碍等环境约束改变抬脚高度、步幅、姿态、落脚点和接触方式。若靠地形匹配演示覆盖所有组合，数据空间会迅速膨胀。
- **映射：** [P-BFM](../../wiki/entities/paper-p-bfm.md) — 将“做什么”与“如何适应地形执行”分离。

### 2) 方法：地形无关意图 + 感知条件执行
- **链接：** <https://arxiv.org/html/2610.15833v1#S4>
- **要点：** Forward–Backward（FB）表征把动作参考、目标状态和奖励映射到共享意图 latent；后向表征只编码本体/身体状态，不接收地形信息，以保证同一意图跨地形一致。前向表征与策略则利用深度感知执行地形适配行为。训练时通过复杂地形中的在线仿真交互学习适配，而非提供地形专属动作演示。
- **ERI：** Explicit Root Instructions 将全局根运动拆为目标朝向和水平速度指令，与行为 latent 并列输入策略；局部全身动作仍由感知策略适应地形，避免出现朝向漂移或原地踏步。
- **映射：** [P-BFM](../../wiki/entities/paper-p-bfm.md) — 意图 latent 管行为目标，深度特征管环境约束，ERI 管全局移动方向与速度。

### 3) 训练与输入：演示提供先验，交互学习地形适应
- **链接：** <https://arxiv.org/html/2610.15833v1#S5>
- **要点：** Unitree G1 在 MJLab 中训练 1.92 亿环境步，使用 8 张 NVIDIA H200，约 10 小时。40 段平地 LaFAN 运动序列作为行为提示与判别器正样本，不合成地形专属动作参考。策略由本体历史、深度视觉特征、意图 latent、朝向和水平速度指令组成；部署时不使用训练特权信息。
- **感知处理：** 50 Hz 控制；缓存 37 帧深度图，按 5 帧间隔取 8 帧形成 0.7 秒视觉窗口；仿真中加入相机外参扰动和 0–1 帧时延随机化。
- **映射：** [P-BFM](../../wiki/entities/paper-p-bfm.md) — 复现时需留意低层控制频率、深度历史和特权信息训练/部署边界。

### 4) 评测与真机：一个冻结策略支持多种接口
- **链接：** <https://arxiv.org/html/2610.15833v1#S5>
- **要点：** 仿真覆盖平地、粗糙地面、上/下楼梯、平台、倒金字塔斜坡和箱体障碍等 7 类地形。论文报告对 994 段未见 SOMA 动作的评估；相较 UFO、PMT，P-BFM 在相应表格指标上取得较低关节误差/足滑、较高扰动恢复率。已见动作比较中 PMT 只有一条公开参考，而 P-BFM/UFO 使用 40 段 LaFAN，作者也提示覆盖并非完全匹配。
- **真机：** Unitree G1 + RealSense D435i；冻结策略以板载深度感知零样本迁移，演示动作跟踪、目标姿态到达、奖励推断、遥操作和地形感知扰动恢复。
- **边界：** 论文结论指出泛化仍受训练所见动作先验与地形多样性限制；复杂全身接触与更广动作数据仍是后续方向。代码仓库 main 分支已于 2026-10-22 前后发布 G1/RP1 训练、推理与 ONNX 导出代码（核查于 2026-10-27，详见 [项目页归档](../sites/p-bfm-project-page.md)）；预训练权重未随仓库提供。

## 相关路线
- 与 [BFM-Zero](../../wiki/entities/paper-bfm-zero.md) 同属 FB + 无监督 RL 的人形行为基础模型路线；P-BFM 的关键扩展是深度感知地形适应与 ERI。
- 与 [Perceptive BFM](../../wiki/entities/paper-perceptive-bfm.md) 区分：两者均面向感知条件全身控制，但 P-BFM 以地形无关意图空间、FB 学习和 ERI 为核心。
- 与 [I-BFM](../../wiki/entities/paper-i-bfm.md) 并读：I-BFM 将对象动力学/接触引入行为空间，P-BFM 聚焦地形适应与全局根运动指令。
