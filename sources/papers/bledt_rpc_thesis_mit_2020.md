# Regularized Predictive Control Framework for Robust Dynamic Legged Locomotion

> 来源归档

- **标题：** Regularized Predictive Control Framework for Robust Dynamic Legged Locomotion
- **类型：** paper（PhD thesis）
- **作者：** Gerardo Bledt
- **机构：** MIT
- **链接：** https://dspace.mit.edu/handle/1721.1/125485
- **年份：** 2020
- **入库日期：** 2026-07-25
- **一句话说明：** Bledt 博士论文：提出 **Regularized Predictive Control（RPC）** 框架，系统化正则启发式以提升动态腿足鲁棒性；后续 ICRA 2020 启发式提取论文与 Mini Cheetah Vision 导航系统以此为控制内核之一。
- **开源状态：** 论文 PDF 经 MIT DSpace 公开；实现能力主要沉淀于 Cheetah-Software / 后续 RPC 论文实验。
- **沉淀到 wiki：** [paper-bledt-rpc-thesis](../../wiki/entities/paper-bledt-rpc-thesis.md)

---

## 核心贡献（摘录）

1. 把「难调的预测控制代价/启发式」上升为可正则、可学习的系统方法。
2. 为 Mini Cheetah 高动态与外感知导航提供 RPC 控制内核叙事。
3. 与 *Extracting Legged Locomotion Heuristics with RPC*（ICRA 2020）直接衔接。
