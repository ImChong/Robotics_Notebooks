# Infinigen 官方项目页

- **标题：** Infinigen：Infinite Photorealistic Worlds Using Procedural Generation
- **类型：** site
- **项目页：** <https://infinigen.org/>
- **官方文档：** <https://infinigen.cs.princeton.edu/docs/latest/Infinigen2.html>
- **机构：** Princeton Vision & Learning Lab（普林斯顿大学视觉与学习实验室）
- **代码：** <https://github.com/princeton-vl/infinigen>
- **关联论文：** [Infinigen CVPR 2023](https://arxiv.org/abs/2306.09310)；[Infinigen Indoors CVPR 2024](https://arxiv.org/abs/2406.11824)
- **入库日期：** 2026-10-17
- **一句话说明：** Infinigen V2 是面向 Blender 的程序化 3D 场景生成系统，通过 Python 可控的生成器构造多样化室内外场景、物体与材质，可用于合成视觉数据和仿真场景原型。

## 项目页与源码开放核查（2026-10-17）

- **开放程度：已开源。** 项目页指向官方公开仓库；仓库包含生成器、示例与文档，许可证为 BSD-3-Clause。
- **数据：** 官方 README 的文档索引包含「下载预生成数据」说明；项目主入口是场景生成代码，本次未找到独立托管的 HF 数据集仓库。
- **版本判断：** 官方 README 与文档入口标注 Infinigen V2。社媒截图提到「一分钟生成」；本次核查未找到对应的官方性能基准，因此不把该速度作为可复现保证。
