## 开源状态（截至入库日）

- **已公开：** Benchmark 代码（MIT，第三方组件另遵各自许可）、训练示范数据、Leaderboard 与部分模型诊断卡。
- **条件：** 官方 README 的运行说明要求 Isaac Sim 5.1、Python 3.11、独立下载并核对匹配 Git commit 和 SHA256 的版本化资产 snapshot；不能仅克隆 GitHub 即运行所有实例。
- **尚待发布：** README 的 Release checklist 将 **Mind2Act Mini World** 和外部提交 Agent 的新榜单标为未完成；官方 docs/submission.md 表示提交细则待公布。不同于目前已经开放的基本代码与训练数据。
