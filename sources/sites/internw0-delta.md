## 页面展示内容

- 项目自述为将视觉动力学和机器人动作联合学习的 embodied world model，Causal Imprint 捕获对动作相关的未来场景变化。
- 页面章节：Demos、Data、Method、Results、Resources。
- 方法摘要突出独立视频/动作专家、mask interaction、Causal Imprint、训练期 4D-aware representation distillation。
- 基准展示 LIBERO-Plus、RoboTwin、RoboDojo、EBench；页面说明结果图坐标轴从零开始，RoboDojo 图表范围为 0–30%，其他面板 0–100%。
- 资源栏列论文、代码和模型集合；页面当前将 **source code** 和 **model checkpoints** 状态分别显示为 “Forthcoming”。截至核验时，GitHub 仓库实际已公开代码，但 README 仍称模型权重 forthcoming；因此权重状态以实际发布资产为准，未把“项目页 code forthcoming”误读为完整项目未开源。
- 页脚说明作者均隶属 Shanghai Artificial Intelligence Laboratory。
