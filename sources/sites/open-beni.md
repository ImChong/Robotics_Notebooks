## 项目页观察

Hugging Face Space 提供可交互的在线游戏入口。官方 GitHub README 将该 Space 标注为部署版本，并将代码开发与贡献入口指向 Mondo-Robotics/open-beni。仓库同时包含 BENI 的 URDF/MJCF、PPO 训练源码、策略与运动数据、ONNX/MNN 导出工具，以及 MuJoCo + ONNX 浏览器游戏。
