## 研究问题

预训练动作条件视频世界模型主要见到专家成功演示，面对真实策略的失败、接触、滑动和可变形物体动力学时偏乐观。真机在线数据宝贵；VLAW 用有限真实成功/失败 rollout 校准 Ctrl-World，再在想象环境中生成更多轨迹，以 Qwen3-VL 奖励模型筛出成功视频监督 VLA。

## 方法：论文 §3–4

1. 当前 π₀.₅ 执行真机 rollout，收集带二元任务成功标签的真实数据（含失败）。
2. 基于 Ctrl-World 视频扩散模型联合后训练：L_WM = L_Dreal + λ L_DROID，保留原 DROID 防遗忘（Eq. 1–2）。
3. 首轮用真实成功标签微调 Qwen3-VL-4B-Instruct 轨迹奖励模型；对生成视频按 p(yes | 轨迹, 指令) > α 判断成功（Eq. 3），附录 C 采用 α=0.8。
4. 真实初始观测 → π₀.₅ 动作 → WM 未来多视角观测 → π₀.₅ 下一步动作，闭环生成合成轨迹，成功部分为 D_syn+。
5. 真实与合成成功轨迹联合做加权 flow-matching 策略监督，失败样本权重置零（Eq. 4）；§4.3 / 附录 A 给出正则化 RL / AWR 视角，而非直接 PPO 或在 WM 反向传播。
6. 新策略再进入真实环境收集数据并更新世界模型和策略，共两轮（Algorithm 1）。

## 实验事实与评测口径

- DROID / Franka Panda 单臂 + Robotiq，2 个第三视角、1 个腕部视角；五任务：堆积木、擦除标记、开书、舀取、画圆。
- 每任务 25 条专家轨迹初始化；每轮每类 50 条真机 rollout、500 条想象轨迹；WM 更新 50K steps；策略更新 2K steps、batch 256。
- 主论文 Table 1：仅专家数据 WM → 混入真实在线 rollout，FVD 99.98 → 64.12，50 个接触事件里的失败误判成功 11 → 1。
- 附录 B Table 2：五任务平均真实成功率 Base **46.0%**、Filtered BC-2 **75.2%**、VLAW-2 **86.8%**。表格可复算真实初始→VLAW **+40.8 个百分点**，合成轨迹相对 Filtered BC-2 **+11.6 个百分点**。
- **论文数字不一致：** Abstract 宣称相对 base **+39.2 个百分点**，和附录 B Table 2 的 46.0→86.8（**+40.8**）并不相等；应分别带出处引用，不能误作相同结果。
- 附录 C：奖励模型使用 16 帧、训练 200 steps、batch 128；在 40 个标注视频上高阈值 FP 8→2，却令 FN 7→12，存在漏掉真实成功的代价。
