## 核心摘录

1. **动机：** flow policies 可从示教中学连续机器人动作，但还需 RL 从交互中改进，或从零训练。
2. **算法：** 在线 off-policy QF3 将 flow matching 与 critic action gradient 结合，通过 flow 一步预测反传梯度。
3. **过滤条件：** 只有在预测动作某一维仍接近 replay action 的维度上施加 critic gradient，以限制 critic 不可靠外推。
4. **人形实验：** 论文报告从零训练离策略 humanoid locomotion 与 motion tracking，并 zero-shot transfer 到 hardware。
5. **速度报告：** 配合 high-throughput recipe，相对 FPO++ 报告约 10× wall-clock 加速。
6. **操纵实验：** 在 ABC-Sim 和 Robomimic 上 fine-tune 预训练 flow policy。
