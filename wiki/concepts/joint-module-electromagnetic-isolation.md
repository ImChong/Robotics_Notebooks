# 关节模组电磁隔离

> **本页定位**：[Zane Hub《机器人关节模组电磁隔离有哪些方式？》](https://mp.weixin.qq.com/s/9_KTmC4yzqRrBEo95Sf4Uw)（2026-10-14）的要点整理。原文是作者个人观点的工程随笔，**数值为作者表述，未核实**；本页不添加原文以外的事实。

## 一句话定义

**关节模组的电磁隔离不是「接好线、壳体接地」，而是按干扰源、传导、辐射、磁场、滤波分层设计的一套方法：隔离切断传导，屏蔽阻挡辐射，磁屏蔽针对静磁 / 低频磁场，三者不能互相替代。**

## 英文缩写速查

| 缩写 | 英文全称 | 简要说明 |
|------|----------|----------|
| EMC | Electromagnetic Compatibility | 电磁兼容 |
| PWM | Pulse Width Modulation | 驱动板以十几到几十 kHz 开关，是主干扰源 |
| dv/dt | Voltage change rate | 开关电压变化率；文中称 IGBT 可达数 kV/μs，SiC 数十 kV/μs |
| CMTI | Common-Mode Transient Immunity | 共模瞬态抗扰度，隔离器关键指标 |
| CTR | Current Transfer Ratio | 光耦电流传输比，随温度和老化衰减 |
| SE | Shielding Effectiveness | 屏蔽效能，单位 dB |
| FOF | Fabric Over Foam | 导电布包裹发泡芯的导电泡棉 |
| CISPR | Comité International Spécial des Perturbations Radioélectriques | 无线电骚扰国际特别委员会，CISPR 11 为工科医设备骚扰限值 |

## 为什么重要

- 直径 50~80 mm 的圆柱内同时有无框力矩电机、减速器、编码器、驱动板、力矩传感器，有的还带抱闸；PWM 强电与毫伏级编码器 / 力矩传感器信号共享不到 2 mm 的屏蔽空间。
- 干扰最终表现为三类失效，也是 EMC 的验收对象：
  - **编码器误码与抖动**：位置环丢计数，低速、高增益时最明显；
  - **通信丢包**：EtherCAT / CAN / 串行链路误帧率上升，触发看门狗甚至断链；
  - **轴承电蚀**：油膜约 0.2~2 μm、介电强度约 15 V/μm，故 3~30 V 轴电压即可放电，滚道出现微坑，噪声、温升增大，寿命骤降。
- 结论：隔离要在设计阶段做成默认选项；测试不过再补，成本高数倍且空间往往已不允许。

## 干扰源与传播

| 干扰源 | 机理 |
|--------|------|
| PWM 逆变器 | 三相桥输出阶跃电压；共模电压近似 `V_cm ≈ (Va + Vb + Vc) / 3`，在母线电压上下摆动，经定子绕组—转子—机壳寄生电容形成共模电流回路，既是传导干扰主因，也是轴承电蚀元凶 |
| 无框力矩电机 | 绕组端部长、匝数多，端部漏磁与寄生电容大，同时放大磁场与电场耦合 |
| 抱闸 | 感性负载通断，反电动势与电弧，频谱从几十 kHz 到几百 MHz |
| 开关电源与母线 | 48 V 降到 5 V / 3.3 V / ±15 V，开关频率 100 kHz~2 MHz，经电源 / 地网络耦合到模拟前端与编码器接口 |

## 传导路径隔离

原则：不共地、不共享回路。

- **信号隔离**：编码器、力矩传感器、霍尔信号进 MCU 前先隔离。
  - 光耦：CMTI 通常低于 15 kV/μs，CTR 随温度与老化衰减。
  - 数字隔离器：CMTI 普遍 25~100 kV/μs，时延抖动小、无 LED 老化；选型看隔离耐压（2.5 / 5 kVrms）、CMTI、速率、传播延迟、通道方向、供电方式。
  - 适用：增量 ABZ、BiSS、多摩川等编码器接口、霍尔换相、故障回读；多摩川等双向串行口应选双向通道器件，而非两颗单向硬拼。
- **电源隔离**：隔离 DC-DC（常见 1~3 W、隔离电压 1.5~5 kV、开关频率数百 kHz）给隔离侧器件独立的地和电源，选型还要看隔离电容——越小，跨隔离栅共模电流越小。隔离运放用于力矩传感器、母线电流采样等毫伏级模拟量，关键参数为隔离耐压、增益温漂、CMTI。
- **总线隔离**：关节间 / 关节到控制器的长线缆最易引入外部共模。CAN（ISO 11898）隔离收发器要与隔离电源成对使用；EtherCAT 的 PHY 自带变压器隔离，但连接器屏蔽地与信号地的处理仍不能省。
- **铁律**：隔离之后两侧的地必须在隔离栅之外各自单点回归，不能「上游隔离、下游又连通」。
- **接地架构**：
  - 星形接地：设备、金属框架、控制箱、机器人底座接到同一星形点再接工厂地；
  - 底座搭接：阳极氧化层绝缘，须用专门搭接点保证低阻连接；
  - 末端工具：ESD 高发场景把末端执行器与法兰电气绝缘并单独接地；
  - 电缆间距：不同电缆至少 100 mm，并远离线圈、电机与频繁通断设备——间距是最廉价的隔离。

## 辐射路径屏蔽

屏蔽效能定义：`SE = 20·lg(E0 / E1)` dB（E0 无屏蔽场强，E1 有屏蔽场强）。铝壳对电场和平面波靠反射 + 吸收，对高频磁场靠涡流，对低频磁场效果差。

**真正的漏洞是缝隙、开孔、连接器**：缝隙长度接近干扰半波长时 SE 急剧下降，处理原则「分段、加密、导电搭接」，重点是壳体接缝、端盖、线缆进出口。

导电泡棉 / 衬垫（FOF、全导棉、SMT 泡棉）：填充 0.5~2 mm 装配公差缝，建立连续导电通路并吸振。不用铜箔（无弹性、振动失效）和铍铜弹片（持续振动易疲劳断裂）。

| 位置 | 做法 |
|------|------|
| 驱动板接地点—壳体 | SMT 泡棉，可回流焊，最小约 1.2 mm × 1.2 mm，硅胶芯吸振 |
| 编码器周围近场 | 全导棉，0.1~0.3 mm 微压缩即低阻导通，对码盘压力小 |
| 连接器法兰—壳体 | 环形泡棉，360° 环接 |
| 线缆进出口 | 环形 / 异形泡棉，保证穿墙处屏蔽层连续 |

工作压缩率通常 25%~30%，回弹率宜大于 90%；持续运动优先硅胶芯，温度范围可达 -40~150 ℃。

**线缆与屏蔽层接地**
- 电机三相线用屏蔽线，屏蔽层尽量两端 360° 端接，不用「猪尾巴」单点；
- 编码器 / 传感器线双绞加屏蔽，屏蔽层通常在驱动器侧单点接地，避免两端接地形成地环；
- 动力线与信号线分开走线，避免长距离平行；
- 一般原则：低频、电场为主用单点；高频或共模电流大时两端 360° 端接更有效；PCB 经多点导电泡棉与壳体搭接即典型多点接地。

## 磁隔离与磁屏蔽

磁编码器靠检测磁场变化取角度，对杂散磁场天然敏感；干扰来自电机端部漏磁、抱闸线圈、相邻关节磁场及外部强磁环境，另有磁钢与读头气隙、偏心及轴电流感应轴电压。

- **坡莫合金屏蔽罩**：原理是「磁分路」，给干扰磁力线一条低磁阻旁路。镍铁系，镍含量通常 45%~80%，高磁导率、低矫顽力。SE 与厚度、层数、开口、热处理相关；经验：尽量包住敏感区、开口越小越好；多层且内外层开口错开，优于单纯加厚单层。
- **磁屏蔽 ≠ 电磁屏蔽**：坡莫合金对高频电磁波一般，铜铝对静磁场几乎无效，「加一层铝壳」治磁编码器受扰往往无效。
- **磁路闭合**：让磁钢与读头间磁路尽量闭合、气隙稳定，从源头降低敏感度。
- **双编码器冗余**：电机端与关节输出端各一个，既提分辨率、补偿减速器误差，也能交叉校验发现单个编码器受扰。

## 滤波

「最后一道防线」，性价比最高；位置越靠近干扰源或受扰设备越好。

- **共模电感**：对共模高阻、对差模低阻，置于母线输入与电机三相输出，关节内常用 2 mH~50 mH 量级，取决于噪声频段与额定电流。
- **X 电容**（相间，抑差模）；**Y 电容**（相—地，抑共模）：受漏电流安规限制，须与共模电感配合；过大会超标，还可能与轴承共模回路构成新低阻路径。
- **铁氧体磁环 / 磁珠**：高频呈电阻性、吸收转热，主要抑几十 MHz 以上；电缆穿绕两次阻抗约提高到 4 倍；对低频无效、饱和失效、外置影响外观与防护等级。
- **馈通滤波器**：装在壳体穿墙处，滤波与穿墙合一，减少长引线泄漏。
- **电机出线滤波器 / 输出电抗器**：抑 dv/dt 与共模电流，对轴承电蚀有直接帮助。
- **编码器信号线端**：共模扼流圈或 RC 网络。

## 标准与限值

整机随 CE / EMC 认证，设计阶段就应把限值当目标。原文列出：

- IEC 61800-3（调速电力驱动系统 EMC，区分第一 / 第二环境，发射分 C1 / C2 / C3，第二环境抗扰度要求更高）；
- IEC 61000-6-2 / 6-4（工业环境抗扰度 / 发射通用标准）；CISPR 11（ISM 设备射频骚扰限值）；
- 国内对应 GB/T 17799 系列、GB/T 18268 等。

标准只是「合格线」，空间紧凑、干扰源密集的关节模组实际要留更宽的设计余量。

## 常见误区与案例

1. 把隔离、屏蔽、磁屏蔽混为一谈；
2. 隔离后两侧地又连通（「白隔离」：器件没坏，效果为零）；
3. 屏蔽层两端接地形成地环，反引入低频干扰；
4. 只屏蔽电机，忽视编码器近场（电机是源，编码器是靶）；
5. 忽视装配公差造成的缝隙——超差常出在壳体接缝而非电路。

案例（原文描述）：整机 30~100 MHz 辐射发射超差，排查发现壳体接缝原用的导电橡胶在振动与老化后变形、缝隙重现；改用高回弹导电泡棉并改善搭接后该频段明显下降。共性：失效往往不是「没有屏蔽」而是「屏蔽路径断了」。

## 选型速查（原文表格压缩）

| 层次 | 主要方式 | 重点参数 |
|------|----------|----------|
| 传导—信号 | 双向数字隔离器、光耦、隔离放大器 | CMTI、隔离耐压、速率、增益温漂 |
| 传导—电源 | 1~3 W 隔离 DC-DC | 隔离电压、隔离电容、功率 |
| 传导—总线 | 隔离 CAN / EtherCAT 收发器 | 隔离耐压、总线故障保护 |
| 辐射—壳体 | 铝壳 + SMT 泡棉 / 全导棉 | SE、缝隙处理、压缩率 |
| 辐射—线缆 | 编织屏蔽线、360° 端接、环形泡棉 | 端接方式、走线间距 |
| 磁—屏蔽罩 | 坡莫合金 | 磁导率、厚度层数、开口 |
| 磁—冗余 | 电机端 + 关节端双编码器 | 分辨率、交叉校验 |
| 滤波 | 共模电感、X/Y 电容、铁氧体、馈通 | 频段、漏电流、饱和 |
| 接地 | 星形点、单点接地 | 搭接电阻、地环路 |

## 设计清单（按原文结语归纳）

- 接口默认考虑隔离；壳体默认考虑搭接；编码器默认考虑磁屏蔽；母线默认考虑滤波；
- 每一层都要与结构、热管理和安规协同设计，而不是堆叠单个器件。
