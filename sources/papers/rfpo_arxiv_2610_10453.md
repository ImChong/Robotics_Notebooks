# RFPO 论文来源归档

- **题目：** *RFPO: Rectified Flow Policy Optimization for Embodied Control*
- **arXiv：** https://arxiv.org/abs/2610.10453
- **HTML v1：** https://arxiv.org/html/2610.10453v1
- **项目页：** https://aigeeksgroup.github.io/RFPO/
- **作者：** Ting Huang, Lisiyu Pan, Haoyu Wang, Zeyu Zhang, Siyuan Qian, Yanjun Li, Yandong Guo, Boxin Shi, Hao Tang
- **机构：** Peking University；AI Robotics
- **提交日期：** 2026-10-07
- **官方代码：** https://github.com/AIGeeksGroup/RFPO

## 论文要点

RFPO 处理具身 flow policy 的 few-step discretization gap：标准向量场在较多 ODE 积分步下可以达到较好控制表现，但直接将推理缩短至极少步会降低回报。论文提出 reward-aware online reflow，配合多预算动作蒸馏；冻结的 Gaussian PPO 控制器提供动作空间监督与回报参照，学生同时学习完整预算和中间预算的控制动作。另加入零噪声初始化等训练设计与自适应计算正则。部署目标是单次 Euler 更新。

## 论文报告结果

- 论文评测 Go2、Spot、H1、G1；报告在不同初始条件下 1-step return 与 64-step 对照相差不超过 2.4%。
- Go2 上单步策略保留 64-step policy 的 98.5% reward。
- Go2 平均 onboard inference latency 从 4.39 ms 降至 0.08 ms（54.9×）。
- 报告真实机器人稳定单步 locomotion 演示。
- 指标只描述论文的机器人与评测协议，不表示任意 flow policy 都可无损降为一步。

## 资料边界

仓库 README 描述的是 Isaac Lab locomotion / manipulation 实验代码并注明不包含 deployment packages。论文中涉及 Spot、H1 的评测不应误写为 GitHub 仓库均提供可部署实现。详见[代码归档](../repos/rfpo.md)。
