# CompactSplat 项目主页

> 来源归档（ingest · 官方项目页核查）

- **标题：** CompactSplat: Spatially Adaptive Gaussian Distribution for Feedforward Scene Reconstruction
- **类型：** site / project-page
- **官方入口：** <https://hebing-sjtu.github.io/CompactSplat-website/>
- **论文：** NeurIPS 2026 Poster；<https://arxiv.org/abs/2610.13177>
- **代码：** <https://github.com/hebing-sjtu/CompactSplat>
- **权重：** <https://huggingface.co/binghe-sjtu/compactsplat>
- **机构：** 上海交通大学（Shanghai Jiao Tong University）
- **入库日期：** 2026-10-23
- **一句话说明：** 稀疏视图前馈场景重建，以纹理驱动的空间分区和多尺度高斯属性采样，降低平坦区域的高斯冗余，并支持推理时稀疏度调节。
- **开源状态（2026-10-23 核查）：** 官方页面与代码仓指向公开 GitHub 实现，仓库包含模型、训练和评估代码；预训练模型另由 Hugging Face 发布。README 说明当前实现配置与论文设置存在差异，复现时应以论文和仓库 reproducibility notes 逐项核对。
