2. **周报所述问题：** 人类操作示范能够提供动作信息，但机器人还需要学习接触发生的位置和方式，才能准确执行灵巧操作。

4. **arXiv 摘要（英文节选）：** Human demonstrations offer an efficient and scalable source of data for dexterous robot manipulation, but differences in sensing and hand morphology complicate the transfer of contact-rich interactions. We present TouchBridge, a hardware--software co-designed framework for human-to-robot data transformation. A wearable human demonstration interface and a corresponding robot interface establish cross-embodiment correspondence in visual and fingertip tactile sensing.
