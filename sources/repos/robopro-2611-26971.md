## 已核实的源码入口

- [README](https://github.com/robopro-bench/RoboPRO/blob/main/README.md)：SAPIEN 3.0.0b1、CuRobo v0.7.8、Aloha-Agilex，基于 RoboTwin 2.0。
- [eval/README.md](https://github.com/robopro-bench/RoboPRO/blob/main/eval/README.md)：固定评测种子、单进程与双进程模式，支持冻结场景包。
- [eval_double_env.sh](https://github.com/robopro-bench/RoboPRO/blob/main/policy/pi05/eval_double_env.sh)：启动隔离 Python 环境的策略服务器和仿真客户端，socket 通信。
- [eval_policy_client.py](https://github.com/robopro-bench/RoboPRO/blob/main/eval/eval_policy_client.py)：setup_demo、set_instruction、get_obs、eval_func、get_collision_metrics；输出 _episodes.jsonl。
- [policy_model_server.py](https://github.com/robopro-bench/RoboPRO/blob/main/eval/policy_model_server.py)：接收序列化的 cmd 与 obs，调用模型方法并返回结果。
- [deploy_policy.py](https://github.com/robopro-bench/RoboPRO/blob/main/policy/pi05/deploy_policy.py)：三路 RGB 与关节状态编码，set_language、update_observation_window、get_action、take_action。
- 官方 README 提供 π₀.₅ [checkpoint](https://huggingface.co/mzxuan/robopro_jax_30000) 与 [X-VLA checkpoint](https://huggingface.co/mzxuan/x-vla-robopro-100k)。

## 复现入口

按官方 README 安装依赖、下载资产、初始化 openpi 子模块和独立 venv 后，在根目录执行：

```bash
source set_env.sh
bash policy/pi05/eval_double_env.sh put_mouse_on_pad bench_demo_office_clean my_office_train pi05_ckpt 30000 0 0
```

配置与模型目录须与本地权重一致。源文件已静态核对，未执行 GPU rollout；碰撞指标关闭或任务未实现目标对象接口时，记录为 null，不能视为无碰撞。
