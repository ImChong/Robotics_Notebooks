## 文章要点（作者表述）

- **前提：** MIT 模式靠高 Kp、临界阻尼 Kd、完整前馈 τff 让关节功能上逼近位置伺服；它不是 CSP，没有位置环积分，静差靠 τff 消除。
- **顺序：** 先 τff → 再 Kp → 最后 Kd；顺序反了，高 Kp 会把重力静差放大成持续力矩，发热、噪声，被误判为参数问题。
- **τff = τg(q) + τf(q̇)：** 重力项用多姿态静态悬浮标定或 Pinocchio `rnea(q,0,0)`，验收是 Kp=Kd=0 时任意姿态手松不下掉；摩擦项各关节多速度匀速实验线性拟合 fc、fv，验收是 1°/s 无爬行、换向无停滞。理由：缺 0.1 N·m 的 τg，在 Kp 下产生约 0.1/Kp rad 稳态偏差。
- **Kp：** 空载单关节 1°~2° 阶跃，从 Kp ≈ J_eff·ω_target²（ω_target 取期望带宽的 2~3 倍）起，向下找刚出现高频振荡或嗡鸣的 Kp,crit，取 0.6~0.7 倍；同时看电流噪声；中小关节经验量级几十到几百 N·m/rad。
- **Kd：** Kd ≈ 2ζ√(Kp·J_eff)，ζ = 0.9~1.1；有超调加 Kd、太钝减；Kd 过大引入相位滞后、降低内环带宽；不要用 Kd 压 Kp 过大造成的振荡。
- **双俯仰 J5、J6：** 惯量耦合，J5 的 Kd 按最不利姿态（工具伸出最远）整定；重力前馈按 τg5(θ5,θ6)、τg6(θ5,θ6) 联合计算。
- **五项验证：** 单关节阶跃（超调 < 5%、稳态误差 < 0.05°、0.2~0.5 s 内达 95%）；1~5 Hz 扫频看谐振峰；整臂空载轨迹（误差 < 0.1°~0.2°，30 min 外壳 < 60 °C）；贴合（恒力波动 < ±0.5 N）；扰动恢复。
- **曲面：** 内环参数不随曲面切换，由外环导纳吸收；J_eff 变化超过 ±20% 才可能需要增益调度（按 θ5 分 3~5 段线性插值）；换清洁模组需重做负载辨识更新 τff 与 J_eff；调度变量必须平滑连续，不能按曲面类型离散切换。

## 本库核对

- **公式自洽（Python / 手算）：** Kp = J·ω² 即 ω_n = √(Kp/J)；Kd = 2ζ√(Kp·J) 在 ζ = 1 时对应临界阻尼；稳态偏差 Δq = Δτ/Kp。例：J = 0.05 kg·m²、期望带宽 5 Hz（ω = 31.4 rad/s）得 Kp ≈ 49 N·m/rad、Kd ≈ 3.1 N·m·s/rad，量级与文章「几十到几百」一致（示例数字为本库代入，不是文章数据）。
- **文章验收口径内部有张力：** 缺 0.1 N·m 重力项、Kp = 100 N·m/rad 时静差 ≈ 0.057°，已超过文章自己的 < 0.05° 验收线；Kp = 300 时 ≈ 0.019°。说明验收线实际靠前馈完整度而不是 Kp 保证。
- **J_eff ±20%：** ω_n 与阻尼比都按 1/√J 变化，约 +12% / −9%，与「超过 ±20% 才考虑调度」的经验相容；数值是本库推算。
- **与本库已有整定页的顺序不同：** [MIT 关节阻抗模式参数整定](../../wiki/methods/mit-joint-impedance-mode-tuning.md)（同一公众号系列的前一篇）的流程是 Kp（Kd = 0、τff = 0）→ Kd → τff，并给了 J5→J3→J1→J2→J6→J4 优先序；本文是 τff → Kp → Kd。两者验收标准（< 0.05°、1°/s 无爬行、30 min < 60 °C）相近。两个顺序哪个更好没有实验对比，不能当结论。
- **CSP 是什么（供应商手册，非标准原文）：** CiA 402 驱动器行规里的循环同步位置模式：主站按固定周期下发绝对目标位置（对象 607Ah，模式 6060h = 8），驱动器内部跑位置环，可在 60C2h 插补周期内插补。「CSP 没有位置环积分」文章没给出处；各厂驱动器内部位置环结构不同，本库未核。检索未取到 IEC 61800-7-201 / CiA 402 规范原文。
- **MIT 模式公式** τ = Kp(q_des − q) + Kd(q̇_des − q̇) + τff 来自 Katz 等的 Mini Cheetah 执行器，见 [Katz 低成本模块化执行器](../../wiki/entities/paper-low-cost-modular-actuator-katz.md)；本库这次没重读原论文。
- **阈值全部是作者经验值**（5%、0.05°、0.2~0.5 s、±0.5 N、60 °C、60~70%）：没有实验数据、驱动器型号、减速比或 J_eff 数值，不能当通用标准。
