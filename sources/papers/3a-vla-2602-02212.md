## 核心摘录（方法级，不等于全文核验）
- **研究问题：** 三维游戏中，高维观测、语言目标与离散动作存在语义粒度落差。
- **主要机制：** 游戏场景与文字任务 → 意图抽象形成高层目标 → 环境语义抽象表达状态 → 抽象对齐动作学习 → 输出游戏操作动作。
- **实验范围：** 原文采用 Minecraft 和 Game for Peace 等三维游戏环境评估代理；不应将游戏成绩称为真机操作成功率。
- **主要限制：** 三维游戏的动作空间和物理交互与真实机器人的接触、时延约束不同。
