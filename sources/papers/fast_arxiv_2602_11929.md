## 摘要与核心贡献

1. **单阶段 MoE + CoM-Aware 全身控制预训练**：摒弃繁琐的多专家离线微调 + 教师学生 DAgger 蒸馏，直接在 29-DoF Unitree G1 上端到端单阶段训练基于 **12 专家混合架构（12-expert MoE）** 的 PPO 通用跟踪策略；引入两阶段自适应动作裁剪与难例运动重采样。
2. **质心感知控制（Center-of-Mass-Aware Control）**：将质心（CoM）与压力中心（CoP）物理关系引入状态观测与平衡塑造奖励；当支撑稳态偏差 $\|x_{\text{CoM}} - x_{\text{CoP}}\| > \tau$ 时自动指数衰减参考轨迹跟踪权重、优先保证不摔倒，显著改善高动态动作（踢腿、大步跑跳、武术转体）的物理稳定性。
3. **Parseval 引导残差策略快速微调（Parseval-Guided Residual Adaptation）**：面对全新 OOD 动作分布时，冻结预训练主干 $\pi_b$，仅训练轻量 3 层 MLP 残差支路 $\pi_r$（$a_t = a_t^b + a_t^r$），并同时施加：
   - **Parseval 正交谱约束** $\mathcal{L}_{\text{Parseval}} = \sum \|W^\top W - sI\|_F^2$：约束残差网络各层权重近似正交、限制 Lipschitz 常数与特征爆发；
   - **KL 散度策略漂移约束** $\mathcal{L}_{\text{KL}}$：抑制灾难性遗忘。
4. **实验效果**：
   - MuJoCo 零样本基准（AMASS / MotionX 成功率）：FAST 分别达 **87.14% / 51.46%**（明显高于 GMT `77.55% / 38.91%` 与 TWIST2 `72.61% / 31.82%`）；
   - LaFan1 新动作快速自适应后，新集成功率达 **90.60%** 且原 AMASS 集保持率高达 **96.92%**，并成功真机部署于 Unitree G1。
