## 原文要点与 wiki 映射

1. **iWSP 定义（§2）：** Agent 根据任务描述编写模型特征与显式权重，不允许在候选网络上跑优化器/反向传播；迭代取得单一 visible score、保存候选、外部审计，再在 hidden set 检验。算法任务须由网络本身给出答案，不允许 Python 代码绕开网络求解。
   - 对 wiki 的映射：[独立论文实体](../../wiki/entities/paper-interpretable-weight-space-programming.md)「核心原理与流程总览」。
2. **解释性检验（§2、§3、附录 A.1/A.2）：** 审计候选修改是否可读，并在修改任务数据时验证编写的权重不依赖样本/标签；用不超过 200 词的文本总结交给新 Agent 复建，比较性能及预测一致性。解释性并非仅以参数少为准。
   - 对 wiki 的映射：「评测结果与证据边界」。
3. **算法及 NLP（§3、附录 A.1）：** 13 个算法任务、4 个 NLP 任务；Claude Opus 5.5 的算法任务 26/26 次运行在测试范围内达到 hidden set 100% 准确率，不能外推为任意输入正确。四项 NLP 中三项高于多数类基线，MRPC 复述判断未超过基线；TREC hidden accuracy 87.3%（Opus）。公开结果不是机器人任务结果。
   - 对 wiki 的映射：「评测结果与证据边界」。
4. **神经科学的固定读出层（§2/§4）：** 在视觉/语言/音频脑响应实验，Agent 生成可解释的特征提取器 f(x)，固定评测器 **会拟合岭回归 W** 预测响应；因此“无反向传播训练”只适用于 Agent 构造的特征/权重，不等于不存在数据拟合。视觉任务限制 <10,000 特征。
   - 对 wiki 的映射：「核心原理」「局限与工程实践」。
5. **视觉皮层（§4.1）：** LAION-fMRI 上搜索可解释视觉特征，最终 14 类计算/9,996 维特征；在未参与搜索的 NSD 数据集，early cortex 相关 0.443 vs 最强可解释基线 0.400，ventral 0.317 vs 0.256；ventral 仍低于 AlexNet 0.391。
   - 对 wiki 的映射：「评测结果与证据边界」。
6. **语言 fMRI 混杂（§4.2、附录 A.3）：** 位置特征使 visible correlation 从 0.067 跳到 0.104；扫描开头/末尾的非语言信号造成虚假提高。裁除边缘 TR 后，iWSP 与 GPT-2 XL 的语义特征性能相近。属于从可解释特征中发现混杂，而非证明位置是语言脑机制。
   - 对 wiki 的映射：「评测结果与证据边界」「局限与工程实践」。
7. **ECoG 音频（§4.3、附录 A.4）：** surface-grid hidden correlation iWSP 0.074 vs Whisper 0.082；全 166 电极分别为 0.065 vs 0.070，特征组合使后者提高到 0.075。不同电极集合不可混用指标。
   - 对 wiki 的映射：「评测结果与证据边界」。
8. **局限与适用边界（§6、附录 A.5）：** 以已知的 Gabor、听觉滤波器、教科书算法为主，未证明发现新计算原理；更深层、多阶段模型表现弱，神经实验观察性、因果性不足。Agent API 成本作者估计约 $17,500，未含计算/回归拟合。研究没有机器人真机实验。
   - 对 wiki 的映射：「结论」「局限与工程实践」。

## 与既有知识的区分

- 本论文的 iWSP 与 [Sparks of Weight-Space Programming](../../wiki/entities/weight-space-programming.md) 相邻但**不是同一研究**：前者明确加上人类可解释的候选约束、审计与神经编码实验；后者来自 MIT CSAIL 的另一份作者博客及实验。
- 原文自身承认与 Takehi 等的同期工作相似；分别以 arXiv 2611.18114 和各自官方仓库维持身份唯一。
