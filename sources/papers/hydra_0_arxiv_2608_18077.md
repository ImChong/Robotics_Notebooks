## 摘录 1：Action Flow 接口（§2）

- **定义：** \(N\) 个跟踪点在 horizon \(H\) 上的图像坐标 \(\mathbf{x}_{n,t}\) 与可见性 \(m_{n,t}\)；同一格式可描述 robot arm、gripper、human hand。
- **训练（video-only）：** AllTracker 稠密轨迹 + grounded mask 分割 embodiment/object；四种采样模式 Embodiment/Object/All/None（概率 0.40/0.40/0.15/0.05）。
- **部署（geometry-aware）：** Isaac Lab 执行候选命令 → 链接变换 → 可见表面点投影到相机平面（式 1）；需几何与标定。

**对 wiki 的映射：** 链接 [generative world models](../../wiki/methods/generative-world-models.md)、Cosmos / Wan 生态。

## 摘录 2：评测（§3–4）

- **相对 Cosmos 2.5 native 6D action：** robot-motion EPE ↓90.4%，object-motion EPE ↓60.2%（五 held-out 数据集）。
- **RoboLab 开环 replay：** 5 策略×6 任务×300 episode；replay vs 参考成功率 Pearson **r=0.96**，Spearman 0.93；aggregate 26.3% vs 26.7%。
- **逆向模式：** 供 object flow（可来自 human demo）→ 生成 robot motion latent → action readout → 14-DoF YAM 真机；无任务专属专家 robot demo。
- **数据：** 过滤后 **2,202 h** 多具身视频 mid-training；IWS 六任务 0% 数据仍优于 pretrained-only。

**对 wiki 的映射：** 与 [SC3-Eval](../../wiki/entities/paper-sc3-eval.md)、[OSCAR](../../wiki/entities/paper-oscar.md) 并列「WM 作策略评估代理」路线。

- **通读：** 已完成
- §2 / 附录：command→Isaac Lab controller+physics rollout→机器人表面点投影，非直接用未来真实物体轨迹在部署偷看；图像平面可见性依赖深度 buffer，未知物体遮挡未完全过滤。轨迹聚合 top-2 原始 Gaussian 权重、不做 softmax 归一化，β=220。
- 表 1：训练 2,201.7 h 是按相机流切窗计数，不能当作唯一物理交互时长；表 2「−90.4% / −60.2%」跨不同骨干的最佳配置，控制同骨干对照另看 Cosmos 2.5。
- 表 3：H100 batch 1，81 帧，4 步 student 1.31 秒 / 61.98 FPS / 16× 是纯生成指标，关掉 guidance 且排除 VAE。逆向 WAM 用 50 步 AR teacher，不是同一个四步实时数。
- §4.5：5 策略×6 任务×10 次=300 episodes，固定 achieved-trajectory replay，不在生成观测上重新查询策略；Pearson 0.96、Spearman 0.93、MAE 5.7pp。
- §4.6 与项目页：逆向控制仅展示柔性管弯折 POC，动作头仍由成功/失败真机配对 rollout 训练。「无需任务专属专家 demo」不等于不需要机器人动作数据。
- 项目页另给 aggregate 26.3% vs 26.7%、逐回合 93% / κ=0.82，以及 14-DoF YAM；这些是项目页补充，不应标成 PDF 表内结果。Code 为 coming soon。
