# KINO（G1 关键帧 VLM 规划控制）

> 来源归档（ingest）

- **标题：** KINO: A Keyframe Interface for VLM Planning and Whole-Body Control in Humanoid Loco-Manipulation
- **类型：** paper / 人形 loco-manipulation / VLM 规划 / whole-body RL
- **arXiv：** <https://arxiv.org/abs/2609.18869>（PDF：<https://arxiv.org/pdf/2609.18869>）
- **机构：** 苏黎世联邦理工学院（ETH Zürich）
- **作者：** Sitong Chen、Fatemeh Zargarbashi、Jin Cheng、Tianxu An、Stelian Coros
- **入库日期：** 2026-09-18（初稿）；2026-09-21（arXiv 深读 + 步骤 2.5 再核）
- **一句话说明：** VLM 从预定义库选 successive whole-body keyframes，场景重定向 + 可选 Dubins 中间 locomotion goals 后，由 keyframe-conditioned multi-critic PPO 策略执行；saliency 采样训练把稀疏 VLM 关键帧端到端成功率 **44% → 92%**；仿真 + **Unitree G1** 真机 pickup/transport/place。

## 摘要级要点

- **分层接口：** Motion keyframes 连接 VLM 语义规划与 RL 关节控制；每 keyframe = 目标全身姿态 +（可选）物体姿态 + 自然语言标签。
- **VLM planner：** 输入语言指令、第三人称场景图、结构化 planner context（上一 keyframe、完成/成功标志、根/物体位姿、goal error）；输出 constrained JSON（`keyframe` / `object_to_manipulate` / `task_complete`）。
- **低层 policy：** Goal-conditioned PPO；观测含 10 步 proprio + object + 上一动作 + keyframe goal；critic 额外特权（reference motion、ΔK、剩余时间）；奖励分 **tracking / goal / regularisation** 三组 multi-critic。
- **Saliency keyframe sampling：** 基于 body 加速度峰值 + 滤除周期性步态 + 物体竖直加速度事件；相对 uniform 1.5s 间隔采样，端到端 SR **44%→92%**。
- **Scene alignment：** 物体 frame 对齐 + 归一化 IK 重定向（MuJoCo damped least-squares）；locomotion 段用 Dubins/圆弧中间 keyframes 泛化到训练分布外 placement。
- **实验：** Qwen3.6-27B @ 4090；box（双手）与 bucket（单手）；真机物体位姿靠外部 mocap。
