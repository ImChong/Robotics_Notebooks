# WorldLine 项目页

> 来源归档（site / project-page）

- **标题：** WorldLine — Action-Driven Visual Simulation
- **官方入口：** <https://zhengsh123.github.io/WorldLine/>
- **论文：** <https://arxiv.org/abs/2609.38059>
- **代码：** <https://github.com/Zhengsh123/WorldLine>
- **入库日期：** 2026-10-15
- **一句话说明：** 项目展示跨本体动作条件视频预测、三阶段训练、离线策略评估和多视角演示。

## 页面核查（2026-10-15）

- 页面展示 10,000+ 小时无动作标注视频、2,000+ 小时动作轨迹、10+ 种机器人本体及四步因果 rollout 等主要数据与方法。
- 页面提供同步多视角、方法对比、长时 rollout 和消融结果的交互视频浏览。
- 顶部 `Code` 按钮指向官方 GitHub 仓库。其 README 当前写明主分支**不包含训练或推理代码**；项目页开放了展示材料，模型实现仍未公开。
