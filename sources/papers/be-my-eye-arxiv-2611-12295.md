## 原文核对摘录及对 wiki 的映射

### 1. 主动上下文共享的准确含义（§1、§2.1–2.2）

- **主动不等于动态调度通讯：** “active” 指依据任务选择要编码的信息，不涉及自动决定何时发送或发送给谁；发送时机与对象可以由高层规划处理。
- 冻结视觉编码器与语言编码器产生多相机图像特征及指令特征；可训练上下文编码器通过 `K` 个 learnable queries 聚合，支持 joint/per-camera query allocation；用学习到的投影将 `K × d_z` 表征映射入 VLA 隐空间。
- 两机器人在相同结构下分别编码本机观测与任务指令，双向传送上下文 token，不需要预先设定永恒的 leader/follower 角色。
- **对 wiki 的映射：** [CoMind 主实体](../../wiki/entities/paper-be-my-eye-comind.md) — 输入输出、流程总览与术语边界。

### 2. Stage 1 无协作角色预设的上下文压缩（§2.3）

- **未来预测：** 从当前上下文 `Z_t` 预测 `t+Δ` 的冻结视觉编码器特征，而不是合成像素；patch 预测误差用与语言指令相关的视觉 patch 相似度加权。权重 detach，不通过该损失更新相关度分支。
- **进度对应：** 数据增强后的两个视图，经池化及仅用于训练的对比头得到 embedding；按任务 ID 和轨迹归一化进度 `γ=t/(T-1)` 生成软关联目标，实例对角项和进度邻近性混合后计算双向软标签 CE。
- **综合目标：** `L_S1 = λ_pred L_pred + λ_con L_con`；进度真值仅用于训练软标签，不直接提供给编码器，也不发给队友。
- **对 wiki 的映射：** 主实体 — 两种监督信号与“不泄露真实进度”说明。

### 3. Stage 2 动作条件化与梯度回传（§2.4）

- 发送端 `Z_j` 经 `P_ρ` 映射后，接收端策略输入本机多相机观测 `V_i`、语言 `ℓ_i`、本体状态 `s_i` 与队友上下文，输出连续 action chunk。
- `L_S2^{j→i} = L_VLA^i + η L_S1^j`，接收端动作损失通过共享 token 反传至发送端上下文编码器，同时保留 Stage 1 辅助监督；两个方向对称共享参数。
- 未来预测解码器和对比投影头只用于训练，部署时不参与跨机通信或动作推理。
- **对 wiki 的映射：** 主实体 — Mermaid 架构图与工程推理链。

### 4. 受控试验与数值（§3.1–3.5）

| 指标与样本 | No Sharing | Generic SigLIP | Ours-Joint |
|---|---:|---:|---:|
| 遮挡目标选框准确率；每设置 18 次（Table 1） | 38.9% | 72.2%（160 token） | **88.9%（32 token）** |
| 交替主从取马克笔：完整双阶段成功率；总 48 次试验（Table 2） | 0% | 100%（160 token） | **100%（32 token）** |

- 交替主从任务：无共享时 B 跟 A 的颜色匹配 16.7%、A 跟 B 33.3%、触发 25%；SigLIP 和 Ours-Joint 四项指标皆 100%。
- **Process Score 计分（§3.3）：** 成功 Leader 抓取 0.25 分、正确触发 Follower 动作 0.5 分、正确颜色匹配的 Follower 抓取 1.0 分，用归一化百分数评价部分完成程度；不是完整双阶段成功率。
- Stage 1 消融的**归一化过程分数（Process Score）**：Full 100%；去未来预测 96.7%；去对比进度学习 68.9%（Table 3）。这是过程分数，不是“成功率”。
- 是否联合优化（Table 4）：冻结 Stage 1 编码器 83.3%，端到端联合优化 100%（过程分数）。
- 通信预算（Table 5，均为 FP32 1,152 维 token、每方向每决策步，不计协议开销）：4/16/32 token = 18/72/144 KiB，对应过程分数 90.5/97.6/100%；Generic SigLIP 160 token = 720 KiB、100%。
- **边界：** 32 vs 160 是 token 和按文中相同维度计算的载荷预算，非测得无线网络带宽/实际时延；遮挡任务 18 次且无置信区间，不足以单凭 16.7pp 差距断言统计显著；SigLIP 与 Ours-Joint 不只是 token 数量不同。
- **对 wiki 的映射：** 主实体 — 实验表与可比口径。

### 5. 定性展示与限制（§3.6、§5）

- 正文另展示冰箱补货、盒体组装、叠被打包 **3 项定性真机任务**；图 4 为示例 rollout，不应写成各自有成功率的 3 个定量 benchmark。
- 图 5 机器人视觉注意力图仅为定性诊断，并非因果解释。
- 作者明确承认共享 token 的语义内容仍未充分理解；更大机器人团队、异步/选择性共享、触觉、本体及时间记忆均属未来工作。
- 论文以两台 Astribot S1、预训练 `π0.5` 为实验平台与策略，未证明大规模/异构团队扩展。
- **对 wiki 的映射：** 主实体 — 局限与风险及 CHORUS 对照。
