# TD-MPC2: Scalable, Robust World Models for Continuous Control（arXiv:2310.16828）

> 来源归档（ingest）

- **标题：** TD-MPC2: Scalable, Robust World Models for Continuous Control
- **类型：** paper / TD-MPC2 / model-based RL / latent MPC / continuous control / multi-task
- **arXiv：** <https://arxiv.org/abs/2310.16828>（PDF：<https://arxiv.org/pdf/2310.16828.pdf>）
- **会议：** ICLR 2024 Spotlight
- **项目页：** <https://www.tdmpc2.com>
- **代码：** <https://github.com/nicklashansen/tdmpc2>（**MIT**）
- **权重 / 数据集：** 项目页 Models / Dataset（300+ checkpoints；30-task / 80-task transition datasets）
- **作者：** Nicklas Hansen、Hao Su\*、Xiaolong Wang\*（\* Equal advising）
- **机构：** 加州大学圣地亚哥分校（UCSD）
- **入库日期：** 2026-07-27
- **一句话说明：** 在 TD-MPC 上改进得到 **TD-MPC2**：解码器无关的隐式世界模型 + 潜空间局部轨迹优化；**单一超参**覆盖 **104** 连续控制任务，并可把单智能体扩到 **317M**、跨域 **80** 任务。

## 开源状态（项目页 + 仓库核查，2026-07-27）

- **已开源：** [nicklashansen/tdmpc2](https://github.com/nicklashansen/tdmpc2) · **MIT**；Docker / conda；`train.py` / `evaluate.py`；状态与像素观测；单任务在线 RL + 多任务离线 RL。项目页开放 **324** 量级 checkpoints 与 **545M / 345M** transition 数据集下载。

## 摘要级要点

- **算法族：** 隐式（decoder-free）世界模型；TD 学习价值；MPC（如 MPPI/CEM 族）在 latent 局部优化轨迹。
- **稳健性：** 相对 TD-MPC / DreamerV3 / SAC，在 4 域 104 任务上一致更强且无需调参。
- **可扩展性：** 模型与数据增大 → 能力上升；多任务 1M→317M 参数曲线。
- **工程：** 官方仓支持 DMControl / Meta-World / ManiSkill2 / MyoSuite；2025-04 起可选 `episodic=true`。
