# BoT-SORT

- **类型：** repo
- **链接：** https://github.com/NirAharon/BoT-SORT
- **论文：** https://arxiv.org/abs/2206.14651
- **入库日期：** 2026-11-01
- **开放状态：** 论文与官方多目标跟踪代码公开。
- **作用：** 结合运动、外观和相机运动补偿进行多目标跟踪。
- **核查范围：** 官方 `tools/demo.py`；未实际运行。

演示入口逐帧调用检测器推理，再将检测结果及原始帧传给 `BoTSORT.update`；可输出可视化和跟踪结果。是否启用外观 ReID 取决于运行参数。它是通用跟踪组件，并不证明截图系统实际使用了此仓库。
