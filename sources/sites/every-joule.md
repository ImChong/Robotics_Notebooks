# Every Joule

- **标题：** Every Joule: a 3D physics book about energy
- **作者：** Techartist（X：[@techartist_](https://x.com/techartist_)）
- **类型：** site / interactive educational resource
- **主题：** GCSE / IGCSE 物理中的能量
- **官方项目页：** <https://iamtechartist.com/every-joule/>
- **第 1 课体验：** <https://iamtechartist.github.io/every-joule-lesson1/>
- **课程规模：** 十课；官方站列出能量储存、动能与重力势能、弹性势能、弹跳球耗能、比热容与保温、功率、效率、发电与电网、食物中的能量、能量守恒。
- **作者说明的构建方式：** Claude Opus 5.5 + Three.js；见[首发帖](https://x.com/techartist_/status/2113310927093436587)及[十课发布帖](https://x.com/techartist_/status/2114035465875824813)。
- **入库日期 / 核查日期：** 2026-10-27
- **代码：** 截至核查日期，项目页和作者公开资料未发现 Every Joule 官方 GitHub 源码仓库链接；在线体验可访问，但不能据此视为源码开放。

## 资料定位

Every Joule 将 GCSE/IGCSE 能量主题编排为浏览器内的 3D 互动书。作者介绍的交互方式包括先预测、再测试、翻开答案并获得印章；项目页同时提供教师说明与课程内容来源。此归档记录项目定位与入口，不代替课程内容或物理概念核验。

## 开放状态核查

官方项目页提供在线互动入口，并说明 3D 图形需要浏览器图形加速；页面也提供教师页和课程文本。页面没有列出 GitHub、权重或可下载源码。作者的公开 GitHub 主页可供持续复查：<https://github.com/iamtechartist>。本条只确认截至入库日未发现官方源码仓库，不推断未来不会发布。
