## 摘要与核心贡献

1. **物理反馈强化学习对齐（RLPF）**：针对大动作模型（LMM）仅从文本-动作对学习易生成「物理不可行/摔倒」动作的问题，在 **MotionX（81,082 条片段）** 上预训练 LLaMA2-7B 离散运动生成模型后，以冻结的物理全身跟踪策略为评价器，通过 **GRPO** 对文本到运动模型做后训练对齐。
2. **双重奖励防语义坍塌**：
   - 物理跟踪成功率奖励 $R_{\text{tracking}} = \mathbb{I}(\text{Succ}(\pi, m))$：由 IsaacGym 内 ExBody2 风格 Teacher PPO + Student DAgger 跟踪策略在 Unitree G1 上判定生成动作是否全程不摔倒；
   - **Alignment Verification** 语义对齐奖励：$R_{\text{TA}}$（文本-动作对比编码器相似度，权重 $\beta=0.3$）与 $R_{\text{MA}}$（参考动作-生成动作嵌入相似度，权重 $\gamma=0.7$），防止模型为迎合站立奖励退化为静止原地不动（消融中去掉对齐约束会导致 FID 飙升至 `32.53 / 41.97`）。
3. **定量与真机效果**：
   - IsaacGym 物理成功率（CMU / AMASS）：Base 仅 `0.43 / 0.48`，RLPF 提升至 **`0.95 / 0.97`（CMU）与 `0.92 / 0.90`（AMASS）**；
   - 跨仿真器 MuJoCo 零样本迁移成功率：`0.75 / 0.61`（CMU）与 `0.63 / 0.66`（AMASS）；真机部署于 Unitree G1（50 Hz 策略控制 / 200 Hz LCM 通信，机载 Jetson Orin NX）。
