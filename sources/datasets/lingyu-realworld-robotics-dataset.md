# LingYu Real-World Robotics Dataset

- **类型：** dataset / 官方数据卡
- **原文：** https://huggingface.co/datasets/LingYu-Robotics/lingyu-realworld-robotics-dataset
- **核对：** 2026-11-05 数据卡完整正文；动态 main，未固定版本。
- **开放状态：** 首发桌面数据公开；零售数据独立于本次发布，计划审核申请访问。
- **许可：** CC BY-NC-SA 4.0。

数据卡报告桌面数据 139.4 小时、13,263 条轨迹、22 个子集及 15 类任务，约 9.16 TB。TA2 双 7 自由度机械臂通过 VR 遥操作采集；三路立体 RGB、双臂状态与动作同步为 45 Hz。格式为 LeRobot v2.1，每个子目录独立，提供 MP4/HEVC 和逐轨迹 Parquet。

资料映射：[LingYu 数据集实体](../../wiki/entities/lingyu-realworld-robotics-dataset.md)。
