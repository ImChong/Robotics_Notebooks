# computed-axial-lithography / VAMToolbox

- **标题：** VAMToolbox
- **类型：** repo
- **源码：** <https://github.com/computed-axial-lithography/VAMToolbox>
- **文档：** <https://vamtoolbox.readthedocs.io/>
- **关联项目：** [OpenCAL](https://github.com/computed-axial-lithography/OpenCAL)
- **入库日期：** 2026-10-23
- **一句话说明：** 面向体积增材制造的 Python 工具箱，计算并优化 CAL 打印所需的投影序列，也为 Tomo 图形界面提供算法后端。

## 开源状态核查

源码与文档公开。仓库 README 说明该软件 **不是 OSI-approved open source**；使用前应查看仓库当前许可与依赖条款，不应把其许可与 OpenCAL 控制软件混为一谈。

## 主要能力

- 从目标体素模型计算 tomographic light projections。
- 提供 OSMO、BCLP 等投影优化方法，并建模 DLP 投影仪。
- 作为 Tomo 的投影计算后端，也可直接用于 Python 工作流。
