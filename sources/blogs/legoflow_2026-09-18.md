- **一句话说明：** LegoFlow 将软件工程数据构建拆成 coding agent 可调用的 Root、Curator、Tracer、Trainer、Evaluator 模块，贯通任务筛选、验证、轨迹采集、SFT 和评测反馈。

## 核心摘录（归纳，非全文）

### 五块式数据工程流程

- **Root** 将用户目标编译为工作流，协调任务分发、资源和反馈。
- **Curator** 从 GitHub 仓库和 PR 中发现候选任务，收集 issue/commit/test 证据，改写成清楚且避免答案泄漏的任务，在 Harbor 环境中确认 bug 版测试失败、reference fix 通过后发布 manifest。
- **Tracer** 将已验证任务分发给 Claude Code、OpenCode、OpenHands 等 coding-agent scaffold，在容器环境中 rollout；记录模型交互、工具调用、reward 与轨迹，再将合格轨迹转成统一训练格式并评分筛选。
- **Trainer** 将轨迹转换为 LLaMA-Factory 格式并进行 SFT；官方博客称正在把 Lego-RL 接入以便用已验证任务做 RL，不能把该集成视为当前已完成能力。
- **Evaluator** 加载 checkpoint，在 Harbor 支持的 coding-agent benchmark 上评测，并将报告回传 dashboard，供下一轮调整数据策略。
- 每个 block 都作为可检查、可复用的 agent skill，并负责相应代码、依赖、环境和 artifacts。

### LegoFlow-SWE 的任务与轨迹

- 从超过 **700K GitHub 仓库 / 12M PR 候选**开始，依靠 diff 规模、测试与 issue 证据等过滤，再结合模型判断和执行验证，筛选出 **5,000 个 verified SWE tasks**。
- 任务覆盖 **8 种语言、20 类 tags**，按 Harbor 格式提供任务说明、容器环境、bug patch、reference solution 和测试。
- 发布 tasks/ 和 tasks-anti-hack/ 两套提示版本：task ID 与任务内容对应，anti-hack 版本在任务提示中附加约束；它不是第二套独立 5,000 任务。
- 数据还包括 GLM-5.2 的 **9,767 条 rollouts**：OpenHands SDK 4,753 条（reward=1 为 1,350），OpenCode 5,014 条（reward=1 为 1,430）。reward=1 表示 verifier 成功，不等于单独审计过整条轨迹无 hack。

### 官方报告的训练结果

在统一配方下从 LegoFlow-SWE 抽取约 **1,000 条轨迹**，从头微调 Qwen3.5-35B-A3B-Base，并使用 OpenHands SDK、no-hack / 200-turn / 256k 设置评测。HF 数据卡报告：

| 基准 | LegoFlow-SWE SFT | Qwen3.5 Instruct 对照 | 差值 |
|------|------------------:|----------------------:|-----:|
| SWE-bench Verified（500题） | 70.2% | 63.4% | +6.8 pp |
| SWE-bench Pro（731题） | 48.8% | 38.2% | +10.6 pp |
| SWE-bench Multilingual（300题） | 57.0% | 51.7% | +5.3 pp |

官方还报告：在 teacher、scaffold、scoring、sampling 和预算固定时，与其在公共实例上采集的 swerebenchv2 相比，实例来源对应的差异为 Verified +5.8、Pro +1.9、Multilingual +1.0 个百分点。该比较是作者公布的特定实验，不能泛化为所有数据来源的普遍优势。

### 递归改进实验

博客另报告一个从 GitHub 仓库开始的端到端实验：基座模型在 SWE-bench Verified 上为 **7.6%**；第一轮筛选后训练达到 **56.1%**，未达 60% 目标；评估暴露出推理轨迹浅、工具调用格式不兼容等问题。第二轮加入推理深度筛选和调用规范化，使用 512 条筛后轨迹训练后达到 **64.4%**。这是独立于发布集总量的迭代实验结果，不应把 512 条直接等同于已发布成功轨迹。

## 开源核查与边界

- LegoFlow 仓库公开，GitHub API 标记 **Apache-2.0**；官方文档提供 block 安装与全流程运行指南。
- LegoFlow-SWE 在 Hugging Face 公开，可访问 tasks 与轨迹文件；数据卡页面本次核验没有清楚显示独立的数据许可字段。代码 Apache-2.0 不自动覆盖数据集及其来源项目，使用/再分发前需分别核实适用条款。
- 训练需要 coding-agent scaffold、兼容 LLM endpoint、GitHub token 与 Docker；GPU 用于自行训练或托管 checkpoint。官方 README 称其在单节点 8×H800 80GB 环境验证，未接好多节点训练。
- no-hack 评测包含 anti-hack prompt、移除 Git 来源信息和网络限制；只下载 tasks-anti-hack/ 仅带有提示约束，Git 清理和网络隔离仍需评测 runner 实施。
