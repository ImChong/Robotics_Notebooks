# I3L: Iterative Interactive Imitation Learning for Whole-Body Mobile Manipulation（arXiv:2610.17748）

> 来源归档（ingest）

- **标题：** I3L: Iterative Interactive Imitation Learning for Whole-Body Mobile Manipulation
- **类型：** paper / interactive imitation learning / DAgger / whole-body mobile manipulation / teleoperation
- **arXiv：** <https://arxiv.org/abs/2610.17748>（v1 提交于 2026-10-13；HTML：<https://arxiv.org/html/2610.17748v1>）
- **项目页：** <https://i-3l.github.io/>（论文指向视频、可视化、附录与 CAD 模型）
- **作者：** Wensi Ai、Christopher Luey、Karthik Dharmarajan、Evans Han、Yunfan Jiang、Stef Ren、Jianwen Xie、Jiajun Wu、Li Fei-Fei、Ruohan Zhang
- **机构：** Stanford University（斯坦福大学）；Lambda Inc.（Jianwen Xie）
- **入库日期：** 2026-10-19
- **一句话说明：** 将部署时的人工接管与多轮策略重训结合：JoyLo+ 在策略执行时跟随其动作、触摸触发接管并记录纠正，随后通过 HG-DAgger 筛选接管数据迭代更新策略；论文在 8 项任务、3 种机器人本体上评估，报告相同轨迹预算下平均自主成功率提高 35.6 个百分点、四轮后接管时长下降 72%。

## 摘录 1：问题与系统

- 离线遥操作示范很少覆盖策略自行造成的状态偏移；在长时序全身移动操作中，少数关键阶段出错即可令整项任务失败。
- I3L 将 JoyLo+ 全身接管接口与策略迭代更新结合。操作者按需接管，系统记录观测、执行动作、策略提议动作和干预标签。
- JoyLo+ 的电机驱动 leader arm 在自主执行时跟踪策略目标；触摸握把后进入柔顺操控。R1 Pro 配置可协调控制双臂、躯干、底盘和夹爪；Franka 配置用于单臂桌面操作。
- 评估包含 8 项任务、29 个子任务和 3 种机器人本体，覆盖仿真、Franka 固定基座操作和 R1 Pro 全身移动操作。

## 摘录 2：纠正数据闭环

1. 从初始专家演示训练策略。
2. 部署策略并通过 JoyLo+ 记录 rollout，包括观测、执行动作、策略动作和干预标签。
3. 在 HG-DAgger 设置下，仅筛选人工主动接管帧作为纠正样本，并聚合到历轮训练集。
4. 每轮从一致的初始权重或同一个 VLA 预训练 checkpoint 重训策略，再部署采集下一轮纠正。
5. 更新后的策略暴露新的失败状态，采集过程因此集中到尚未掌握的阶段。

本文将人类干预用作策略诱导分布上的选择性监督；它与经典 DAgger 的在线标注思路相通，同时评估接管接口、数据筛选方式和多轮更新效果。

## 摘录 3：实验数字

| 评测 | 基线 / 对照 | 论文结果 |
|------|-------------|----------|
| 仿真草莓采摘放置 | 初始策略 53.2%；追加 100 条演示 55.6% | 100 条纠正轨迹、四轮 HG-DAgger 后 92.8% |
| 仿真开冰箱取收音机 | 初始策略 39.6%；追加 100 条演示 30.4% | 100 条纠正轨迹、四轮 HG-DAgger 后 90.0% |
| Franka 挂杯（真实） | 初始策略 6/25；追加 100 条演示 17/25 | 100 条纠正轨迹后 23/25 |
| 全套评估（8 项任务） | 相同轨迹预算下的演示训练基线 | 摘要报告平均自主成功率提高 35.6 个百分点，所有任务至少 90% |
| 四轮迭代 | 按论文摘要汇总 | 每回合接管时长平均下降 72% |

仿真算法对比中，四轮 HG-DAgger 在两项任务上取得最高最终均值成功率。系统性纠正策略比较主要在仿真中进行。
