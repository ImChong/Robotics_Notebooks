## README 摘要

WorldArena 2.0 从三个方向扩展具身世界模型评测：视触觉模态、把世界模型作为在线强化学习环境、以及跨本体仿真到真实机器人平台的迁移。仓库 README 将 Hugging Face Space 指定为官方排行榜入口。结果说明中包含 Xiaomi Robotics 团队条目。
