## 资料摘记

- 架构：Wan2.2-TI2V-5B 初始化视频专家；视频与动作经共享注意力和联合去噪生成配对候选，冻结的 1.1B、12 专家 AVLA 提供技能条件。
- 决策：K=4，先做具身约束和风险门控，再按价值、不确定性及执行成本排序；执行短前缀，云端异步重规划。
- 经验：Stored-K 保留候选、评估、选择及实际执行记录，仅在有效执行窗口对齐预测与结果；未执行候选不继承已执行候选的成功或失败标签。
- 学习：Evolution Judge 在有效证据规则内选择经验；Training Agent 在有限配置下调整采样与损失权重，分支同起点、同数据池与预算；独立评估器每轮固定并共享。
- 数据：超过 10,000 小时自有第一人称视频和 30,000 小时 F1/F2 交互数据；第一人称视频不直接提供价值、风险和失败标签。
- 实验：四项完整演示第 0 → 30 轮自主成功率分别为叠衣 54.6% → 96.8%、晾衣 46.2% → 91.2%、意面 42.7% → 89.5%、辣椒炒肉 38.2% → 68.9%。接管后完成不算自主成功；超时和失败计入分母。
- 限制：表 4 不能单独区分反馈机制与持续训练等因素的贡献；报告将 21 个子任务的独立成功率、泛化、机制消融和误差归因列为后续工作。网页未给出各单元格试验次数或置信区间。
