# humaps4d.wp.imt.fr（HUMAPS-4D 项目页）

- **标题：** HUMAPS-4D: A Multimodal Dataset for Human Motion Analysis with Physiological and Semantic Informations
- **类型：** site / project-page / dataset
- **URL：** <https://humaps4d.wp.imt.fr/>
- **配套论文：** [CVPR 2026 Open Access PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Dabrowski_HUMAPS-4D_A_Multimodal_Dataset_for_HUman_Motion_Analysis_with_Physiological_CVPR_2026_paper.pdf) — [`sources/papers/humaps4d_cvpr_2026.md`](../papers/humaps4d_cvpr_2026.md)
- **作者：** Matthieu Dabrowski、Ouala Ben Jemaa、Benjamin Allaert
- **机构：** IMT Nord Europe；Institut Mines-Télécom；里尔大学（Université de Lille）
- **入库日期：** 2026-09-06

## 一句话摘要

14 小时、32 被试、30 类动作的多模态人体运动数据集：外视 RGB + Qualisys MoCap + 16 路 sEMG/IMU + Moticon 足底压力鞋垫，并配三层语义语言标注与人体测量元数据。

## 开源核查（2026-09-06）

项目页 **Access** 区要求签署 DUA 并邮件 `benjamin.allaert@imt-nord-europe.fr` 获取下载凭证；**未列出 GitHub / Hugging Face 等代码仓库**。

- **数据集：** 学术用途可申请（非商业科研与教育）；需签署 Data Usage Agreement。
- **代码 / 基线：** 论文描述 baseline 与附录实验，但项目页截至入库日 **无公开代码链接**。
- **结论：** **数据部分开放（DUA 门槛）**；**训练/评测代码未开源**。
