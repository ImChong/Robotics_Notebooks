## 要解决的问题

机器人示范数据在任务间严重不均衡。当尾部任务缺少足够视觉证据时，共享策略会退回到数据丰富的头部任务学到的动作模式，损害尾部任务。论文用 Head-Prior Score（HPS(x)=P_H(x)/(P_H(x)+P_T(x))）与 Head-Action Rate（尾部指令下初始动作朝向头部任务物体的比例）刻画这一偏置。

## 方法与训练信息

- **证据定位：** 对每个视觉 token j，相关度 r_j=α_j^L·α_j^A（指令相关注意力 × 动作相关注意力）；取前 K 个 token 组成证据集 R，默认选择比例 10%（16×16=256 patch 网格）。论文自述注意力并非可靠的因果解释。
- **反事实构造：** I⁻=Mask(I,R)，指令不变；事实预测 z⁺=f(I,L)，遮挡预测 z⁻=f(I⁻,L)，对比输出 z_effect=z⁺−λ·z⁻，训练时 λ=0.3。反事实分支仅训练使用，部署只跑事实策略。
- **损失：** L_BC=ℓ(z⁺,a*)，L_mask=ℓ(z⁻,a*)，L_CF=ℓ(z_effect,a*)。
- **频次加权：** r_i=(N_max−N_i)/(N_max−N_min)；单样本目标 L_i=L_BC+μ·L_mask+r_i·L_CF，最频繁任务 r_i=0，最稀有为 1。μ 的默认值在可见文本中未给。
- **骨干：** MiniVLA 与 π0.5。π0.5 使用 OpenPI LIBERO 配置：动作视野 10、batch 256、学习率 5e-5、warmup 1 万步、共 3 万步优化、EMA 0.999。训练硬件在可见文本中未给。
- **无需额外数据或区域标注；部署零额外计算。**

## 论文报告的结果

- **仿真 LIBERO-Core（10 任务，头部 0–2，尾部 3–9）：** FULL 共 435 条示范；LT（长尾子集）共 154 条（46/28/19/15/11/9/8/7/6/5）。评测每任务 225 episode（3 种子×75），350 步上限。
- **平均成功率（%）：** MiniVLA：FULL 57.2 / LT 40.8 / APA 44.8 / ECL 53.0；π0.5：FULL 55.3（表头标注 “synthetic”，原文未解释）/ LT 40.3 / APA 41.7 / ECL 47.2。相对 LT 的提升：MiniVLA +12.2 点（约 29.9%），π0.5 +6.9 点（约 17.1%）。尾部任务 7–9 的 APA→ECL：MiniVLA 11.3→23.5，π0.5 19.0→21.6（由表计算）。MiniVLA 任务 1 的 FULL（78.2）高于 ECL（68.9），说明“头部任务受益”相对 LT 成立、相对 FULL 并不处处成立。
- **真机：** AgileX PIPER（全局 + 腕部相机）与 xArm6（仅全局相机），6 任务，LT 分布每任务示范 50/46/29/13/10/9（共 157，约 5.56:1），每策略每任务 50 次。平均成功率：PIPER MiniVLA APA 17.3→ECL 25.7，π0.5 21.0→27.3；xArm6 MiniVLA 19.3→26.0，π0.5 24.0→30.7。论文称尾部任务相对 APA 在 PIPER 提升 9.0%、xArm6 提升 4.3%，但取均值的口径未定义，无法复现该数字。
- **消融（MiniVLA，LIBERO-Core-LT，数值多在图中）：** λ 最优 0.3；token 选择“物体–动作联合”最佳（53.0%）；遮挡比例最优 10%；μ=0 时接近 LT 基线。
- **上下文级长尾（LTC，300 FULL / 125 LT 示范，六场景 50/25/20/15/10/5）：** 仿真 34.7%→37.6%；真机 28.5%→34.3%（MiniVLA）。
- **基线 APA：** 用 YOLOv8 与图像修复构造物体替换示范；ECL 不用额外示范。

## 复现与解释边界

- 作者自述限制：反事实样本构造带来训练开销（额外前向），固定时钟预算下这些算力原可用于头部任务；用频次近似每任务监督量；注意力不是因果解释。
- 原文有不一致：1 处 “FACS” 命名、附录 rollout 文件名 “FT-RCD”、比例 “5.56:15.56:1” 笔误、π0.5 FULL 列 “synthetic”。
