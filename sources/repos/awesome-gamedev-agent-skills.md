## 仓库核查（2026-10-22）

- README 给出的安装命令为 `npx skills add gamedev-skills/awesome-gamedev-agent-skills`；也提供 Claude Code 插件方式。
- README 声明技能基于各引擎官方文档编写，标注引擎版本基线，并可通过仓库中的 validator 校验。
- 路由器根据项目文件识别引擎，再结合任务描述选择所需技能；仓库列出 Codex、Cursor、Copilot、Gemini CLI 等代理兼容方式。
- 项目涵盖游戏开发工作流，也包含 three.js 场景、GLTF 加载和材质灯光技能，可作为交互式 3D 可视化或模拟器前端开发的参考。仓库本身不提供机器人模型、控制算法或仿真器集成。
