# 香港大学 OpenDriveLab 与 MMLab 官方导航核查

- **类型：** site / lab
- **核查日期：** 2026-10-21
- **OpenDriveLab：** <https://opendrivelab.com/>
- **MMLab @ HKU：** <https://mmlab.hk/>
- **团队背景：** <https://mmlab.hk/about-us>
- **MMLab 研究入口：** <https://mmlab.hk/research>
- **一句话说明：** 为实验室技术路线补充港大两支相关研究视角，复用已有论文实体，不重复建项目节点。

## 官方信息与边界

- OpenDriveLab 官网标题标注香港大学、具身智能与自动驾驶，列出 AgiBot World、RoboNaldo、EgoHumanoid 系列等研究入口；不同项目开放范围分别核对，不把实验室有 GitHub 等同于所有项目完整开源。
- MMLab 首页明确列出 HKU、CUHK、NTU 三个分支；本次路线是 **HKU 分支**，研究涵盖深度学习、强化学习、机器人、自动驾驶、多模态、生成式 AI 和 3D 视觉。
- About Us 中李弘扬简介明确写明自 **2021 年**领导 OpenDriveLab；该时间只作为团队排序锚点，不证明团队当年已隶属香港大学。
- HKU 分支未见独立成立日期；用 About Us 中罗平 **2019 年**加入港大的履历作排序锚点，并明确标注尚非核实的成立年。官网 **2001-07** 指汤晓鸥创立的 MMLab 体系，不能直接套用于 HKU 分支。
- 两个入口存在成员和合作项目交叉；路线按研究视角组织，不将论文归属解释为排他。χ₀ / kai0 等合作项目的 GitHub 组织名也不能单独决定机构归属。
