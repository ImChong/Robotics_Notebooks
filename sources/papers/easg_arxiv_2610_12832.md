## 要解决的问题

预训练 VLM 已具备视觉、空间与推理能力，缺的是一个能暴露这些能力的动作接口。VLA 需要额外的可学习动作组件与机器人数据；模块化“基础模型 + 外部规划控制”的方案又不是单一策略。EASG 想证明：只要动作接口合适，预训练 VLM 本身就能输出可执行的连续动作。

## 方法与训练信息

- **动作坐标系投影：** 以当前 TCP 为原点建局部动作坐标系，用标定的腕部相机外参与内参把原点与 x/y/z 轴投影到腕部图像上画出来；提示词解释各轴方向、平移单位、旋转参数化与夹爪语义。提示词（附录）：X 轴红色横跨手指，+Z 蓝色指向指尖，Y 绿色，右手系。
- **度量深度：** 对齐深度估计 TCP 沿 +Z 到最近可见表面的距离 d_t，作为度量尺度输入。深度具体来源/估计方法原文未说明。
- **文本动作格式：** `state | vx,vy,vz,d | rx,ry,rz,θ | gripper`；平移为单位方向 + 非负距离（cm），旋转为单位轴 + 带符号角度（度），数值带显式符号与两位小数；state=1 表示任务完成（无操作）。
- **执行：** 动作从 TCP 系旋到基座系，目标位姿经逆运动学转关节指令；机器人运动学由确定性模块处理，不由 VLM 负责。闭环：观察 → 预测 → 执行 → 再观察。
- **语法约束解码（GCD）：** 推理时 logits 处理器，把动作语法编译成有限状态机，非法 token 的 logits 置 -∞；只约束语法，数值仍由 VLM 预测；无额外参数与动作头。
- **模型：** 零样本与真机微调使用论文所称 “Qwen-3.8-27B”（正文与图注/参考文献中写作 Qwen3.5 / Qwen3.8-next，命名在原文内不一致，此处照录）；真机微调用 LoRA；LIBERO 仿真微调用 Qwen3.5-0.8B 且不使用深度输入。
- **真机：** UR3 + Robotiq 2F-85，腕部 Orbbec Gemini 305 + 固定 Intel RealSense D435i，60×60 cm 工作区；Haptic Touch 遥操作，20 Hz 记录；Task Group 2 每任务 30 条示范。学习率、轮数、训练 GPU 原文未给出。

## 论文报告的结果

- **零样本真机（6 个任务，每任务 3 轮×10 次）：** EASG 平均 79.4%（抓黄瓜 93.3、拿积木 90.0、香蕉放盘 66.7、合上笔记本 100、推抽屉关闭 93.3、折毛巾 33.3）。
- **对比微调 VLA（每任务 10/30/50 条示范，平均 %）：** π0.5 43.9 / 76.1 / 96.7；π0-FAST 30.6 / 56.7 / 85.6；GR00T N1.6 38.9 / 67.8 / 95.6；OpenVLA-OFT 41.1 / 66.1 / 88.9。30 条示范时只有 π0.5 接近 EASG 的 79.4，其余仍低。
- **随机化（物体位姿/位置/颜色）：** EASG 77.3±5.9；50 条示范微调的 π0.5 40.2±8.7、π0-FAST 25.5±9.5、GR00T 37.8±10.6、OpenVLA-OFT 28.1±10.9（它们在原始设置分别为 96.7 / 85.6 / 95.6 / 88.9）。
- **更难的真机任务（微调后）：** EASG 平均 75.5；π0-FAST 77.8；Octo 69.7；OpenVLA 67.8。表内 EASG 低于 π0-FAST。附录 Table A5 另有 EASG 67.2±5.1、π0-FAST 70.0±3.3、OpenVLA 55.0±3.3（设置与正文表不同，原文未交代）。
- **LIBERO（0.8B）：** EASG 平均 83.3（Spatial 92.5 / Object 93.8 / Goal 83.1 / LIBERO-10 63.7）；π0-FAST 85.5；OpenVLA 76.5；Octo 75.1。
- **跨本体：** UR3 平均 63.9，换成 Flexiv 7-DoF 平均 62.2（同一数据管线，Flexiv 不用外部相机）。
- **消融：** 零样本去掉动作坐标系或去掉度量深度，平均均降为 0.0（相对 79.4）；去掉 GCD 的 LIBERO 平均由 83.3 降至 72.7（正文写 72.6）。思考与记忆：Thinking+Memory 79.4，Thinking 无 Memory 64.4，无 Thinking 有 Memory 11.7，两者皆无 8.9。
