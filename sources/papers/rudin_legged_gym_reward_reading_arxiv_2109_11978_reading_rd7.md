# Rudin 等 legged_gym 论文通读（奖励设计视角）

> 来源归档（原文通读 · 支撑 `wiki/concepts/reward-design.md`）

- **标题：** Learning to Walk in Minutes Using Massively Parallel Deep Reinforcement Learning
- **作者：** Nikita Rudin, David Hoeller, Philipp Reist, Marco Hutter（ETH Zurich / NVIDIA）
- **类型：** paper / rl / locomotion
- **原文：** <https://arxiv.org/abs/2109.11978>（2026-11 通过 arXiv PDF v3 获取全文）
- **一句话说明：** 用 Isaac Gym 全 GPU 流水线并行数千台机器人，配合自动地形课程与一组很简单的九项加权奖励，在 20 分钟内训出可上实机的 ANYmal 崎岖地形策略。
- **核对范围：** 通读正文 §1–§5（含 §2 并行 PPO 改动、§3 任务 / 课程 / 观测动作奖励 / sim-to-real 附加项、§4 实验）及附录 A.1–A.5（吞吐分析、超时 bootstrap、奖励项表、PPO 超参、观测噪声）；参考文献列表仅浏览，未逐篇核对被引文献。奖励设计的通用理论（Ng 1999 势函数塑形等）未在本档案阅读，依赖 wiki 页面既有内容。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **总奖励（§3.2）：** 九项加权和；主项为跟踪指令线速度 / 偏航角速度，同时惩罚其余轴向的基座速度；为获得更平滑自然的运动，惩罚关节力矩、关节加速度、关节目标变化（动作变化率）与碰撞；另加一项鼓励更长步幅（足端滞空时间）。膝、小腿、足端撞竖直面算碰撞，基座接触算 crash 并触发重置。单一策略、同一奖励适用于所有地形。
- **奖励项与权重（附录 A.3，表 2，均乘 dt）：** 线速度跟踪 φ(v−v*) 权重 1；角速度跟踪 0.5；竖直线速度惩罚 −v_z² 权重 4；横滚 / 俯仰角速度惩罚 0.05；关节速度 + 加速度惩罚 0.001；关节力矩 2e-5；动作变化率 0.25；碰撞 0.001；足端滞空 Σ(t_air−0.5) 权重 2。φ(x)=exp(−‖x‖²/0.25)。
- **无步态先验（§3.2、§4.2）：** 奖励与动作空间均不含步态相关项；策略自由选步态，实验中总收敛到小跑（trot），但常有拖腿或基座过高 / 过低等伪影，需"调奖励权重"后才满足约束并可上实机。
- **跨机器人迁移（§4.2）：** ANYmal B、带臂 ANYmal C 无需改奖励与超参即可重训；Unitree A1 需去掉执行器网络、降低 PD 增益与力矩惩罚、改默认关节构型；双足 Cassie 必须再加一项"单脚站立"奖励才能走出步态。
- **课程（§3.1）：** 机器人走出地形边界则升级，回合内位移不到目标速度所需距离的一半则降级，通关最高级后随机回到某一级以防遗忘；台阶 / 障碍高 5→20 cm，坡度 0→25°；无需外部调参。
- **超时处理（§2.2.2、A.2）：** 区分失败终止与超时终止，超时时用 critic 自身预测做 bootstrap；Gym 接口默认不区分；有无此处理，总奖励差约 10%–20%，critic loss 更高。
- **并行 PPO（§2.2、§4.1、A.4）：** B = n_robots × n_steps；n_steps 少于约 25 步（0.5 s）时 GAE 失效学不好；采用 4096 机器人、批量 98304、mini-batch 24576、5 epoch、clip 0.2、γ=0.99、λ=0.95、自适应学习率；1500 次更新 <20 分钟。
- **sim-to-real（§3.3、§4.3）：** 摩擦 [0.5,1.25] 随机化、观测噪声（表 4）、每 10 s 随机推（±1 m/s）；实机地形高度图（激光建图）质量差，故实机速度指令限制在 0.6 m/s。
- **局限（§5）：** 目的不是最强鲁棒性；未使用教师-学生结构，作者列为未来工作。
