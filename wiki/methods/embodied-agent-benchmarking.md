# 具身智能体评测方法

## 一句话定义

围绕任务、环境、动作接口和结果度量组织具身智能体评测。

## 英文缩写速查

| 缩写 | 英文全称 | 说明 |
|---|---|---|
| API | Application Programming Interface | 组件交互接口 |

## 关联概念

- [相关概念](../concepts/ai-agent-evaluation.md)：了解本方法涉及的背景与边界。

## 为什么重要

明确任务边界、数据来源和验证方式，有助于比较不同系统并避免把背景任务误认为已经完成的实验。

## 主要技术路线

1. **界定任务和环境**：明确本体、场景、初始状态、指令和可用工具；区分仿真、真机与离线数据。
2. **规范交互与预算**：记录感知输入、动作接口、调用次数、运行时间及人工介入，避免比较中信息或计算预算不一致。
3. **报告结果与失效**：同时报告成功判据、试验次数、任务分布与失败类型；需要时给出重复试验和不确定性。

[RoboArena](roboarena.md) 是面向机器人操作策略的真机成对比较实例；它不能代表所有导航、仿真或智能体基准的评测协议。
