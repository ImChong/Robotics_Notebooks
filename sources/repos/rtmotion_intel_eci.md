## 一手描述（README / 官方文档）

ECI 官方文档（3.3）：「RTmotion is an open source C++ library created by Intel」，实现 PLCopen motion control standard 的 part 1 和 2，加上机器视觉与 ROS 2 扩展后已被部署用于离散自动化设备、AMR 与机械臂；通过 ECI 的 apt 仓库分发（含 `plcopen-motion`、`plcopen-servo`、`plcopen-ruckig`、`plcopen-databus` 等包）。
