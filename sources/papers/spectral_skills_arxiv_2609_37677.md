## 核心问题及创新

上层规划器与底层全身控制器之间，需要同时兼顾可预测、易执行、可组合的命令接口。作者不让编码器仅重建自身输入动作，而是从动作片段 B 提取技能 z，再联合前文 X **预测后续运动 Y**；其条件扩散噪声预测器被设计为相对于 z 的仿射形式。

论文采用连续 64 维 z；在 Unitree G1 29 DoF、50 Hz 场景中，编码窗口 H=10 帧＝0.2 s（附录 A/B）。**注意：0.2 s 是单个运动技能窗口，不等于 0.2 s 的推理延迟**。

## 方法摘录（§3、附录 A/B）

1. **三窗口预测学习：** 每条动作划分上下文 X（P=6 帧）、待编码片段 B（H=10 帧）和未来 Y（L=10 帧）。技能编码器 Eψ(B) 生成 z，条件去噪学习 Y 的后续运动；论文对照重建损失说明预测监督的重要性。
2. **因式化条件扩散：** 噪声预测由未来特征、历史特征和 `Az+b` 构造；z 只通过仿射映射进入预测器，因而单个固定历史／固定噪声步的响应关于 z 有精确线性结构。这一性质**不等于整个扩散采样结果、机器人闭环动力学在 z 上精确线性**。
3. **谱方向：** 以预测器相对技能的雅可比 J，对上下文集合求平均 Gram 矩阵 C＝E[JᵀJ]，其特征向量给出互相正交的谱方向 vᵢ；按照平均预测响应排序，**并非按人类可解释性或动作成功率排序**。
4. **冻结控制器：** 编码器预训练后冻结，用 PPO 训练 50 Hz 全身跟踪策略。部署时 z＝z_base＋Σηᵢ(t)vᵢ，用同一策略做运动跟踪、技能切换与组合，不为每个组合单独训练控制器。
5. **语言规划：** 以语言和历史为条件的 flow-matching 高层模型预测技能序列；附录指出论文主对照中的语言规划成功率使用**早期 256 维技能接口**，不可直接写成 64 维最终谱方向控制器的对照成绩。

## 实验核对（§4、附录 C–H）

| 实验 | 原文数据与限定 |
|---|---|
| 主要仿真跟踪 | 4096 条动作，同设置 SONIC v1.1：MPJPE-G **187.86 → 70.51 mm**（约 **−62.5%**）；MPJPE-L **26.74 → 20.54 mm**；成功率 **98.88% → 98.27%**（略降）。 |
| 较小 124 动作测试集 | MPJPE-G **173.92 → 65.06 mm**，两者成功率均 100%。 |
| 仿真训练量比较 | 约 **5×10¹⁰** 仿真帧；与 SONIC 大模型报告的 **6.29×10¹¹** 帧对比（非相同训练管线的严格算力消融）。 |
| 技能切换 | 42 条组合序列中 36 条更平滑；13 个双技能切换报告约 **0.04 s** 过渡。该值是论文测量的切换过渡表现，不能泛化为所有动作或上层规划延迟。 |
| 技能组合 | 从走、慢跑、蹲、倒走、搬运等基础动作，叠加抬手、转弯、抬脚、快慢等属性；训练集少见的组合可执行，但受基础动作与方向兼容性、幅值制约。 |
| 语言规划 | 论文报告 N=10 时约 **91.1% vs 77.1%** 的对照；附录 C 明确该规划比较使用更早的 **256-D 技能控制器**，而非本文主要 64-D 仿射谱模型。 |
| 真机 | 官网页面有 Unitree G1 跟踪、切换、合成和语言控制视频；上述仿真 MPJPE 数字**不是**真机定量测试结果。 |

## 重要反例与边界（附录 F/G、§5）

- 谱方向自动产生，但不保证每个方向都清楚、稳定、有用：部分方向会造成跌倒或弱效果，标签依靠执行后观察。
- **方向叠加不保证作用完全独立**：不同指令可能相互抵消或放大；附录中多个同时叠加的转向指令出现明显非线性交互。
- 主要跟踪测试取训练运动语料的动作集合，不应误读为「在全部未见动作上降低 62%」。
- 一项实验中使用的网页 ONNX + MuJoCo WASM 现场演示，不等同于完整公开可复现训练仓库。
- 研究目标是便于规划和组合的接口，而非已经实证「无限组合」或保证任意任务成功。
