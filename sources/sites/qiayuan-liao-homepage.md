# Qiayuan Liao — 个人学术主页

- **类型：** 个人研究主页
- **链接：** <https://qiayuanl.github.io/>
- **核查日期：** 2026-11-01；核查范围为主页公开内容及所列代码仓库页面。
- **简介：** 主页自述为加州大学伯克利分校博士生，导师为 Koushil Sreenath 与 Pieter Abbeel；研究人形机器人全身移动操作，以及数据、硬件与控制协同设计。曾在 Boston Dynamics 参与 E-Atlas 强化学习控制研究。
