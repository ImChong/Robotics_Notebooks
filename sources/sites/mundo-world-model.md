## 项目可核对的展示内容

- 从 1–12 张场景图生成新视角；大型场景支持几十张上下文视图与分段长视频。
- 脚本化修改质量、摩擦、外力、动作，MuJoCo 等引擎给出接触/运动轨迹，类别色代理帧驱动生成视频。
- 机器人演示涉及酒店楼层的目标导航、洗衣房的空间探索与开门动作，以及第一/第三人称机器人操作视频。
- 项目页的 Mundo API 代码是简化示意，不能据此声称代码已开源或示例能够直接运行。
