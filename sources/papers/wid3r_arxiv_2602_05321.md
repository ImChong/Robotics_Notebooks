## 摘录 1：问题与核心主张（arXiv abstract）

- **瓶颈：** 现有前馈视觉几何方法多假设 **针孔/已校正** 输入；宽 FoV（鱼眼、360°）需额外标定与去畸变，且畸变会破坏针孔假设下的特征与几何一致性。
- **Wid3R 解法：** **射线表示 + 球谐编码** 与 **相机模型 token** 条件化，使网络 **畸变感知**；同一前馈 pass 预测稠密点图与相机位姿。
- **首创性（作者声称）：** 首个支持 **360° 影像** 的多帧前馈 3D 重建方法。
- **数据效率：** 混合多种相机模型训练可 **缓解 360 数据稀疏**，并提升泛化。

## 摘录 2：机制与 I/O（项目页 + README）

| 模块 | 要点 |
|------|------|
| **输入** | `images: B×N×3×H×W`（[0,1]）+ `cameras: B×N` 相机模型参数 |
| **相机条件** | **Camera model token** 适配不同投影模型（demo 提供 fisheye / 360 模式） |
| **几何表示** | **Ray-based** 图像特征与 **spherical harmonics** 射线几何融合 |
| **输出** | `local_points`、`camera_poses`、`points`（全局对齐点图）、`uncertain`（转置信度滤点） |
| **推理** | 单次前馈；Gradio demo 导出彩色点云 GLB |
| **训练初始化** | [Pi3](https://huggingface.co/yyfz233/Pi3) `model.safetensors`；Hydra + Accelerate DDP |
| **训练混合** | TartanAirV2、ASE、Hypersim、KITTI-360、Loc360、Matterport3D、ScanNet++、EDEN、Virtual KITTI 2 等 |
