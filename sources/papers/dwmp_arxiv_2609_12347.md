## 核心摘录

1. **模态分治：** 本体观测低维但动力学强非线性 → Auto-Koopman 提升到近似线性潜空间；头戴深度高维冗余 → DepthDreamer（RSSM）压缩为随机潜状态，保留障碍几何。
2. **两阶段共训：** Phase 1 用特权教师探索数据预训双 WM；Phase 2 学生策略在融合潜表示 \(\mathbf{x}_t^{\mathrm{policy}}=[z_t^{\mathrm{prop}}, z_t^{\mathrm{vis}}]\) 上 RL+行为克隆，WM 编码器随学生分布在线微调。
3. **仿真（MuJoCo / G1）：** 五类障碍（Ceil / Bar / Narrow / Mbar / Mceilbar）成功率 0.85–0.95，优于 HumanoidPF、Dreamer-v3、VAE 等；相对强 teacher-student 基线约 **+10%**。
4. **真机：** 随机布局 Ceil / Mceilbar / Narrow 通过率 0.95 / 0.80 / 0.70，对照 HumanoidPF 直接蒸馏 0.80 / 0.60 / 0.65。
