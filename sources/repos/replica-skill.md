## 仓库内容

README 将 11 个技能串成 `recon → architect → design → build → backend → test → diff → entrepreneur → brand → launch → deploy` 工作流。技能把调研结果、功能矩阵和设计资料写入项目的 `replica/` 目录，供后续步骤继续使用。另含图像差异、功能覆盖率、评论分析、对比度、品牌残留扫描和商店文案检查等 Python 命令行工具。

## 使用与边界

README 标注 Python 3.8+，工具使用标准库，无需额外 pip 安装。作者声明采用 clean-room 方式重建功能和交互，不复制目标项目代码、商标、专有素材、文案或私有 API；建议只查看获准访问的公开页面和用户自己的账户。该声明是项目方的设计约束，不替代使用者对目标服务条款、知识产权和发布内容的核查。
