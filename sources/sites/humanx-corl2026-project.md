# HumanX（CoRL 2026）官方项目主页

> 来源归档（site / project page）

- **标题：** HumanX: Toward Agile and Generalizable Humanoid Interaction Skills from Human Videos（HumanX：从人类视频学习敏捷可泛化的人形交互技能）
- **URL：** <https://wyhuai.github.io/human-x/>
- **论文：** <https://arxiv.org/abs/2602.02473>（v2，2026-10-09；CoRL 2026）
- **作者：** Yinhuai Wang、Qihan Zhao、Yuen Fui Lau、Runyi Yu、Hok Wai Tsui、Qifeng Chen、Jingbo Wang、Jiangmiao Pang、Ping Tan
- **机构：** 香港科技大学、上海人工智能实验室
- **代码：** <https://github.com/wyhuai/humanx>
- **入库日期：** 2026-11-18
- **核对范围：** 阅读官方项目主页、作者与机构、摘要和代码链接。
- **一句话：** XGen 合成与增强人形-物体接触数据，XMimic 训练交互优先的模仿策略。
