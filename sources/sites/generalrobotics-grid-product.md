## 开源核查（2026-09-27）

| 资源 | 状态 | 说明 |
|------|------|------|
| GRID Enterprise monorepo | **未开源** | 企业版为可扩展私有部署；无可公开克隆的完整平台仓库 |
| **Open GRID** | **Web 平台（免安装）** | <https://grid.generalrobotics.dev>；与 CLI/集群文档（v2.1）并列，面向快速上手 |
| **GRID-playground** | **部分开源** | [GenRobo/GRID-playground](https://github.com/GenRobo/GRID-playground) — 示例 **JSON 配置 + Jupyter notebook**（AirGen / Isaac 场景），非平台本体 |
| 技术报告 | **公开 PDF** | [arXiv:2310.00887](https://arxiv.org/abs/2310.00887) |

**结论：** **Open GRID + Playground + 文档** 可审计入门路径；**Auto-Engineering 四类 harness 与 Enterprise 训练闭环** 仍以产品/博客描述为主，复现需组织账号或 PoC。

## 页面要点（策展）

- **定位：** Physical AI intelligence platform；模块化技能库 + auto-engineering 复利。
- **流程：** Connect 任意机器人 → Deploy 技能或工作流 → Evolve 随部署改进。
- **内容营销：** Auto-engineering 发布、DreamControl 人形技能、agentic 架构演示等视频链。
