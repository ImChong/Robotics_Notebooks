## 核心论点（归纳，非直接摘录）

- 机器人交付不能只看 demo 成功：系统集成（PLC/MES/传感器/工装）、节拍、异常恢复、稳定运维与复制成本同样关键。
- 文章将服务提供者分为本体/模型厂商、模型与后训练服务、第三方系统集成及 RaaS 租赁运维。
- 从派驻专家到可复用模板和平台是 FDE 商业化的关键假说；**这是作者判断，不是已证明的行业结论**。
- **文章案例**：智元 Genie Studio 2.0、原力无限 Deployment Scaling、破壳 RoboAPI、原力灵机 Dexmal MaaS；Agility、Tesla、Physical Intelligence、Dream Labs；Formic、NCS/华智天成、擎天租、公共中试平台。

## 文章与一手证据的边界

1. 智元关于三模块及常州 6 台 CNC/14 天验证，厂商 2026-10-26 原文直接支持；这是厂商公布的单个项目**验证**，不等于跨客户普遍部署周期。
2. 破壳 RoboAPI 的视觉/状态/任务指令到动作输出，官方开发文档支持；产品处于技术预览，实际零样本表现需要独立验证。
3. PI API beta、Dream-1 API/FaaS、Formic 月费及试点范围可由各自官方材料支持；Dream-1 明确说明是研究 beta，不适用于安全关键任务。
4. Agility 约 50 万美元是 CAP 项目费（SEC 文件口径），**不是 Digit 的单台售价，也不是所有客户的交付费**；部署/承诺部署需分别区分。
5. 原力无限年会发言、Tesla 自有工厂策略、NCS/华智天成合作、擎天租及公共中试平台细节，本次没有取得逐项完整的一手证明；保留为**文章陈述/待核验**。
