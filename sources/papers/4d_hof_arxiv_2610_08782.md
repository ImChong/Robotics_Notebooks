## 原始贡献

- 目标：从单目 RGB 视频重建随时间变化的手部 MANO 状态、物体几何和 6D 物体姿态。不同于纯噪声采样或每段视频独立做耗时优化，以视觉基础模型的粗初始化作为有结构的起点。
- 初始化：VLM + SAM 3 做对象识别/分割；WiLoR 预测手部；MoGe-3 深度/相机辅助度量尺度与手物体对齐；多关键帧 + 多视图生成恢复物体网格；增强 FoundationPose 估计逐帧物体 6D。
- 模型：点云由 Point Transformer V3 编码，RGB 由 DINOv2 提特征，DiT 通过时间 self-attention 与视觉/3D cross-attention 预测条件速度场，联合更新手部与物体状态。
- 监督：基于原始 GT HOI 轨迹注入结构化扰动训练；总损失为 flow matching、3D 监督、接触/交互与手部保持正则之和。
- 推理指导：后期流积分期间使用轮廓对齐、手物接触与速度/加速度平滑约束；不是另起独立的 per-sequence 后处理优化。
- 数据：HO-Cap、OakInk、SHOWMe 训练；HO3D-v3（18 条序列）与 DexYCB（20 条）测试；测试数据不用于训练。

## 消融与复现边界

- 去掉条件桥：仅基础模型输出 + guidance，HO3D-v3 CD_h 41.75，而完整版 5.98。
- 去掉时间设计：JM 由 1.61 升到 4.26；去掉 guidance：CD_h 由 5.98 升到 8.03。
- 论文局限：严重 MoGe-3 点图误差可令初始化失败；当前研究限单手与刚性物体，未覆盖双手、铰接或可变形物体。
- 开源边界（2026-11-12）：官方仓库发布 HO3D 推理/评测、checkpoint 和预处理初始化下载脚本，尚无完整训练流水线；MANO、HO3D 需分别按许可证取得。不能把论文中全流程基础模型初始化的描述当成该 GitHub 已可端到端重跑的能力。
