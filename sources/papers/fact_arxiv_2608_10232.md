## 论文核对要点（v1，带章节）

- **问题（§1）：** 现有 WAM 的未来预测多在成功演示上训练，坏动作在测试时仍可能配上 success-biased 的未来；作者提出用失败 rollout 做「后果监督」而非行为模仿。
- **形式化（§3.1）：** 动作块 \(a_{t:t+H}\)；世界支路 \(p_\theta(o'_{t:t+K}, v_t \mid o_t,\ell,a)\)；进度 \(p_t=G_t/G_T\)；实验里用均匀进度奖励，\(p_t=t/T\)。
- **架构（§3.2）：** token 序 \([P\|A\|G\|V\|I]\)；训练时 V/I 只看干净动作 G，A 看不到 G；共享视频扩散 Transformer，在每块 FFN 后挂轻量 action adapter（对比 MoT 的独立世界专家）。
- **目标（§3.3，式 6–9）：** 失败样本的进度目标为 \(\mathrm{clip}(p_{t+H}-\lambda_{fail}\mathbb{1}_{fail},0,1)\)；flow matching；成功样本 \(w_aL_a+w_vL_v+w_IL_I\)，失败样本仅 \(w_vL_v+w_IL_I\)。超参：WAN2.2-5B 初始化，AdamW，学习率 action FFN 2e-4 / backbone 2e-5，\(w_a=20, w_v=w_I=1\)，\(H=48\)，\(\lambda_{fail}=1\)，20 步 flow-Euler；未来监督取 [0,H/4,H/2,3H/4,H] 五个帧偏移。
- **推理（§3.3，式 10，附录 A 算法 3）：** Stage 1 去噪动作；若需打分或想象，Stage 2 把动作填入 G 再去噪 value（可选视频）；可选 best-of-N 取 value 最大者，真机用 N=4。
- **RoboTwin（§4.1，表 1，附录 D/E/表 6）：** 50 任务，加约 1.3K 失败 rollout；训练含 clean 2,500 条（50/任务）与 randomized 25,000 条（500/任务）；每任务每 split 100 次试验。Ours 85.6（Clean 86.3 / Rand. 84.9），w/ failure 87.5（88.4 / 86.6），w/o video co-train 81.8，Motus 87.8，Gigaworld-Policy 86.0，π0.5 79.8，π0 62.2，X-VLA 72.9。
- **真机（§4.2，表 2/3，附录 B/C）：** 双 YAM 臂，三路相机（1 RealSense D435 + 2 D405 腕部），GELLO 遥操；5 个 seen 任务、3 个 unseen 变体；cube 任务 200 条示范，其余 50 条；每个 cube 任务约 30 条失败 rollout；每格 20 次试验；所有基线都只在同样的成功示范上微调。seen 平均：Ours 82 / w/ failure 89 / +scoring 92；π0.5 88，Motus 64，π0 48，Cosmos 25。unseen：67 / 77 / 82；π0.5 85，Motus 62，π0 57，Cosmos 8。
- **消融（§4.3）：** 去视频共训 真机 seen 82→58，RoboTwin 85.6→81.8；去因果掩码（无失败数据）真机 82→77；加入失败动作模仿损失 63；仅加 scoring 而无失败共训 79。
- **失败想象（§4.3，表 4/8）：** 512 个留出样本（成功 / 失败各半）。PSNR：失败窗口 19.51→25.92，成功窗口 26.12→26.08；SSIM：失败窗口 0.7461→0.8290，成功窗口 0.8285→0.8286。
- **失败数据 scaling（§4.3，图 6）：** 3 个 RoboTwin clean 任务（Handover Block / Open Microwave / Put Bottles Dustbin），失败比例 p=0/50/100%，平均 32.7%→57.3%（单调）；p=100% 时失败数据约占训练集 45%。
- **候选数（§4.3，图 7）：** 长程抓取任务上 N=1→4 相对完成率明显提升，N 更大收益递减、延迟上升（数值只在图中）。
- **延迟（附录 E，表 7）：** RTX PRO 6000：π0.5 47 ms，π0 45 ms，Motus 1220 ms，Cosmos 620 ms，Ours w/ failure 380 ms（动作-only 部署）。
- **局限（§5，作者自述）：** 可扩到更大的机器人 / 人类交互数据；value head 可换成更强的进度估计器；best-of-N 以算力换可靠性，打分需额外一次前向。

## 摘要级要点

- **问题：** 多数 WAM 在成功演示上训练未来预测，测试时坏动作仍被配对 success-biased 未来；失败数据若直接当模仿目标会污染策略。
- **主张：** 把「学什么动作」与「学动作后果」分开——失败轨迹应监督 **后果**，而非行为。
- **方法：** token 序 \(P\|A\|G\|V\|I\)；世界支路 teacher-force 干净动作 \(G\)；失败样本 \(\mathcal{L}_{\mathrm{act}}\) 掩码，保留 value / future-video；推理 Stage1 出动作、Stage2 可选 value / 视频；value 可对 \(N\) 候选打分。
- **结果要点（项目页 / 论文）：**
  - RoboTwin 50 任务平均：无失败 **85.6%** → 含失败 **87.5%**（接近 Motus 87.8%，部署约 **3×** 更快）
  - 真机 seen：失败共训 **82→89%**，+ scoring **92%**（无大规模机器人预训练）
  - 失败想象诊断：坏动作下未来 PSNR **+6.4 dB**，成功未来不变
- **局限：** 失败数据主要来自模型 rollout；评测主轴为双臂桌面操纵；可选 scoring 增加 Stage2 开销。

## 核心摘录（面向 wiki 编译）

### 1) 因果「先动后想」

共享因果扩散 Transformer 联合去噪 action / value / future-video；value 与未来只看干净动作槽 \(G\)，noisy \(A\) 不可见 \(G\)。

### 2) 失败感知损失

- 成功：\(w_a\mathcal{L}_a+w_v\mathcal{L}_v+w_I\mathcal{L}_I\)
- 失败：仅 \(w_v\mathcal{L}_v+w_I\mathcal{L}_I\)，进度目标下调 \(\lambda_{\mathrm{fail}}\)

### 3) 复现入口（README）

```bash
bash setup_env.sh && conda activate fact
python -m scripts.prepare_robotwin --robotwin_root ./datasets/RoboTwin ...
python -m scripts.train --config world_action_model.configs.robotwin.config
python -m scripts.inference_server --transformer_path ./models/fact-wam/transformer ...
```
