## 核心摘录（归纳，非全文）

### 背景与动机

- 羽毛球：高初速 + 强空气阻力致轨迹非线性衰减；重心/压心偏移致飞行翻转 → **落点预测难**。
- 领域趋势：**分层**（AdaPT / HITTER / LATENT 等规划+跟踪）与 **人类先验**（动捕/视频）；公开工作多聚焦 **接球**，**对战胜负策略层** 仍相对空白。
- 动易路线：把 **策略博弈（大脑）** 与 **本能执行（小脑）** 拆开；真机 **人机对拉 40+ 拍**（文内口径）；仿真内用联赛式 MARL **自我博弈学算球**。

### 小脑：步法 + 挥拍（延续 2511.11218 并扩展）

| 模块 | 文内要点 |
|------|----------|
| 退火课程全身控制 | 先下肢移动奖励，再逐步让击球奖励主导；保留已学步法能力 |
| 风格扩展 | 多参考动作 + **三个判别器**（上手、下手正手、下手反手）；可扩展更多风格 |
| 落点控制 | 退火后加 **回球奖励** + 目标区域 **one-hot** 观测 |
| 技能选择器 | 学 **Q(状态,动作)** 预测各技能 **任务效用**（击中奖励 × 落点奖励）；选效用最高技能，避免无选择器时回合过早结束 |
| 真机演示 | **PHYBOT C2**，身高 **1.35 m**，覆盖约 **4.4×4.4 m** 场地；文称腿式机器人羽毛球 **最长对峙回合** 之一 |

### 大脑：战术与自博弈（仿真为主）

- 表述为 **零和多智能体 RL**；**PFSP** 优先练仍难胜的历史对手；胜率够高则存快照继续训。
- **GRU 高层** 观测：机器人状态、击球状态、对手状态、历史决策 → 输出 **击球方式** + **回球落点** 两个离散决策 → 交给 **固定低层全身控制器** 执行。
- **联赛角色：** Main Agent（提整体）、Main Exploiter（挖主智能体弱点）、League Exploiter（多样化联盟策略）→ 缓解石头剪刀布式 **循环支配**。
- 文称高层战术结果 **仍主要在仿真**；下一步真机验证。
- **跨球类迁移：** 同一框架约 **一周** 迁到乒乓球、足球。

### 自主与部署：DQ-Flow 捡球 + 商场快闪

- **DQ-Flow：** 运动生成与执行分离；短时 RGB 历史 + 本体感知，**flow matching** 生成全身参考；训练用 **深度查询** 作辅助监督，**部署不需深度**。
- **混合全身接口：** 下肢/躯干 RL 跟踪（平衡）；上肢/夹爪直接跟踪生成目标（精度）。
- 与低层 **异步**：执行当前动作时，新参考 **时间对齐交接**，不必停步等上层推理。
- 另线：**DAgger 蒸馏** 捡球（仿真特权教师 → 夹爪 RGB 学生）。
- **商场羽毛球快闪：** 与不同用户互动；强调通信、感知噪声、长期可靠性等实验室难复现问题。

### 现场问答（部署读法）

| 问题 | 回答要点 |
|------|----------|
| 感知 | 当前 **动捕 8 相机**（非端侧相机闭环）；快球（杀球）可达 **20+ m/s** |
| 仿真空气动力学 | **有** 模拟空气阻力 |
| Sim2Real | **零样本**；域随机化 + 噪声 |
| 更快/更强 | 瓶颈主要在 **关节力矩与峰值速度**（硬件迭代）；动捕可 **200 Hz+**，非主要瓶颈 |
| 技能选择器 vs 对手状态 | 选择器 **无对手概念**，按来球区域选技能；**对手位置/线速度/角速度** 在高层 MARL 仿真里通过动捕估计 |

### 演讲五条总结（文内）

1. 人类先验仍重要，如何有效利用仍是开放问题。  
2. 先验打基础，**竞争/实战** 驱动进一步提升。  
3. 仅靠仿真不够 → 系统辨识、世界模型、真机 RL 等需更广方法。  
4. **工程与算法同等重要**（延迟、控制、硬件、微调）。  
5. 运动智能是 **系统级** 问题：策略 + 自主 + 可靠性 + 真机运行。
