## 页面核查（2026-10-13）

- 主页将方法概括为从捕获场景到个性化 VLA 操作；作者单位对应 Georgia Tech、Waymo、Toyota Research Institute。
- 手持扫描建立外观逼真的数字孪生和碰撞网格；系统发现 receptacles，生成可执行拾取任务与成功演示，再做两阶段策略适配。
- 结果摘要显示 101 个室内场景、852 个承载面、68,021 条演示；Stretch 3 上 12 项任务子集成功率为 63.9%。
- 主页另报告 Office 目标场景聚合成功率 62.5%，并指出未见承载面仍有明显性能下降。
- Code 与 dataset 均标为即将发布；当前不视为已开源，也不建立源码仓库归档。

**结论：截至入库日，论文与项目页可读，官方代码与数据仍未公开。**
