## 三方向架构

| 方向 | 主要技术 | 在线接口 |
|---|---|---|
| **TGR-GenRank** | CCFormer：user、behavior、target 三类 feature token；field-separated cross attention + subspace token mixing + hierarchical sequence compression | 仍输出逐 item 多任务分数，兼容既有级联 |
| **TGR-GenRec** | 两条**并行、独立**的生产生成式推荐工作：BARGE（item SID 预测）和 HiGR（整 slate 规划） | 生成 item 或列表；并非把 BARGE 与 HiGR 串联 |
| **TGR-Reason** | LatentRec 离线 Think 模型输出 reason tokens；DRI 注入和 GMR 群体记忆增强 | request-path 读已物化的 Reason Store，不实时运行大规模推理 |

共享基础设施包括 Numerous-Torch、用户/上下文编码接口；BARGE 的 OSQ-VAE 与 HiGR 的 PCRQ-VAE 是不同 tokenizer，尚未统一为一个模型。

### 技术细节

- **CCFormer**：三路定向注意力 user→sequence、target→sequence、target→user；target token 不互相注意，便于单次并行候选打分；长历史用子空间 token mixing 与逐层压缩控制复杂度。
- **BARGE**：通过 Item Context-Aware Attention、Hierarchical Path Reranking 与 Dual-Path Decoding 缓解 SID 序列物品边界混叠及上层生成错误导致的 semantic drift。
- **HiGR**：PCRQ-VAE 前缀结构化 SID → HSD 粗到细列表生成 → ORPO listwise 多目标对齐；详见独立 HiGR 来源归档。
- **TGR-Reason**：Qwen3-1.7B Think 模型用 LatentRec/Soft Token Selection 训练，离线导出 reason tokens。在线通过 DRI（软提示）及 GMR（基于 reason SID 的群体记忆）融入生成器。
- **版本化存储**：Reason 记录按行为截止时间 behavior_cutoff（而不是任务完成时间）判断新鲜度；离线/近线 conditional update 防止陈旧覆盖。

## 报告数据与边界

- **GenRank CCFormer**：对 HSTU 训练吞吐约 **2.21×**；五个 A/B 场景显著收益，其中视频推荐 CTR **+3.57%**，广告场景收入 **+1.71%**；不同场景不能合并为单一实验。
- **GenRec BARGE**：对 OneRec，两个场景的 Hit@5 相对提升约 **10.2%–16.9%**；线上 CTR **+0.60%**、阅读时长 **+1.70%**。
- **GenRec HiGR**：工业与公开数据上优化列表质量；生成解码相比对照加速约 5×；线上平均观看时长 **+1.22%**、视频观看次数 **+1.73%**。
- **Reason**：新用户冷启动 Hit@1 相对提高 **477.8%**；线上有效消费率 **+1.75%**、新用户曝光到转化率 **+13.09%**（报告给定场景、相对基线）。
- **作者明确局限**：三分支尚未统一为单一端到端模型；新品冷启动仍受 SID tokenizer 所限；多目标 ORPO 权重未按用户/场景自适应；在线推理并非 request-time 实时思考。
