## 仓库现状

README 表示代码、预训练模型和评估脚本将发布，并列出 PamiVAE、PamiGen、PamiRefiner 权重等发布项。数据准备与预处理脚本也尚未提供。当前应把该仓库视作官方发布占位，而不是已经可运行的开源实现。

项目使用 InterAct 及多个既有 HOI 动捕来源进行训练/评估；人体模型资产（如 SMPL-H / SMPL-X）与数据集需分别按各自许可和获取要求处理。
