## 论文要解决的问题

VLA 基于预训练 VLM，但不从未来世界状态中学习；世界–动作模型（WAM）先预测未来再条件化动作，推理多一次未来生成，且视觉预测误差会传入动作。FDM 让“未来预测依赖动作特征”（action-to-future），动作预测读不到未来 token，因此训练时用真实未来监督策略，推理时直接跳过未来生成。

## 方法与训练信息

1. **结构：** Mixture-of-Transformers；生成专家读取动作专家的隐状态 H_a，动作专家不能读生成分支 token（含间接路径）。对照变体 C（stop-gradient）把面向生成的 H_a 换成 sg(H_a)，前向不变但未来损失梯度不回流。
2. **FDM w/ VLM：** 基于 π0.5（pi05_base_pytorch；Gemma-2B 语言骨干、Gemma-300M 动作专家、So400m/14 视觉编码器），生成专家随机初始化为动作专家同架构；未来图像损失为 Wan VAE 潜变量上的 MSE（由 t−15 与 t 帧预测 t+15 帧，单次回归，无视觉去噪）。
3. **FDM w/ VGM：** 基于 Wan2.2-TI2V-5B，动作专家随机初始化；两专家均 30 层，隐层维度 3072（视频）/ 1024（动作）；未来视频损失为流匹配速度损失，仅作用于未来潜变量。
4. **总损失：** L_total = λ_a·L_act + λ_v·L_world，λ_a=λ_v=1；动作为动作块上的流匹配。
5. **训练设置：** AdamW(0.9,0.95)，梯度裁剪 1.0，BF16，DeepSpeed ZeRO-2，种子 42，8 张 H100 训练、1 张 H100 推理。LIBERO（1,659 / 34 train/val episodes）：VLM 30k 步、lr 2.5e-5、batch 128、动作 horizon 15；VGM 22k 步、lr 1e-4→1e-6、batch 128、horizon 32。RoboTwin：VLM 60k 步、batch 256、horizon 50、3 视角；VGM 29,375 步、batch 1,024、horizon 32。真机：30k 步、batch 64、执行 horizon 25。

## 论文报告的结果

- **LIBERO（成功率，FDM 无机器人预训练）：** FDM w/ VLM Spatial/Object/Goal/Long = 99.2/100.0/99.8/98.6，平均 99.4；π0 94.1、π0.5 96.9。FDM w/ VGM 98.8/100.0/99.2/94.2，平均 98.1；Motus 97.7、LingBot-VA 98.5（VGM 平均低于 LingBot-VA，Long 低于 Motus 与 LingBot-VA）。
- **RoboTwin 2.0（50 任务，clean/randomized/平均）：** FDM w/ VLM 81.54/80.86/81.20（π0.5 为 82.74/76.76/79.75，clean 低于 π0.5）；FDM w/ VGM 88.84/89.62/89.23（Motus 87.8，LingBot-VA 92.20，VGM 低于 LingBot-VA）。
- **真机（双臂 ARX-X5，5 任务，每方法每任务 20 次，各任务 150 条示范）：** FDM w/ VLM 平均 96% 对 π0.5 83%；FDM w/ VGM 83% 对 FastWAM-Joint 78%、DreamZero 71%。两个 FDM 变体在 Cup 与 Block 均为 100%；基线逐任务数字仅在图中。
- **消融（真机平均）：** VLM：A 仅动作 83 → B 仅作上下文的未来 87 → C stop-gradient 89 → D 完整 FDM 96；VGM：66 → 72 → 78 → 83。D 对 C 的反向监督增益 +7（VLM）/ +5（VGM）。
- **效率：** VLM 训练步时 0.4436 s → 0.6305 s（+42.14%），峰值显存 67.08 → 72.04 GiB，推理 203.77 ms（π0.5）对 202.98 ms/chunk；VGM 训练步时与 FastWAM-Joint 基本持平（0.9754 s 对 0.9729 s），推理 446.55 ms 对 253.45 ms/chunk（1.76×，−43.24%）。
- **扰动分析：** FastWAM-Joint 在未来扰动 α=1.0 下动作误差上升 4.44%（LIBERO）与 5.52%（RoboTwin）；FDM 的动作误差对未来扰动按构造不变。
- 梯度对齐分析只在图中，无数字。

## 复现与解释边界

- 论文没有显式局限节；从结果看，FDM w/ VLM 在 RoboTwin clean 上低于 π0.5，FDM w/ VGM 在 LIBERO 与 RoboTwin 上均低于 LingBot-VA。
- 仿真单种子（42）；真机每任务仅 20 次试验。
- 官方代码 README 注明：基础 YAML 与启动脚本只是起点，部分默认值与论文不同（如 RoboTwin 需关闭本体状态）；数据集与 FDM checkpoint 不随仓库发布。
