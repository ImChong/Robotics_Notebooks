## 仓库入口

| 仓库 | 作用 |
|------|------|
| [eidon-tracker](https://github.com/Eidon-AI/eidon-tracker) | 电池供电的 IMU 到 Bluetooth Tracker，配合官方 7-IMU 穿戴方案采集上肢朝向。 |
| [eidon-glove](https://github.com/Eidon-AI/eidon-glove) | Hall-effect 传感器手套，提供 16-DOF 手指关节追踪；包含固件、PCB/CAD 与 Web 可视化代码。 |
| [eidon-sim](https://github.com/Eidon-AI/eidon-sim) | Eidon Sim 的运动学、骨架可视化及视频同步轨迹回放工具。 |
