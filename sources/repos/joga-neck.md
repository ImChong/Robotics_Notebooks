# joga-neck（Joga 2-DoF 主动相机颈部）

> 来源归档（ingest）

- **标题：** Joga Neck: a 2-DoF yaw-pitch active camera neck for the Unitree G1
- **类型：** repo（开源硬件 / CAD / 机器人模型）
- **来源：** MIT Improbable AI Lab · Joga 项目
- **链接：** <https://github.com/mfpeticco/joga-neck>
- **项目页：** <https://joga.csail.mit.edu/neck/>
- **论文：** <https://joga.csail.mit.edu/static/joga.pdf>
- **许可证：** CC BY 4.0（仓库说明；第三方 DYNAMIXEL、OAK-1 和 Unitree G1 模型另受各自条款约束）
- **入库日期：** 2026-10-20
- **一句话说明：** 面向 Unitree G1 的 2-DoF yaw-pitch 相机颈部开源硬件，提供打印件、CAD、STEP、URDF、BOM 与装配/布线指南。
- **开源状态：** **已开源（硬件资料）**；此仓库不含 Joga 足球策略的训练或部署实现。

## 仓库概况

| 字段 | 内容 |
|------|------|
| 自由度 | 2-DoF，yaw ±90°；pitch 向上 20°、向下 90° |
| 执行器 | 2× DYNAMIXEL XC330 系列舵机 |
| 相机 | Luxonis OAK-1 W |
| 质量 | 约 178 g |
| 文件 | STL、STEP、Onshape CAD、URDF、G1 MuJoCo 模型、BOM |
| 装配 | 打印设置、安装、供电和布线说明 |
