# ω-HOME：Hugging Face 数据集

- **类型：** dataset / humanoid / loco-manipulation / whole-body-control
- **数据集：** <https://huggingface.co/datasets/keycharon/omega-HOME>
- **项目页：** <https://gentlefress.github.io/OMEGA-0_page/>
- **代码：** <https://github.com/gentlefress/Omega-0>（[归档](../repos/omega-0.md)）
- **论文：** <https://arxiv.org/abs/2608.06375>（[摘录](../papers/omega0_arxiv_2608_06375.md)）
- **许可证：** Hugging Face 页面标注 MIT
- **核查日期：** 2026-10-03
- **一句话说明：** ω-0 配套的真实家庭场景人形 loco-manipulation 数据集；项目页报告原始采集规模为 40.3 小时、24 项任务、4,827 个 episode。

## 当前托管页面信息

Hugging Face 数据集页目前可访问，标注 video 模态、humanoid / whole-body-control / sonic 标签、MIT 许可证；页面预览列出 train split 9,656 行、总大小 38.2 GB。数据集卡 README 目前为空，因此具体文件组织、逐模态覆盖、下载与使用约束应以仓库/数据卡后续更新为准。

注意区分项目页论文统计的原始采集集规模（4,827 episodes）与 HF viewer 显示的行数（9,656 rows）；两者计数口径未在数据卡中解释，不应直接视为同一统计量。
