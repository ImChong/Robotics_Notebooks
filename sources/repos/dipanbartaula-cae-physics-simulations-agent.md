## 仓库说明

This repository contains the agentic solution for running CAE Simulation tasks using julia_CUDA scripting and thus executing jobs in cluster compute. Job Scheduling and tracking is implemented using REDIS/Celery+SLURM Cluster Management

## 文章中的定位

使用 Julia/CUDA 脚本运行 CAE 物理仿真，并以 Redis/Celery 与 SLURM 管理集群任务；与桌面软件助手相比，重点在集群计算编排。
