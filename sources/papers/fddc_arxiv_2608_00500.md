## 摘要级要点

- **问题：** 通用全身跟踪策略能跳能舞，但在单腿支撑上只会**踩/跳恢复**，不会**干净站住**；8 个 2024–2026 已发布通用策略在持出集上 Perfect = **0/90**。
- **可部署障碍：** capture point \(\xi=c+\dot{c}/\omega_0\) 需要基座线速度 \(v_b\)，机载传感器通常没有 → 以往只进奖励/特权 critic，上真机靠蒸馏。
- **关键改写：** 相对支撑足中心 \(s\) 后 \(v_b\) **精确相消**，得到 \(o_{\mathrm{bal}}=(r^B,\dot{r}^B)\in\mathbb{R}^4\)，仅需编码器 + IMU + 运动学/质量模型。
- **奖励：** 人体姿势控制逐项翻译 — MoS（空间软边）+ TTB（时间软边）+ 踝→膝→髋 action-rate 层级 + jerk。
- **训练：** asymmetric FastSAC；actor 463-D 全可机载重构；critic 看世界系特权量；**无** teacher–student 蒸馏。
- **基准：** 共享 MuJoCo G1 核 + 每方法薄适配器；Perfect / Marginal / Failure 三档；sim2sim（≠训练仿真）。
- **结果：** FDDC Perfect **95.6%**（86/90）；去掉动态 CoM 观测 → **55.6%**（−40 pt）；TTB −24 pt；真机定性成功。

## 核心摘录（面向 wiki 编译）

### 1) 可部署动态 CoM

\[
\xi = c + \dot{c}/\omega_0,\quad \omega_0=\sqrt{g/h}
\]

相对支撑足：\(\xi-s\approx r+\dot{r}/\omega_0\)，\(r\triangleq c-s\)。机载重构（附录 A）：

\[
r^B=d_c-d_s,\qquad
\dot{r}^B=\omega^B\times(d_c-d_s)+(J_c-J_s)\dot{q}
\]

### 2) 分层动作集（§4.1）

- 来源：AMS 合成平衡集 9,814 → 蒸馏 **900** 条（每条 4.98 s）
- 两轴分层：支撑腿蹲深（骨盆高）× 摆动足高度 → \(3\times3\) 九类，每类 100（左右各半）
- 划分：720 / 90 / 90（train/val/test，seed 42）
