# R3LIVE（arXiv:2109.07982）

> 来源归档（paper）

- **标题：** R3LIVE: A Robust, Real-time, RGB-colored, LiDAR-Inertial-Visual tightly-coupled state Estimation and mapping package
- **类型：** paper
- **作者 / 机构：** Jiarong Lin、Fu Zhang；香港大学机械工程系（arXiv v1 首页）
- **arXiv：** <https://arxiv.org/abs/2109.07982>（v1，2021-09-10；arXiv 备注为 "Submitted to IEEE Robotics and Automation Letters"）
- **PDF：** <https://arxiv.org/pdf/2109.07982v1>
- **正式发表：** 仓库 README 称论文已被 ICRA 2022 接收（IEEE Xplore 9811935）；本次未打开 IEEE 页面核对，该条为「README 自述」

- **一句话说明：** 以 FAST-LIO 做 LIO 重建几何、以点颜色为状态量的 VIO 做帧到地图光度误差最小化并为全局点云上色的 LiDAR-惯性-视觉紧耦合 ESIKF 系统。

## 核心摘录（均为论文原文内容，括号为位置）

1. **架构（II，Fig. 2）：** LIO 子系统（沿用 FAST-LIO）用 ESIKF 最小化点到面残差并构建全局地图几何；VIO 子系统渲染点云颜色，并通过「帧到帧 PnP 重投影误差」与「帧到地图光度误差」更新状态。
2. **状态与地图（III-A、IV-B）：** 状态 x 为 29 维（含 IMU 姿态位置、速度、陀螺/加计零偏、重力、相机外参、相机-IMU 时间偏移 I_tC、相机内参）；地图由体素（如 0.1 m 立方）与点组成，点为 6 维（位置加 RGB）并带位置/颜色协方差。
3. **VIO 两步（V-A、V-B）：** 先用 Lucas-Kanade 光流在相邻帧间跟踪「已在地图中的点」，据此做 ESIKF 的 PnP 更新；再对跟踪点用「地图点颜色 c_s 与当前图像插值观测颜色 γ_s 之差」做光度更新。论文称单点颜色是点的固有属性、对相机平移旋转不变，故无需图像金字塔（V 开头）。
4. **纹理渲染（V-C）：** 对激活体素内的点，用贝叶斯更新融合新旧颜色（式 32 至 34），并含随时间增长的随机游走噪声项以应对光照变化。
5. **实验 1（VI-B，Fig. 7/8）：** 激光退化且视觉无纹理的白墙 T 形通道，回到起点后相对 ArUco 板真值漂移 1.62 度、4.57 cm。
6. **实验 2（VI-C，Table II）：** HKUST 校园 4 条轨迹，长 1317/1524/1372/1191 m，平移漂移 0.093/0.154/0.164/0.102 m，旋转漂移 2.140/0.285/2.342/3.925 度；不使用回环。引言称最长约 1.5 km 漂移 0.16 m 与 3.9 度。
7. **实验 3（VI-D，Table III，Fig. 12）：** 海滨两条序列，D-GPS RTK 真值；对比 R3LIVE-HiRes（1280x1024 图像、点距 0.01 m）、R3LIVE-RT（320x256、点距 0.10 m）、LVI-SAM（作者改了其 LiDAR 前端以适配 Livox Avia）、R2LIVE、VINS-Mono、FAST-LIO2；指标为 50 至 300 m 子序列的相对旋转/平移误差。
8. **耗时（VI-E，Table IV）：** 桌面机（i7-9700K）与机载机（i7-8550U）上，VIO 单帧耗时随图像尺寸与点云分辨率从 7.01 ms 到 43.71 ms（PC）、15.00 ms 到 166.08 ms（OB）；LIO 单帧 18.40 ms（PC）/ 39.56 ms（OB）。
9. **应用（VII）：** 离线用 CGAL 做 Delaunay 加 graph-cut 网格重建与贴纹理，导出 pcd/ply/obj，接入 Unreal Engine、AirSim 与游戏演示。

## 作者自述与核对者判断的区分

- **作者自述：** 摘要称 "more robustness and higher accuracy in state estimation than current counterparts"；VI-D 称其轨迹「与真值吻合最好」。全文未出现 "state-of-the-art" 字样（对 PDF 文本检索确认）。
- **核对者判断（读 Table III 数值）：** 相对 LVI-SAM、VINS-Mono 优势显著（RTE 常为其数分之一）；相对 R2LIVE 与 FAST-LIO2 差距很小，且有逐项互有胜负或持平（例如序列 a 的 100 m RTE，FAST-LIO2 0.82 低于 R3LIVE-HiRes 1.02；序列 b 的 200 m RTE，R2LIVE 0.57 低于 R3LIVE-HiRes 0.59）。属判断，非论文结论。
