# TACROSS 项目页（tacross-touch-project.github.io）

> 来源归档

- **标题：** TACROSS: An Efficient and Low-Cost Scalable Human Touch System Across Heterogeneous Tactile Sensors for Dexterous Robot Learning
- **类型：** site（项目页）
- **URL：** <https://tacross-touch-project.github.io/>
- **论文：** <https://arxiv.org/abs/2610.11945>
- **代码：** 页面标注“Planned release”，尚无 GitHub/Hugging Face 链接；数据集同样为 Planned release
- **入库日期：** 2026-10-12
- **一句话说明：** 10.86 美元的 285 点压阻触觉手套 + 接触语义对齐，使人类触摸数据可辅助 Revo2 灵巧手策略学习。

## 页面结构

| 区块 | 内容要点 |
|------|----------|
| Overview / Video | 三分钟项目视频 |
| Demonstrations | 定点点胶、液体转移、移液、水果取放四任务 |
| Method | 传感器专属适配器 + 共享接触语义空间；机器人动作为动作真值 |
| Dataset | 159.09 小时人类 + 24.86 小时机器人记录，21,412 条有效人类示范 |
| Evaluation | 140 对 40 条/小时（3.5 倍），520 对 12,000 美元（-95.7%）；消融 51.3 / 73.1 / 49.4 / 91.9%；人类示范 0 到 90 条使成功率 32.5% 到 85.6% |

页面署名机构：香港大学、香港中文大学（深圳）、中国海洋大学、武汉大学、武汉纺织大学、INFIFORCE。

## 开源核查结论

截至 2026-10-12：硬件、软件、数据均为计划发布，无可访问仓库；局限：仅 Revo2 手与四个任务，仍需机器人示范和本体专属重定向/标定。
