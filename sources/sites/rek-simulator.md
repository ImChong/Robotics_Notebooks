# REK Simulator 官方产品页与 iOS 测试版

- **标题：** REK Simulator
- **类型：** site（人形机器人格斗模拟器）
- **项目页：** <https://rek.com/sim>
- **Steam 产品页：** <https://store.steampowered.com/app/4582660/REK/>
- **开发者 / 发行商：** REK
- **入库日期：** 2026-10-18
- **一句话说明：** REK 的人形机器人格斗模拟器；官方称其使用与真实人形机器人相同的 AI，模拟赛表现可关联线下真实机器人 pilot 资格。更新记录提及 iPhone 与 iPad TestFlight 测试版。

## 官方页面核查

| 主题 | 页面公开信息 |
|---|---|
| **模拟器定位** | REK 将其描述为真实机器人格斗的模拟器，模拟器使用与真实人形机器人相同的 AI。 |
| **仿真机制** | Steam 页面称格斗由物理与自平衡 AI 驱动，不使用预制动作；玩家通过屏幕或 VR 操作虚拟机器人。 |
| **Sim-to-real** | 官方模拟器页称模拟赛优秀选手可取得线下 REK 活动驾驶真实机器人的机会。 |
| **平台** | Steam 页面列出 PC / macOS / Linux 等桌面端；更新记录提到 iPhone 和 iPad 通过 TestFlight 提供测试版。 |
| **可访问性边界** | TestFlight 是测试分发渠道；目前所查资料不足以确认 App Store 正式发布状态，也未说明完整 AI 是否在 iPhone 本地运行。 |
