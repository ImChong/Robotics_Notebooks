## 官方页面摘录

UniUni 将自身定位为“智能集群控制系统”，强调零代码、可视化编排与机器人编队。页面列出的核心能力如下：

| 模块 | 页面描述 |
|------|----------|
| 编舞 | 2D / 3D 双视图；以贝塞尔曲线绘制各机器人轨迹；时间线绑定动作 API；音乐伴舞、舞蹈调试、循环执行三种模式；实时状态、温度、雷达监控及急停 |
| 建图与定位 | 激光点云查看与地图管理；3D 定位、坐标转换和定位测试；N×M 阵型规划、间距与偏移设置、碰撞检测 |
| 动作市场 | 浏览、安装、卸载、云端同步社区动作；页面称与 UniStore 联动 |
| AI 编舞 | 根据自然语言指令建议编队轨迹和动作序列，并同步到时间线供用户微调 |

### 页面展示的接入流程

1. 安装桌面端并用宇树账号登录；应用扫描局域网机器人并配对。
2. 导入点云地图，绘制轨迹并编排动作；将机器人分组、绑定轨道。
3. 将机器人放到初始位置并初始化定位，同步地图、轨迹和任务后启动演出。

### 公开边界

- 页面明确列出支持 Windows 与 Apple Silicon macOS，版本均为 **v1.0.1**；没有列出明确兼容机型矩阵、网络同步协议、控制接口或定位精度数值。
- 页面声称曾用于央视春晚、中央广播电视塔、中美乒乓外交及香港橄榄球赛等场景；这些属于厂商页面自述，未在本归档中独立核验。
- 官网提供可下载应用，但截至核查日未提供源码链接，因此归类为**闭源软件**。页面提及的功能不能据此推断为公开 API 或可复现算法。
