## 项目概览

RT-Thread 是开源、社区驱动的实时操作系统，面向 MCU 与 IoT 设备。项目文档与 README 介绍 Standard / Nano 版本、内核、组件层、BSP、支持架构与开发工具。官方仓库 README 称 Nano 可裁剪至约 3 KB Flash 和 1.2 KB RAM 的最低资源需求。
