## 核心论文摘录（全文核对）

### 1) 问题：阶段歧义与部分可观测

- **链接：** <https://arxiv.org/abs/2606.23589> §I
- **摘录要点：** 长程操作常出现 **stage ambiguity**：当前视觉相似但应执行不同动作，取决于已完成子步骤。仅条件于当前观测的 VLA 难以在歧义点选对动作。现有记忆增强路线两类局限：**稠密历史**（token merge / RNN / 固定潜表示）易把稀疏状态转移与大量冗余帧混压；**任务分解**（VLM 跟踪进度）需子任务监督、在线推理成本高且语义摘要/子目标幻觉可传播。
- **对 wiki 的映射：**
  - [KEMO（论文实体）](../../wiki/entities/paper-kemo-event-driven-keyframe-memory-vla.md) — 问题定义与记忆范式定位。
  - [Manipulation](../../wiki/tasks/manipulation.md) — 长程桌面/双臂操作语境。

### 2) 事件驱动关键帧检测（无任务标注、无在线 VLM）

- **链接：** arXiv §3.3；Appendix D（Table 6）
- **摘录要点：**
  - **事件显著性：** 关节位移滑动均值 $\bar{\delta}_t$ 得 $S_t=1/(1+\bar{\delta}_t)$，减速峰对应抓放、覆盖、释放等过渡。
  - **因果峰检测：** 在线确认局部极大候选关键帧。
  - **视觉去重：** 冻结 **DINOv2** 嵌入，候选与上一接受帧余弦距离 $v_i>\epsilon$（统一阈值 $\epsilon=0.05$）才保留；否则视为无场景变化的运动停顿。
  - **任务级超参（Appendix Table 6）：** `w / peak / r` 分别为 Cover Blocks `30/20/8`、Find Block `40/20/8`、Drawer Items Replacement `30/20/60`、Swap Foods `10/60/8`、Box Refill `10/60/8`、Make Sandwich `10/60/8`。
- **对 wiki 的映射：**
  - [KEMO](../../wiki/entities/paper-kemo-event-driven-keyframe-memory-vla.md) — 检测管线 Mermaid 与工程超参边界。
  - [机器人关键帧与运动编辑工具](../../wiki/entities/robot-motion-keyframe-editors.md) — 关键帧抽象对照（离线示教 vs 在线事件检测）。

### 3) 关键帧记忆注入与门控融合

- **链接：** arXiv §3.4
- **摘录要点：**
  - 接受帧用与骨干相同的 **SigLIP** 编码，$4\times4$ 空间池化将每帧 **256→16** token；bank 保留最近 **$K$** 个关键帧（不足则以最近关键帧 pad + binary padding mask）。
  - **可学习时序位置嵌入** 广播至每帧 16 token 以区分阶段顺序。
  - 当前帧 patch token 为 Query，bank 为 KV；**masked cross-attention** 后 **gated residual**：$\hat{X}_t=X_t+\sigma(g([X_t;X'_t]))\cdot X'_t$，门控负偏置初始化以训练初期保持原 $\pi_{0.5}$ 行为。
  - 在 **视觉编码阶段** 注入，不改 LLM 前缀长度与架构。
- **对 wiki 的映射：**
  - [KEMO](../../wiki/entities/paper-kemo-event-driven-keyframe-memory-vla.md) — 记忆融合表。
  - [π₀.₇ Policy](../../wiki/methods/pi07-policy.md)、[VLA](../../wiki/methods/vla.md) — π 系骨干与记忆增强对照。

### 4) 关键帧一致训练（Appendix Table 3–5）

- **链接：** arXiv §3.5；Appendix C
- **摘录要点：** 关键帧索引同时决定 $\mathcal{M}_t$ 内容与监督权重 $w_t$：距任一关键帧 $\leq\delta$（$\delta=3$）将 flow-matching loss 乘 $\lambda=8.0$，其余为 1。
- **训练配置：** KEMO 与无记忆 $\pi_{0.5}$ 均用 3 相机、AdamW（peak lr `2.5e-5`，min lr `2.5e-6`，1,000 warmup steps，总 `30,000` steps，batch size `32`，`2×A100`），`action_horizon=50`，joint-space 动作空间；对照 MemoryVLA 用 Prismatic VLM 单顶视相机、batch `128`、40,000 steps、`8×A100`。
- **对 wiki 的映射：**
  - [KEMO](../../wiki/entities/paper-kemo-event-driven-keyframe-memory-vla.md) — 训练目标与工程实践节。
  - [Action Chunking](../../wiki/methods/action-chunking.md) — $H=50$ 动作块设定。

### 5) 真机六任务与定量结果

- **链接：** arXiv §4；Appendix A–B；项目页
- **摘录要点：**
  - **平台：** **YAM 双臂** 6-DoF leader–follower 遥操作采 100–200 demo（Swap Foods ~100，Find Block ~160，Cover Blocks ~200，Box Refill ~150，Make Sandwich ~100，Drawer Items Replacement ~120）；三视角 **Decxin RGB**（固定顶视 + 左右双腕）；推理仅 follower 自主执行。
  - **聚合（Table 2）：** 每任务 **12 trials**；KEMO TSR **51.4%** vs $\pi_{0.5}$ **27.8%**（**+23.6 pt**）；SCR **76.4%** vs **42.3%**（**+34.1 pt**）；vs MemoryVLA（TSR 1.4%）TSR **+50.0 pt**、SCR **+60.9 pt**。
  - **Cover Blocks 消融（Table 1）：** 事件关键帧 TSR **3/12 (25.0%)** > 近帧 **1/12 (8.3%)** > 均匀采样 **0/12 (0%)**（此时关 loss 加权）；去掉门控融合 TSR 跌至 **0/12 (0%)**、SCR `0.000/6`；去掉 loss 加权 TSR **3/12 (25.0%)**、SCR `2.500/6`；完整 KEMO 达 **9/12 (75.0%)**、SCR `5.250/6`。
