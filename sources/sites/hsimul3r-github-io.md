## 页面要点（2026-09 快照）

- **核心叙述：** casual captures → 3D explicit generative prior → **双向物理优化**（正向 scene-targeted RL 优化人体、反向 DSRO 优化场景）→ **simulation-ready HSI**。
- **HSIBench：** 16-view 同步采集，覆盖多样场景物体、受试者与动作。
- **机器人：** 优化后人体运动可 **seamlessly transferred and deployed in humanoid robotics**（项目页视频）。
- **外链：** 摘要区 BibTeX；未见 Hugging Face / 数据集直链于首页快照。
- **开源结论：** GitHub 仓库存在（[yukangcao/HSImul3R](https://github.com/yukangcao/HSImul3R)），根目录仅 `README.md` + `docs/` → **部分开源 / 占位**，待训练推理脚本发布。
