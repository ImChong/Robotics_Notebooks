## 摘要级要点

- **问题：** 既有 WAM 提供动作条件的未来预测，但缺少组合复用技能的显式机制；代码规划又常缺少物理动态预测的约束。
- **方法：** Mixture-of-Transformers（MoT）中设代码、视频、动作三个专家，通过联合去噪建模技能程序、未来视觉状态和底层动作。
- **代码的作用：** 代码专家生成带参数的技能程序和控制逻辑，既提供多步规划结构，也形成后续 agentic 执行可复用的技能表示。
- **数据管线：** 自动为机器人和人类视频轨迹标注对齐程序，并把重复出现的套路整理为技能库。
- **执行：** 论文默认让代码作为规划条件；混合执行评测会在代码技能调用与动作 chunk 之间切换。项目页描述了语法、阶段、依赖、白名单等检查。
- **评测：** RoboTwin 2.0 与真实双臂操作任务；论文摘要报告优于 VLA 与 WAM 基线。真实任务包含并行夹爪与灵巧手平台，详细结果以论文表格和协议为准。
- **开源状态：** 官方代码与预训练权重已公开；预训练数据及其起始 Cosmos-Predict2.5-2B 视频权重不包含在代码仓库发布内容中。

## 关键复核补充（arXiv v1）

- **共享状态与动作：** 将双臂夹爪与人手示范映射到 **64 维**空间：每侧为 9 维末端位姿（3D 位置 + 6D 旋转）、22 维灵巧手关节、1 维夹爪宽度；不同本体的无效维度置零。RoboTwin 独立使用其 14 维关节接口（论文附录 A；官方 README）。
- **训练数据：** 约 2,000 小时 YAM 机器人示教与约 1,000 小时第一人称人类视频；技能库共 50 项（YAM 23、Ego 27）。这些属于论文所述训练规模，不等于公开可直接下载的原始数据（§2.4 / 附录 B）。
- **协同去噪：** 视频和动作使用连续 flow matching，程序使用离散 masked diffusion；跨专家按 **code → video → action** 的 blockwise causal attention 传递，代码既指导未来预测也指导动作（§2.1–2.2）。
- **消融：** 8 个真机任务的评分均值：联合去噪 71.1、先程序自回归版本 54.5；项目页报告 RTX 5090 上单次推理延迟约 0.23 s 与 0.55 s。属于作者报告的同环境实验，不代表任意硬件的控制频率（§3.3 / 项目页）。
- **评价口径：** RoboTwin clean/random 是 50 任务 × 每任务每设置 50 次 rollout 的**成功率**；真机的 71.1 是 8 个任务 × 3×16 次 rollout 的**分项评分均值**。仿真 hybrid 使用另外采集的 CaP 示范，不能将与默认模式的差异归因于仲裁器自身（§3 / 附录 J）。
- **实际限制：** 生成程序语法正确不等于参数和对象 grounding 正确；混合执行在 clean 降低成功率。真机 hybrid 主要在 YAM 折叠毛巾任务评估（附录 L）。

## 核心论文摘录（MVP）

### 1) 三专家联合建模
- **链接：** [arXiv 摘要](https://arxiv.org/abs/2610.30136)
- **摘录要点：** 代码专家生成程序化技能，视频专家预测未来视觉状态，动作专家生成连续低层动作；MoT 让三路表示在同一生成过程中交互。

### 2) 程序化规划与技能复用
- **链接：** [官方项目页](https://agentic-wam.github.io/)

### 3) 评测与复现入口

- **摘录要点：** 仓库提供预训练、后训练、RoboTwin 2.0 和真实机器人部署代码；权重另在 Hugging Face 发布。复现需要按 README 准备数据、模型组件与硬件环境。
