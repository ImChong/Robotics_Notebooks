ForceHarness 为不更新权重的多模态模型提供自终止力控制原语和带不确定性的力觉物理量摘要，让接触阶段由快速局部控制闭环完成，再由慢速模型进行任务规划。

## 开放状态

代码已公开 MIT，提供 HiddenPhys/Fake backend 示例，且多模态模型测试可能产生付费 API 费用。
