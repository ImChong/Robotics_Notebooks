## 摘录 1：问题与贡献

- **动机：** 虚拟人需求增长，但 SMPL 等参数化模型只覆盖 **皮肤外表面**，缺乏驱动运动的肌肉/软组织洞察；FEM 准确但难扩展；传统肌骨仿真工具常 **不联动外观形变**。
- **逆问题：** 从可见皮肤与姿态恢复 **内部肌肉形变** — 论文称 **首次** 从多视角 RGB 尝试。
- **贡献：**
  1. **SOMA** — person-specific 模型：体表信号 → 时空肌肉行为；
  2. **SKIM** — 个体化软组织形变数据集（皮肤 / 肌肉 / 骨 / 单块肌肉 mesh + marker 残余）；
  3. 无需传统仿真复杂度即可得 **解剖可信动画**，可扩展、低成本。

**对 wiki 的映射：** 升格 [`wiki/entities/paper-soma-surface-observations-muscle-anatomy.md`](../../wiki/entities/paper-soma-surface-observations-muscle-anatomy.md)；与 [UMA](../../wiki/entities/paper-uma.md)、[MAMMA](../../wiki/entities/paper-mamma-markerless-motion-capture.md) 同属 MPI 人体捕获/数字人谱系但任务不同（**内层解剖反演** vs 外观 avatar / SMPL-X mocap）。

## 摘录 2：方法 — 多层 corrective blendshape + 级联 U-Net

- **表示：** 由单层皮肤 corrective blendshape 扩展到 **体素化多层解剖**（皮肤、肌肉、骨）。
- **网络：** 给定骨骼姿态，两级 **非线性 U-Net**：
  - \(D_{\mathrm{musc}}\)：肌肉层位移（鼓胀）；
  - \(D_{\mathrm{res}}\)：皮肤相对组织的残余滑动/压缩。
- **监督：** SKIM 规范空间 **marker 残余**（稀疏体表信号）。
- **正则（生物力学启发）：** 面积归一 Laplacian 平滑、双调和弯曲、边拉伸、切向滑动、棱柱 **体积保持**（近似不可压软组织）。
- **传播：** 学习到的边界形变经 **预计算重心绑定** 映射到高分辨率 **单块肌肉 mesh**。

**对 wiki 的映射：** 实体页「核心原理 / 流程总览 / Mermaid」。

## 摘录 3：SKIM 采集与数据形态

- **被试：** 5 人；紧身 suit + **ArUco marker**。
- **动态：** 120 相机 markerless mocap 棚；**静态：** 140 相机扫描皮肤/肌肉/骨架层与单块肌肉。
- **处理链：** 检测 marker → 规范点云展开 → 肌肉绑定 → 跨帧跟踪 → pose-normalized **残余形变场**。
- **规模：** ~**45 分钟** 多视角录像；GT 含骨骼姿态、marker 轨迹、可见性 mask、完整多层解剖。
- **发布形态（仓库 README）：** 每被试 `canonical.npz`、`shot_XXX.npz`、`preprocessed_vFinal_clean/<shot>.npz`（`pose`、`residuals`、`masks`）；`skim_loader.py` + Viser viewer。

**对 wiki 的映射：** 实体页「数据集速查 / 工程实践」；[`sources/repos/soma-surface-muscle.md`](../repos/soma-surface-muscle.md)。

## 摘录 4：训练、评测与开源边界

- **训练：** `05-Training/01_end_to_end_training.py`；`ARCH` 可选 linear / mlp / unet；`LAMBDAS` 字典配置 data / smooth / biharmonic / spring / tangent / volume 损失；90/10 train-val 按被试缓存。
- **评测：** 验证脚本 + `hit_bio_evaluation.py`（肌肉顶点穿透皮肤比例、体积变异系数、与 SMPL 对齐 `smpl_alignment.py`）。
- **管线阶段：** `01-Suit-Processing` → `02-Canonical-Model` → `03-Registration` → `04-Blender` → `05-Training` → `06-Evaluation`；`Residuals-Python/` 产出发布版 SKIM。
- **局限（归纳）：** 需 **个体扫描 + 定制 suit**；五人规模；推理侧当前以 **姿态 / marker 残余** 为条件，非端到端 RGB 前馈（与摘要「RGB cameras」的长期目标需结合代码入口理解）；与机器人重定向无直接接口。
