# Rokoko

**Rokoko** 长期服务于 **3D 动画与影视动捕** 市场，近年将同一套 **人体运动采集** 能力 pivot 到 **人形机器人 / 物理 AI** 数据赛道——代表「已有垂直硬件公司横向切入机器人数据」的路径。

## 一句话定义

**把动画行业的惯性/光学动捕生意，复用到机器人需要的「人类怎么做」数据上。**

## 英文缩写速查

| 缩写 | 英文全称 | 简要说明 |
|------|----------|----------|
| mocap | Motion Capture | 运动捕捉 |
| IL | Imitation Learning | 动捕数据常见下游 |
| Retargeting | Motion Retargeting | 人体运动映射到机器人骨架 |
| SDK | Software Development Kit | Rokoko 提供采集与导出工具链 |
| POV | Point of View | 与纯腕相机 egocentric 路线可互补 |

## 为什么重要

- **供给侧扩容：** 机器人数据饥渴吸引 **非机器人原生** 硬件商入场，降低纯靠遥操作采数的瓶颈。
- **与可穿戴/遥操作三角：** 对照 [Paxini](./paxini.md) 触觉手套、[Figure Index](./figure-ai.md) 众包视频、[Boston Dynamics](./boston-dynamics.md) VR 遥操作。

## 核心信息

| 项 | 内容 |
|----|------|
| **原主业** | 动画/游戏动捕套装与云服务 |
| **新定位** | 人形/机器人训练数据采集（Substack 2026-09 产业观察） |
| **开源** | 商业产品；非开放权重/数据集 |
