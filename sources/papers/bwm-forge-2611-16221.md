## 原文对应知识归纳

- **核心贡献：** Preprocessing Agent 校验 URDF 资产与视频/Parquet 轨迹；Building Agent 生成 Blender 场景及动画；Review Agent 核查结构和运动一致性；Rendering Agent 使用代理渲染视频和条件视频模型生成高质量片段。
- **评测读法：** 按视频质量、跨视角一致性和人工评审衡量生成；并未证明生成视频会提高机器人策略训练真实成功率。
- **边界：** 依赖 Blender 与独立的视频模型服务；资产与轨迹必须对齐；视频质量分数不能视为真实机器人策略复现。
