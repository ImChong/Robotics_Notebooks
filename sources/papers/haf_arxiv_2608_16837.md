## 摘要级要点

- **问题：** 通才 VLA 的单阶段全身 action 生成难以协调 locomotion、躯干姿态与双臂操作；纯离线 BC 部署次优；直接在线 RL 微调大 VLA 计算昂贵且真机探索不安全。
- **HAF 回答：**
  - **HAF-VLA：** 共享 action expert 按累积 action mask 分三阶段扩展活跃动作空间；前一阶段 clean action 编码为 KV cache 条件化后续阶段。
  - **HAF-Steer：** 利用 flow-matching **可逆性**，将专家 action chunk **反向**穿过冻结 flow field，**DCT** 压到低频系数作为紧凑潜空间；混合离线–在线 **SAC** 优化噪声模式，**不更新** VLA 骨干。
  - **评测：** 七项长程家庭任务（洗衣、取衣、整理桌面、篮筐搬运、玩具收纳、投球、箱子搬运）；主指标为 **归一化任务分**（里程碑子目标加权，而非单纯 pass/fail）。

## 核心摘录（面向 wiki 编译）

### 1) HAF-VLA：三阶段层次化 action flow

- **链接：** <https://arxiv.org/html/2608.16837#S3>
- **摘录要点：**
  - 阶段 1：**Locomotion + Head**；阶段 2：**+ Waist**；阶段 3：**+ Manipulation**。
  - **Stage embedding** + **cross-stage clean-action KV caches** 保留从基座稳定到精细操作的运动学依赖。
  - 建立在 **预训练 flow-matching VLA** 之上，避免为人形重训大规模 foundation model。
- **对 wiki 的映射：**
  - [HAF（论文实体）](../../wiki/entities/paper-haf-humanoid-vla-adaptation.md)
  - [VLA](../../wiki/methods/vla.md) — 人形全身 action 生成的阶段化结构

### 2) HAF-Steer：频谱潜空间离线–在线 RL

- **链接：** <https://arxiv.org/html/2608.16837#S4>
- **摘录要点：**
  - **Flow reversal** 构造专家频谱目标；**DCT** 降维到紧凑噪声子空间。
  - **Regularized SAC** 混合离线与在线数据；生成器全程冻结。
  - 对比既有 latent-noise RL：避免全维时序噪声低效或单向量重复牺牲时序表达力。
- **对 wiki 的映射：**
  - [HAF](../../wiki/entities/paper-haf-humanoid-vla-adaptation.md) — 与 [ROVE](../../wiki/entities/paper-rove-humanoid-vla-intervention.md)、[Green-VLA](../../wiki/entities/paper-greenvla-staged-vla-humanoid.md) 等人形 VLA 后训练路线对照

### 3) 真机实验与主结果

- **链接：** <https://arxiv.org/html/2608.16837#S5>
- **摘录要点：**
  - 平台：**TienKung 2.0 / 3.0**；每任务 120 条同构遥操作演示。
  - 七任务平均归一化分：HAF-VLA **70.5%**；π₀.₅ **53.3%**；GR00T N1.7 **38.1%**；Cosmos **27.6%**；ACT **25.2%**。
  - OOD：Laundry Loading 路径旁未知椅子 HAF-VLA **40.0%** vs π₀.₅ **26.7%**；Clothes Retrieval 起始后移 20 cm 时 **43.3%** vs **36.7%**。
  - HAF-Steer 在 Toy Storage / Basket Transfer 上对 π₀.₅ 与 HAF-VLA 骨干均有离线–在线增益；不安全探索设置下 DSRL 训练被终止（论文注明）。

## 知识归纳（wiki 升格依据）

- 解释 **通才 VLA → 人形全身** 的低成本适配路径（结构重组 + 潜空间 RL，而非重训 foundation）。
- 与 π₀.₅ / GR00T N1.7 等同场真机对比，影响人形 VLA 选型判断。
- HAF-Steer 的 **DCT 频谱潜空间** 为 flow-VLA 后训练提供可复用设计模式。
