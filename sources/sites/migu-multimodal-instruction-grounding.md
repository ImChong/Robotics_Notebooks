## 主页核对摘要

- **页面归属与结构：** 静态学术项目主页展示了 Mingke Lu\*（NUS, UCLA）、Anxing Xiao\*（NUS）与 David Hsu（NUS）的工作 *MIGU: Multimodal Instruction Grounding under Uncertainty*，页面导航提供了 arXiv（2609.24995）与 GitHub 代码仓库按钮，并声明链接到 `https://github.com/MingkeLu/MIGU.git`。
- **与仓库的关系：** 主页本身未内嵌完整实验表格，但指向的 GitHub 仓库包含了复现 100 帧基准测试与 ROS 在线感知节点的完整工程实现与实验手册（`EXPERIMENTS.md`）。
