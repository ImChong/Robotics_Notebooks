## 核心问题与判据（§II）

不是只让球飞出去，还必须在脱手瞬间使球的长轴、线速度方向和自转轴基本对齐。以球头单位向量 n、球速度 v、角速度 ω 定义：

- **旋转效率：** η_spin = |n·ω| / ||ω||；理想为 1（100%）。
- **球头误差角：** α_nose = arccos(|n·v| / ||v||)；理想为 0 rad。
- 原文严格紧密螺旋条件还要求球头正向朝向速度（n·v > 0）。上述绝对值指标主要刻画轴线对齐，不能单独用来判断球头是否朝前。
- 这些指标表征释放状态的几何对齐；论文明确不建模释放后的空气动力学与最终落点精度，不能直接推导传球命中率。

## 两阶段控制机制（§III）

1. **下肢稳定：** GR00T Whole-Body controller 负责腿部；腿部控制器接收上肢状态以应对扰动，基于足接触、腿运动学和 IMU 的 EKF 估计骨盆运动，并补偿上肢轨迹跟踪。
2. **Throw phase（投掷阶段）：** 假设手球不打滑、球相对手刚性固定；10-DoF 腰和投掷臂模型，使用 Pinocchio 动力学 + Crocoddyl 约束 DDP，在 0.60 s、50 个离散点上离线优化；末端同时约束速度、角速度、球头姿态、关节位置，惩罚力矩、加速度、限位与鼻轴偏差。在线使用 PD 跟踪加力矩前馈。目标出球仰角 35°。
3. **Follow-through（出手随动）：** 到投掷末端只先打开拇指，其余手指短暂维持接触；腰/肩/肘跟踪球轨迹，腕及仍接触的手指控制释放。MPC 预测时域 H=15、Δt=4 ms（60 ms），惩罚偏轴自转、球头-速度失配、关节动作和手指向内挤压。
4. **接触模型：** 使用可微超椭球球体与指腹离散采样估计接触点、穿透和弹簧-摩擦力；短暂接触时触觉信号不可靠，作者没有使用触觉传感器进行接触力估计。
5. **关键部署约束：** 采样式 MPC 每次求解约 500 ms，无法跟上任务所需的 250 Hz；实际出手阶段使用**由真机数据离线建立的 52 维状态查表 MPC**，不是在 250 Hz 下在线反复运行完整优化求解器。

## 原文结论与边界（§V）

- **主要创新：** 将出手看成有限时长的多手指滚动/滑动接触过程，而非瞬时张开夹爪；投掷加速与残余接触解耦建模，关注角动量方向和速度方向的协同。
- **实验边界：** 受电机过热、硬件磨损和高速关节非线性影响，作者明确称当前数据尚不足以支持统计显著的重复性分析。
- **物理边界：** 对球的空气动力学、长距离落点/精度并未形成完备检验；对人体投球机制的比较属机器人力矩分布启示，非人体生物力学定论。
- **未来工作：** 更统一地利用全身惯量、在 MPC 中增加自旋加速目标、扩展五指仿人手。
- **源码：** 截至 2026-11-14 作者项目页仅有 Paper、Video、作者 GitHub 个人资料入口；未找到该研究的公开可运行训练/控制/部署仓库或权重。因此代码时序图不适用，不能把论文伪代码当成已发布源码。
