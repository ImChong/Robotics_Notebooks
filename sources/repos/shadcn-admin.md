# shadcn-admin

> 来源归档（ingest）

- **类型：** repo / 管理后台 UI
- **作者：** [satnaing](https://github.com/satnaing)
- **代码：** <https://github.com/satnaing/shadcn-admin>（公开，MIT）
- **在线演示：** <https://shadcn-admin.netlify.app/>
- **入库日期：** 2026-10-29
- **定位：** 使用 Shadcn UI 和 Vite 构建的可复用管理后台界面集合；作者说明它并非 starter project。

## README 要点

- 支持明暗主题、响应式布局、无障碍设计、侧边栏、全局搜索、RTL 及 10 个以上页面。
- 技术栈：Shadcn UI（Tailwind CSS 与 Radix UI）、Vite、TanStack Router、TypeScript；部分认证使用 Clerk。
- 部分 UI 组件经过修改以支持 RTL 或其他改进；使用 shadcn CLI 更新这些组件时应检查并手动合并差异。
- 本地运行：克隆仓库后执行 `pnpm install` 与 `pnpm run dev`。
