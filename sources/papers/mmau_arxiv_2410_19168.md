## 核心摘录（面向 wiki 编译）

- 10,000 道 MCQ，test-mini 1,000 题、test 9,000 题；信息提取 3,499 题、推理 6,501 题（论文 Table 1）。
- 难度 Easy / Medium / Hard 占比 22% / 56% / 22%；平均音频 10.14 秒。
- 评测指标：微平均准确率；各模型选项顺序随机打乱 5 次取多数票；采用正则与字符串匹配从输出中抽取选项。
- 主结果（Table 3，test 平均）：Gemini Pro v1.5 52.97，Qwen2-Audio-Instruct 52.50，GAMA 31.81；人类（test-mini）82.23；GPT-4o 配强描述文本 58.74。
- 噪声替换音频实验：MuLLaMa 与 SALMONN 几乎不变，GAMA、Qwen2-Audio-Instruct、Gemini Pro v1.5 明显下降，说明后者更依赖音频输入。
- 错误分析（500 条）：Qwen2-Audio-Instruct 感知错误 55%、推理错误 18%；Gemini Pro v1.5 感知错误 64%、推理错误 11%。
- 局限（论文 §6）：信息提取与推理技能互不重叠；标注与 LLM 选项增强可能引入偏置；只做选择题，不评测开放生成。
