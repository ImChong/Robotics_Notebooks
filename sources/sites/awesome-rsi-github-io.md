## 一句话

把 **Recursive Self-Improvement** 相关 **方法、基准与系统** 整理成 **可筛选的双语网页**：按 RSI artifact / mode / topology / feedback 等多维 tag 组合检索，并附引用图谱与 RSI 入门导读。

## 为什么值得保留

- **Methods 页是核心入口**（用户指定 `#methods`）：在 README 一维分组之外，支持 **跨维度过滤** — 例如「改 Skill + Online + Environment feedback」的组合查询。
- **可视化导航**：paper map（artifact 树）、benchmark map（mode 树）、citation graph（methods/benchmarks 分图）降低「RSI 文献爆炸」下的选题成本。
- **中英双语**：右上角语言切换；Understanding RSI  illustrated guide 有独立 blog 路由。
- **与仓库分工**：站点侧重 **交互探索**；仓库 README 为生成式目录快照，适合版本 diff 与 PR 协作。

### 探索流程（站点自述）

1. 选择集合：Benchmarks 或 Methods & Systems。
2. 在同一行选多个 tag，再跨行组合维度。
3. 搜索标题、按时间或引用排序、展开摘要与 taxonomy profile。
4. 打开 Citation graph，切换 methods/benchmarks，搜索节点并缩放邻域。

### 与 README 对齐的 taxonomy

- **RSI artifact**（方法侧主分组）：Model parameters · Harness code · Context · Memory · Skill · Other artifacts。
- **RSI mode**（基准侧主分组）：Online · Offline · Offline → Online。
- 收录口径：既含 **显式自修改**，也含 **长程任务中的经验驱动改进**。
