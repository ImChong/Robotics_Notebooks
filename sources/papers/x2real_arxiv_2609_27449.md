# X2Real: an eXtensive simulation benchmark for real-world generalist policies (arXiv:2609.27449)

- **类型：** paper / simulation benchmark / robot manipulation
- **链接：** <https://arxiv.org/abs/2609.27449>（PDF：<https://arxiv.org/pdf/2609.27449>；HTML：<https://arxiv.org/html/2609.27449>）
- **提交日期：** 2026-09-23（v1）
- **作者：** Lian Ruan, Jade Yang, Sherphylan Gao, Felix Gao, Kyson Liang, Galen Liu, Ligo Wu, Lane Jin, Guu Gu, Bevan Xie, Cloud Yan, Zongzi Yuan, Kino Luo, Emma Chen, Shuwen Chen, Yang Ping, Miles Guo, Rain Sun, Kayden Zhang, Alex Du, Ruihai Wu, Liang Hao, Zhaoshuo Li, Roy Gan, Hao Wang, Qian Wang
- **机构 / 团队：** X Square Robot（自变量机器人；按用户提供项目归属与团队公开资料记录。arXiv 摘要页未列作者逐人机构映射）
- **项目页：** <https://x2robot.com/en/pages/x2real>
- **一句话说明：** 基于 NVIDIA Isaac Lab-Arena，提出面向真实世界通才操作策略的可扩展仿真基准，强调仿真保真度、任务多样性与评测公平性。

## 摘要核实

论文摘要报告：X2Real 对仿真视觉和物理属性进行校准，使仿真与真机评测结果达到 **0.84 线性相关**；任务体系覆盖 **10 个能力维度、44 个层次化长程任务**，并采用多轴域随机化与严格分离的训练 / 评测流程。Mana 物理领域专用语言支持模块化任务设计；论文同时提到近 **300 小时标注仿真轨迹数据**。

注意：0.84 是论文摘要中的线性相关系数，不是成功率，也不表示所有机器人、任务和策略上都具有相同预测精度。具体验证样本与实验口径应以论文全文为准。
