# Contact-GraspNet 论文通读（接触点锚定的 6-DoF 抓取生成）

> 来源归档（原文通读 · 支撑 `wiki/methods/grasp-pose-estimation.md`）

- **标题：** Contact-GraspNet: Efficient 6-DoF Grasp Generation in Cluttered Scenes
- **作者：** Martin Sundermeyer, Arsalan Mousavian, Rudolph Triebel, Dieter Fox（NVIDIA / DLR / TUM / UW）
- **类型：** paper / grasping / point-cloud
- **原文：** <https://arxiv.org/abs/2103.14127>（ICRA 2021；2026-11 通过 arXiv PDF v1 获取全文）
- **一句话说明：** 把平行夹爪 6-DoF 抓取投影到点云中的接触点上，用「接触点分类 + 3-DoF 旋转 + 宽度」的 4-DoF 表征从单帧深度端到端稠密生成抓取。
- **核对范围：** 通读摘要、§I 引言、§II 相关工作、§III 方法（表征 / 数据生成 / 网络 / 损失 / 实现细节）、§IV 实验（推理、指标、真机、消融、失败案例）、§V 结论及参考文献列表；论文无附录。GraspNet-1Billion、GSNet、AnyGrasp 原文未在本归档中阅读，页面中对它们的描述仍依赖 wiki 既有内容。
- **通读：** 已完成

## 核心摘录（均出自原文）

- **问题设定（§I–III）：** 输入原始深度图（可选物体掩码），输出 6-DoF 平行夹爪抓取与宽度；目标是对未知物体、结构化杂乱场景鲁棒、多样、无碰撞。直接在 SE(3) 回归被认为困难（多模态、不连续、类别不平衡、遮挡歧义）。
- **接触抓取表征（§III-A，式 1–2）：** 多数两指抓取至少一个接触点可见，故把真值抓取映射到可见接触点 c。抓取位置 t_g = c + (w/2)·b + d·a，旋转 R_g = [b, a×b, a]（a 为接近向量，b 为夹爪基线向量，d 为基线到夹爪基座的固定距离）；只需估 3-DoF 旋转 + 宽度共 4-DoF。该旋转表示无歧义、无不连续，并可通过对接触点采样覆盖整个可见表面。
- **数据（§III-B，图 2）：** ACRONYM 数据集，8872 个 ShapeNet 网格、1770 万条仿真抓取（不同摩擦）；训练时把网格随机稳定放置，去除夹爪碰撞抓取，渲染虚拟相机点云；点云中距某网格接触点 5 mm 内的点记为正接触点（式 3），并关联最近接触点对应的抓取（式 4–5）。
- **网络（§III-C）：** PointNet++ 的 set abstraction / feature propagation 构成非对称 U 形网络；输入 n=20000 随机点，仅对最远点采样得到的 m=2048 个点预测抓取；四个头输出接触成功分数 s、z1、z2（经 Gram-Schmidt 正交化得到 b̂、â，式 6）和 10 个等距宽度 bin。
- **损失（§III-D）：** 接触分类用二元交叉熵，仅反传误差最大的 top-k=512 个点以缓解不平衡；位姿用 5 个夹爪关键点的最小平均距离损失 l_add-s（考虑夹爪对称，并以预测置信度加权，式 7–8）；宽度 bin 用按 bin 大小反比加权的多标签 BCE；总损失权重 α=1, β=10, γ=1。
- **实现（§III-E）：** Adam，学习率 1e-3 阶梯衰减到 1e-4；10000 个桌面场景（每个 8–12 个物体）；batch size 3，144000 次迭代，单张 V100 约 40 小时，较此前方法（约一周）收敛快。
- **推理（§IV-A，图 4）：** 全场景约 0.28 s，目标物体局部区域约 0.19 s；接触置信度阈值 0.23（不足时降到 0.19），对过滤后接触点做最远点采样，执行运动学可达且无碰撞中置信度最高者；可结合未知物体实例分割，按接触点归属过滤抓取，对欠分割容忍（图 7）。
- **指标（§IV-B）：** 真机报告成功抓取数与尝试数，每物体最多 2 次尝试；仿真（FleX）成功 = 张开夹爪无碰撞且摇晃后物体仍在夹爪中；覆盖率 = 真值抓取（含被遮挡者）基座坐标 2 cm 内有生成抓取的比例。
- **真机结果（§IV-C，表 I）：** Franka Panda + RealSense L515，复刻 [12] 的 9 个杂乱场景、51 个未见物体；成功率 90.20%（6-DoF GraspNet 62.7%，+CollisionNet 80.39%），首次尝试成功 84.31%（对比 68.63%），尝试次数 59（对比 67）。
- **消融（§IV-D，图 5–6）：** 宽度 bin 加权对成功率和覆盖都关键（不加权则预测塌缩到窄宽度）；l_add-s 提升高置信度接触的成功率、改善置信度校准；局部区域裁剪提高覆盖；训练加噪声对真实传感器泛化有帮助；只用 110 物体 5 类的小数据集无法跨类别泛化，说明 ACRONYM 规模的重要性。
- **失败案例：** 需接近最大宽度才能抓的厚物体（决策边界不连续）和小物体的接触置信度偏低。
- **作者定位：** 目标是有完整表面接触的稳定抓取；认为无可见接触的抓取（如握把手）难以保持物体状态；与基于夹爪 / 机器人模型的抓取排序方法互补。
