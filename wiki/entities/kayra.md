# Kayra

**Kayra**（[GitHub](https://github.com/assadollahi/kayra)）是 [GitHubStore《19 款能自己造的开源人形机器人》](https://mp.weixin.qq.com/s/UUwUAcKdVrlo-N60Oar3Xg) 的第 5 项，文章标价 价格未确认。

## 一句话定义

**Kayra 是 Ramin Assadollahi 发起、由社区演进的易改装 3D 打印开源人形，目标是行走接近人类幼儿速度、手臂能举起玩具，并支持 Arduino、ESP32 等多种控制器。**

- **文章：** 文章称使用 FreeCAD 设计、低成本、易修改、可步行，含设计文件、打印指南、接线图与仿真环境，强调「社区共同进化」。
- **README / 核查：** README 列出目标：行走接近幼儿、手臂能举起至少一个玩具、搭好即可行走/抓取动作、易充电换电、多种控制器（Arduino、ESP-32 等）、可选 PS2/8Bitdo 遥控、可连接主机做机器学习/视觉、舵机可替换、模块化、易打印易装配（理想情况无需焊接）、软件用主机 Python + 控制器 MicroPython。
