# Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention（Transformer 也是 RNN：用于快速自回归建模的线性注意力）

- **类型：** paper
- **论文编号：** arXiv:2006.16236
- **作者：** Angelos Katharopoulos 等
- **年份：** 2020
- **原始来源：** https://arxiv.org/abs/2006.16236
- **版本：** 以以上链接当前公开版本为准；版本间差异未核完
- **一句话要点：** 通过 kernel feature map 重写注意力，并利用矩阵乘法结合律把特征键值积累为可递推状态，从而将序列长度方向的计算规模由二次降至线性。
- **评测摘要：** 论文在自回归建模实验上比较线性注意力与标准 Transformer；报告长序列推理效率收益，质量与模型任务依赖核近似表达力。
- **局限：** 线性注意力不等于原始 softmax 注意力的精确重排；递推状态的表达容量与数值稳定性是独立约束。
