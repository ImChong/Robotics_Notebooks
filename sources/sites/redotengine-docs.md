## 官方资料核查

官方仓库 README 将项目定义为 2D/3D 跨平台游戏引擎，说明其从 Godot 分叉，分支时间为 2024 年 9 月。引擎采用 MIT 许可证，仓库提供编辑器和导出模板的获取入口。

官方 FAQ 列出 Windows、macOS、Linux / BSD 编辑器支持；游戏导出目标包括 Windows、macOS、Linux / BSD、Android、iOS 和 Web。FAQ 还说明 Redot 团队不提供开源控制台导出模板，原因是主机制造商许可条款；当前文档同时注明 C# 项目无法导出到 Web。

官方许可页将引擎标为 MIT，并提醒第三方依赖另有许可证，Redot 名称和 Logo 属于 Redot 社区商标。官方文档默认 CC BY 3.0（特定内容例外）。

## 版本核查

截至 2026-10-06，GitHub 最新正式发行版是 Redot LTS 26.2（2026-06-30），最新预发布为 Redot 26.3-rc.2（2026-09-30）。项目应依使用场景选择 LTS 或候选版本，并为扩展、插件和导出模板固定同一引擎代际。
