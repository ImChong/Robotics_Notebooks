## 文章要点（作者表述）

- 普通螺纹基本尺寸：H = 0.866P；d2 = d − 0.6495P；d1 = d − 1.0825P。
- 管螺纹、梯形螺纹（GB/T 5796.3-86）的基本尺寸表；性能等级表 3.6–12.9（σb 最小 330…1220 MPa，σs 最小 190…1100 MPa）。
- 攻丝底孔：塑性材料 D − P，脆性材料 D − (1.05~1.1)P；盲孔深度加 0.7D；套丝杆径 D − 0.13P。
- 文中引用 GB/T 192-81、7306-87、5796.3-86 等旧版标准号。

## 本库复核（用 Python 重算，非一手来源）

- 系数：3/8·√3 = 0.6495，5/8·√3 = 1.0825，√3/2 = 0.866，与文章一致。
- 55° 圆锥管螺纹（Rc）：按 P = 25.4/n、h = 0.640327P、d1 = d − 2h 重算 8 行，与文章 d1 一致（差 ≤ 0.001 mm）。
- 梯形螺纹 8 行（d3、d2、D4、D1）按 h3 = 0.5P + ac 重算，全部一致。
- 性能等级：4.6、5.6、6.8、8.8、9.8 的 σb、σs 与「前数 ×100、后数 ×10% 屈强比」一致；3.6、4.8、5.8、10.9、12.9 表值略高于名义值（如 12.9：1220 vs 1200），与等级的最小值取法有关（**推测**，未回标准核对）。
- **疑点 1：** 文章写锯齿形螺纹「工作面牙型斜角 30°、非工作面 3°」。检索到的第三方文章与标准名称 GB/T 13576「锯齿形（3°、30°）螺纹」均指承载牙侧 3°、非承载牙侧 30°，与文章相反；第三方文章非标准原文，未能读到 GB/T 13576.1-2008 条文。
- **疑点 2：** 文章引用的标准版本偏旧；Mechtool 螺纹页给出的是 -2003 版。以现行版本为准。
