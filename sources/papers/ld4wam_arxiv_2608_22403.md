## 核心摘录（MVP）

### 1) 人视频进 WAM：像素预测不可执行，重定向又绑死本体

- **摘录要点：** 多数 WAM 用人视频只做像素未来重建，动力学停在生成通路、缺动作锚点。重定向把人运动映到机器人动作，但纠缠本体执行并留下视觉 gap。像素变化 latent action 解释外观而非可执行运动。LD4WAM 提出 **motion-aligned latent dynamics**：语义空间压外观/本体，Delta EE 把它钉在真实运动上。

  - [World Action Models](../../wiki/concepts/world-action-models.md) — Joint / 人视频轴。
  - [EgoWAM](../../wiki/entities/paper-egowam-egocentric-human-wam-co-training.md) — 同为人视频，世界目标是 DINO/flow 而非运动对齐码。

### 2) LDM → WDAM：query 单向桥接 video→dynamics→action

- **摘录要点：** LDM：随机 stride 采样 → 冻结 DINOv3 → 时空 Transformer → SoftVQ → 语义重建 +（有标签帧）Delta EE + codebook 正则。WDAM：Wan2.2 TI2V-5B 视频专家自注意；learnable queries 只看预测视频，回归冻结 LDM 的 \(\{z_i\}\)；动作专家看视频+动力学。推理先去噪视频，再一次性解动作，不额外加步。三阶段：I 全数据训视频+动力学（冻动作）；II 机器人数据对齐；III 任务后训练。动作专家共享躯干、换 I/O 投影以覆盖夹爪与灵巧手。
- **对 wiki 的映射：**

  - [Being-H0.7](../../wiki/methods/being-h07.md) — 潜空间世界–动作、部署不滚像素的对照。

### 3) 5k h 语料、RoboTwin 与真机泛化

- **摘录要点：** 八源统一 LeRobot 15 FPS：Ego4D / EgoVerse / EgoDex / EgoSuite / Xperience + AgiBot-World / RoboMIND 2.0（Franka/Agilex/UR）/ RoboMIND 1.0；**274.66M 帧 / 5,086 h**。RoboTwin 50 任务 Clean **93.96** / Random **92.78** / 均 **93.4**，略高于 Lingbot-VA 92.2、Fast-WAM 91.8、ACE-Ego-0 90.9。真机：双臂 PIPER 夹爪五项 + 天玑臂+无极手两项，均 **70.5** vs π₀.₅ 63.3 / Lingbot-VA 64.3 / Fast-WAM 47.1。未见物体保留 ID 的 **88.6%**；背景扰动 **44.4%** 仍低于 π₀.₅ **54.5%**（视频预测怕纹理）。去运动对齐使潜回归误差放大 3.7–5.0×。
