## 核心摘录

1. **策展来源：** [【10.26-10.30前沿论文动态】人形／四足33篇](../blogs/wechat_senlanke_weekly_humanoid_quadruped_2026-10-26_30.md)
2. **周报所述问题：** 速度指令不足以描述舞蹈、格斗等复杂全身动作，而密集动作参考不适合作为高层任务接口。
3. **周报所述创新点：** 用随机动作 Tokenizer 将全身运动压缩成离散 token，并将 token 直接输入跟踪策略；同一接口能够生成并执行行走、格斗、舞蹈以及长时技能转换。
4. **arXiv 摘要（英文节选）：** While velocity-commanded RL policies are effective for controlling quadrupeds, they are a limited interface for humanoids that need to perform complex whole-body motions. Furthermore, RL tracking policies for whole-body motions typically have limited information about the desired future motion, preventing them from performing controlled deviations to achieve long-term task success; such information is particularly relevant when a controller must prepare for transitions between behaviors. We address these challenges using concise motion representations that can be generated by a high-level controller, given a behavior label or text command.
