## 方法

RoboScript 用冻结基础模型作为 agent，而不训练专门动作策略：先抽取可重用技能（S1），再以每任务**一条演示**在模拟世界反复试演（S2），把结果写入 **Task Memory** 而非模型权重；部署与官方测试时仅暴露实际机器人可获得的观测与工具（P3），并可后续反思更新。模拟评判所需的 ground truth 由控制面持有，不应泄漏到行动代理可用提示。

## 结果与边界

- 官方 RoboTwin 2.0 共 **50 项双臂任务**，作者报告平均成功率 **83.4%**；clean **83.6%**，randomized **83.2%**。对照最强训练策略用 50 演示/任务得到 **61.7%**。
- 项目展示模拟 ALOHA 记忆映射到真机双臂 PiPER 的示范；仓库 README 同时将 **Real-robot deployment code** 列为 TODO。真机视频不意味着相应执行/安全代码完整开源。
- 源码可运行 mock smoke test 和 RoboTwin 管线，但仍需网关凭据、RoboTwin 资产、模型与运动服务。

## 全文核验补充（2026-11-11）

### 世界上下文学习机制

- **S1** 从机器人演示构建可复用 primitives；**S2** 在干净场景模拟试演并通过控制面评判整理 **Task Memory**；**P3** 新场景只开放真实机器人可用的动作与观测工具。模型权重冻结，反思可以继续改善记忆，不是 PPO / SFT 训练。
- 控制面可以用真值打分，但不能让部署行动者从 prompt 或服务接口直接读到 ground truth。任务记忆是 agent 可读的结构化经验，不等于世界模型参数。
- 官方框架在 mock 环境有可运行 smoke test，RoboTwin 2.0 有集成执行；真机视频展示双臂 PiPER，但 README 的部署代码仍列 TODO。

### 实验协议与局限

- RoboTwin 2.0 **50 项双臂操作**，官方报告 Clean **83.6%**、Randomized **83.2%**、合计 **83.4%**；每任务每设定 10 episodes。与最优训练策略 **61.7%** 的对比基于不同演示、计算和评测预算，不可视为严格等资源 ablation。
- 真实 PiPER 四个任务分别 **10/10、7/10、7/10、6/10** 的成功样例；该样本规模不能推断未见任务大规模零样本能力。
- 消耗主要转移到长时间多轮试演、模型工具调用和仿真/运动规划运行时；单条示范不等于一次模型调用就能完成全部训练。

## 补充：机制与数据分层（论文 §3–4）

- WICL 把学习上下文写作 `C₀ = Iθ(d)`，试演得到 `(τₖ, rₖ)` 后按 `Cₖ₊₁ = Uθ(Cₖ, τₖ, rₖ)` 更新，整个过程保持基础模型权重 `θ` 冻结；训练实例与测试实例不重叠。
- **构建技能 → S1 → S2 → P3 → reflection**：先将示范拆成可复用技能；S1 在示范 seed 上模仿与审阅以构建初始 Task Memory；S2 在新训练 seed 上试演，只有经成功验证的修改才并入共享记忆；P3 冻结记忆并在未见 seed 上执行；后续反思按不重叠评测块追加 Guidance。
- 记忆是结构化 Markdown：对象角色、相对几何、阶段工作流、GraspSpec/PlaceSpec、试演教训。memory linter 排除绝对位置、仿真真值术语与特定 seed 标识。
- **关键权限边界**：S1 演示角色、S2 审阅角色与控制面可用训练期特权信息；acting agent 在学习试演和 P3 均限定为真实机器人可部署观测及动作工具。动作 receipt 来自本体状态/运动规划，不能直接代替成功判定。

## 补充：消融与成本（论文表 2、表 3；2026-11-18 复核）

- 表 2 只覆盖 10 个任务、每任务每种场景 10 episodes；**冻结记忆部署组**完整方法 78.5%，不与世界试演（仅把示范写入记忆）69.0%，去掉动作失败恢复 69.0%。
- **重学记忆组**中，完整方法 86.0%，不给示范仅 56.5%；该 ablation 同时去掉依赖示范的 completion check，因此不把差值解释为只消融示范的纯粹因果效应。无特权监督 86.5% 对照该组 86.0%，说明不依赖 ground-truth 诊断也能在作者测试上工作。
- **成本**：GPT-6.1-Sol 每次 P3 episode 平均 54.7 模型调用、233 万 tokens、149 仿真步骤；按论文采用的 API 列表价，全部 50 任务学习 + 1000 评测 episodes 为 1911 美元。这个值不是单条示范、单次机器人执行或独立复现实验成本。
- **真机协议**：双臂 PiPER 在模拟 ALOHA 冻结记忆基础上仅映射坐标/臂运动学/夹爪参数；四项任务各 10 次成功 10、7、7、6 次。论文 §5.7 是离线规划完整动作序列而不是在线重规划，因此后者不能由此推断。
