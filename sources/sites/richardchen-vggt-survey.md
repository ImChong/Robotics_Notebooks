## 项目页功能（2026-09-22 核查）

| 区块 | 内容 |
|------|------|
| Overview | 几何状态 **Z<sub>geo</sub>**（多视图几何 latent）与 **R<sub>geo</sub>**（相机 / 点图 / 深度 / track 结构化输出）双组分框架 |
| Taxonomy | **5** 条 state strengthening + **5** 条 state reuse 分支 |
| Literature | 可检索论文列表（method / title / author / venue） |
| Datasets | 按 reconstruction / NVS / downstream 分组的数据集能力与评测任务覆盖热力图 |
| Challenges | 可靠持久几何状态、下游自适应表示、benchmark 设计三类开放问题 |
