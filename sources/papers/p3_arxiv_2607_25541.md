## 摘录 1：问题与主张（§1–§3）

- **痛点：** 足式/人形 locomotion 广泛采用 VAE 把本体历史与外感知压成随机潜变量 $z$，再与 PPO 联合训练。有效策略是边缘分布 $\pi_\theta(a|o)=\int p_\psi(a|z)\,q_\phi(z|o)\,dz$，但既有实现用**单个** $z$ 样本估计概率比与 KL。
- **后果：** 单样本把「分量高斯」当成「边缘策略」，KL 被高估约 3 倍；同等策略诊断下 $D_{\mathrm{eff}}$ 仅 **64.6%**（35.4% 样本被错误 clip）。梯度噪声随动作维 $d_a$、VAE 方差与 actor 雅可比放大，Adam 在 $\sigma_{act}$ 收敛时步长被压死。
- **主张：** PPO 应对**边缘动作似然**做 clip，而不是对单个潜样本的条件策略。用 Jensen 上界把策略 KL 拆成「actor 在整段旧潜分布上的一致性」+「编码器分布漂移」（后者已被 VAE KL 隐式约束）。

## 摘录 2：方法（§4）

- **MM（Moment Matching）：** 把 $(\boldsymbol{\mu}_z,\boldsymbol{\sigma}_z^2)$ 经线性层 Hadamard 传播与 ELU 解析一/二阶矩，得到对角近似 $\widehat{\pi}^{\mathrm{MM}}=\mathcal{N}(\boldsymbol{\mu}_{out},\mathrm{diag}(\mathbf{v}_{out})+\sigma_{act}^2 I)$。条件于 $o_t$ 确定，消除有限样本比波动；$D_{\mathrm{eff}}=100\%$。对角假设会低估动作协方差。
- **MC：** $N$ 个独立 $z^{(i)}$ 的高斯混合平均；并行扩 batch。$N=50$ 时 $D_{\mathrm{eff}}=96.5\%$，但 actor 计算/显存 $\propto N$（$N=50$ 约 31.9 GB vs MM 约 15.1 GB）。
- **默认日程：** 先 MM 训到平台，再切 MC（论文 $N=15$，约 1k epoch）做 **LSFT**（Latent Sample Fine-Tuning）。MM 与 MC 共享同一套 encoder/actor 权重，只换边缘似然估计器。

**对 wiki 的映射：** 实体页画 MM→LSFT 流程图与源码运行时序图；强调「换估计器、不换网络」。

## 摘录 3：实验（§5 / Table 1–3）

| 发现 | 要点 |
|------|------|
| 数据效率 | 同等策略诊断：$N{=}1$ VAE 64.6% → $N{=}50$ 96.5% → MM **100%** |
| 收敛 | $P^{3}$（7k MM + 1k LSFT）约 **8k** epoch 达课程难度 ≥4.5；相对最强 MC-only（$N{=}50$，10k）少 **>20%** 步；单样本 VAE / $N{=}5$ 在 15k 内不收敛 |
| vs 表征基线 | AE 约 12k 才收敛且终态难度更低；SPR 与纯 Actor–Critic 未达标 |
| MuJoCo 迁移 | Total Reward / Lifetime：$P^{3}$ **20.1 / 20.0** > $P^{3}$-MM 18.9 / 19.7 > MC-only($N{=}50$) 18.2 / 19.4 > AE 17.9 / 18.0 > VAE 16.2 / 15.4 |
| 真机 G1（10 trial） | 踏石 / 楼梯 / 缺口：$P^{3}$ **8 / 9 / 10**；$P^{3}$-MM 7/7/9；MC-only($N{=}50$) 8/7/9；VAE 6/7/7 |
| 栈 | Isaac Sim + RSL-RL，4096 env，200 Hz 仿真 / 50 Hz 策略；真机 29-DoF G1 + FAST-LIO + Livox Mid-360 高程图，笔记本 RTX 5090 推理 |
