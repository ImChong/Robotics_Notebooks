## 官网陈述（与源码归档分开）

- **个人常驻代理：** Another Me 支持消息、Library/Wiki、外部连接器、电脑任务及多人 Agent 协作界面。
- **主动跟进：** 官网展示晨报、会议前准备、后续催办示例；是产品交互示例，非第三方可验证的交付证明。
- **本地模型：** 官网宣传 PolyStrata 运行 Qwen、DeepSeek、Gemma 等模型，并给出硬件速度数字；细节和假设应以官方技术文档及原始基准为准。
- **部署与接入：** FAQ 指向 macOS / Windows / Linux 源码和发布包。官网“Download”区当前仍显示 Coming soon，因此**官网待发布状态**与**仓库提供安装/发布文档**须区分。
- **隐私边界：** FAQ 明确 Local model 本机推理；cloud model 和连接服务使用外部提供方；会议语音依赖 Soniox，实时语音依赖 xAI，需另行配置。
- **许可证：** 网站链接的协议为修改版 Apache-2.0；实际条款参见仓库 LICENSE，不写成 MIT 或标准 Apache-2.0。
