# PointWAM 项目页

> 来源归档（site；核对日期：2026-10-06）

- **论文：** <https://arxiv.org/abs/2610.02840>
- **项目页：** <https://chrockey.github.io/PointWAM/>
- **代码：** 页面按钮显示 “Code soon”；截至核查日期没有仓库链接，代码待发布。
- **预训练数据：** 项目页称使用 1.15M EgoDex 与 VITRA 人类演示 episode 预训练；细节以论文为准。
- **方法：** 统一三维空间内共同预测 scene point / hand keypoint 轨迹，再把 hand forecast retarget 到机器人动作。
- **评测摘要：** DexJoCo 十项任务平均成功率 69.0%，比 GR00T N1.6 高 11.7 个百分点；OpenArm + Inspire hands 真机展示。
- **交互内容：** 项目页提供 3D 轨迹浏览器、结果表和真实机器人 rollout；未见单独权重或数据下载链接。
