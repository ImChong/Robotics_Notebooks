## 摘录 1：问题与主张（Abstract / §1）

- **痛点：** 手持接口采集示范可扩展，但多数缺少直观的力反馈，接触丰富的示范难以采集；现有主动力反馈方案需要力传感器、执行器与反馈控制。
- **主张：** 用剪刀式机构把交互力直接传到操作者手上，不需要力传感器与主动执行器；操作者可在采集时据此实时调整动作。
- **系统：** 采集系统集成传感器标定、数据采集与同步；把 FOMI 的位姿变化与夹爪开度映射为机器人末端位姿与夹爪指令，同一接口即可遥操作。

## 摘录 2：实验要点（§4，数字取自 Table 2、Fig. 5、Fig. 7–8）

| 项 | 结果 |
|----|------|
| 采集效率（Robot-free，成功示范 / 10 min，3 名操作者） | FOMI **17.8**；UMI 13.8；Ring 11.6；相对 UMI 提升 **29.0%** |
| 采集效率（遥操作） | FOMI **8.4**；GELLO 7.1；VR 3.4；相对 GELLO 提升 **18.3%** |
| 完成率（Robot-free） | FOMI **86.6%**；UMI 64.6%；Ring 64.5% |
| 完成率（遥操作） | FOMI **75.6%**；GELLO 54.0%；VR 34.1% |
| 策略（robot-free 示范，π0.5 微调） | 每任务 25 / 50 / 100 条：成功率 **42.0% / 59.1% / 78.4%** |
| 策略（遥操作示范 25 条/任务） | 平均成功率 **70.5%**，进度 83.0% |
| 任务 | Pick Chip、Insert Tube、Wash Dish、Open Pouch（Franka 与 Flexiv 双臂，Robotiq 2F-85 夹爪） |

- 评测为探索性的组内设计：3 名无机器人操作经验的人员，每人每种接口在四项任务上各做 3 个 10 分钟时段。
- 夹爪指令标定 RMSE（Table 3）为分段二次映射加方向相关偏移，原表数值未在摘录中逐条核实。
