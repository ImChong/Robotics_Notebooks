## 核心摘录

> 2026-10-05 核对 arXiv HTML v1。

- 两级分层 RL：冻结 3-kp 硬低层跟踪器，高层残差 + analytical compliance-space MoE（10 个 EE 专家）实现 100–600 N/m 逐轴可调刚度；root 提供 resistance 与 B = 60 / 200 两种 damping 模式。
- 仿真全范围评测（960 trials）：MoE 柔顺矩阵误差 0.278、EE 误差 0.0349 m、刚度 MAPE 0.249，优于 stiffness-conditioned HL/E2E 与 oracle-force 基线（Table IV）。
- 真机 Unitree G1，无腕部 F/T 传感器；任务含书写、受扰画线、斜面书写、瑜伽球抓取、3 kg 拖拽与人机协作搬箱。
- 对比工作（Table I）：GentleHumanoid、CHIP、SoftMimic、CEER、LAC；论文称自身是唯一显式支持方向柔顺并覆盖 EE + root 的方法。
