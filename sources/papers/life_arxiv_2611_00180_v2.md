## 论文主张与系统边界

- **LIFE = Lifelong Intelligence from Experience**，不是单个直接输出机器人关节动作的策略。
- **RoboBeats**：轻量 VLM 对 1 fps 视频流逐时刻回答条件真假或“是否出现新事件”，不读取未来帧；事件检测驱动写入稀疏观察。
- **Plastic Memory**：存储带时间戳的原始影像证据，并挂载语义 / 空间元数据、可重建索引；强调后续查询可重新解释，而不是只留下不可逆的文字摘要。
- **EDM（Explore–Distill–Mount）**：在记忆、工具或技能不足时主动探索，蒸馏复用能力并挂载至后续运行；论文明确依托前作 [ReSight: Task-Driven Self-Improving Memory for Embodied Agents](https://arxiv.org/abs/2610.33487)，不能将其所有实验归为 LIFE 新实验。

## 方法核心

1. **因果取证**：固定文本标记后取 false/true 两个 token 的概率，不向输入上下文写入预测答案。训练结合逐时刻的监督与区间目标，强调触发时刻。
2. **记忆选择**：事件触发与滞回阈值降低无信息帧占用；跨事件和普通观察仍可能遗漏重要信息，因此不是无损长期记忆。
3. **证据优先**：原始帧及时间 / 空间关联可供追溯，在相机姿态等数据可用时建立视点关联；在线事件摘要不替代原始影像。
4. **经验转能力**：EDM 负责解决仅有事件记忆却无可复用技能的问题；与纯视觉问答流水线的边界不同。

## 关键评测和阅读边界

| 论文 / 官方材料报告 | 结果与正确读法 |
|---|---|
| SSS-Bench | 618 题 / 171 个视频，最长 30 min，跨 6 个公开来源；因果截断严格限制到 \`query_time_s\` |
| 事件门控 | 论文的 Charades-STA R@0.5、StreamingBench 触发指标用于检验 RoboBeats；不同数据集与阈值下的指标不可混成统一成功率 |
| 记忆效率 | 论文讨论门控减少写入帧 / writer tokens，但不同 reader 与“全帧”基线可出现精度反转 |
| 24 小时实例 | 单次 24 小时机器人观察的记录 / 重放式评估；回答指标不能解释为真实环境中的长期自主学习成功率 |
| EDM 评测 | ReSight 的前置能力扩展结果与 LIFE 本文新实验须分别归因 |

- **官方仓库的 SSS-Bench 说明**：618 题，171 段源视频、14 类题型，其中 260 数值题与 358 简短语义题；参照答案由 LLM 辅助起草并经视觉模型独立复核，**并非人工标注**；源视频因版权由用户按原始数据集许可获取。
- 论文系统概念上覆盖观察、记忆与能力增长，公开可运行实现的范围窄于完整系统架构；不要从代码仓库的开源状态推断 Plastic Memory/EDM 的全部工程代码及训练流水线已公开。
- 表格和案例来自论文作者报告，**未独立复现**，尤其要分清门控 / SSS 测试、24 小时展示和前作 ReSight 实验。
