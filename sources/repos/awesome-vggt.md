## 一句话说明

**VGGT 几何状态综述官方 companion 仓库**：按 **state strengthening / state reuse** 十类组织 **142 篇** 文献链接，与交互项目页共享 catalog；**非** 可运行 VGGT 实现。

## 仓库内容

| 资源 | 作用 |
|------|------|
| `README.md` | 十类论文目录（S1–S5 strengthening、R1–R5 reuse），含 Paper / Code / Project Page 链接 |
