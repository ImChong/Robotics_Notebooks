# RoboMIND 官方项目页

> 来源归档

- **类型：** 项目主页 / 数据集主页
- **团队：** RoboMIND Team；主页列出北京人形机器人创新中心、北京大学和北京智源人工智能研究院作者单位
- **项目页：** https://x-humanoid-robomind.github.io/
- **RSS 2025 论文：** https://www.roboticsproceedings.org/rss21/p152.html
- **RoboMIND 2.0 论文：** https://arxiv.org/abs/2512.24653
- **RoboMIND 1.x 下载：** https://huggingface.co/datasets/x-humanoid-robomind/RoboMIND
- **RoboMIND 2.0 下载：** https://modelscope.cn/collections/X-Humanoid/RoboMIND20
- **网站源码：** https://github.com/x-humanoid-robomind/x-humanoid-robomind.github.io
- **数据工具：** [RoboMIND-dataset-utils](https://github.com/Open-X-Humanoid/RoboMIND-dataset-utils)；[Open-X-Humanoid 训练工具链](https://github.com/Open-X-Humanoid/x-humanoid-training-toolchain)
- **入库日期：** 2026-10-26
- **开源状态：** 数据集提供公开下载入口；Hugging Face 数据卡注明访问文件前需同意共享账号信息。网站源码、数据校验工具和训练工具链是不同项目，使用时分别查看其仓库说明和许可证。
- **一句话说明：** RoboMIND 官方主页汇总 RSS 2025 基准、数据分析、版本更新及 RoboMIND 2.0 ModelScope 集合入口。

## 站点摘录要点

- 主页介绍 RoboMIND 1.x：107K 真实轨迹、4 种机器人本体、479 个任务、96 类物体，并提供多视角观测、本体状态和语言任务描述。
- 主页发布 RoboMIND V2.0 ModelScope 集合公告；2.0 论文报告超过 310K 条轨迹、6 种本体和 739 个任务。
- 主页面明确链接论文、Hugging Face 数据卡和 GitHub 网站仓库；数据工具与训练工具链则由官方 GitHub 组织中的单独仓库提供。
