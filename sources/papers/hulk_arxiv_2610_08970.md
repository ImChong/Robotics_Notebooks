## 方法摘录

HULK 将载荷接触造成的质心与上身受力变化纳入 whole-body policy learning。载荷动力学预测由 centroidal model 和 MPC 提供，MPC 输出接触力、CoM 与骨盆姿态等指导信号给强化学习，而非部署时直接执行整条 MPC 轨迹。

论文训练两种专长策略：① wrist-force teacher，在手腕受力下跟踪手臂姿态；② grasp teacher，维持躯干 / 手臂上的已建立抓握并抱持物体行走。Capture-point control barrier function (CP-CBF) 在 wrist-force teacher 的训练阶段提供平衡指导；作者将两个 teacher 蒸馏为单一学生策略供部署。CBF 过滤器会在部署时移除，因此学习到的是受训练约束塑造的策略，而不是运行时带形式化安全保证的 CBF filter。

## 论文报告结果

- 仿真中，CP-CBF wrist-force teacher 在每臂 10 kg 负载下取得较低前向 / 侧向速度跟踪误差；与仅 MPC-guided RL 比较，论文报告 aggregate balance metric 降低 35.7%。
- Wrist-force teacher 可抵抗最高 130 N 躯干推扰动。
- Unitree G1 真机四项任务：推 / 拉手推车、手提负载行走、胸前抱冰箱、侧身抱罐行走。
- 蒸馏学生在真机任务上：手推车 5/6 次完成、最大 300 kg；负载行走 4/4、最大 12.25 kg；冰箱抱持 4/4、最大 7.0 kg；罐体抱持 4/4、最大 6.1 kg。成功率分母和共同负载见论文 Table III；最大质量来自单独 load sweep。
- 论文另报告在共同评测负载下的成功率；“最大完成负载”是单独逐级增加负载的测试，不应将最大质量当作成功率试验的固定负载。

## 局限与边界

论文指出 centroidal 预测未显式求解关节级可执行性；wrist-force teacher 训练为静态手臂姿势，grasp teacher 从既有稳定抓握开始，抓握获取、重新抓握及快速接触切换尚未覆盖。CP-CBF 的训练过滤近似且部署时移除，不提供 runtime safety guarantee。
