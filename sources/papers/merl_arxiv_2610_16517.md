## 论文要点（均出自上述原文）

### 问题与方法（摘要、§1、§3）

- 设定：对预训练 VLA 做在线 RL 后训练，仅有稀疏终局成功标签 z(τ)∈{0,1}（§3.1）。作者指出两类范式的张力：无模型精修无模拟器偏差但交互密集，基于模型的精修会利用不可靠的想象（摘要）。
- 想象器 = 世界模型 Wφ（动作条件视频预测，一次预测一个动作块 C 帧）+ 奖励代理头 Qψ（输出 [0,1] 的进度分）（§3.2、A.1）。代理头的监督目标是截断折扣的 success-to-go：q*_t = z·γ_q^min(T−1−t, H_q−1)（式 1）。
- 作者强调贡献不在模拟器结构，而在位于想象与策略学习之间的「信任层」（§1）。
- 阶段级信任（§3.3、A.3）：模拟器更新后，用已存的真实窗口重放记录动作，得观测失配 E^obs 与代理失配 E^proxy，加权为 ε̄s，经指数平滑得 ε̃s（式 15），再经 χs=(1+(ε̃s/ε_ref)^κ)^-1（式 16）映射到想象比例 ρs=ρmin+(ρmax−ρmin)χs（式 17，ρmin=0.05、ρmax=0.95）与视野 hs=⌊hmin+(hmax−hmin)χs⌋（式 18，hmin=C、hmax=4C，C=8，即 8–32 环境步）。
- 块级信任（§3.4、A.4）：每个想象块的误差 εs,i 给出回放优先级 a=(ε+ζ)^-αp（式 22，归一化为 p_s,i）与优化权重 w=clip(exp(−ηw ε), wmin, 1)（式 24）。无真实后续的递归块由残差预测器 gξ 打分；gξ 在每次模拟器更新后用已存真实–预测配对刷新，随后冻结；打分不查询未来真实观测。
- 策略目标：L = (1−ρs)·L_real + ρs·L_imag（式 4/25）；token 级 clipped、GRPO 式组相对优势；想象分支乘 w_s,i；想象优势来自模拟器的进度信号（A.5）。作者明确写：式 29 是「信任加权的想象更新」，不是均匀想象回放的无偏估计。
- 理论（附录 B）：命题 1（代理偏差 ≤ L_q Σγ^(j−1)δ）、命题 2（Δs ≤ K ρs hs ε̃s）、命题 3（加权偏差上界不劣于均匀）。作者自述：均为条件界，非收敛保证；平均误差是调度统计量，不是对每条 rollout 的认证（§3.3）。

### 实验设置（§4、C）

- 基准：LIBERO-PRO 的 Spatial / Object / Goal / Long 四套扰动任务；所有方法共用 OpenVLA-OFT 初始化、动作块 C=8、7 维动作、单个全局 RGB 相机且默认关闭本体感知（C.1–C.2）。
- 预算：每阶段后每个在线方法累计 6s 条真实轨迹，转移数上限 ≤3072s；校准复用存储窗口，不增加环境交互；想象 rollout 算模型计算，不计入真实交互预算（C.4）。
- 指标：最终成功率 SR、学习曲线归一化面积 AUC、达到阈值所需阶段数 S2T；S2T-H 对 Spatial/Object/Goal 取 80 阈值、Long 取 65 阈值后平均（C.3）。
- 算力：单节点 4×H100，3 卡做策略侧，1 卡做模拟器；100 阶段在线运行约 35 小时（C.5）。
- 对照：SFT、MFRL（仅真实 GRPO 式精修）、Static-MBRL（冻结模拟器、固定比例与视野、均匀回放）、Static-MBRL+Trust、Online-Updated MBRL（在线更新模拟器、固定调度与均匀回放）、MERL（C.6）。

### 主要结果

- Tab. 1（匹配对照，单次点估计）：Avg. SR / AUC / S2T-H —— SFT 30.2 / – / –；MFRL 77.2 / 67.9 / 103.4；Static-MBRL 73.3 / 59.8 / 168.9；Static-MBRL+Trust 75.1 / 63.5 / 145.8；Online-Updated MBRL 76.2 / 65.4 / 139.6；MERL 79.7 / 70.6 / 92.1。分套件 MERL：Spatial 82.8、Object 85.2、Goal 81.9、Long 68.8。
- 「10.9%」= S2T-H 从 103.4 降到 92.1（MFRL 对照），按阶段数计，非墙钟或环境转移节省（C.4 明说）。
- Tab. 2（三个训练种子，均值±标准差，同协议）：SimpleVLA-RL 77.1±1.1 / 67.8±1.0 / 104.1±7.0；WMPO† 75.4±1.2 / 63.2±1.3 / 149.6±10.2；WoVR† 77.8±0.9 / 68.4±0.9 / 101.3±6.2；MERL 79.7±0.7 / 70.6±0.8 / 92.1±4.8。† 表示作者移植到新基准/模型资产上的版本（非原作者原始实现）。Tab. 4 配对 95% CI：MERL−WoVR ΔAUC=2.2 [1.2, 3.3]，ΔS2T-H=−9.2 [−15.4, −3.1]；MERL−Online-Updated MBRL ΔAUC=5.0 [3.8, 6.2]。
- 消融（Tab. 5）：Online-Updated 上只加阶段信任 AUC 68.4、S2T-H 113.2；只加块信任 AUC 67.6、S2T-H 121.5；两者都加 70.6 / 92.1。
- 模拟器诊断（Tab. 6，留出的策略诱导轨迹）：冻结 vs 演化模拟器 PSNR 22.4→25.9，SSIM 0.684→0.759，LPIPS 0.238→0.171，FVD 286.0→198.0，代理 MAE 0.183→0.126。
- 信任估计器（Tab. 7）：随机 r=0.02；仅世界模型潜变量误差 0.55；仅代理残差 0.49；残差预测器 0.71；组合 0.79（Rank-AUC 0.87，ECE 0.044）。无预言机的递归深度 2–4（N=1500）：Pearson r=0.68、Rank-AUC=0.80、ECE=0.067、Top30 精度=0.77；深度 3–4（N=900）降至 0.64/0.77/0.074/0.74（Tab. 9）。
- 信任链（Tab. 8）：模拟器误差与 ρs 的 Spearman −0.967，与 hs −0.963；块误差与 p_s,i −0.750，与 w_s,i −0.950；高误差四分位的回放份额为均匀份额的 0.18。
- 信任分桶（Tab. 10）：等量 Top/Mid/Bottom 信任块精修的策略 AUC 69.9±0.8 / 68.3±0.9 / 66.7±1.0，Top−Bottom 3.2 [2.0, 4.4]。
- 超参敏感（D.5）：κ 与 λq 做 {0.5,1,2}× 一次一变，Avg. SR/AUC 变化至多 1.4/1.6，且仍比 Online-Updated MBRL 高至少 +1.8/+3.1。
- 跨套件（Tab. 11）：MERL 平均 79.7、最差套件 68.8，但跨套件标准差 6.37 不是最低（Online-Updated MBRL 6.08）。

### 真机（§4 Tab. 3、附录 E）

- 平台 AgileX PiPER X 单臂 + 固定全局 RGB 相机；两个任务 Block-to-Box、Lid-to-Pot，每任务 50 条专家示范；所有方法只用这批固定示范做离线精修，不采集额外物理 rollout（E）。每任务 20 次试验、留出摆放与颜色。
- 结果（成功次数 / 平均 SR [95% CI]）：SFT 8+6/40=35.0% [22.1, 50.5]；MFRL 12+10=55.0% [39.8, 69.3]；Online-Updated MBRL 13+11=60.0% [44.6, 73.7]；MERL-Visual（αq=0）16+15=77.5% [62.5, 87.7]；MERL 完整 17+15=80.0% [65.2, 89.5]。作者自述：完整版与视觉版区间重叠，不能断言代理头的统计显著增益。
- 作者列出的剩余失败：固定相机深度歧义、夹爪打滑、相机–机器人标定漂移、短视野 RGB 预测难捕捉的接触动力学（E）。

### 作者自述局限（§5、E）

- 只验证了 token 化 VLA 与结构化桌面任务，固定 RGB；LIBERO-PRO 保持任务语义，不能说明新任务学习或接触丰富场景的泛化。
- 信任是基于视觉与代理残差的预测估计，深度越大准确性越低，不保证物理正确；信任分桶实验只证明预测效用，单个块的因果贡献未解。
- 在线更新模拟器增加计算；校准依赖真实数据覆盖。
- 真机只有两个任务且为离线精修，不是在线物理 RL；连续动作生成式策略（flow / diffusion）与更大的闭环机器人研究留作未来工作。
