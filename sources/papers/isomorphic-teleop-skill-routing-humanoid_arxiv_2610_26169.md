## 核心摘录

1. **策展来源：** [【10.19-10.23前沿论文动态】人形／四足39篇](../blogs/wechat_senlanke_weekly_humanoid_quadruped_2026-10-19_23.md)
2. **周报所述问题：** 分别采集的左右臂技能难以自由组合，而为每种双臂技能组合重新示范成本过高。
3. **周报所述创新点：** 提出共享专家池、左右臂独立语义路由的扩散策略；设计 G1Exo 同构外骨骼直接采集关节级接触操作数据，并通过语义调度器交替执行操作与身体重定位。
4. **arXiv 摘要（英文节选）：** Humanoid manipulation requires reusable arm skills, yet demonstrating every possible skill combination is impractical. We present Humanoid Semantic Mixture-of-Experts Diffusion Policy (HS-MoDP), which composes separately demonstrated arm skills through independent semantic routing over a shared expert pool. This design preserves arm-specific skill control while sharing action-generation parameters across arms.
