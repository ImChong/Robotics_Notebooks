# TraceExtract（μ₀ 数据引擎）

- **类型：** repo
- **链接：** https://github.com/Yoonkyo/TraceExtract
- **项目页：** https://mu0-wm.github.io/
- **论文：** https://arxiv.org/abs/2606.13769
- **发布：** 2026-10-07

官方 README 与 `infer.py` 核查：`run_traceextract.sh` 根据数据源设置预设并调用 `infer.py`，支持自定义视频；输出图像、深度、相机参数、查询点、未来及历史轨迹、有效性掩码。可选 `caption/curate_captions.py` 生成事件语言标注。与主模型仓库分开维护，不代表完整预训练数据已发布。
