模型最初于 11 月 24 日以 Adaptive UI 名称发布。当前官方页为模型 v0.4、React 套件 0.5；模型 142 KB，gzip 后 32 KB。官方报告为 80 名模拟用户及十多名真人的交互记录，真人测试采用逐人留出，有 48/60 个布置的问题超过告警线，以及 2.3% 的平静时间被标记（按人中位数 1.5%）。这些口径不是六类准确率或真实情绪诊断，没有独立复跑。

当前文件需免费账号从 Install 下载，模型和套件适用单独条款。许可第 9 节说明 React 套件 0.4 曾按 MIT 发放，按当时许可取得的副本保留旧授权；模型没有这个例外。本文档只存公开声明、来源链接和分析，不转存模型、套件或受许可约束的加载代码。
