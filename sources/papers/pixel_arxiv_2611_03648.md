# Pixel: A Co-Designed Full-Stack Robot System for Learning General-Purpose Mobile Manipulation

- **中文标题：** Pixel：用于学习通用移动操作的协同设计全栈机器人系统
- **类型：** 论文，arXiv 预印本
- **作者：** Tony Tao、Jason Jingzhou Liu、Ruslan Salakhutdinov、Deepak Pathak
- **机构：** 卡内基梅隆大学（Carnegie Mellon University）
- **论文：** <https://arxiv.org/abs/2611.03648>（v1，2026-11-02）
- **项目页：** <https://pixel-robot.com/pixel>
- **入库日期：** 2026-11-04

## 初步摘要

论文摘要介绍了协同设计的移动操作系统：低成本轮式人形机器人、柔顺夹爪、多种遥操作与无需机器人参与的人类示范采集接口、统一全身控制器，以及处理人类和机器人示范的策略学习流程；分层学习用于语言条件视觉运动控制与长时程任务。
