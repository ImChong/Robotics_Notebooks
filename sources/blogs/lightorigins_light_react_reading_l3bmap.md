## 核心摘录（均出自原文）

- **韧性金字塔（四层）：** 适度推力保持平衡 → 强烈推力后起身并行走 → 硬件受损后起身/跛行/单腿跳等适应性步态 → 严重受损转爬行。目标是保住移动能力而非固定步态。
- **阶段一（专用教师）：** 3 类受损（驱动失效、关节锁定、屈膝约束）共 196 种情形（驱动失效 86、关节锁定 86、屈膝约束 24，角度 90°–150°）x 2 类技能（起身与直立运动、爬行）= 6 个教师，均用 PPO + AMP；教师额外获得 21 维二值受损标记（特权信息，学生不接收）。起身教师先学起身（课程化向上辅助力）再加速度跟踪；爬行教师含俯卧朝向奖励。
- **阶段二（多教师蒸馏）：** 基于 DAgger；学生仅收速度指令 (vx, vy, 偏航角速度) 与本体感知。对比 MLP、RNN（GRU 512 + MLP 512-256-128）、64 帧因果 Transformer：Transformer 动作 MSE 最低，且各受损条件下「其他」行为占比最低。
- **行为分类判据：** 直立（骨盆高 >= 0.40 m 且躯干倾角 <= 70°）；爬行（骨盆高 < 0.35 m、朝向、前向速度误差 <= 0.25 m/s）；其余为「其他」。
- **阶段三（偏好对齐）：** RL 微调，奖励起身与直立跟踪，爬行跟踪奖励显著更低；示意图中 Transformer 直立占比由 42% 升至 76%；MLP/RNN 退化为以爬行为主。博客称原因为推测性解释。
- **真机演示：** 双膝过热断电后恢复、双腿绑带剪断、环境约束解除后，对齐的 Transformer 能重新站起（蒸馏策略在一次演示中未完成切换）。
- **博客引用：** BeyondMimic、SONIC、HoST、HUMANUP、LocoFormer、TOLEBI、PPO、AMP、DAgger。
