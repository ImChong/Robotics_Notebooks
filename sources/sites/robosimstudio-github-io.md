- **类型：** 项目页

- **一句话说明：** 面向机器人操作任务 Real2Sim 的开放交互式 GPU 仿真工具包，可由人或编码 Agent 根据真实任务构建仿真。

## 项目定位

官方仓库 README 将 RoboSimStudio 定位为用于复现真实机器人操作任务的开放交互式 GPU 仿真工具包，支持手动搭建或通过编码 Agent 创建环境。项目页介绍的演示场景包括从手机擦拭视频构建数字孪生，并让 Fable、Astra、Argon 等 AI Agent 在仿真中处理海绵、线缆和布料等对象。
