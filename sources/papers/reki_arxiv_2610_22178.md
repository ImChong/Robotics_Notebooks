## 核心论文摘录

### 方法与结果

REKI 是 2.4B 参数 VLA，由视觉语言模型与 flow-matching 动作专家组成。每帧 VLM 表征被压缩进动作专家的 32 个 register tokens，并保存在 expert cache 中。官方仓库说明这些寄存器读取开销低于动作块预测耗时的 1%；在 LIBERO-Plus、RoboTwin Clean 和 RoboCasa365 上分别报告记忆带来的成功率提升，且姿态振荡约减少至四分之一。

- 模型只用公开数据预训练；仓库公开数据整理、训练、推理、评测、部署代码与预训练/微调权重。
- 仓库 README 报告：两张 256×256 相机图像输入时，H100 编译推理约 21.8 ms/动作块。
- REKI 在多个公开数据预训练模型的 OOD 基准上表现突出；这些指标应按各基准协议分别阅读。
