## 核心摘录

1. **问题（§1）：** 偏好微调可利用次优 rollout，但依赖昂贵人工标注；目标是只用少量专家示范 + 自主收集 rollout，在没有人工标注与手写奖励下微调生成式策略。
2. **方法三步（§4.1，图 1）：** (1) 以 ORCA（式 2）逐步计算 rollout 相对一条示范的有序子目标覆盖进度 r̂_t，该量随时间单调不减；(2) 边际进度打分：r_t = r̂_t - r̂_{t-1}，段分数 R(σ) = r̂_{t+L} - r̂_t（式 3–4，望远镜求和），比较两段分数定偏好（式 5），差值低于判别阈值 ε_σ 的对被丢弃；(3) 多示范聚合：对 M 条参考示范分别算段分数后取 max（式 6，在段级而非整条轨迹级取 max）。
3. **实现（§4.2、A.2.5）：** 图像经预训练 R3M 编码后做 ORCA（余弦距离，自适应温度）；偏好数据以 CPL（式 1）微调，扩散 / 流策略分别用去噪误差 / 速度预测误差替代对数似然比（A.2.2，式 10–11），并按动作块步长 T_p 稀疏求和以省显存。
4. **设置（§5.1、A.2.3–A.2.5）：** Robomimic 五任务（Lift、Can、Square、Transport、Tool Hang，仿真），参考策略 π_ref 约 40% 成功率，收集 500 条 rollout，仅保留 40% 示范（约 120 条，Tool Hang 约 80 条），除 Tool Hang 外用 mh 数据；策略只用低维状态，图像仅供 PGPG 生成偏好；50 episode x 3 随机种子。每任务的参考示范数 M（10 / 20 / 40）、采样对数 N（1 万 / 2 万 / 3 万）、段长 L（100 / 200 / 300，表 9）、阈值 ε_σ（候选 {0.3, 0.4, 0.6}，取仍能保留至少 1000 或 5000 对的最高值）均按任务设定。
5. **基线（§5.1）：** Base、Mixed BC、Filtered BC（用基准 oracle 成功判据，特权信息）、CPLKL（用基准真值奖励生成偏好，稠密奖励任务 1000 对，稀疏任务 5000 对，特权信息）、DPPO（仅扩散策略）。
6. **主结果（§5.2，图 2）：** 作者称 PGPG 平均成功率最高，明显优于 Mixed BC 与 DPPO；稠密奖励任务上与 CPLKL 持平（流策略在 Square 上除外）；稀疏奖励任务 Transport、Tool Hang 上持续优于 CPLKL。具体数值只画在图 2，正文未给平均值。
7. **度量消融（表 1，扩散策略，成功率 %）：** ORCA + MPS 为 Lift 96.7、Can 89.3、Square 72.0、Transport 58.7、Tool Hang 56.0；ORCA 不加 MPS 为 32.0 / 70.7 / 42.0 / 47.3 / 41.3；Temporal OT 与 DTW 加 MPS 不稳定（DTW 在三个任务上变差）。
8. **数据量与阈值（§5.3、图 3、表 2–6）：** 示范数 1 到 10 提升快，10–20 条后饱和；ε_σ = 0.6 时下游最好，ε_σ = 0.95 保留数据过少导致性能骤降；500 / 125 条 rollout 时 Square 为 72.0 / 65.7、Lift 为 96.7 / 92.3（表 2）；40 条示范时 Lift、Can、Square 为 95.3 / 88.0 / 56.7，0 示范（纯 rollout）时 Lift 32.7（低于基座 44.0）、Can 64.7、Square 51.3（表 3）；编码器 R3M 优于 VC-1 与 SigLIP2（表 4）；L = 100 / 150 / 200 在 Square 上为 54.3 / 71.3 / 72.0（表 5）；max 聚合优于 mean（表 6，Lift 96.7 对 90.7，Square 72.0 对 52.7）。
9. **与 VLM / 进度奖励模型对比（A.1.6–A.1.7，表 7、图 4）：** 在同一管线只换标签来源，CLIP、S3D、Robometer 的 Lift 为 36.0 / 53.3 / 38.7，PGPG 为 96.7；Robometer 仅在 Can 上有竞争力（85.3 对 89.3），计算上约比 PGPG 慢 31 倍。
10. **VLA 扩展（A.1.8，表 8）：** 在 LIBERO-10（仿真）上微调 GR00T N1.7（3B，VLM 主干冻结，只更新动作头），每任务仅 5 条示范与 20 条 rollout（共 50 条示范与 200 条 rollout，其中 75 条成功）；平均成功率 50.5%（预训练）→ Filtered BC 64.8% → PGPG 72.1%；10 个任务中 PGPG 在 7 个最优，T5、T6 上 Filtered BC 更好，T9 三者均不超过约 3.3%。
11. **作者自述局限（§6）：** 依赖预训练视觉编码器的鲁棒性；重遮挡下视觉序列匹配会误判任务；边际进度打分假设进度大体单调，需要策略性回退的长程任务可能打分不准。
