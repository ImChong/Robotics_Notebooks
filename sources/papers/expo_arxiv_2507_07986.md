# EXPO: Stable Reinforcement Learning with Expressive Policies（arXiv:2507.07986）

> 来源归档（ingest）

- **标题：** EXPO: Stable Reinforcement Learning with Expressive Policies
- **类型：** paper
- **来源：** arXiv:2507.07986（ICLR 2026；HTML v3 含代码链接）
- **项目页 / 代码：** <https://github.com/pd-perry/EXPO>
- **入库日期：** 2026-09-29
- **一句话说明：** 用 **大 expressive base policy（模仿）+ 轻量 Gaussian edit policy** 构造 on-the-fly RL 策略：base 与 edit 动作经 **Q 选优** 再用于采样与 TD backup，避免对扩散链直接反传 Q；离线→在线样本效率相对 prior 平均 **2–3×**。

## 核心论文摘录

### 1) 问题与 insight（Abstract / Intro）

- **链接：** <https://arxiv.org/abs/2507.07986>
- **核心贡献：** 扩散/flow 等 **expressive policy** 在线 RL 微调时，**Q 梯度难以稳定穿过长去噪链**；EXPO **不直接对 expressive policy 做 value 梯度**，而用 **即时组装的 RL policy**：base 采样 → edit 修正 → **取 Q 最大者**（base 或 edited）用于环境交互与 critic 目标。
- **对 wiki 的映射：**
  - [Reinforcement Learning](../../wiki/methods/reinforcement-learning.md)
  - [paper-expo 实体](../../wiki/entities/paper-expo.md)

### 2) 算法结构

- **Base policy：** 模仿学习预训练（可表达、多模态）。
- **Edit policy：** 轻量高斯，对 base 动作做小步修正 toward 高 Q。
- **On-the-fly policy：** 每步从 base 采样，edit 产生候选，**Q 比较** 选执行动作；TD backup 用同一选择规则。

### 3) 实验读点

- **设定：** 给定 offline 数据的 **fine-tune** 与 **offline 初始化 + online** 两类。
- **结果：** 相对 prior 方法平均约 **2–3×** 样本效率（论文摘要；D4RL Antmaze / Adroit 等，见仓库 `scripts/`）。
