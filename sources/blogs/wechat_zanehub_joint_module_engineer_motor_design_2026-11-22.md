## 文章内容结构（归纳，非全文复制）

1. **关节集成链路**：无框力矩电机定转子 + 减速器 + 电机端/输出端编码器 + 驱动器；按需求配置抱闸与力矩传感器。壳体导热、配合公差、轴承支撑和中空走线属于一体化电机工作边界。
2. **看懂口径**：电机转矩密度须指明连续/峰值及质量口径；分数槽集中绕组、槽极配合、齿槽转矩与转矩纹波影响低速力控表现；谐波减速器的额定、平均负载允许、重复峰值、瞬时峰值分开核对。
3. **知识进阶**：先电机与永磁机基础，再学习电磁仿真结果解读，随后做安装态热仿真、反电动势/转矩/温升等台架验证；FOC/SVPWM 学到足以跨专业沟通。
4. **时间计划（作者建议，非业界定额）**：理论 3–6 月、FEMM 工具 1–2 月、联合仿真与台架 6–12 月；根据既有基础调整。
5. **自研与外购的六问**：规模、是否特殊性能、核心知识产权、全成本、交期与迭代、战略能力；团队有限优先考虑采购/联合定制并强化供应商审核能力。

## 工程核验与勘误（原文观点 vs 可核实事实）

| 原文要点 | 对照结论 / 使用边界 |
|----------|----------------------|
| GB/T 35089—2018《机器人用谐波齿轮减速器》 | **标准名称需更正**：GB/T 35089—2018 官方名称为《机器人用精密齿轮传动装置 试验方法》。不能用这条标准号指代《机器人用谐波齿轮减速器》；后者对应另一个标准编号。具体 ±3% 回差定义和测试细节应以实际标准全文确认。 |
| 谐波寿命公式 `Lh = Ln × (Tr/Tavg)^3 × (Nr/Navg)` | Harmonic Drive LLC 工程资料确有这类波发生器轴承寿命模型；其中 `Tavg` 必须按**负载循环规定的等效平均转矩**计算（变转矩工况常涉及立方平均与转数权重），不可简单代入各工况转矩算术平均。该模型并不保证所有厂商/构型通用。 |
| 负载降 20%，寿命接近翻倍 | 仅在输入转速不变、其他工况/寿命主导失效机理不变，且等效转矩从 `Tr` 降至 `0.8Tr` 时，有 `1/0.8³≈1.953` 的模型推论；不是任意产品的实测保证。 |
| 背隙、±3% 滞回、输出编码器 19 bit | **背隙（backlash）**、**回差/空程（lost motion）**、弹性迟滞应区分；19 bit 是 524288 计数/转（约 2.47 角秒/计数），不等于 2.47 角秒的系统绝对定位精度，也不意味着弹性变形都能补偿。 |
| 12 槽 10 极必然降低纹波、外转子正全面替代内转子 | 槽极配合与转矩纹波还受绕组因数、磁极形状、控制与工艺影响；外转子方案是否最优取决于径向包络、惯量、热与制造，不应把文章中的趋势性语言当普适结论。 |
| Optimus 使用 28 个无框电机、BHR-6 与商用品对比等 | **本次未独立核验该具体代数、结构清单和厂商型号**，仅作为作者叙述保留线索，不进入 wiki 的确定性事实。 |
| 台架测试能完全验证设计 | 对拖/测功可验证 TN/TI、反电势、温升等，**退磁、长期寿命、EMC、批量一致性**还需专项试验；测试工况与装配热边界必须明确。 |
