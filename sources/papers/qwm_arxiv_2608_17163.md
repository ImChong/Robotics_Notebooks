# Q-Learning With World Models（arXiv:2608.17163）

> 来源归档（ingest）

- **标题：** Q-Learning With World Models
- **缩写：** **QWM**（Q-Learning with World Models）
- **类型：** paper / 模型基强化学习 / 世界模型 / 操作
- **arXiv：** <https://arxiv.org/abs/2608.17163>（PDF：<https://arxiv.org/pdf/2608.17163>）
- **项目页：** <https://pd-perry.github.io/qwm/>
- **作者：** Perry Dong, Yueru Jia, Chelsea Finn, Dorsa Sadigh（Stanford University；Yueru Jia 亦属 Peking University）
- **入库日期：** 2026-09-21
- **一句话说明：** 在标准 Q-learning 之上用学习到的世界模型做 **测试时树搜索**：策略采样候选动作、世界模型想象短视界未来、Q 函数打分选动作；**策略与 critic 仅在海量真实转移上训练**，避免想象 rollout 的复合偏差，在 Robomimic 与 LIBERO 上显著优于 EXPO、TD-MPC2 等强基线。

## 摘要级要点

- **问题：** 离策略 RL 已很 sample-efficient，世界模型进一步提供状态演化预测，但多数 model-based RL **直接在想象轨迹上优化策略/价值**，易累积模型误差，难扩展到高维视觉操作与长视界。
- **主张：** 世界模型不用于 **训练时的想象梯度**，而用于 **在线采样与评测时的 test-time search**——问「哪个动作导向最好未来」而非「哪个动作现在看起来最好」。
- **机制：** 每步以当前状态为根建搜索树；策略提出候选动作 → 世界模型递归预测未来状态 → Q 函数评估树内 state-action → 聚合中间/叶节点价值得到根动作分数；在线 RL 与评测均可用该分数选动作。
- **与 prior MBRL 差异：** 不在 imagined rollouts 上更新策略/critic； imagination 只服务 **动作选择**，学习仍 grounding 于真实环境转移。
- **基座：** 主要实例化在 **EXPO** 之上；亦可叠在 **RLPD** 等任意带 Q 函数的 RL 算法上。
- **实验：** **Robomimic**（state，Lift/Can/Square/Tool Hang 等，sparse/dense reward）与 **LIBERO**（pixel，多任务）；对比 model-free、TD-MPC2、EZ-V2；世界模型在 LIBERO 上展示 action-conditioned next-step 生成可视化。
- **消融：** 在线采样 **与** 评测同时使用搜索最佳；中等搜索深度、future-value 加权与适量 action 候选在 lookahead 强度、模型可靠性与算力间平衡最好。
