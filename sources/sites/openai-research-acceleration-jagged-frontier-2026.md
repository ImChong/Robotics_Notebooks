## 原文框架：Inputs → Process → Outputs

报告将编码 Agent 对 AI 科研的作用拆为三个层面：

1. **Inputs（投入）**：Agent 使用成本（按 API 标价估值）、累计运行时间、并发数、与人力薪酬的相对比例、各研究方向人力分配。
2. **Process（研究过程）**：无人干预完成任务的估计成功率；研究人员如何分派任务、筛选候选、提出想法、审查实验；问卷与访谈。
3. **Outputs（产出）**：每活跃贡献者的代码变更行数、每活跃实验者的实验数、OpenAI ECI 能力指标。原文明确指出这些产出并非严格因果测得的 AI 加速效应。

## 原文主要量化结论（均为 OpenAI 自报）

| 维度 | 报告数据 | 解释边界 |
|------|----------|----------|
| 2–4 小时人类任务，零人类干预成功率 | 2026-03 约 23% → 2026-10 约 46% | 估计成功率；每档被委派的任务构成随时间变动 |
| 4–8 小时人类任务，零人类干预成功率 | 13% → 35% | 同上；不能直接视为实验室吞吐量提升倍数 |
| 任务类型：监控训练 / 启动训练 / 推理与服务栈编码 | 79% / 35% / 25% | 类型差距体现「jagged frontier」 |
| 类别：沟通 / 分析 / 构建 | 69% / 58% / 43% | 2026-08-01 至 2026-10-18 估计，按 O*NET taxonomy |
| Agent 每研究员每日工作日 | 0.5 → 5.7（每 8 小时运行时长算 1 工作日） | 是 Agent 运行墙钟汇总；不等于人类劳动生产率 |
| Agent API 等值用量（日中位 / P90） | 2026-10 约 $2,400 / $23,000；相较 9 月 +62% / +105% | **API 标价等值**，不等于实际付费账单 |
| 研究部门 Agent API 等值与非股权薪酬比 | 2026-09 约 2:1 | 薪酬排除 equity（报告称占目标薪酬 70–80%），不能据此称 Agent 成本已全面超人力 |
| Agent 内部研究算力份额 | 2% | 报告口径包括内部 Codex、ChatGPT、API 使用 |
| 安全与对齐文档化人力投入 | 2026-01 至 09 +77% | 据内部 Slack/PR/文档分类估计，不是安全成果增幅 |
| 活跃实验者的实验次数 | 截至 2026-10-18 四周均值，为 2025 基线的 1.68 倍 | 实验次数 ≠ 实验质量或科学发现速率 |
| OpenAI ECI 前沿趋势 | 2025-08 起约 +16.4 分/年 | OpenAI 自定义公开+内部基准混合；不宜与 Epoch 外部 ECI 直接横比 |

原文还报告：2026-10 中旬，被纳入统计的研究者中超过 2/3 的每日并发 Agent 峰值达到 4 个及以上，超过 10% 达到 16 个及以上。2026-08 至 09 对 101 名研究人员的假设问卷，中位受访者愿以 40% 团队 headcount 或（另一问题）30% 团队 compute 换回最前沿 coding agents；这代表**主观估值**，不能作为实际可替代比例。

## 人与 Agent 的研究边界

- **执行能力不均衡**：技术问答（72%）及监控运行（79%）高于构建评测/RL/Agent 环境（29%）与推理服务栈编码（25%）。
- **研究想法来源**：对 GPT-6 Astra / GPT-6.2 Astra 的少量关键研究想法做回溯，后训练和安全监控受访者把被问到的重要想法归于人类，AI 帮助实现；预训练组在较新版本出现与 Codex 协作提出或修正重要思路的个例。样本很小，不支持「AI 完全没有科研创造力」的概括。
- **人类仍是闭环**：十位研究人员访谈反复出现无效分析、低质 PR、无用数据、盲目扩展实验等风险；建议先委派一件可核查小任务，再扩展批量任务。
- **研究自动化 ≠ 完全 RSI**：报告将人工监督和能力进展监测视为当前阶段，呼吁同行报告 RSI 指标，并未宣称已实现递归自主研发。

## 证据分级和局限

- **数据来源与观察性**：全部为组织内部记录、任务分类器与员工问卷/访谈；公开材料无法独立重建样本、标注与统计图原始点。
- **混杂因素**：模型更强、价格变化、harness 改造、任务选择变化都会改变用量和成功率。
- **产出代理偏差**：代码行数、实验次数只度量活动，不能等同于可靠研究贡献；OECI 是能力变化趋势，不构成 Agent 使用导致能力增长的因果识别。
- **具身应用边界**：不包含机器人真实场景 reset、数据采集、物理实验的 Agent 测试；机器人研究的迁移建议仅属本库工程归纳。
