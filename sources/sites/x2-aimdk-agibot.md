- **文档站：已公开** — 完整中文文档在线可读，含接口说明、快速开始、FAQ 与二次开发边界声明。
- **SDK：部分开放** — 需持有 X2 硬件并通过文档「获取 SDK」流程获取开发包；**非**像 AimRT 一样在 GitHub 全量开源。

## 设计目标（文档摘录）

- 简化机器人开发流程 — 统一接口与标准化通信，降低底层复杂度；
- 提升开发效率 — 高层 API 与任务级控制逻辑，快速从动作到场景；
- 降低开发门槛 — Python 与 C++ 双语言；
- 支持模块化扩展 — 便于集成算法、应用与外部系统。

## 接口模块（5.x 摘要）

**5.1 控制模块：** 运动模式切换、走跑控制、MC 控制信号仲裁（多输入源）、运控状态、上肢控制、预设动作、灵创（LinkCraft）动作、末端执行器、关节控制。

**5.2 交互模块：** 语音（TTS/播放/麦克风）、屏幕（表情/视频）、灯带、灵心云（LinkSoul）。

**5.3 故障与系统管理：** 故障处理、诊断码参考表（PDU/ECAT/感知/导航/运控等子系统）。

**5.4 硬件抽象：** IMU、触摸、RGB/深度/双目/Lidar/GNSS、PMU 电源。

**5.5 感知（选装）：** SLAM（建图/重定位）、导航、Foxglove/RSView/RViz 可视化。

**5.6 系统模式：** 查询系统状态、进入开发者模式。

## X2 硬件变体（文档提及）

- **X2 Ultra**（旗舰版）
- **X2 Ultra (new version)**（旗舰焕新版）
- **X2 EDU**（人人造版）

开发模式：旗舰/焕新版支持机载 SDK 直连或容器开发；亦支持上位机/外接算力包跨机组网。
