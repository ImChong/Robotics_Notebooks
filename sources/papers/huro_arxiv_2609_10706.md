## 论文要点（带章节）

1. **问题（§1）：** 联合观测加动作的机器人化此前多在 task-matched 设定验证；规模化工作要么保留人类观测只做动作监督（VITRA、EgoScale），要么只把机器人化用于视觉或辅助预训练目标（H2R、Masquerade）。论文研究异构人视频能否成为联合 robot-aligned 的 VLA 预训练监督。
2. **流水线（§3.1，附录 G，Algorithm 1）：**
   - 标注：droidcalib 估内参（近静止片段退到 AnyCalib），100DoH 检手加 BOT-SORT 跟踪，HAWOR 估 MANO 手姿，masked DROID-SLAM 加 MoGe-2 尺度加 GeoCalib 重力对齐得度量相机轨迹，按手部有效帧切 manipulation segment 与 chunk，Qwen3.5 在叠加手腕轨迹的帧上生成指令并做一致性校验。
   - 动作转换：PyRoKi 两阶段求解，稀疏帧联合优化 chunk 级世界到机器人基座变换（3D 平移加 yaw）与关节，固定变换后全时序加平滑项再优化；动作定义为 a_t = s_{t+1}（Eq.8，末帧取自身）。目标项含指尖位置、局部手部结构、ego-view 一致性、关节限位与静止姿态惩罚（附录 G.2）。
   - 视觉转换：SAM2（加 Detectron2 提示）分割人臂，ProPainter 修补，Isaac Sim 渲染 ALLEX 并按同一对齐变换后的相机轨迹叠加（Eq.2、Eq.7）。
3. **数据集（§3.1.4，附录 D Table 5）：** ALLEX（双 7-DoF 臂、双 15-DoF 灵巧手、2-DoF 颈、2-DoF 腰）实例化；142.2M 帧、1,316.8 小时；按帧数 EgoDex 55.5%、EgoVerse 26.5%、Ego4D 10.4%、Ego10K 6.0%、EPIC-Kitchens 1.7%（正文 §3.1.4 四舍五入写 56/27/10/6/2）。EgoVerse 只用 in-the-wild 子集；EgoVerse 与 EgoDex 的语言被重新生成（附录 D.1）。
4. **策略与训练（§3.2）：** 基于 GR00T-N1.6-3B，EEF 动作接口，H=40 步动作块；腕部目标为相对当前腕姿的 3D 平移加连续 6D 旋转，手部为绝对关节目标；VLM 从官方 GR00T-N1.6-3B 初始化，动作头从零训练，flow-matching 目标，视觉编码器一起微调；预训练 80k 步、全局 batch 2048、AdamW、学习率 1e-4、权重衰减 1e-5；下游微调 30k 步、batch 128、cosine 衰减。
5. **真机评测（§4.1，附录 A Table 1–2）：** 四项 ALLEX 任务及示范数：Apple P&P 43、Cup Stacking 40、Cup-Noodle Handover 16、Microwave Loading 20。每格 rollout 数很小：Apple 12 ID/12 OOD，Cup Stacking 12 ID/24 OOD（12 空间加 12 格子桌布），Handover 12/12，Microwave 只有 10 条 OOD。Apple 二值成功，其余按 3 个子目标部分得分；平均 ID/OOD 只在有该评测的任务上取平均，Overall 为二者无权重均值。论文未报告重复种子或方差。
6. **主结果（§4.2，Table 2，Fig.3）：**
   - 0% PT / 10% / 50% / 100%：Overall 51.5 / 68.2 / 74.0 / 80.3；ID 68.1 / 76.9 / 78.2 / 88.4；OOD 34.9 / 59.5 / 69.8 / 72.2。注意 51.5% 对应的是不做 HuRo 预训练（0% PT）直接微调，不是「小规模预训练」。
   - 参照模型直接微调：π0.5 Overall 48.2（ID 68.5 / OOD 28.0），GR00T N1.6 Overall 52.0（ID 66.7 / OOD 37.4）。全量 HuRo 在 ID 与 OOD 都高于二者（Fig.3c）。
   - Cup Stacking 个案（§4.2，Fig.4）：OOD 从 10% PT 的 60.4% 升到 100% PT 的 79.2%。
7. **视觉机器人化（§4.3，Fig.3b）：** no-overlay（同样的重定向动作监督、保留人类观测）ID 89.4% 与全量 88.4% 相当，OOD 55.7% 对 72.2%，且低于 10% PT 的 59.5%。附录 A Table 2 给出 no-overlay Overall 72.5%。
8. **端到端动作预训练（§4.4，Fig.5）：** Diverse Pick-and-Place，ID 36 次试验、OOD 18 次；PT(Visual Only)（只留视觉通路、动作头重置）相对 No PT 仅小幅提升；PT(Visual+Action) 达 ID 61.1%、OOD 50.0%。
9. **对比视频生成预训练（§4.5，Fig.6）：** I2V+IDM（按 DreamGen 与 RoboCurate 的 ALLEX 设置自建）对 HuRo，在 0.7M / 3.5M / 7.0M 帧匹配预算下，HuRo 0.7M 已在 ID 与 OOD 都超过 I2V+IDM 7.0M；I2V+IDM 的 OOD 在 3.5M 到 7.0M 无进一步提升。该实验在独立物理环境中重新采集示范与评测。
10. **附录消融：** 附录 B Table 3（EPIC-Kitchens 2.4M 帧，Diverse P&P）ID/OOD：No PT 63.9/25.0，Fixed-EEF(Masquerade 式) 75.0/50.0，Fixed-EEF+Hand 80.6/61.1，HuRo-EEF+Hand 86.1/63.9。附录 C Table 4（OOD，独立环境）Cup Stacking / Handover：No PT 31.9/16.7，Human-HRDT 5.6/37.5，Human-VITRA 0.0/9.7，100% PT 70.8/66.7。附录 D：Mixed 50%（约 71.1M 帧）ID/OOD 78.2/69.8 对 EgoDex-only 全量（78.9M 帧）63.9/54.2，Table 6 的动词、物体、动宾对数量也更多。附录 E：OpenArm 水果抓放，HuRo PT Overall 72.9 对 No PT 49.0、Human-HRDT 65.6；ALLEX+OpenArm 联合预训练 Diverse P&P ID/OOD 91.7/77.8 对 ALLEX-only 86.1/63.9（联合设置数据量约翻倍，预训练更新次数与 batch 不变）。
11. **效率与质量（附录 F Table 8–10）：** 单卡 RTX 5090，15 分钟片段全流程约 8–10 倍片长（EPIC 143.1 min 即 9.5×，Ego4D 120.1 min 即 8.0×）；换目标机器人只需重算重定向与叠加，占全流程 10.6%（EPIC）与 5.5%（Ego4D）。选出 manipulation 段的帧占比 EPIC 17.3%、Ego4D 6.9%；选中后保留 98.1% / 97.0%。EgoDex 复算对照：相机旋转误差中位 0.218°、位置 ATE 中位 4.47 mm、21 关键点手姿误差中位 20.4 mm；IK 后指尖残差中位 21.2 mm；62.5% 的轨迹无超过 1° 的关节限位违例；55.2% 的轨迹在抽样帧中无非抓取自接触；修补重建中位 24.8 dB；人体去除后检出人像素下降 93.3%。
12. **论文自述局限（§6）：** 观测保真度受重建与视觉转换质量限制，当前叠加不显式建模机器人与场景几何的遮挡；缺力与触觉信号；运动学重定向不建模自碰撞与物理接触，只有 55.2% 轨迹无检测到的非抓取自接触，因此轨迹只是预训练监督，不是可直接执行的机器人示范。
