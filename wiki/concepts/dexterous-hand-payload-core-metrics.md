# 灵巧手负载与核心指标

## 一句话定义

灵巧手的「能搬多重」不只由手决定，而取决于抓取姿态、摩擦、重心、包覆与机械臂加速度；因此负载只是入场券，真正的评价要看**带条件声明**的一组耦合指标：力量、自由度、力控、精度、感知、可靠性、轻量化、效率、集成与成本。

> 说明：本页整理自作者个人观点文章，文中数值与厂商/产品信息均为作者表述，**未核实**；原文「个人观点，仅供参考」。

## 英文缩写速查

| 缩写 / 术语 | 英文全称 | 简要说明 |
|-------------|----------|----------|
| DoF | Degrees of Freedom | 自由度；文中拆成运动学/驱动/独立控制/耦合/被动/腕部六层 |
| Payload | Payload Capability | 最大静/动态负载，受摩擦、姿态、重心、加速度共同影响 |
| Power / Pinch grasp | 包络抓 / 指尖捏 | 包络抓整手参与，力最大；指尖捏仅拇指+食指，力最小 |
| MTBF | Mean Time Between Failures | 平均无故障时间 = 规定期间寿命单位总数 / 故障总次数 |
| FMEA | Failure Mode and Effects Analysis | 故障模式与影响分析（IEC 60812） |
| SDK | Software Development Kit | 供货范围中是否含软件开发包 |

## 为什么重要

- 展会上「10 kg 哑铃」「负载 30 kg」「抓握力 50 N」等数字难以复现，把任务结果当产品参数会造成口径混淆。
- 灵巧手是否能落地、长期稳定干活，由一组相互制约的工程指标决定；负载只是第一道门槛，而非充分条件。
- 为采购、选型和跨厂商比较提供「每个数字必须带口径与条件」的统一框架。

## 一、负载的三种口径

| 口径 | 含义 | 要点 |
|------|------|------|
| 抓握力（Grip Force） | 整手在特定姿态下各指协同施加的合力 | 强依赖姿态；孤立发布无意义 |
| 指尖力 / 手指输出力 | 整手固定，单指持续按压测力计的最大力 | 相对干净、可复现 |
| 最大静/动态负载 | 最贴近应用、最易夸大 | 受摩擦、姿态、重心、加速度共同影响 |

负载进一步区分三个量：**主动力**（手指主动施加，取决于执行器与传动）、**被动载荷**（静止/半夹持下可承受的重量，取决于结构刚性）、**额定动态负载**（规定轨迹与加速度下可持续携带的质量）。

作者举例（厂商表述）：因时机器人手指输出力约 30 N（约 3 kgf），单指被动载荷可达 15 kg 以上，二者是不同物理量；「拎起 10 kg 哑铃」不能直接写成「负载 10 kg」。结论：谈负载必须声明哪种力、什么姿态、是否含加速度、主动还是被动。

## 二、自由度的六层含义

| 层次 | 含义 |
|------|------|
| 运动学自由度 | 结构上可实现的独立运动数 |
| 驱动自由度 | 由执行器主动驱动的轴数 |
| 独立控制自由度 | 不与他轴联动、可单独指令的轴数 |
| 耦合自由度 | 经齿轮/连杆/腱索从属于其他关节 |
| 被动自由度 | 靠外力和弹簧自适应、不可直接控制 |
| 腕部自由度 | 属于腕部而非手指的轴 |

- **全驱动**：每关节独立执行器，控制最细，但数量、重量、成本、热负荷同步上升；**欠驱动**：少量执行器带动多关节，靠耦合实现自适应包络抓取。
- 作者例（因时）：6 个微型伺服电缸驱动 12 个关节（四指各 1 缸驱 2 关节，拇指 2 缸驱 4 关节），对外称「12 自由度 = 6 主动 + 6 被动」；作者称该厂 2016 年经抓取实验认定 12 自由度更均衡，缺拇指关键关节的 10/11 自由度运动范围受限。
- **自由度不等于灵巧**：自由度只说明能摆多少姿态，关节轴的位置与方向才决定姿态是否有用。例如 4 自由度中「直线排列屈曲轴」利于深度包覆，「1 基部外展 + 3 屈曲」利于侧向移动指尖、在球面上分散接触点；拇指上布置跨掌对掌轴，往往比多加屈伸轴更有价值。
- 共识：自由度决定算法能力上限而非产品实际表现；超过个位数后边际收益递减（甚至超过人手 27 自由度），重量、功耗、可靠性代价同步放大。

## 三、五个核心指标

### 1. 力控能力与力分辨率

关键不是最大力，而是**最小可控力**（抓鸡蛋、草莓、豆腐）。电流控制方案通常仅几个力度档位，本质开环估算；力传感器方案可做到 1000 挡以上，力控精度可达 ±0.1 N 级（作者表述）。动态品质用一阶闭环近似：

```
F(s)/F*(s) = ωc / (s + ωc),   上升时间 tr ≈ 2.2 / ωc   （ωc 为闭环带宽 rad/s）
```

带宽越高，对扰动抑制越快、抓取瞬间越不易过冲。人抓取依靠前馈+反馈两个闭环，机器需在毫秒级完成同样调节。

### 2. 重复定位精度与执行一致性

由传动回差、齿轮间隙、丝杠导程精度和编码器分辨率决定：

```
Δθ_out = Δθ_backlash + Δθ_elastic + Δθ_sensor   （回差 + 弹性变形 + 传感误差）
```

行业可做到 ±0.2 mm（高精度微型伺服电缸+闭环），也有 ±1 mm 级产品。比单个实验室数值更重要的是同批次不同手之间的**离散度**。

### 3. 触觉与力觉感知

评价三点：分辨率、覆盖（指尖/指腹/掌面）、长期漂移，而非「装了多少点」。作者给出的大致水平：指尖阵列每指尖 7 个感知点、毫牛级灵敏度；三维力触觉传感器 0–5 N 量程、0.2 N 分辨率、重复性误差约 1.5%；视触觉传感器毫米级厚度、高空间分辨率。无对应分辨率与标定的堆点不带来能力提升。

### 4. 寿命、可靠性与批次一致性（一票否决项）

高自由度放大磨损、热管理、疲劳与一致性问题；作者引述有从业者在真实分拣场景观察到长期高强度训练的手寿命可能只有数周量级。评价必须区分空载活动与额定负载下反复接触/碰撞。参考标准：ISO 9283 / GB/T 12642（工业机器人性能规范及试验方法）、GB/T 39590.1（可靠性，MTBF 验证）、IEC 60812（FMEA）。可比的寿命指标至少标注：负载状态、动作循环类型、样本数、失效判据；缺这些则「通过两百万次测试」无法比较。

### 5. 功率密度、效率与热管理

末端供电与散热空间极有限；电流到指尖力的转换效率决定续航与发热，紧凑高自由度结构里热量难散，长时间工作会力输出衰减与定位漂移。

## 四、轻量化与负载自重比

手重直接影响机械臂负担、响应、能耗与整机重心稳定。更有意义的比值：

```
R = 额定负载 / 整手（含必要驱动与传动）质量
```

口径示例：负载取指定姿态下的可持续动态负载；质量取腕部法兰以下手部本体，或含前臂执行器的系统质量——**系统边界必须一致**，价格比较同理（仅手本体 / 含电机控制器 / 左右一对 / 含触觉）。作者例：某「腱绳+直驱混合驱动」方案 23 自由度（19 主动 + 4 被动），整手约 400 g，大推力电机前置前臂、腱绳远距离传动，约每秒两次完整握拳—伸展循环。

## 五、传动与驱动架构

| 传动方案 | 精度与刚性 | 寿命与维护 | 效率 | 典型问题 |
|----------|-----------|-----------|------|----------|
| 连杆 | 刚性高、精度较好 | 结构简单、寿命较长 | 高 | 自由度扩展受限、走线复杂 |
| 腱绳（丝） | 精度受绳长变化影响 | 易磨损、需张紧 | 较低 | 长期一致性难保证 |
| 蜗轮蜗杆 | 自锁、减速比大 | 效率低、发热 | 低 | 传动效率与热管理 |
| 微型行星滚柱丝杠 | 承载大、寿命长、响应快 | 加工难、成本高 | 高 | 微型化工艺壁垒 |

趋势：大推力执行器前移、丝杠做直线转换、腱绳引力到指尖。作者提到 Tesla Optimus Gen 3 手采用「齿轮箱 + 丝杠 + 腱绳」三级方案（22 手部自由度、约 50 个执行器，驱动多后移至前臂）；复杂度陡增，24×7 工业耐久数据要待规模化产线才会积累。没有「最好」传动，只有是否匹配任务：精密装配看刚性与回差，物流看效率与寿命，科研遥操作看自由度与可维护性。

## 六、测试条件与评价流程

- 铁律：测试条件与方法一致时数字才可比（指尖力随手指伸直/弯曲而异；耐久「次数」随是否带载、是否含碰撞而异）。
- **三阶段评估**：规格评估（结构参数与公开规格）→ 单项性能测试（手指力、抓握力、速度、传感器）→ 任务性能测试（真实物体与任务的成功率、节拍、误动作率、耐久）。
- **三类系统边界**：手本体（腕部法兰以下）；实际安装系统（含腕部适配器、线缆、控制器、前臂执行器、散热）；产品供货范围（是否含传感器、SDK、支架、保修与支持）。
- **复现记录至少保留**：产品名与硬件版本、左/右手、固件版本、控制模式、指尖与传感器类型、供电电压、电流/扭矩限值、控制周期、环境温度、物体类型与表面状态、测试前关节温度、机械臂与支架型号、软件版本。

## 七、核心指标体系（作者总表）

| 维度 | 建议指标 | 口径要求 |
|------|----------|----------|
| 力量 | 手指输出力、抓握力、被动载荷 | 标注抓取姿态、是否含加速度 |
| 自由度 | 主动/独立控制/耦合/被动分列 | 拒绝只标一个总数 |
| 力控 | 力分辨率（挡位/牛顿）、力控精度、带宽 | 注明传感器方案与闭环类型 |
| 精度 | 重复定位精度、批次离散度 | 注明负载与温度 |
| 感知 | 触觉分辨率、覆盖位置、长期漂移 | 注明量程与标定方式 |
| 可靠性 | 负载循环寿命、MTBF、失效判据 | 注明带载状态与样本量 |
| 轻量化 | 整手质量、负载自重比 | 明确系统边界 |
| 效率 | 功率密度、续航、温升 | 注明工作占空比 |
| 集成 | 通信接口、控制周期、掉电自锁 | 注明是否需外部控制器 |
| 成本 | 完整配置价格 | 明确供货范围与许可 |

优先级三句话：力量与自由度是门槛（达不到出局，堆高不等于赢）；力控、精度、感知是差异化能力；可靠性、轻量化、效率是长期价值（从「能用一次」到「能用一年」）。
