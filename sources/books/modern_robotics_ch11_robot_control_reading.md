## 核心摘录（均出自原文）

- **控制系统概览（§11.1）：** 控制器按数百到数千 Hz 采样；速度常由位置差分加低通滤波得到；把放大器 + 电机 + 传动抽象成"力矩变换器"；柔性、回差、饱和、传感器分辨率不在本章范围。
- **误差响应指标（§11.2）：** 稳态误差、超调、2% 调节时间。二阶标准形 θ̈_e + 2ζω_n θ̇_e + ω_n² θ_e = 0，ζ>1 过阻尼、ζ=1 临界、ζ<1 欠阻尼；p 阶线性误差动力学稳定当且仅当特征方程所有根实部为负，p=3 时需 a₂'a₁'>a₀'。
- **速度输入（§11.3）：** P 控制 θ̇ = K_p θ_e 给出一阶误差动力学，时间常数 1/K_p，2% 调节时间约 4/K_p；对恒速参考的稳态误差为 c/K_p（K_p 受速度限幅和数字控制器稳定性所限）；PI 把误差动力学变成二阶，ω_n=√K_i、ζ=K_p/(2√K_i)，临界阻尼 K_i = K_p²/4；作者推荐的前馈 + 反馈律 θ̇ = θ̇_d + K_p θ_e + K_i∫θ_e。
- **PID（§11.4.1.1）：** τ = K_p θ_e + K_i∫θ_e dt + K_d θ̇_e；K_p 是虚拟弹簧，K_d 是虚拟阻尼。单关节水平面 PD：Mθ̈_e + (b+K_d)θ̇_e + K_pθ_e = 0，ζ=(b+K_d)/(2√(K_pM))，ω_n=√(K_p/M)，临界阻尼取 ζ=1。竖直面 PD 的静平衡满足 K_pθ_e = mgr cosθ，**稳态误差非零**（θ_d≠±π/2）；加 K_i>0 后误差动力学变三阶，稳定条件 K_d>−b，K_p>0，(b+K_d)K_p/M > K_i > 0（K_i 既有下界也有上界）。作者建议先按瞬态选 K_p、K_d，再取足够大又不破坏稳定性的 K_i；"实践中许多机器人控制器取 K_i=0，因为稳定性第一"，并用积分抗饱和（anti-windup）限制误差积分。PID 对轨迹跟踪同样适用，但积分不能消除沿任意轨迹的跟踪误差。
- **前馈与前馈加反馈线性化（§11.4.1.2–11.4.1.3）：** 前馈力矩 τ = M̃(θ_d)θ̈_d + h̃(θ_d, θ̇_d)；模型错误（算例中 r̃=0.08 m、真值 0.1 m）下误差可观，因此前馈总与反馈合用。计算力矩 / 逆动力学控制：θ̈ = θ̈_d + K_dθ̇_e + K_pθ_e + K_i∫θ_e，τ = M̃(θ)(θ̈_d + K_pθ_e + K_i∫θ_e + K_dθ̇_e) + h̃(θ,θ̇)；模型完美时每个关节的误差动力学为线性 θ̈_e + K_dθ̇_e + K_pθ_e + K_i∫θ_e = c，实践中 K_i 常取 0；仿真显示计算力矩的跟踪优于单独前馈或反馈，控制能量小于单独反馈。
- **多关节（§11.4.2）：** 分散式（每关节独立）适合解耦的情形（笛卡尔 / 龙门机器人，或高减速比且无重力的机器人，质量矩阵近似对角）；重力显著或质量矩阵不对角时用集中式计算力矩 τ = M̃(θ)(θ̈_d + K_pθ_e + K_i∫θ_e + K_dθ̇_e) + h̃，增益矩阵通常取 k_pI、k_iI、k_dI。动力学太复杂或算不动时，在期望速度和加速度较小的前提下可用"PID + 重力补偿"近似：τ = K_pθ_e + K_i∫θ_e + K_dθ̇_e + g̃(θ)。
- **PD + 重力补偿的全局收敛：** 无摩擦、重力模型完美、设定点控制（K_i=0，θ̇_d=θ̈_d=0）时，取"误差能量"V = ½θ_eᵀK_pθ_e + ½θ̇ᵀM(θ)θ̇，利用 Ṁ−2C 反对称得 V̇ = −θ̇ᵀK_dθ̇ ≤ 0，由 Krasovskii–LaSalle 不变原理得机器人从任意初态收敛到 θ_d。
- **任务空间控制（§11.3.3、§11.4.3）：** 可把轨迹经逆运动学转到关节空间，或用任务空间动力学 F_b = Λ(θ)V̇_b + η(θ,V_b)，τ = J_bᵀ(θ)F_b，取计算力矩形式的任务空间律。
- **力 / 阻抗（§11.5、§11.7）：** 纯力控制 τ = g̃(θ) + Jᵀ(θ)F_d，加六维力矩传感器后为 PI 力反馈（微分项因噪声通常不用）；阻抗控制让末端表现为质量 - 弹簧 - 阻尼 Mẍ + Bẋ + Kx = f_ext，阻抗控制型机器人测运动、输出力，导纳控制型测力、输出运动；高刚度、延迟与量化可致振荡或不稳定。
- **关节力矩控制（§11.8）：** 直驱电机电流环（典型 10 kHz 内环 + 1 kHz 力矩外环）；有减速器时摩擦与回差引起力矩不确定；输出端应变片反馈可补偿摩擦；串联弹性执行器（SEA）使关节天然柔顺，但高频运动更难控。
- **历史注记（§11.12）：** 计算力矩控制起源于 1970 年代；其计算复杂度与建模误差问题推动了非线性控制、鲁棒控制、迭代学习控制与自适应控制；PD + 重力补偿由文献 [184] 提出并分析；操作空间控制由 [99, 74] 勾勒；阻抗控制由 Hogan 提出。
