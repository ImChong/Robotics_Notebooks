## 一句话摘要

AnySkin 官方项目页：磁触觉 **可更换表皮** 制程视频、原始 **5×3 轴** 磁信号可视化、滑移检测与 **跨实例 BC 策略** 演示，以及开源 **设计工具 + 接口库** 入口。

## 公开信息要点（截至入库日）

- **核心叙事：** 像手机壳一样安装、像充电一样接电路；解耦电子与软表皮解决 **耐用性 + 可替换 + 跨实例数据复用**。
- **Fabrication：** DragonSkin + MQFP-15-7 磁粉 **1:1:2**；脉冲磁化；两部件模具。
- **实验区块：** Cross-Instance Generalization、Slip Detection、Raw Signal Visualization、Experiment Results。
- **开源锚点：** 页上 **Design Tool** 链 GitHub；设计文件链 Google Drive；论文 arXiv **2409.08276**（非旧误引 2401.17695）。
