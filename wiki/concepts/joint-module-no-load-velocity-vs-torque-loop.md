# 关节模组空载：速度环与力矩环的输出扭矩区别

## 一句话定义

空载时**速度环的输出扭矩是「结果」**（摩擦要多少、闭环给多少，转速恒定），**力矩环的输出扭矩是「原因」**（指令多少就是多少，转速只是动力学的后果）。

> 来源：[Zane Hub《机器人关节模组空载运行在速度环和力矩环时电机的输出扭矩有什么区别？》](https://mp.weixin.qq.com/s/TCBOhaBcSR_SVB-g54RR4w)（2026-10-27，个人观点）。**数值为作者表述，未核实**；本页不含原文之外的补充。

## 英文缩写速查

| 缩写 | 英文全称 | 简要说明 |
|------|----------|----------|
| PI | Proportional-Integral | 速度调节器，由转速偏差算出扭矩/电流给定 |
| CST | Cyclic Synchronous Torque | 总线力矩模式（文中与 Profile Torque 并提），绕过速度调节器 |
| Kt | Torque Constant | 扭矩常数，τ = Kt·iq |
| iq | Quadrature-axis current | 交轴电流，产生扭矩的电流分量 |
| J_eff | Effective inertia | 折算到电机轴的等效惯量 |
| τ_c / B | Coulomb friction / viscous coefficient | 库仑摩擦 / 粘滞摩擦系数 |
| RLS | Recursive Least Squares | 递推最小二乘，文中用于在线惯量辨识 |

## 为什么重要

空载调试是每颗关节模组出厂前的工序。同一模组、同一转速，速度环下驱动器电流只有额定的几个百分点；力矩环给恒定指令电机却一路加速到超速保护。理解「谁决定扭矩」，才能解释电流读数、爬行、飞车，并正确使用空载台架做摩擦与惯量标定。

## 空载不等于零负载

输出法兰不接外载，但动力链（驱动器 → 无框力矩/伺服电机 → 谐波减速器 → 输出法兰，可带电机端与输出端双编码器）本身仍在「吃」扭矩：

- 摩擦：轴承、齿面、密封、润滑脂搅油，谐波内波发生器与柔轮的摩擦；
- 惯量：转子与减速器旋转件，加速时需扭矩推动；
- 齿槽转矩：永磁转子扫过定子齿槽的周期波动，与电流无关；
- 驱动器零漂：电流采样直流偏置，等效为「凭空出现」的电流指令。

这些内部负载量级小、规律性强，是观察两种模式差异最干净的工况。

## 前提：力矩环永远在闭环

伺服为位置环（外）→ 速度环（中）→ 电流/力矩环（内）三环级联，电流环在所有模式下都闭环工作。区别只在力矩给定来源：

```
速度模式：转速指令 → 速度PI → 电流(扭矩)给定 → 电流环 → 电机
力矩模式：外部扭矩/电流指令 ────────────────→ 电流环 → 电机
```

速度模式下扭矩是因变量；力矩模式下速度调节器被旁路，扭矩成自变量，转速反而无人管。电流环最快（典型 kHz 量级），速度环慢一级（几十到几百 Hz）。

## 速度环空载：扭矩是摩擦「要」出来的

**稳态**（dω/dt = 0）：

```
J·dω/dt = τ_m − τ_f(ω)，  τ_f(ω) = τ_c·sgn(ω) + B·ω
稳态： τ_m = τ_c·sgn(ω) + B·ω
```

输出扭矩恰好等于整条传动链摩擦，不由指令决定。作者称正常的中小规格谐波关节，该稳态空载扭矩通常只占额定扭矩的百分之几。

- 作者引用 SHF-20 谐波减速器实测研究：空载时柔轮弹性变形损失约占总能量损失 20%，满载升到约 50%——空载摩擦主要来自润滑与啮合。
- 空载稳态电流是摩擦健康度的「体检指标」：多个恒速点记录稳态电流 × Kt，正反向各测，得到 τ_f(ω) 曲线，截距 ≈ 库仑摩擦，斜率 ≈ 粘滞系数。
- 谐波厂商样本参照（Harmonic Drive CSF/CSG，作者转述）：「空载运行扭矩」指输出无载时驱动波发生器所需扭矩；速比 100、输入 2000 rpm 下约 0.5 N·cm（8 号机）到约 100 N·cm（100 号机），换速比需查补偿表，输入转速越高越大。额定扭矩下效率大致 50%～90% 以上，随速比、转速、负载、温度、润滑脂变化。
- **启动扭矩**（从静止转动输入端）普遍明显高于同机座运行扭矩，例如速比 50 组件型：14 号机约 3.3 N·cm、32 号机约 26 N·cm、65 号机约 120 N·cm。低速空载「带不动」未必是故障，可能是启动摩擦大于运行摩擦。

**加速段**：速度给定阶跃时 τ_m = J_eff·dω/dt + τ_c·sgn(ω) + B·ω。外部负载折算到电机端除以速比平方，空载只剩模组自身惯量。扭矩曲线呈「加速脉冲 + 贴摩擦线的平台」。

**扰动与纹波**：突加扰动时转速先跌、PI 加大扭矩拉回，输出扭矩自动适应；齿槽转矩等周期扰动大多被闭环与惯量滤掉，表现为微小速度纹波而非扭矩纹波；积分器消化温度引起的摩擦漂移。因此产线快速自检默认用速度环。

## 力矩环空载：扭矩是指令「压」下来的

力矩模式下 τ_m = Kt·iq，空载唯一能消化它的是模组自身惯量：

```
J_eff·dω/dt = τ_cmd − τ_c·sgn(ω) − B·ω
```

三种典型工况：

| 指令 | 现象 |
|------|------|
| τ_cmd 明显大于摩擦 | α = (τ_cmd − τ_f)/J，速度一路上涨，直到粘滞摩擦平衡或触发超速保护；B 通常很小，自然平衡转速高到不可接受 |
| τ_cmd ≈ 摩擦 | 理论可稳定，但摩擦随温度、转速漂移，平衡脆弱、不可复现 |
| τ_cmd < 启动摩擦 | 输出端不动（死区）；再小的指令易进入爬行（stick-slip）：静摩擦 > 动摩擦，叠加低速 Stribeck 负阻尼，在「粘住」与「滑动」间切换，产生低频振荡 |

**纹波直接透传**：速度环的「兜底」被拆掉，电机的每一分不完美直接落到输出扭矩：

- 齿槽转矩：与电流无关、随转子位置周期变化；工艺好的可压到额定扭矩百分之几，但在力矩环原样叠加，低速时明显；
- 电流零漂：采样直流偏置变成虚假扭矩指令，温度是主因，零指令时仍可能缓慢蠕动；
- Kt 非线性：大电流磁路饱和、永磁体随温度退磁（作者给钕铁硼磁通温度系数约 −0.1%/°C）、换相角误差，使「电流 × Kt」偏离真实值；速度环会自动多给电流吃掉误差，力矩环没有这层修正。

力控关节选型强调齿槽转矩、电流采样精度、Kt 线性度，本质是为「力矩模式裸奔」买单。

**零指令与安全边界**：零指令下摩擦反而帮忙把输出端「摁」住。要防的是非零指令：空载加速度只受惯量限制，反电动势超过母线电压后进入弱磁区、扭矩能力下降，多以过压或超速故障收场。作者称安川、三菱、Kollmorgen 等驱动器内置力矩模式专用限速功能；力矩环台架测试前先确认限速、限流、急停链路。

## 对比表

| 维度 | 速度环（空载） | 力矩环（空载） |
|------|----------------|----------------|
| 扭矩的身份 | 因变量，由摩擦与加速需求决定 | 自变量，= Kt × 电流指令 |
| 稳态表现 | 转速锁死，扭矩 ≈ 摩擦力矩 | 转速漂移：加速 / 脆弱平衡 / 死区 |
| 扰动响应 | 转速恢复，扭矩自动补偿 | 无自恢复，转速单向漂移 |
| 纹波传递 | 被闭环与惯量抑制 | 齿槽 / 零漂 / Kt 非线性直接透传 |
| 零指令 | 转速锁零，主动克服零漂 | 依靠摩擦保持，有微动风险 |
| 典型用途 | 连续运转、摩擦测量、走轨迹 | 力控、阻抗控制、惯量与摩擦辨识 |

两种模式下扭矩**数值**可以完全相同；差别在由谁决定、错了谁纠正：速度环靠反馈自我修正，力矩环把修正责任交给上层算法或外部传感器。

## 空载台架的三种用法

1. **速度环扫速测摩擦**：覆盖工作转速的若干恒速点（如 10%、30%、50%、80% 额定转速），正反向各记稳态电流，温度稳定后测；拟合库仑与粘滞系数，有条件补低速段观察 Stribeck 下落。曲线是摩擦补偿与出厂一致性的底账；某转速点电流突升，常意味着轴承或齿面异常。
2. **力矩环恒扭矩阶跃辨识惯量**：先设好限速保护，给小扭矩阶跃，用编码器记转速斜坡斜率：`J_eff = (τ_cmd − τ_f) / α`。结果用于速度环加速度前馈与观测器整定；变载关节（夹爪、换装）可用带遗忘因子的 RLS、模型参考自适应等做在线辨识。
3. **协作机器人**：力矩（或基于力矩的阻抗）模式是常态，输出扭矩精度取决于摩擦补偿模型，而模型参数来自空载测试；拖动示教要把重力矩与摩擦力矩补偿干净。更高精度的关节在输出端加装力矩传感器，绕开「电流估计扭矩」的误差链。

## 带走的三件事

- 空载电流是关节摩擦的体检报告，多速点扫一遍即得；
- 力矩环空载永远先设限速、再给指令；
- 齿槽、零漂、Kt 非线性这些「小误差」在力矩模式下会放大成「大问题」，选型与标定要多留心。

两种模式没有优劣只有分工：要稳、要快、要看健康度用速度环；要力、要柔顺、要做辨识用力矩环——前提是限速保护和摩擦模型已备好。
