# GAIT: Legged Robot Proprioceptive State Estimation with Attention over Inertial-Leg Tokens

> 来源归档（ingest · arXiv 原文）

- **标题：** GAIT: Legged Robot Proprioceptive State Estimation with Attention over Inertial-Leg Tokens
- **类型：** paper
- **arXiv：** <https://arxiv.org/abs/2606.14160>（PDF：<https://arxiv.org/pdf/2606.14160>，v1，2026-06-12）
- **作者：** Young-Rang Seo, Hajun Kim, Sangmin Kim, Dongyun Kang, Hae-Won Park（KAIST）
- **全文核对：** 2026-11-06 通读 PDF 正文（8 页，含方法、实验、结论与参考文献；无独立附录）
- **代码 / 数据：** 截至 2026-11-06，arXiv 摘要页与论文 PDF 未给出官方代码或数据链接
- **一句话说明：** 用 Inertial-Leg 分词 + Perceiver IO 交叉注意力输出机身线速度与不确定度，作为伪测量接入 IEKF；仅用仿真 trot 数据训练，在 Unitree Go1 实机的未见步态与未建模地形上优于 NMN 与接触辅助 IEKF。
