# Towards Human-Like Manipulation through RL-Augmented Teleoperation and Mixture-of-Dexterous-Experts VLA

- **类型：** 论文
- **作者：** Tutian Tang、Xingyu Ji、Wanli Xing、Ce Hao、Wenqiang Xu、Lin Shao、Cewu Lu、Qiaojun Yu、Jiangmiao Pang、Kaifeng Zhang
- **机构：** 北京中关村学院、上海交通大学、上海人工智能实验室、上海创智学院、新加坡国立大学、Sharpa
- **发布日期：** 2026-03-09（arXiv v1）
- **入库日期：** 2026-10-16
- **arXiv：** 2603.08122
- **论文：** <https://arxiv.org/abs/2603.08122>
- **项目页：** <https://sites.google.com/view/mode-vla/home>
- **一句话说明：** 用 RL 原子手内技能 IMCopilot 同时辅助双手遥操作采集与 VLA 执行，再用 MoDE-VLA 将手臂力觉和指尖触觉作为独立专家残差注入预训练策略。

## 论文摘录

1. **系统与平台：** 论文将双手灵巧操作的瓶颈归纳为示范采集、多技能分工和力 / 触觉融合。SharpaNorth 平台由两条 7 DoF 手臂、两只 22 DoF SharpaWave 灵巧手组成；固定下肢时有 63 个活动自由度，并记录双臂关节扭矩和十个指尖触觉传感器的 6 DoF 力 / 力矩。
2. **IMCopilot：** PPO 在 IsaacLab 中训练稳定抓持、绕指定轴手内旋转等原子技能，采用非对称 actor-critic 和 teacher–student 蒸馏。遥操作时由操作员控制大臂和手部动作，并通过脚踏板触发手内技能；自主执行时 VLA 也可调用它们作为低层原语。
3. **MoDE-VLA：** 在预训练 π₀ 主干外增加力觉 / 触觉独立路径。双臂关节扭矩共 14 维，十个指尖的 6 DoF 读数共 60 维；模态 token 与视觉、语言、本体及动作 token 交互，经稀疏专家路由后，分别给手臂和手部动作注入残差修正。
4. **评测：** Gear Assembling、Charger Plugging、Tube Rearranging、Apple Peeling 四项任务，每种方法每项 20 次试验。论文报告 MoDE-VLA 平均成功率 34%，较 π₀ 基线 15% 高 19 个百分点；苹果削皮成功率 30%、完成比例（PCR）73%。去掉力觉 / 触觉后平均成功率分别为 23% / 26%；去掉 IMCopilot 后苹果任务 PCR 从 73% 降到 25%。
5. **采集对照：** 稳定手内旋转总体成功率从纯遥操作 34%（31/90）提升到 IMCopilot 89%（80/90）。齿轮装配示范采集加入力 / 触觉反馈后，100 次试验耗时从 75 分钟降到 65 分钟，成功示范从 85 次增至 93 次。
